# 📗 ส่วนที่ 1: ระบบกลาง 6 ชนิด, สถานะใหม่, คอมโบข้ามวิถี 8 คู่, และกลไกอุปกรณ์ M1–M15 จากเอกสารที่ 3 (Claude)

## ส่วนที่ 3 — ระบบกลางและสถานะใหม่ที่หลายวิถีใช้ร่วมกัน

หัวใจของข้อเสนอคือ สร้างระบบกลาง 5–6 ชิ้นครั้งเดียว แล้วให้หลายวิถีใช้ร่วม แทนที่จะสร้างกลไกพิเศษแยกต่อวิถี


### 3.1 ตัวจับเวลาซ่อน (Delayed Fuse)

สถานะที่ซ่อนอยู่และ “ระเบิด” เมื่อครบเวลาหรือเข้าเงื่อนไข ใช้โดย: ฟักตัว (PESTILENCE), เสียงสะท้อน (MEMORY), บูดเน่าและรอยร้าวโครงสร้าง (RUST/ARCHITECT) เกมมีสถานะต่อเนื่องอยู่แล้ว ส่วนใหม่คือ “ตั้งเวลาล่วงหน้า + มองไม่เห็นจนถึงเวลา + เงื่อนไขยกเลิก” เพียงหนึ่งชั้น API


### 3.2 เกจสองขั้ว (Dual-Pole Gauge)

เกจที่มีสองด้านและสถานะกลาง ใช้โดย DRUNKEN_TEA (เมา–สงบ) และสายหยินหยางของ XIAN/CHAOS ที่มีอยู่แล้วสามารถย้ายไปใช้ได้ กำหนดผลที่ 0, ช่วงกลาง และ 100 ต่างกัน ผู้เล่นเลือกอยู่ปลายใดปลายหนึ่งหรือเลี้ยงสมดุล


### 3.3 ชั้นภาพลักษณ์ (Perception Layer)

แยก “ตัวตนจริง” กับ “ตัวตนที่ผู้อื่นเห็น” ใช้โดย MASK_OPERA, FOLKLORE_RUMOR, SHADOW_INTELLIGENCE_MARSHAL ที่มีอยู่ และนินจาเร้นกาย ผลสำคัญคือ การกระทำถูกบันทึกในพงศาวดารตามภาพลักษณ์ที่ใช้ขณะนั้น ซึ่งเปิดโปงได้


### 3.4 กราฟการแพร่กระจาย (Propagation Graph)

ระบบเดียวที่ปล่อย “สิ่งหนึ่ง” ไปตามเส้นสัมพันธ์ของ NPC และเส้นทางคาราวาน ด้วยความน่าจะเป็นต่อเส้นและการกลายพันธุ์ ใช้ได้กับ โรค (PESTILENCE), ข่าวลือ (FOLKLORE), ความจำเท็จ (MEMORY) นี่คือชิ้นที่คุ้มที่สุดเพราะเสียค่าสร้างครั้งเดียวได้สามวิถี


### 3.5 ร่องรอยถาวรบนโลก (Persistent World Marks)

สิ่งที่วางบนโหนด/เส้นทางแผนที่แล้วคงอยู่ มีเจ้าของ ความทนทาน และถูกยึด/ทำลายได้ ใช้โดย ARCHITECT (สะพาน ถนน หอสัญญาณ), ROADSIDE_SHRINE_PILGRIM (ศาล), RUST_DECAY (ผิวปาทีนา/สนิมบนสิ่งก่อสร้าง), LIGHTHOUSE_FOG_PILOT (ประภาคาร)


### 3.6 ตัวคูณจากความสัมพันธ์ (Relationship-Scaled Modifier)

อ่านค่าความสัมพันธ์จริงแล้วแปลงเป็นตัวคูณการรบ โดยมีเพดาน ใช้โดย BOND_COMPANION และบางส่วนของ FOLKLORE สิ่งสำคัญคือกำหนดเพดานและเงื่อนไขห้ามใช้ซ้ำเพื่อกันการ “ปั๊มความสัมพันธ์” เกินจริง


### 3.7 สถานะใหม่ที่เสนอรวม

ข้อเสนอทั้งหมดแนะนำสถานะใหม่ประมาณ 30 ชื่อ หลายตัวเป็นรูปแบบเดียวกัน จึงทำเป็นชุดเทมเพลตได้ เช่น สะสมเป็นชั้น (ผุกร่อน, ตราสี), ตั้งเวลาซ่อน (ฟักตัว, เสียงสะท้อน), ตำแหน่งแพร่ (ตำนานบิดเบือน, ความจำเท็จ), ผูกพันธะ (ผูกใจ, ใจสลาย) ควรตกลงเทมเพลตกับทีมก่อนลงมือเขียนสถานะรายตัว




## ส่วนที่ 5 — คอมโบข้ามวิถีที่น่าสนใจ

เกมมีระบบการประสานวิชาข้ามวิถีอยู่แล้ว วิถีใหม่ออกแบบให้เกิดคอมโบที่ผู้เล่นค้นพบเอง:

- PESTILENCE + ARCHITECT — เขตกักกันที่สร้างขึ้นจริงในสนามหรือสำนัก (กำแพง ประตู) ตัดการแพร่ได้ด้วยโครงสร้างจริง ไม่ใช่เอฟเฟกต์ลอยตัว
- MASK + FOLKLORE — วีรกรรมที่ทำภายใต้หน้ากากสร้างตำนานของ “ผู้สวมหน้ากากปริศนา” ที่ NPC เล่าลือ ผู้เล่นเลือกได้ว่าจะเปิดเผยตัวตนเมื่อใดเพื่อรับชื่อเสียง
- MEMORY + BOND — ลบความทรงจำเจ็บปวดของคู่พันธะที่ใจสลาย แต่แลกกับการลบเสี้ยวของพันธะนั้นไปด้วย เป็นทางเลือกที่มีราคา
- RUST + MECH_PUPPET — คู่ปรับตรงข้าม ผู้เล่นหุ่นต้องเตรียมวัสดุเคลือบกันสนิมหรือสายช่างซ่อมกลางศึก
- PRISM + CELESTIAL_WEATHER — แสงแรงสุดตอนเที่ยงวันฟ้าโปร่ง ลดลงในเมฆครึ้ม ผู้เล่นสองวิถีวางแผนตามเวลาและอากาศร่วมกัน
- DRUNKEN_TEA + MERCANTILE — ถังสุราบ่อเก่าเป็นสินทรัพย์ที่ใช้เป็นหลักประกันตามสัญญาการค้า (ใช้กับระบบสัญญาที่มีสถานะ OFFERED/ACTIVE/SETTLED/BREACHED)
- BOND + ANCESTRAL_RITUAL — พันธะสายอาจารย์–ศิษย์ผูกกับป้ายวิญญาณและสายตระกูลของสำนัก ศิษย์รุ่นหลังได้บัฟจากบรรพชนที่เคยผูกพันกับสายเดียวกัน
- ARCHITECT + WANDERING (ศาลรายทาง) — เครือข่ายสะพาน ถนน และศาล ทำให้เส้นทางหลักของสำนักเร็วและปลอดภัย กลายเป็นเป้าหมายของสำนักคู่แข่งที่ต้องการตัดเส้นทาง

## ส่วนที่ 6 — ลำดับการทำและความเสี่ยง


### 6.1 ลำดับที่แนะนำ

ระยะแรก (ใช้ระบบเดิมเป็นหลัก)

- DRUNKEN_TEA_DAO — เกือบทั้งหมดต่อกับอาหาร/ตำรับ/ตลาดที่มี
- RUST_DECAY — ต่อกับระบบสึกหรอ/ซ่อมที่มี
- BOND_COMPANION (ส่วนในศึกก่อน) — ใช้ค่าความสัมพันธ์ที่มี
- สายย่อยเดิมที่เบา: BATTLE_SCAR_ARCHIVE, TRIBULATION_WALKER_IMMORTAL, CENSOR_INSPECTOR_AUDITOR, UNDERDOG_REDEEMER
ระยะที่สอง (ต้องเพิ่มระบบกลาง 1–2 ชิ้น)

- MASK_OPERA (Perception Layer)
- PRISM_LIGHT (ปฏิกิริยาแสงรวมและสี)
- ARCHITECT_FORTIFIER ส่วนในศึก ก่อนส่วนบนแผนที่โลก
- ตระกูลอาวุธ โล่, โซ่ตะขอ, ค้อน
ระยะที่สาม (กระทบ sim ทั้งระบบ)

- กราฟการแพร่กระจาย → PESTILENCE_REMEDY, FOLKLORE_RUMOR
- MEMORY_OBLIVION (ต้องเข้าระบบ cognition)
- ร่องรอยถาวรบนโลก → ARCHITECT ส่วนโลก, ROADSIDE_SHRINE_PILGRIM

### 6.2 ความเสี่ยงที่ควรหารือกับทีม

- ความหนาแน่นของเนื้อหา: เกมมี 286 สายย่อยแล้วและรายงานตรวจระบุปัญหาความหนาแน่นของวิชา อาวุธ และสายโซ่วัตถุดิบ แนะนำให้วิถีใหม่ทุกวิถีผ่านเกณฑ์ “มีวัตถุดิบ แหล่งหา ตำรับ และผู้ใช้ครบสายโซ่” ก่อนเพิ่มจำนวน
- Save schema: ตัวจับเวลาซ่อน สถานะแพร่ และร่องรอยถาวรเพิ่มข้อมูลที่ต้องเก็บ ต้องวางแผน migration จาก schema 2.3.0
- AI ของ NPC/สำนักคู่แข่ง: AI ต้องรู้วิธีรับมือโรค ข่าวลือ สนิม และหน้ากาก ไม่เช่นนั้นผู้เล่นจะได้เปรียบเกินจริง ควรกำหนดเกณฑ์ “ฝ่ายตรงข้ามตอบโต้ได้” ทุกวิถี
- ภาระ UI: วิถีใหม่ 9 วิถีเพิ่มเกจใหม่ 9 แบบ ควรเลือกใช้เกจที่แสดงผลได้ด้วยแถบ/จุดสไตล์เดิมให้มากที่สุด
- เนื้อหาที่ละเอียดอ่อน: MEMORY_OBLIVION (แทรกแซงความทรงจำของเชลยหรือ NPC) และ DRUNKEN_TEA (ติดสุรา) ควรมีต้นทุนทางสังคมและผลข้างเคียงที่ชัดเจนเพื่อไม่ให้เป็นทางลัดแบบไร้ราคา
- ความซ้ำซ้อน: FOLKLORE_RUMOR เฉียดกับ ARENA_GLORY และ INK_LITERATI (สายอาลักษณ์จารึกพงศาวดาร) ส่วน ARCHITECT เฉียดกับ ARRAY_TALISMAN และ DRAGON_VEIN_GEOMANCY ต้องยืนยันขอบเขตให้ชัดตั้งแต่ต้น

### 6.3 คำถามเปิดสำหรับทีมงาน

- ทีมอยากเพิ่ม “วิถีใหม่” เพื่อความหลากหลาย หรืออยาก “เติมสายย่อยลึก” ให้วิถีเดิมก่อน (ส่วนที่ 2 ทำให้เร็วกว่า)
- ระบบแพร่กระจายและชั้นภาพลักษณ์เป็นการลงทุนระบบใหญ่ ทีมพร้อมให้เป็นแกนของรุ่นถัดไปหรือไม่
- ต้องการให้วิถีใหม่ใช้ได้กับ NPC ทุกคน หรือเปิดเฉพาะผู้เล่น/ตัวละครสำคัญก่อน
- ชื่อ ID และชื่อไทยที่เสนอ ต้องตรวจซ้ำกับทะเบียนวิชา ไอเทม และสถานะเดิม ใครเป็นผู้ตรวจ
- มีวิถีใดที่ทีมอยากให้ผมขยายเป็นสเปกละเอียด (รายชื่อวิชา ขั้น ตัวเลขตั้งต้น) ต่อ
เอกสารนี้เป็นแนวคิดระดับกลไก ไม่รวมตัวเลขสมดุล รายชื่อวิชารายท่า หรือค่าสถานะรายตัว ซึ่งควรกำหนดหลังตกลงขอบเขตกับทีมงาน


## ส่วนที่ 7 — คลังแนวคิดอุปกรณ์ (ระดับ 1 สามัญ → ระดับ 5 ตำนาน)

ส่วนนี้เป็นคลังข้อมูลที่ต่อเติมได้ ไล่ตั้งแต่ของเรียบง่ายที่มีแค่หนึ่งสถานะ ไปจนถึงอุปกรณ์ตำนานที่มีหลายสถานะ หลายกลไก และผูกกับโลก ใช้ช่องสวมใส่ที่เกมมีอยู่ (อาวุธ เกราะ เครื่องประดับ) และบางรายการเสนอ “เครื่องมืออาชีพ” เป็นหมวดเสริม ชื่อสถานะที่ระบุว่า (ใหม่) คือที่เสนอเพิ่ม ส่วนสถานะเดิมของเกม (เผาไหม้ เลือดออก พิษ สโลว์ สตัน ใบ้ อ่อนแอ ตาบอด ลดเกราะ) ใช้ชื่อเดิม ค่าตัวเลขในเอกสารเป็นตัวอย่างเพื่อสื่อแนวคิด ไม่ใช่ค่าสมดุล

ระดับความซับซ้อน

- ระดับ 1 สามัญ: หนึ่งเอฟเฟกต์หรือหนึ่งสถานะ ไม่มีเงื่อนไขซ้อน
- ระดับ 2 ชำนาญ: หนึ่งกลไกที่มีเงื่อนไขหรือสถานะภายในตัว
- ระดับ 3 หายาก: สองกลไกที่เสริมกัน พร้อมข้อแลกเปลี่ยนที่ชัดเจน
- ระดับ 4 มรดก: กลไกที่เติบโตหรือวิวัฒน์ตามการใช้งาน มี 3 ขั้น
- ระดับ 5 ตำนาน: หลายสถานะ หลายกลไก ปลุกเป็นขั้น ผูกกับเหตุการณ์โลก พงศาวดาร และสำนัก

### 7.1 กลไกอุปกรณ์ใหม่ที่ใช้ร่วมกันได้ (15 ชนิด)

รายการอุปกรณ์ด้านล่างอ้างรหัสกลไกเหล่านี้ เพื่อให้ทีมสร้างกลไกครั้งเดียวแล้วนำไปใช้ซ้ำ

- M1 ประจุสะสม (Charge Cells) — อุปกรณ์เก็บประจุจากเหตุการณ์ (ถูกตี ป้องกันสำเร็จ สังหาร) แล้วใช้ประจุปล่อยเอฟเฟกต์
- M2 สมุดจารึกวีรกรรม (Deed Ledger) — บันทึกการกระทำของอุปกรณ์เอง ปลดล็อกขั้นตามจำนวนและชนิด เชื่อมพงศาวดาร
- M3 สลับท่วงท่า (Stance Toggle) — สองโหมดที่ต่างกัน การสลับเสียจังหวะ
- M4 สั่นพ้องคู่ (Paired Resonance) — สองชิ้นเป็นคู่ ได้ผลเมื่ออยู่ใกล้กันหรือเจ้าของมีพันธะต่อกัน
- M5 นิสัยอุปกรณ์ (Item Temperament) — อุปกรณ์มีนิสัย (หวงแหน ใจกล้า ขี้ระแวง) เทียบกับบุคลิกเจ้าของใน Human Core เข้ากันได้โบนัส ขัดกันถูก “งอน”
- M6 สัญญาผนึก (Sealed Pact) — ได้พรตราบที่ทำตามข้อห้าม หากผิดข้อสัญญาเกิดผลสะท้อน
- M7 ปรับตามสภาพโลก (Environmental Tuning) — พลังแปรตามเวลา อากาศ ภูมิภาค
- M8 เครื่องราชอำนาจ (Regalia) — ผูกกับหนึ่งใน 25 ตำแหน่งของสำนัก ใช้ได้เมื่อดำรงตำแหน่ง

# 6. กลไกแกนกลางที่ควรพัฒนาร่วม 20 รายการ

1. การบันทึกรอยจำเชิงเหตุการณ์ (`M01`) — เมื่อเกิดเหตุการณ์สำคัญบันทึกประเภท เวลา เจ้าของ และรหัสเหตุการณ์เพื่อให้ NPC เรียนจากประสบการณ์ เชื่อมระบบ: NPC memory, chronicle, AI เกณฑ์กันบัค/กันวงจร: หนึ่งเหตุการณ์สำคัญสร้างผลรางวัลได้ครั้งเดียว; บันทึกแบบย่อและจำกัดขนาด

2. คำสัตย์ผูกเงื่อนไข (`M02`) — NPC เลือก pledge แบบมีเป้าหมายจริง งาน/ระยะ/ค่าเสียโอกาส เมื่อสำเร็จได้ Resolve เชื่อมระบบ: AI goals, diplomacy, sect duties เกณฑ์กันบัค/กันวงจร: ห้ามสาบานสิ่งที่สำเร็จอยู่แล้ว และแก้กรณียกเลิก/ตาย/เปลี่ยนตำแหน่ง

3. เครือข่ายฝันร่วมแบบย่อ (`M03`) — รวมผลพักของ NPC ที่มีสัมพันธ์กันเป็นโบนัสวันถัดไป ไม่จำลอง combat โลกฝันแยก เชื่อมระบบ: AI sleep, relationship, training เกณฑ์กันบัค/กันวงจร: คำนวณวันละครั้งต่อกลุ่ม; จำกัดจำนวนคู่ ไม่ทวีคูณ NPC²

4. ดุลเส้นใยสำนัก (`M04`) — ชีวมวลใช้แล้ว → กากหมัก → ดินบำรุง ผ่านเวลาผลิตและสูญเสียคงที่ เชื่อมระบบ: economy, farming, crafting เกณฑ์กันบัค/กันวงจร: mass conservation; แยกมลพิษ/ปุ๋ยและกำหนด consumer

5. บัญชีแลกเปลี่ยนความร้อน (`M05`) — ให้เกจ heat/cold สะสมที่ตัวละคร; ใช้ effect คู่ตรงข้ามจึงเกิดปฏิกิริยา เชื่อมระบบ: combat, weather, equipment เกณฑ์กันบัค/กันวงจร: ไม่ใช้พลังจากความว่างและ cap เกจ; ป้องกัน loop heat↔cold

6. ตราขั้วตามวัสดุ (`M06`) — effect ทำงานเต็มเฉพาะ equipment/material tag ที่นำแม่เหล็ก เชื่อมระบบ: weapon, combat, monsters เกณฑ์กันบัค/กันวงจร: boss CC budget และไม่ปลดอาวุธจาก inventory

7. การสะท้อนแบบขอบเขต (`M07`) — ลำแสงมี hops 0–2, damage falloff, LoS check ทุกครั้ง เชื่อมระบบ: combat, array, prism gear เกณฑ์กันบัค/กันวงจร: ห้ามเกิด reflection recursive; อาวุธที่ไม่ใช่ ray ไม่ถูกเปลี่ยน

8. เบาะแสกลิ่นเสื่อมเวลา (`M08`) — กำหนด freshness ที่โหนด ไม่ผูกข้อมูลทุก NPC ตลอดโลก เชื่อมระบบ: expedition, beasts, world map เกณฑ์กันบัค/กันวงจร: ไม่เผยตัวตนแน่นอน; จัดเก็บไม่เกิน N ร่องรอยต่อโหนด

9. เรียนจากบาดเจ็บหลังฟื้น (`M09`) — scarInsight เพิ่มเมื่อบาดเจ็บในเหตุการณ์ต่างกันและรักษาจนหาย เชื่อมระบบ: health, medicine, mentorship เกณฑ์กันบัค/กันวงจร: ไม่ให้คะแนนจากการทำร้ายตนเอง/การเจ็บซ้ำชนิดเดิม

10. วัฏจักรภัยพิบัติ (`M10`) — คาดการณ์→จัดเสบียง→รับภัย→ฟื้นฟู แล้วบันทึกความเสียหายจริง เชื่อมระบบ: weather, expedition, economy, chronicle เกณฑ์กันบัค/กันวงจร: ห้ามเกิดภัยพิบัติใหม่เพียงเพราะเพิ่ม path; ต้องมี fallback event

11. จังหวะก้าว 3 ท่า (`M11`) — สะสม cadence เมื่อย้ายระยะถูกเงื่อนไขและเชื่อมท่าที่ 2–3 เชื่อมระบบ: 5-range combat, AI, weapon tactics เกณฑ์กันบัค/กันวงจร: ไม่ฟาร์มจากเดินไปกลับ; ขั้นตอนถูก interruption ต้อง reset

12. บัญชีกากและ provenance (`M12`) — บันทึก receipt ของผลพลอยได้และการคืนรูป; กัน loop ไอเทมเดิม เชื่อมระบบ: economy, recipes, inventory เกณฑ์กันบัค/กันวงจร: ห้าม output มากกว่ามูลค่าวัสดุ input หลังหักค่าแรงและค่าขนส่ง

13. พยาน/ข่าวลือหลายความเชื่อมั่น (`M13`) — ข้อมูลจากความทรงจำหรือฝันใช้ confidence 0–1 แยก verified/unverified เชื่อมระบบ: cognition, diplomacy, explore เกณฑ์กันบัค/กันวงจร: ข่าวลือห้ามแปลงเป็น fact โดยไม่มี event ยืนยัน

14. คุณภาพวัตถุดิบมีอายุ (`M14`) — เครื่องหอม เห็ด สารสกัด มี shelf-life แบบ batch compact เชื่อมระบบ: stock, market, alchemy เกณฑ์กันบัค/กันวงจร: ใช้ batch bucket ไม่เก็บ timestamp ต่อหน่วย

15. ความทนระดับชิ้นส่วน (`M15`) — อุปกรณ์สะท้อน/แม่เหล็ก/ไอน้ำต้องมี charge/durability ไม่ได้บัฟฟรี เชื่อมระบบ: equipment, repair, crafting เกณฑ์กันบัค/กันวงจร: ซ่อมกินวัสดุ; ห้าม repair item ระดับสูงด้วยกากต่ำไม่จำกัด

16. การจัดสำรองค่าย (`M16`) — ใช้สต็อกสำรองและเสบียงจริงแลกผลป้องกันภัยครั้งต่อไป เชื่อมระบบ: sect governance, inventory เกณฑ์กันบัค/กันวงจร: ไม่สำรองติดลบ; คืนของเมื่อยกเลิกตามรายการ

17. การเลือกวิถีของ NPC แบบมีเหตุผล (`M17`) — คะแนนจากความสนใจ/ค่านิยม/ความถนัด/วัสดุ/โอกาสฝึกในสำนัก เชื่อมระบบ: AI, cognition, training เกณฑ์กันบัค/กันวงจร: ฟังก์ชันประเมินอ่านอย่างเดียว ไม่มี RNG ใช้แล้วเปลี่ยนโลก

18. ความเสี่ยง/แก้ทางประกอบกัน (`M18`) — สถานะใหม่ทุกตัวระบุ trigger, duration, stack, dispel, immunity, boss cap เชื่อมระบบ: combat, status registry, UI เกณฑ์กันบัค/กันวงจร: stack หลัง cleanse และ save/load ต้องคงความหมายเดียวกัน

19. การแบ่งรางวัลเชื่อมเวลา (`M19`) — คราฟต์/สำรวจ/รักษาได้ exp จากผลสำเร็จจริง ไม่ใช่จากการเริ่มงานซ้ำ เชื่อมระบบ: progression, economy, EXP เกณฑ์กันบัค/กันวงจร: receipt idempotent, abort ไม่ได้รางวัล, rollback คืน input แบบมีสถานะ

20. สมดุลพลังข้ามวิถี (`M20`) — ใช้ equivalent stage, role power envelope, cooldown budget และแหล่งต้นทุนของทุกพลัง เชื่อมระบบ: CULT, combat, AI เกณฑ์กันบัค/กันวงจร: วิถี 4/5/8/9 ขั้นเทียบตามอำนาจ ไม่ใช้ stage เลขดิบ




# 12. ตัวอย่างปฏิสัมพันธ์ข้ามวิถี — 12 คู่

- ความจำ + อาลักษณ์ (MEMORY_ECHO × LORE_ARCHIVIST): จดจำเหตุการณ์เป็นเบาะแส แล้วให้อาลักษณ์ตรวจโครงสร้างตำรา/หลักฐาน / การควบคุมสมดุล: ถ้าข้อมูลยังไม่ยืนยันไม่เปิดรางวัลหรือวิชาให้ใช้
- สัตย์ + การปกครอง (VOWBOUND_HEART × STRATEGY_GOVERNANCE): นายกองมีคำมั่นคุ้มกันแนวหลัง เพิ่มความมั่นใจในการป้องกัน / การควบคุมสมดุล: การละเมิดหน้าที่ลดความเชื่อถือจริง
- ฝัน + หมอ (DREAM_COMMONWEAL × SAGE_SUPPORT): พักร่วมและดูแลเครียดหลังภัย เพิ่มประสิทธิภาพการฟื้นตัว / การควบคุมสมดุล: ยาต้องใช้จริงและ AI ต้องนอน
- ใยเห็ด + เกษตร (MYCELIAL_CYCLE × SPIRIT_HUSBANDRY): แปลงกากชีวภาพเป็นปุ๋ยให้สวนสมุนไพร / การควบคุมสมดุล: ต้องรักษา mass balance ไม่คูณผลผลิตไร้จบ
- ดุลร้อนเย็น + ช่างหลอม (THERMAL_BALANCE × CRAFT_CREATION): คงอุณหภูมิเตาลดอัตราของเสียจากงานคราฟต์ / การควบคุมสมดุล: แยกโบนัสคุณภาพจากโบนัสเพิ่มจำนวน output
- แม่เหล็ก + กลจักร (FERRO_POLARITY_DAO × MECH_PUPPET): ตราขั้วช่วยเล็งโพรเจกไทล์โลหะของหุ่น / การควบคุมสมดุล: ไม่ปลดอาวุธศัตรู; ใช้ความร้อนแกนจริง
- ปริซึม + ค่ายกล (PRISM_OPTICS × ARRAY_TALISMAN): กระจกวางเป็นโหนดย่อยให้วิชาลำแสงเลี้ยวได้ / การควบคุมสมดุล: สะท้อนสูงสุด 2 จุดและลดดาเมจทุกครั้ง
- กลิ่น + ราชันอสูร (SCENT_TRACE × BEAST_SOVEREIGN): สัตว์คู่สัญญาดมตามรอยเป้าหมายทำให้ตามล่าง่ายขึ้น / การควบคุมสมดุล: ลมฝนและรอยลวงยังหลอกได้
- รอยแผล + พุทธธรรม (SCAR_TEMPERING × BUDDHA_DHARMA): การรักษาหลังศึกเปลี่ยนเป็นความเข้าใจเมตตา ไม่เพิ่มพลังจากการบาดเจ็บใหม่โดยตั้งใจ / การควบคุมสมดุล: รอยแผลเรื้อรังเป็นความเสียหาย ไม่ใช่บัฟ
- กู้ภัย + ยุทธศาสตร์ (DISASTER_RELIEF × STRATEGY_GOVERNANCE): แบ่งคลังสำรองและส่งคณะช่วยภัยไปยังโหนดสำคัญ / การควบคุมสมดุล: การช่วยเหลือมีโอกาสขัดแย้งกับหน้าที่สำนัก
- ระบำก้าว + เสียง (DANCE_FOOTWORK × SONIC_HARMONY): คอร์ดช่วยตั้งจังหวะให้คอมโบสามก้าวสำเร็จง่ายขึ้น / การควบคุมสมดุล: บัฟความเร็วมีเพดานและถูกใบ้/ตรึงแก้ทาง
- คืนรูป + พาณิชย์ (RECLAMATION_DAO × MERCANTILE_DAO): ระบุของเหลือที่ควรซ่อม/ขาย ลดความสูญเสียในคลัง / การควบคุมสมดุล: ราคาขายสุทธิต้องไม่เกินต้นทุนเก็บและแปรรูปวนซ้ำ

# 13. เส้นทางผลกระทบลูกโซ่: ตั้งแต่ไอเดียจนถึงผลของโลก


## ก. ฝันร่วมทำให้ศิษย์ฝึกเร็ว

สายโซ่: ความสัมพันธ์ NPC → การพักจริง → ฝันร่วม → ความเครียดลด → ความสำเร็จฝึกดีขึ้น → ฝึกเสร็จไว → ความต้องการโอสถ/ห้องพัก/งานครูลด → งบสำนักเหลือ → สำนักเติบโตเร็วขึ้น

จุดตัดเพื่อไม่พังสมดุล: cap โบนัสต่อคืน, ต้นทุนที่พักและอาหาร, ห้ามซ้อนกับยากระตุ้นนอน และวัดการเติบโตเฉลี่ย 100–1,000 วัน


## ข. คืนรูปกากโลหะกระทบเงินเฟ้อ

สายโซ่: คราฟต์ → ของเสีย → คืนรูป → วัตถุดิบเพิ่ม → ต้นทุนศาสตราลด → NPC ผลิตมาก → ตลาดมีของล้น → ราคาลด → รายได้เหมืองลด → งาน NPC เปลี่ยน

จุดตัดเพื่อไม่พังสมดุล: ต้นทุนพลังงาน/เวลา, loss ratio, sink ของวัสดุ, ป้องกันการวนขาย–ซื้อ–ย่อยกำไร


## ค. ตราขั้วแม่เหล็กกระทบเมตาการรบ

สายโซ่: ศาสตราแม่เหล็ก → ลูกศร/เข็มโลหะเบี่ยง → AI เลือกไม้/หมัดมากขึ้น → คุณค่าคราฟต์เปลี่ยน → ตลาดแร่แม่เหล็กแพงขึ้น → สำรวจเหมืองถี่ขึ้น → การแย่งทรัพยากร

จุดตัดเพื่อไม่พังสมดุล: ประสิทธิภาพตาม material tag ไม่ใช่ hard-counter 100%, มีเครื่องป้องกันราคาถูกและ boss attenuation


## ง. การกู้ภัยเปลี่ยนการเมือง

สายโซ่: ภัยพิบัติที่โหนด → สำนักส่งคณะช่วย → ใช้ยาและเสบียง → ผู้คนรอด/สูญเสียลด → ชื่อเสียงและความสัมพันธ์กับสำนักอื่นเปลี่ยน → ข่าวเข้าสู่พงศาวดาร → NPC มีเป้าหมายใหม่

จุดตัดเพื่อไม่พังสมดุล: ไม่ให้ค่าชื่อเสียงจากภารกิจที่ไม่มีการเสียของจริง/ไม่เกิดภัย; ห้ามกู้ node เดิมซ้ำโดยไม่เกิด event ใหม่


## จ. ความจำทำให้ NPC ฉลาดขึ้นหรือยึดติด

สายโซ่: ผลศึก/ถูกทรยศ → event memory → การเลือกวิถี/ครู/ความสัมพันธ์ → การออกสำรวจและต่อสู้เปลี่ยน → ความขัดแย้งระหว่างสำนัก → ผลเศรษฐกิจและการสืบทอด

จุดตัดเพื่อไม่พังสมดุล: ความจำมี confidence และ expiry; ห้ามให้ความรู้ทุกเหตุการณ์ omniscient, AI reason เป็นภาษาไทยอ่านได้


## ฉ. ยาสมานแผลลดความตายแต่เพิ่มภาระระบบสุขภาพ

สายโซ่: ได้รับบาดเจ็บ → ยาคราฟต์และเวลารักษา → แผลเป็นที่หาย → ฝึกต่อได้ → ประสิทธิภาพสำนักสูงขึ้น → บริโภคโสม/ไหมมากขึ้น → การเพาะเลี้ยงและราคาตลาดเปลี่ยน

จุดตัดเพื่อไม่พังสมดุล: แผลเป็นให้ bonus เล็ก, ห้ามสร้างผลตอบแทนจากตั้งใจบาดเจ็บ และกำหนดไม่ตาย/ตายอย่างชัดเจน

| MECH-04 | ประจุกันเบิกซ้ำ (Escrow Charge) | จอง charge และ input items ระหว่างเริ่มงานและ settle แบบธุรกรรมเดียว | job id และ stock จริง | การผลิต/เศรษฐกิจ | rollback อย่างชัดเจนและป้องกัน duplication |

| MECH-11 | รักษาแล้วเหลือหนี้ (Overheal Reserve) | ส่วนรักษาเกินเปลี่ยนเป็นโล่เล็กภายใต้เพดาน แทนเพิ่ม HP เหนือ max | heal event + capped source | โอสถ/อุปกรณ์ | กัน double conversion เมื่อ DoT/HoT ทำงาน |

| MECH-13 | งานข้ามวันมีใบเสร็จ (Long-job Receipt) | งานผลิต/ปรับปรุงที่มี stage, reserved inputs และ partial failure | recipe id + progress + receipt | คราฟต์/เซฟ | โหลดระหว่างรอบต้องไม่จ่ายของซ้ำ |
| MECH-14 | ชื่อเสียงจากการช่วยจริง (Rescue Attribution) | อุปกรณ์กู้ภัยให้ชื่อเสียงจากจำนวนรอดและทรัพยากรเสียจริง | crisis event + beneficiary id | การเมือง/โลก | กันกู้ภัยสมมติและช่วยคนเดิมซ้ำไร้เหตุ |
| MECH-15 | สมบัติใช้แล้วล้า (Relic Cooldown On UID) | ใช้พลังระดับตำนานแล้วความล้าติด UID ไม่ติดแค่ผู้ใช้ | gear UID + current day | สมบัติ/ตลาด | ขาย/ย้าย/อัปเกรดไม่รีเซ็ต |
| MECH-16 | ระบบจุดสวมใส่แบบ tag (Slot Tags) | ความเป็นรองเท้า แหวน กระเป๋า คทา หรือโรงงานกำหนดข้อจำกัดพร้อมคำอธิบาย UI | slot + class + family | สวมใส่/AI | ต้องสร้าง slot ใหม่เมื่อจำเป็นจริงหรือถือเป็น active item |
| MECH-17 | คำสัตย์มีต้นทุนจริง (Oath Bound Gear) | คำสัตย์มีผู้รับประโยชน์ เวลาเริ่ม/จบ และเงื่อนไขผิดชัดเจน | vow id and verified events | สังคม/ศึก | ไม่มีคำสัตย์จากการกดเมนูซ้ำ |
| MECH-18 | สายใยคู่หนึ่งเดียว (Unique Tether) | หุ่น/อสูรกับผู้ใช้ผูกหนึ่งเส้นกับ owner ref ไม่แชร์หลายเจ้าพร้อมกัน | ownerId + beastId or puppetId | สัตว์/หุ่น/เซฟ | cleanup NPC ตาย ย้ายสำนัก หรือสัญญายกเลิก |
| MECH-19 | แพทเทิร์นสองจังหวะ (Paired Beat) | ได้เอฟเฟกต์ต่อเมื่อท่าสองชนิดเกิดตามลำดับ ไม่ใช่เพียงมี stat สูง | lastActionId + expiresAt | วิชา/เสียง/คอมโบ | ควบคุมคูลดาวน์รวมและ no-proc on echoes |
| MECH-20 | แนวรับครั้งเดียว (One-hit Intercept) | แบ่งดาเมจก่อน proc สะท้อนและดูดเลือดครั้งเดียว | damage packet id | แทงก์/ค่ายกล | ห้ามวนแบ่งรับเป็นกราฟวงกลม |
| MECH-21 | เส้นทางปลอดภัยตามความรู้ (Known Safe Path) | เลี่ยงได้เฉพาะกับดักที่เคยตรวจพบหรือมีเบาะแสเข้าถึง | fog-of-war + trap record | สำรวจ/AI | ไม่เปิดแผนที่/ของลับทั้งหมด |
| MECH-22 | ชำระสมบัติตามฤดู (Seasonal Attunement) | ยกระดับสมบัติเมื่อเควสต์ฤดูจริงจบ; stage 0–3 บันทึกที่ UID | world event & season | สมบัติ/พงศาวดาร | เปลี่ยนฤดูวนไม่ให้โบนัสซ้ำ |
| MECH-23 | ชุดอุปกรณ์เป็นคำถาม (Set Choice) | ใส่ครบชุดเปิดตัวเลือกกลยุทธ์หนึ่งอย่าง ไม่ทับชั้นโบนัส stat ทั้งหมด | unique tag set count | คอมโบ/AI | ห้ามนับไอเทม UID เดียวสองช่อง |
| MECH-24 | ฝันเป็นเบาะแสไม่ใช่ข้อมูลจริง (Dream Signal) | ข้อมูลในฝันเพิ่ม lead confidence เท่านั้น ต้องส่งคนสำรวจยืนยัน | sleep group + clue id | NPC/สำรวจ | ไม่มี omniscience จาก UI หรือ AI |
| MECH-25 | พื้นที่มีมลภาวะ (Waste Footprint) | คราฟต์หรือหลอมที่ไม่ดีสร้างกาก/น้ำเสีย และต้องมีการบำบัดตามมวลจริง | batch and node id | โลก/เศรษฐกิจ | รีไซเคิลต้องมี loss ratio และใช้แรงงาน |
| MECH-26 | เงื่อนไขแบบอ่อนต่อบอส (Boss Soft Counter) | บอสเปลี่ยนการตรึงเป็น slow หรือ vulnerability ขนาดจำกัด | boss tag + cc diminishing | ต่อสู้ | ห้าม CC-lock และ ignore boss identity |
| MECH-27 | อุปกรณ์พิพาท (Custody Lock) | ของที่ยืมหรือเป็นคดีห้ามย้าย/ขาย/ย่อยจนเรื่องจบ | legal hold + UID | คลัง/ทูต | แก้ deadlock ด้วยคำสั่งคืนของและ expiration |
| MECH-28 | ผังผลิตมี sink ที่ตรวจได้ (Material Sink Ledger) | ชุดไอเทมจ่ายวัสดุให้กิจกรรมตาม recipe receipt; กำไรต้องเกิดจากแรงงาน/ความเสี่ยง | source, sink, loss | เศรษฐกิจ | ใช้สเปกเดียวกับกฎ mass balance ที่มีในเอกสารเดิม |
| MECH-29 | อุปกรณ์ปรับตัวตามงาน (Role-Adaptive Loadout) | NPC เลือกของทำงานต่างจากชุดรบและสลับเฉพาะจุดพักที่อนุญาต | task type + role + inventory | AI/NPC | ไม่ติด loop เปลี่ยนชุดหรือแย่งของจากคลัง |
