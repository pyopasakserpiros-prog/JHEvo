# 📋 คลังข้อมูลและระบบที่เกม JianghuSect 2 (JS2-v2.4.0) มีอยู่แล้ว — แยกออกจากคลังอัปเดตใหม่

> **วัตถุประสงค์ของเอกสารนี้:**
> ตามคำสั่งของคุณที่ต้องการให้ **"อันไหนที่เกมส์เรามีแล้ว ก็แยกไว้ในเอกสารอีกไฟล์นึง เป็นไฟล์สำหรับที่เกมส์เรามีแล้ว"** เอกสารฉบับนี้จึงรวบรวมข้อมูลทั้งหมดจากซอร์สโค้ดจริงของ **`JS2-v2.4.0`** และแยกเนื้อหาจากเอกสารทั้ง 4 ฉบับที่มีอยู่ในเกมแล้ว (ทั้งที่มีอยู่ตรงกัน 100% และที่มีระบบแกนกลางอยู่แล้วในชื่ออื่น) มาเก็บไว้ในไฟล์นี้อย่างละเอียดครบถ้วน เพื่อ:
> 1. **ป้องกันการสร้าง ID ซ้ำหรือเขียนระบบทับซ้อน** ในแพตช์ `JS2-v2.5.0+`
> 2. **เก็บรักษาเนื้อหาต้นฉบับจากทั้ง 4 เอกสารไว้ครบ 100%** โดยชี้ชัดว่าส่วนใดมีในโค้ดแล้ว และส่วนใดเป็นรายละเอียดเสริมที่นำไป **"อัปเกรดต่อยอด (Extend/Upgrade)"** ระบบเดิมได้ทันที

บทเรียนเชิงออกแบบจากชุด A–C

1. ของ Tier 1–2 ควรมี "ข้อจำกัด" ชัดเจน — ไม่ใช่ของ "กลางๆ ที่ดีทุกอย่าง" แต่เป็น "ของที่เลือกใช้ตามสถานการณ์" เช่น พลองไม้ = ตีไกลแต่เบา, มีดสั้น = ตีหลายครั้งแต่เบา
2. ไม่มี gauge ใหม่ — ทั้ง 12 ชิ้นใช้แค่ field ที่มีอยู่: damage, crit, accuracy, pierce, knockback, DEF, SPD, HP — ไม่ต้องเพิ่มระบบใหม่
3. แต่ละชิ้นมี "จุดเด่น 1 อย่าง + ข้อจำกัด 1 อย่าง" — ผู้เล่นเข้าใจได้ทันที ไม่ต้องอ่านคู่มือ
4. ของ Tier 1–2 เป็น "บันได" — ผู้เล่นใหม่อาจเริ่มด้วย WOODEN_STAFF (Tier 1) → IRON_LONGSWORD (Tier 2) → ของ Tier 4+ ในภายหลัง
5. ไม่มีของที่ "ดีทุกอย่าง" — ทำให้ผู้เล่นต้องเลือก (build diversity)

บทเรียนเชิงออกแบบจากชุด D–G

1. Tier 3 ควร "แรงกว่า Tier 2 เล็กน้อย" ไม่ใช่ "แรงกว่ามาก" — STEEL_LONGSWORD แรงกว่า IRON_LONGSWORD แค่ 10% crit + 10% dmg แลกกับ SPD −10% — เป็น "sidegrade" ไม่ใช่ "upgrade" ที่ทำให้ของเก่าขยะ
2. ของ Tier 3 ควรมี "ข้อจำกัดที่ชัดขึ้น" — PLATE_ARMOR ได้ DEF +35% แต่ dodge ไม่ได้เลย — เป็น tradeoff ที่ผู้เล่นต้องคิด
3. เครื่องประดับ Tier 1–2 ควร "เบาๆ" — COPPER_RING (HP +5%), WOODEN_EARRING (accuracy +5%) — เป็นของประดับที่ไม่ทำให้เกมพัง
4. Consumable Tier 1–2 ควร "ใช้บ่อยได้" — RED_POTION ฟื้น 30% ใช้ได้ 1 ครั้ง/ศึก — เป็นของที่ผู้เล่นใหม่พกติดตัวตลอด
5. ของ Tier 1–2 เป็น "บันได" ที่สำคัญ — ผู้เล่นใหม่ควรมีของให้เลือกใช้ตั้งแต่ต้นเกม ไม่ใช่ต้องรอ Tier 4+

บทเรียนเชิงออกแบบจากชุด H–K

1. Tier 4 ควรมี "แมคคานิค 2 อย่าง" แต่ยังไม่ซับซ้อน — FOLDED_STEEL_BLADE มี crit + crit dmg + ignore dodge (3 อย่างแต่เป็นกลุ่มเดียวกัน) — ยังเข้าใจง่าย
2. Tier 4 ควรมี "ข้อจำกัดที่ชัด" — COMPOSITE_BOW ยิง 2 ครั้งแต่เบา, WAR_SCYTHE กว้างแต่ไม่แม่น — เป็น tradeoff ที่ผู้เล่นต้องเลือก
3. วัสดุ Tier 1 ควร "หาได้ง่าย" — IRON_ORE, LEATHER, CLOTH — เป็นของพื้นฐานที่ผู้เล่นใหม่ควรมีติดตัว
4. ตำรับ Tier 1 ควร "ใช้ของน้อย" — IRON_SWORD_RECIPE ใช้ IRON_ORE 3 + LEATHER 1 — ไม่ต้องเก็บของเยอะ
5. ของขายในร้านควร "มีประโยชน์เฉพาะทาง" — BANDAGE (หยุด bleed), TORCH (vision), ROPE (quest), LOCKPICK (เปิดหีบ) — ไม่ใช่ของที่ใช้ตลอด แต่ใช้เมื่อจำเป็น
6. วงจรครบ: เก็บวัสดุ (I) → คราฟต์ด้วยตำรับ (J) → ได้ของ (A–H) → ใช้ของ (K) — เป็นวงจรพื้นฐานที่ผู้เล่นใหม่เข้าใจได้ทันที

ข้อสังเกตสำหรับทีมงาน

1. ชุด A–K ทั้ง 44 ชิ้นเป็น "ของพื้นฐาน" — ไม่มี ultimate, ไม่มี gauge ใหม่, ไม่มีสถานะใหม่ที่ต้อง track — เหมาะสำหรับ ผู้เล่นใหม่ และ Tier 1–4 เท่านั้น
2. ของ Tier 4 (ชุด H) ยังเป็น "ของกลางๆ" — ไม่แรงเท่า legendary/epic ที่เสนอในชุดก่อนหน้า — เป็น "บันได" ระหว่างของพื้นฐานกับของชั้นสูง
3. ชุด I–K เป็น "ระบบเศรษฐกิจ" — ถ้าทีมงานทำระบบคราฟต์/ร้านค้า ชุดนี้เป็น "ตัวอย่าง" ที่สามารถใช้เป็นจุดเริ่มต้น
4. ตัวเลขทั้งหมด (damage %, crit %, ราคา) เป็น "ตัวอย่าง" — ต้องปรับบาลานซ์ตามระบบจริงของเกม
5. ไม่มีสิ่งใดในชุดนี้ที่ "ต้องทำ" — ทั้งหมดเป็นเพียง "ข้อเสนอ" ที่ทีมงานสามารถหยิบไปปรับใช้หรือเพิกเฉยได้

บทเรียนเชิงออกแบบจากชุด L
