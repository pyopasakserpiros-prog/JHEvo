## 📑 สารบัญเอกสารไอเดียในหมวดเกมบริษัท

| เอกสาร | สิ่งที่ออกแบบไว้ |
| :--- | :--- |
| **1. [ระบบรางวัลพนักงานดีเด่น และสวัสดิการองค์กร](01_ระบบรางวัลพนักงานดีเด่น_และสวัสดิการองค์กร.md)** | • การประเมินผลงานสิ้นเดือนอัตโนมัติ (KPI Evaluation)<br>• พิธีมอบรางวัล Townhall สิ้นเดือน พร้อมเงินโบนัสก้อนโต (Bonus Lump-sum)<br>• ป้ายทองเกียรติยศหน้าตึก HQ<br>• ปฏิกิริยาทางจิตวิทยา: พนักงานดีเด่นปลดหนี้/มีไฟ, เพื่อนร่วมงานอิจฉาหรือยินดี<br>• การอัปเกรดเครื่องกาแฟสด, อาหารฟรี, โต๊ะสุขภาพ, ประกันกลุ่ม |
| **2. [ระบบชีวิตหลังเลิกงาน ชมรม และความรักในที่ทำงาน](02_ระบบชีวิตหลังเลิกงาน_ชมรม_และความรักในที่ทำงาน.md)** | • ชมรมวิ่ง/ฟิตเนสหลังเลิกงานตอน 17:30 น.<br>• วงหมูกระทะและเบียร์วันศุกร์ ฟื้นฟู Burnout<br>• ข่าวลือและการนินทาที่ตู้กดน้ำเรื่องเงินบริษัทและเดดไลน์<br>• ความรักในที่ทำงาน แอบชอบ เดต แต่งงาน และดราม่าเลิกรา |
| **3. [ระบบวิกฤตเศรษฐกิจ เหตุการณ์ฉุกเฉิน และการตรวจสอบโรงงาน](03_ระบบวิกฤตเศรษฐกิจ_เหตุการณ์ฉุกเฉิน_และการตรวจสอบโรงงาน.md)** | • วิกฤตไฟดับทั่วนิคมอุตสาหกรรม พนักงานออกมารวมตัวกลางแจ้ง<br>• วัตถุดิบติดด่านศุลกากร / ซัพพลายเชนชะงัก<br>• น้ำท่วมรอระบาย รถขนส่งเข้าไม่ได้<br>• การตรวจสอบมาตรฐาน ISO 9001 และสุ่มตรวจความปลอดภัยแรงงานกะทันหัน<br>• ลูกค้ารายใหญ่เบี้ยวหนี้ เกิดวิกฤตเงินสดช็อต |
| **4. [ระบบการเติบโต พี่เลี้ยงสอนงาน และการขยายอาคารใหม่](04_ระบบการเติบโต_พี่เลี้ยงสอนงาน_และการขยายอาคารใหม่.md)** | • ระบบพี่เลี้ยง (Senior สอนงาน Junior) เพิ่ม XP 2.5 เท่า ลดของเสียครึ่งหนึ่ง<br>• การเลื่อนตำแหน่งสู่ Master Tech และ Sales Director<br>• การขยายอาคารในนิคม: โรงงานแห่งที่ 2 (Cleanroom), คาเฟ่พนักงาน, ศูนย์ซ่อม RMA, หอพักพนักงาน<br>• ลำดับการปลดล็อกสินค้าเทคโนโลยี Tier 1–Tier 5 (ลำโพง ➔ โคมไฟ ➔ สมาร์ตวอตช์ ➔ โดรน ➔ สมาร์ตโฮม) |
| **5. [ระบบการผลิตสมจริง BOM จัดซื้อ และคลังสินค้าครบวงจร](05_ระบบการผลิตสมจริง_BOM_จัดซื้อ_และคลังสินค้าครบวงจร.md)** | • วัตถุดิบ 4 หมวดหมู่จริง 16 รายการ (ชิป, แบตเตอรี่, น็อต, ตัวถัง, บรรจุภัณฑ์)<br>• คลังสินค้า 3 ระดับ (คลังวัตถุดิบ ➔ พื้นที่ WIP ➔ คลังสินค้าสำเร็จรูป)<br>• ระบบจัดซื้อ 3 ช่องทาง (โรงงานนอก, ตัวแทนในประเทศ, ตลาดด่วน)<br>• สูตร BOM และต้นทุนกำไรขั้นต้น (Gross Margin) ของลำโพงและโคมไฟ |
| **6. [ระบบกำลังคนสองระดับ คนงานตัวเลข และหัวหน้ากลุ่ม](06_ระบบกำลังคนสองระดับ_แรงงานตัวเลข_และหัวหน้ากลุ่ม.md)** | • คนงานสายผลิตทั่วไปเป็น "ตัวเลขเชิงสถิติ (Headcount Pool)" ไม่กินแรม สเกลได้เป็นพันคน<br>• หัวหน้าช่าง/โฟร์แมน/คีย์แมนเป็น "NPC มีตัวตนเต็มรูปแบบ (Named Core)" ปล่อยออร่าคุมงาน<br>• กลไกการเลื่อนขั้น: คนงานนิรนามผลงานเด่น ได้รับการโปรโมทกลายร่างเป็นตัวละคร Chibi มีชื่อจริง! |
