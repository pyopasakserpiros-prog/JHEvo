# [RAW DRAFT] โลกที่สูงกว่า: โครงสร้างมหาพิภพและทวยเทพโบราณ (Higher Realms Cosmology)
## สำหรับส่งต่อเป็นไอเดียตั้งต้นให้ Gemini พัฒนาระบบจริง (Proposals & Implementation)

> **สถานะเอกสาร:** RAW DRAFT / CONCEPT PROPOSAL (ร่างไอเดียคร่าวๆ สำหรับตั้งต้น)  
> **เป้าหมาย:** สรุปโครงสร้างของมหาพิภพที่อยู่เหนือยุทธภพมนุษย์ เพื่อให้ Gemini นำไปออกแบบต่อยอดเป็นระบบ:
> 1. ระบบยืมพลังข้ามมิติ (Cosmic Channeling)
> 2. ระบบสัญญาสถิตร่าง (Divine Possession / Avatar Descent)
> 3. ระบบเสาบูชา/วิหารเชื่อมแดนบน (Celestial Shrine / Beacon)

---

### 🌌 1. โครงสร้างของ "โลกที่สูงกว่า" (Cosmic Plane Hierarchy)
โลกในเกมไม่ได้มีแค่มิติมนุษย์/โลกเซียน แต่เชื่อมโยงกับมหาพิภพชั้นสูง 5 มิติหลัก:

```
                      [มหาพิภพไร้ขอบเขต / แดนโกลาหลบรรพกาล]
                                       |
    +-----------------+----------------+-----------------+-----------------+
    |                 |                |                 |                 |
[แดนไศวะ-ไวกูณฐ์]  [แดนสวรรค์เก้าชั้น]  [โอลิมปัส-เอลิเซียม]  [ดูอัต-เนเธอร์]   [หิมพานต์-ทวยเทพสยาม]
(พราหมณ์-ฮินดู)       (เต๋า-จีนโบราณ)      (เกรกโก-โรมัน)      (ยมโลกอียิปต์)       (พระเวท-แรงครูไทย)
    |                 |                |                 |                 |
    +-----------------+----------------+-----------------+-----------------+
                                       |
                         [ยุทธภพโลกมนุษย์ (Jianghu World)]
                           (สำนักเซียน / NPC / ผู้เล่น)
```

1. **แดนสวรรค์เก้าชั้นและสุริยันบรรพกาล (Heavenly Court & Primordial Sun):**
   - *บรรยากาศ:* ทะเลเมฆสีทอง วิหารหยก ตำหนักดวงดาว
   - *ตัวแทนเทพ:* ผานกู่ (กำลังแยกฟ้า), เจ้าแม่หนี่วา (ปฐพี-ฟื้นฟู), ตงหวงไท่อี้ (สุริยันบรรพกาล), เอ้อหลางเสิน & ซุนหงอคง (กายาทองคำ-เนตรสวรรค์)
   - *จุดเด่น:* กฎสวรรค์เข้มงวด มอบพลังสายฟ้าทัณฑ์ ปราณสุริยันหยาง และการทลายค่ายกล

2. **แดนมหาเทวะไศวะ-ไวกูณฐ์ (Vedic Cosmic Realm):**
   - *บรรยากาศ:* จักรวาลหมุนวนด้วยธรรมจักร เพลิงกัลป์ทำลายล้างเพื่อสร้างสรรค์ใหม่
   - *ตัวแทนเทพ:* พระศิวะ (เนตรที่สาม/นาฏราชทำลายล้าง), พระวิษณุ (ตรีศูล-กงล้อคุ้มครองจักรวาล), พระแม่กาลี (สังหารมาร), พญาครุฑ & พญานาค
   - *จุดเด่น:* พลังแรงสุดขั้ว ลบล้างเกราะปราณ ศัตรูยิ่งบาปยิ่งโดนหนัก

3. **แดนดูอัตและยมโลกทรายดูด (Duat & Egyptian Netherworld):**
   - *บรรยากาศ:* ทะเลทรายสีดำ แม่น้ำวิญญาณ ตาชั่งทองคำยักษ์
   - *ตัวแทนเทพ:* อนูบิส (ชั่งหัวใจ/ประหารฉับพลัน), รา (สุริยันแผดเผามลทิน), โอซิริส (คืนชีพ), เซธ (พายุทรายกลืนปราณ)
   - *จุดเด่น:* เล่นกับความตาย ชุบชีวิต คำสาปกัดกร่อน และการพิพากษาบาป

4. **แดนยอดเขาโอลิมปัสและทาร์ทารัส (Olympian & Tartarus Realm):**
   - *บรรยากาศ:* ยอดเขาสูงเสียดฟ้าที่ผ่าด้วยสายฟ้าตลอดเวลา และคุกมืดใต้พิภพ
   - *ตัวแทนเทพ:* ซูส (สายฟ้าไร้เทียมทาน), ฮาเดส (หมวกพรางเงา/โซ่ยมโลก), อาธีน่า (ปัญญาศึก/โล่สะท้อน), อาเรส (สงครามคลั่ง)
   - *จุดเด่น:* สปีดความเร็ว พลังธาตุธรรมชาติล้วนๆ และจิตวิญญาณนักรบไม่ยอมตาย

5. **แดนทิพย์หิมพานต์และสยามเทวา (Himavanta & Siamese Mystic Plane):**
   - *บรรยากาศ:* ป่าหิมพานต์ลี้ลับ อักขระเลขยันต์ลอยในอากาศ เสียงสวดพระเวทและปี่พาทย์พิธี
   - *ตัวแทนเทพ:* ท้าวเวสสุวรรณ (กระบองเพชรสยบภูติ/โชคลาภ), พระพิราพ (แรงครูนาฏยยุทธ์/ปราบเสนียด), เจ้าป่าสมิง (สัญชาตญาณสัตว์ป่า), พระแม่ธรณี (มวยผมสยบมาร)
   - *จุดเด่น:* แรงครู อาคมคงกระพันชาตรี แคล้วคลาด และโชคลาภสำนัก

### ⚙️ 2. ไอเดียกลไกสำหรับเชื่อมต่อเกม (Raw Gameplay Hooks)
เพื่อให้ Gemini นำไปออกแบบโค้ดและระบบต่อ:

1. **ระบบเสาบูชา/เทวสถานในสำนัก (`Sect Divine Shrine`):**
   - ผู้เล่นสามารถสร้างอาคารแท่นบูชาเทวะ และเลือกได้ว่าจะ "ผูกจิตกับแดนใด"
   - แต่ละแดนจะมีเงื่อนไขการบูชาต่างกัน (สังเวยสมุนไพร, ศิลาปราณ, หรืออาวุธศัตรู)
2. **ระบบทำพันธสัญญารายบุคคล (`Individual Deity Pact`):**
   - ศิษย์ที่มีค่าสเตตัสเฉพาะ (เช่น ค่าความซื่อตรงสูง, ค่าความดุดันสูง) จะสามารถสื่อจิตกับเทพประจำสายได้
   - ได้รับ Passive ประจำตัว เช่น "พรแห่งอนูบิส", "เนตรพระศิวะ", "เกราะท้าวเวสสุวรรณ"
3. **ระบบสถิตร่างกลางศึก (`Avatar Descent / Divine Possession Gauge`):**
   - ในการต่อสู้ เมื่อสะสมเกจความศรัทธาเต็ม ศิษย์สามารถเข้าสู่ภาวะ "ทรงเจ้า / อวตารประทับ" รูปลักษณ์จะขยายใหญ่ มีออร่าเทวะ และเปลี่ยนสกิลเป็นท่าไม้ตายระดับทลายล้าง
