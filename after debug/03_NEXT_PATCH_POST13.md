# ใบส่งต่องานหลังตรวจหมวด 01–13

สถานะ: เสนอสำหรับแพตช์ถัดไป รอผู้ใช้สั่งเริ่ม

อ่าน AGENTS.md, สรุปเกม, สกิลที่เกี่ยวข้อง และ `02_POST13_REVIEW_AND_NEXT_PATCH.md` ก่อน ใช้ฐานล่าสุดที่รวมการแก้ R01–R04 รักษางาน 01–13 เดิม

1. N01: ทำแผนที่รายได้/รายจ่าย/การโอนศิลาทุกแหล่ง ตัดสินนโยบายแหล่งกำเนิดที่อนุญาตกับผู้ใช้เมื่อมีข้อแลกเปลี่ยนสำคัญ แก้คู่ต้นทาง/ปลายทางโดยไม่หักซ้ำ ตรวจ zero/partial/duplicate/replay/cancel และบันทึกรางวัลตามยอดจริง
2. N02: สำรวจปุ่มเปลี่ยนโลกที่ละเมิดหลัก NPC ตัดสินใจเอง ตรวจผู้ตัดสินใจและ trigger อัตโนมัติ แปลง UI เป็นการสังเกตผลโดยคงเครื่องมือแก้สถานะ/ตัวเสกที่ผู้ใช้อนุญาต ตรวจโลกเดินต่อโดยไม่กดสั่ง
3. N03: จำลอง reserveInputs ล้มเหลวระหว่างหักวัตถุดิบ ตรวจ stock/provenance/quality/receipt/stockTracker ให้คืนสถานะอย่างถูกต้อง แล้วแก้ rollback เฉพาะที่พิสูจน์แล้ว
4. N04: ทำตารางปิด audit รายข้อจากเอกสารต้นฉบับ 01–13 ระบุ fixed/not-applicable/deferred พร้อมหลักฐานและข้อจำกัด ข้อเสนอในเอกสารเป็นข้อมูลให้ตัดสินใจ ไม่ใช่คำสั่งให้ทำทุกอย่างโดยไม่ตรวจ

ทดสอบตาม AGENTS.md รวม regression เฉพาะสาเหตุ เซฟโหลด การจำลองต่อเนื่องและเบราว์เซอร์ตามผลกระทบ อัปเดตสกิล/สรุปเกม/รายงาน และ build offline ให้ตรงซอร์ส ก่อนส่งงานระบุสิ่งที่ตรวจได้จริง ไม่อ้างว่าทั้งโลกไม่มีบัคเพราะจำนวนชุดทดสอบผ่านครบ
