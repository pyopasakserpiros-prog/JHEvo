# 04 — โหมดผู้สังเกตการณ์และโอกาสเกิดขึ้นจริงของโลก

วันที่ตรวจ: 2026-11-15 · สาขา main-debug · ฐานก่อนแก้ 9410322

ผู้ใช้ขอเอาปุ่มสั่ง NPC ออก และให้ระบบมีโอกาสเกิดจาก NPC หรือธรรมชาติ โดยไม่บังคับว่าจะต้องเกิด แพตช์นี้ตรวจส่วนเชื่อม UI → การตัดสินใจ → ผลจริง รวมทั้งช่องที่เคยมี API แต่ไม่มีผู้เรียกจากการจำลอง ไม่ใช่ใบรับรองว่าทุกสถานะของเกมหรือทุกข้อจาก PDF ทั้ง 13 หมวดปลอดบัคแล้ว

## ปุ่มและสิทธิ์ผู้เล่น

- ลบ handler สั่งการเดิม 157 action และกรองปุ่ม/ช่องสั่งการออกจากหน้าที่แสดงจริง รายชื่อครบอยู่ใน `docs/audits/OBSERVER_ACTION_POLICY.json`
- อนุญาต 114 action สำหรับดูข้อมูล กรองข่าว กล้อง ภาพตัวอย่าง การแสดงผล เซฟ/โหลด และเปิดเครื่องมือแก้สถานะ; action ที่ไม่รู้จักถูกปิดโดยปริยาย
- อีก 29 action แก้สถานะโดยตรงใช้ได้เฉพาะหน้า Edit Hub ตามข้อยกเว้นใน AGENTS.md เครื่องมือเสกศิลา/อาหาร/รักษายังคงอยู่ แต่ raid/beast/recruit/banquet/tourney/challenge จากตัวสั่งเดิมใช้ไม่ได้
- การเรียก `UI.doAction` ด้วยรหัสเก่าโดยตรงก็ถูกปฏิเสธ ไม่หักทรัพยากรหรือเปลี่ยนเซฟ/RNG การซ่อนปุ่มเพียงอย่างเดียวไม่ใช่หลักฐานเพียงพอ
- หน้าอ่านข้อมูลและเวลาอยู่ต่อ การซื้อขาย สวม/ใช้ของ เลือกนโยบาย จัดทีม สั่งสำรวจ บังคับเหตุการณ์หรือการต่อสู้ ถูกถอดจากการควบคุมปกติ ผู้เล่นแก้สถานะ/เสกของแล้ว NPC ตัดสินใจต่อเอง

## ทางเลือก NPC ที่เพิ่มจริง

`AI.ACTS.opportunity` เข้าตัวเลือกปกติของ AI ใช้เวลา 30 นาที cooldown 360 นาที เงื่อนไขสร้างจากสภาพจริงโดยไม่สุ่มระหว่างประเมิน ตรวจเงื่อนไขใหม่เมื่อทำงานเสร็จ และยังมีทางเลือก “รอ” ที่มีน้ำหนักจริง ทุกทางเลือกมีน้ำหนักบวก; ไม่ใช้ forceWin/free/บังคับผลสำเร็จ ทางเลือกหลายเป้าหมายถูกถ่วงน้ำหนักตามกลุ่มเพื่อไม่ให้กลบกลุ่มอื่น บันทึก cooldown ในเซฟและจำกัดประวัติ 80 คีย์

31 กลุ่มที่ทดสอบผลจากฟังก์ชันจริง:

| กลุ่ม | เงื่อนไข/ผลสำคัญ |
|---|---|
| oath, seal | คำสัตย์ตามบุคลิก; ตราวิถีต้องมีผลงานจริง ชนะประลองต่อเนื่อง/ฝึกกายบริสุทธิ์/ปราบบอสเดี่ยว |
| core, marrow | กินแก่นอสูรที่มีจริง เหลือสำรอง จำกัดชนิด/โบนัส; ล้างไขกระดูกเฉพาะผู้มีสายเลือดแฝงและบ่อ |
| totem | เจ้าสำนัก/รองมีขั้นและทุนสำรอง จ่าย 150 ศิลาจริง ไม่ติดธงผู้เล่นสร้าง |
| micro, bounty, claim | สำรวจตามความสนใจ/อันตราย รับค่าหัวที่เปิดจริง ยึดแหล่งทรัพยากรผ่านการเดินทางและเสบียง |
| exchange, craft-exchange, recruit | ศึกษาต่างสำนักตามไมตรี แลกของกับช่างที่มีชีวิต รับผู้มีไมตรีเมื่อมีที่พัก |
| siege, coalition, beacon | เป้าหมายเป็นคู่ขัดแย้งจริง ทัพออกเดินทาง ไม่ชนะทันที; พันธมิตรต้องมีจริง; จุดควันขอหนุนเฉพาะถูกล้อม |
| schism, nomination, appease | ตอบวิกฤตแตกก๊ก/การเสนอชื่อที่ค้างอยู่; ใช้เงินลดกระแสใต้น้ำตามบุคลิก |
| stipend, black-market | จ่ายรางวัลตำแหน่ง/เข้าประมูลเฉพาะเมื่อมีเงินสำรองและตลาดเปิด |
| peak-leader, anchor | แต่งตั้งเมื่อว่าง เลือกบุคคลที่พร้อมและเข้าเงื่อนไข |
| seclusion-policy, peak-policy, leave-peak | ปรับนโยบายจากตัวตน/ทุน; NPC ไม่พอใจและรักอิสระเลือกออกยอดเขาได้ |
| ally-aid, nemesis | ใช้สายสัมพันธ์/คู่อาฆาตที่เกิดจริง ไม่สร้างเพื่อนหรือศัตรูขึ้นเพราะกดปุ่ม |
| tomb-discovery, tomb | สำรวจร่องรอยตามขั้นและความสนใจ ไม่ค้นซ้ำสุสานเดิม; ผ่านแต่ละชั้นด้วย NPC ที่พร้อมและความเชี่ยวชาญเหมาะสม |
| crisis | ผู้นำตอบสนองวิกฤตที่เกิดแล้วทีละบทตามหลักที่ยึดถือ ไม่เรียกวิกฤตมาเอง |
| covenant, infernal | ผู้มีวิถี/ความทะเยอทะยานที่ยอมรับพันธสัญญาและมีทุนสำรอง เลือกมารจาก catalog จริง มีต้นทุน/ผลย้อนกลับ; การบูชาผ่านทางเลือกนี้ไม่ผูกพัน NPC คนอื่นแทนเจ้าตัว |

ผู้ตาย ถูกขัง ออกนอกสำนัก เดินทาง อยู่ในศึก/บำเพ็ญคู่/ทะลวงขั้น/รับโทษ ไม่ได้รับทางเลือกเหล่านี้ การตัดสินใจหนึ่งอย่างอาจทำให้เงื่อนไขอื่นหมดไป ซึ่งเป็นผลตามธรรมชาติ ไม่ใช่รับประกันว่าจะได้เห็นทุกกลุ่มในเซฟเดียว

`EXPED.considerNaturalEndgameEvents` ถูกเรียกจาก tick โลกทุก 10 วัน: โลกเลือกได้ว่าจะรอ; สำนักศัตรูที่เป็นปฏิปักษ์และมีกำลังพอมีโอกาสล้อมจริง และโลกที่มีผู้บำเพ็ญขั้นสูงมีโอกาสเริ่มวิกฤตโดยยังไม่มีคำตอบของผู้นำ ตรวจซ้ำวันเดียวกันไม่สร้างเหตุการณ์ซ้อน มีช่วงพักหลังจบเหตุการณ์ และหลังถูกล้อมครบ 20 วัน (ตรวจทุก 10 วัน) จะคำนวณการรับศึกด้วยกำลังตนเองหากยังไม่จบ ไม่ค้างรอให้มีพันธมิตร/ผู้เล่นกด

## ระบบเดิมที่คงใช้เส้นทางจำลอง

การทำงาน ผลิต ค้าขาย ใช้/บริจาค/สวมของ ตกปลา เปิดหีบ กินอาหาร ฝึกวิชา เลือกวิถี ความสัมพันธ์ อาจารย์ศิษย์ การรับศิษย์ ยกระดับสำนัก ตำแหน่ง สร้างยอดเขา จัดทรัพยากร งานประลอง/ชุมนุม ข่าวลือ ทูต เขตลับ วาสนา สัตว์วิญญาณ การเมืองสำนักบริวาร และการเก็บผลทรัพยากร มีจุดเรียกเดิมใน AI/SECT/EXPED/วงรอบโลก ใช้ regression ของระบบเหล่านี้ประกอบ ไม่ตีความแค่จำนวน callsite ว่าเส้นทางเกิดได้แน่นอน

การบำเพ็ญคู่ใช้ `AI.pairTick`; การปลดยอดเขาใช้วงรอบตำแหน่งว่าง/การแต่งตั้งแทน; การเปิดตำแหน่งใช้ระดับสำนัก; ค่ายกลยอดเขาใช้ `PEAKS.tick`; alignment ประเมินจากผลงาน/ผู้นำ โอสถหลายระยะทั้ง 48 แบบมีสูตรและเส้นทางผลิตปกติ ไม่ต้องใช้ปุ่มพิเศษ ตัวอย่างสภาพอากาศที่เคยสั่งได้ใช้ระบบอากาศ/ดาราธรรมชาติ ส่วนรหัสหยกสำหรับข้ามเซฟเป็นเครื่องมือส่งข้อมูล ไม่ใช่เหตุการณ์ในโลกที่ต้องให้ NPC เรียกเอง

## ข้อผิดพลาดที่พบและแก้ระหว่างตรวจ

1. สูตร `REC_V222_EQ_05/06/10/11/13/16/22/24` ต้องการโรงหลอมระดับ 4–5 แต่โรงหลอมสร้างได้สูงสุด 3 ปรับเพดานสูตรให้ตรงสถานที่จริง และเพิ่ม schema gate ป้องกันข้อกำหนดเกินเพดาน
2. `ECO.mintGear` เมื่อรับสูตรที่มีทั้ง slot และ outItemId เคยใช้ตัวสูตรแทน item ทำให้รหัส/ข้อมูลผลผลิตไม่ตรงอุปกรณ์ แก้ให้เลือก authored item ก่อน ทดสอบผลิตทั้ง 8 สูตรจนได้รหัสผลผลิตจริง
3. แก้การจ่าย/รับศิลาในแลกเปลี่ยนช่าง ลดกระแสใต้น้ำ ขอความช่วยเหลือ และท้าคู่อาฆาต ให้โอนเข้า/ออก world pool เมื่อทางเลือกใหม่เปิดให้เกิดจริง ไม่สร้าง/ทำศิลาหายจากการโอนเหล่านี้
4. บันทึก streak ประลองและชัยชนะบอสเดี่ยวจากผลต่อสู้จริง ตราไม่ต้องพึ่งผู้เล่นแจก
5. ปิดล้อมที่ไม่มีคนเลือกตอบสนองจบเองได้ แก้ข่าวศึกให้ตรงผลแพ้/ชนะและทัพหนุนที่มีจริง รางวัลชัยชนะโอนจาก world pool ตามยอดคงเหลือ ไม่ผลิตศิลาฟรี
6. พบตัวเชื่อม API ที่ยังไม่เชื่อมวงจำลอง: สุสาน วิกฤตโลก ศึกพันธมิตร ขอทัพหนุน และแท่นมาร จึงเพิ่มเส้นทางข้างต้นพร้อมทดสอบผลจริง

## หลักฐานและขอบเขตการทดสอบ

- `test/observer_controls_browser.js`: กวาดหน้า UI บน Chromium ตรวจ 462 controls; รหัสถูกถอดทั้ง 157 และ action แก้สถานะ 29 ตัวถูกปิดนอก editor; รหัสใหม่ไม่หลุด; เครื่องมือเสกที่อนุญาตยังทำงาน
- `test/observer_autonomy_suite.js`: สร้างสถานะที่เข้าเงื่อนไขแล้วเลือกเฉพาะตัวเลือกที่จะทดสอบ เพื่อพิสูจน์เส้นทาง/ต้นทุน/ผล/การเดินทางจริง ไม่ใช้การทำเช่นนี้ยืนยันอัตราเกิดตามธรรมชาติ ทดสอบครบ 31 กลุ่ม และเหตุการณ์โลกทั้งสองแบบ
- จำลอง 30,000 tick ด้วย seed trace โดยไม่แก้ RNG/กด UI พบ NPC เลือก micro exploration จริง 1 ครั้งในซอร์สสุดท้าย แล้วเซฟโหลดและจำลองต่อได้ ความถี่ต่ำหรือบางเซฟไม่มีเหตุการณ์เป็นพฤติกรรมที่อนุญาต ไม่เร่งให้ทุกเหตุการณ์ต้องเกิด
- การทดสอบ UI เดิมปรับจาก “กดปุ่มแล้วสำเร็จ” เป็น “ไม่มีปุ่มและคำสั่งถูกปฏิเสธ” โดยคงทดสอบกลไก backend และเพิ่ม lifecycle อัตโนมัติ ไม่ลบทิ้งเพื่อทำให้จำนวนผ่านดูดี
- ชุดวัดความเร็ว v320 จัดรันเดี่ยวเช่นเดียวกับชุดงบ CPU อื่น เพราะการรันชน Chromium เคยได้ 3.820 ms/tick แต่รันเดี่ยวซอร์สเดิมได้ 0.580 ms/tick บันทึกผลรอบสุดท้ายใน evidence
- ผลตรวจทั้งชุดและ schema ดูส่วนผลตรวจท้ายเอกสาร/ไฟล์ evidence หลังการรันเสร็จ

ข้อจำกัด: เป็นการตรวจเส้นทางและเงื่อนไขที่ระบุ ไม่ใช่การพิสูจน์ทุก seed ทุกทรัพยากร ทุกรางวัล ทุกจังหวะชนกันหรือผลกระทบระยะยาว N01 เศรษฐกิจทั้งระบบ, N03 rollback วัตถุดิบ และ N04 ปิดรายการ PDF รายข้อจากใบส่งต่อเดิมยังเป็นงานต่อเนื่อง แพตช์นี้ไม่อ้างว่าปิดงานเหล่านั้นทั้งหมด
