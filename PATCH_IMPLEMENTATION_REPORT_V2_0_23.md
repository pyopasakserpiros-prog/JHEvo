# v2.0.23 — UI and baseline corrections

Based on the v2.0.22 full package from Gemini. The sect inventory is a separate tab with 24 items per page and six columns, a compact selection summary, filters, and a full-detail dialog. The library shows Thai path, subpath and weapon compatibility information and a non-modal detail panel. The people list shows cultivation, path, subpath, elemental roots and sect position. A small illustrated atlas supplements the existing atlas by item type and tier; unsupported kinds retain their prior icons.

Restored determinism after loading: the founding chronicle was recreated on every load because its transient guard was removed during serialization. Existing chronicle sequence state now prevents a duplicate. Corrected v2.0.22 beast pool entries that violated pool tier or land habitat constraints, moving compatible species into suitable pools. Added missing reverse source-beast references for v2.0.22 anatomy materials.

Validation: schema audit reports zero errors and warnings; core lock, save integrity, cognition replay, wildlife pool integrity, inventory viewport interactions, and fishing browser checks pass. The full regression runner reports 93 of 99 groups pass; six referenced suites (v215, v216, v217, v218, v219, v222) are absent from the v2.0.22 package and cannot run. Several older suite expectations were updated to allow the additional v2.0.22 content, keeping baseline minimums and subsequent content checks. The stock UI test was updated for its new tab. Browser tests used installed Chromium served over HTTP because file URLs are blocked in this environment.
