# พงศาวดารแกนหลักแห่งอนุทวีป: ห้าวิถีต่อชะตาใต้ฟ้าปิด — บันทึกผู้จำศีลผนึกเวลา ผู้ผูกชีพจรตาน้ำ และราคาของความดื้อยาโอสถ

> **บันทึกเอกเทศแกนหลักแห่งอนุทวีป (หมวดวิถีการยืดอายุขัยโลกเบื้องล่างและการปรากฏตัวข้ามยุค)**  
> **หัวข้อ:** ห้าวิถีต่อชะตาใต้ฟ้าปิด: บันทึกผู้จำศีลผนึกเวลา ผู้ผูกชีพจรตาน้ำ และราคาของความดื้อยาโอสถ  
> **ขอบเขตเวลา:** ยุคที่ ๓๔ ปีที่ ๑,๐๐๐ – ยุคที่ ๑๐๑ ปีที่ ๑ (ศ.ท. ๓๔,๐๐๐ – ๑๐๐,๐๐๑ · ครอบคลุมสี่ยุคสมัยต่อเนื่อง)

## ๑. ข้อมูลกำกับเอกสารและจุดยึดแกนหลัก

| รายการ | รายละเอียดอ้างอิงแกนหลัก |
| :--- | :--- |
| **ชื่อคัมภีร์** | **ห้าวิถีต่อชะตาใต้ฟ้าปิด: บันทึกผู้จำศีลผนึกเวลา ผู้ผูกชีพจรตาน้ำ และราคาของความดื้อยาโอสถ** (หมวดปูมชราภาพและขีดจำกัดชีวิตใต้เพดานโลกเบื้องล่าง) |
| **พื้นที่ปฏิบัติการ** | สมมาตรครบทั้งเก้าแคว้น — **เป่ยหมิง**, **ตงหวง**, **ซีหรง**, ห้ารัฐกันชน (**โยวหมิง**, **หยุนเซียว**, **ฉื่อเยี่ยน**, **สุวรรณโพธิ์**, **กู่เจียว**), **หุบเขาหยุนเหอ**, และสำนักทั้งสิบเก้าเสาหลัก |
| **ช่วงเวลาครอบคลุม** | สี่ยุคสมัยต่อเนื่อง — รอยต่อกลียุคก่อนนครคงเฉิง (ยุคที่ ๓๔), ยุคกลางศึกมารจันทร์เลือด (ยุคที่ ๖๘), ยุคเจ็ดยุคแห่งฎีกากระดาษ (ยุคที่ ๙๒), และยุคที่ ๑๐๑ ปัจจุบัน |
| **จุดยึดแกนหลักร่วม** | กฎ **เพดานโลกเบื้องล่างขั้นที่ ๙**, **กฎบัตรสหพันธ์องค์กรกลางเจ็ดหอ** (ศ.ท. ๘๙,๓๑๐), **หุบเขาโอสถบัวหยก**, **ยอดเขากระบี่สวรรค์เทียนเจี้ยน**, **ภาคีมารกลืนสวรรค์เก้าโลหิต**, **หอผนึกชาด**, **รอยแยกบรรพกาลแห่งสุสานสวนสวรรค์**, และ **คืนมหาพิธีดับสุริยคราสโลหิต** |
| **ห้าวิถีที่บันทึก** | (๑) จำศีลผนึกเวลาชะลอชราร้อยละเก้าสิบ (๒) โอสถอายุวัฒนะแบบสะสมความดื้อยา (๓) ผูกชีพจรแกนวิญญาณสำนัก (๔) พันธะแบ่งปันอายุขัยสัตว์อสูร และ (๕) ผู้จำศีลข้ามยุคที่ตื่นตามธรรมชาติ |

ในอนุทวีปพันลี้ใต้ทะเลหมอกพิษ ปราณฟ้าดินบางเบาและถูกตรึงไว้ใต้ **เพดานโลกเบื้องล่างขั้นที่ ๙** แม้ยอดฝีมือจะฝึกถึงจุดสูงสุดของแดนมนุษย์ อายุขัยก็ยังคงสิ้นสุดเหมือนเทียนไขที่ละลายทีละหยด หลายท่านเลือกวางกระบี่ลงอย่างสงบเมื่อถึงวัยชรา ทว่ายังมีผู้อาวุโสอีกมากที่ไม่อาจวางห่วงลงได้ จึงหันไปพึ่ง **ห้าวิถีต่อชะตาใต้ฟ้าปิด** ซึ่งล้วนทวงคืนราคาอย่างยุติธรรมและโหดร้ายไม่แพ้กัน

## ๒. สี่กรณีศึกษาข้ามสี่ยุคสมัย

### กรณีที่ ๑ (ปลายกลียุคตอนปลาย): ราคาของเม็ดที่ห้าและคำสาบานใต้ตาน้ำ
* **กาลเวลา:** ยุคที่ ๓๔ ปีที่ ๑,๐๐๐ · เดือนสิบเอ็ดน้ำค้างแข็ง วันที่ ๑๒ (ศ.ท. ๓๔,๐๐๐)
* **บริบท:** รอยต่อก่อนการสถาปนา **นครหอคอยมิติย่อยคงเฉิง** (ยุคที่ ๓๕–๓๘) และยุคปฏิวัติหอโอสถในยุคที่ ๔๒

คืนน้ำค้างแข็งเกาะหนาบนหลังคาหอปรุงยาเชิงเขาบูรพา **เสิ่นจิงเหอ** แพทย์โอสถอาวุโสนั่งเฝ้าเตาสัมฤทธิ์ที่เพิ่งดับไฟ ด้านในคืออาจารย์ของเขา — ยอดฝีมือขั้นที่ ๗ วัยสองร้อยเก้าสิบสี่ปี ผู้กลืน **โอสถอายุวัฒนะผลัดแก่น** มาแล้วสี่เม็ดตลอดหกสิบปี เม็ดแรกยืดอายุได้เต็มร้อย เม็ดสองเหลือครึ่งเดียว เม็ดสามลดเหลือหนึ่งในสี่ และเม็ดสี่ประคองได้เพียงหนึ่งในสิบส่วน ครั้นคืนวันที่สิบสอง เดือนสิบเอ็ดน้ำค้างแข็ง อาจารย์ยืนกรานกลืนเม็ดที่ห้าซึ่งหลอมด้วยสมุนไพรหายากทั้งคลังสำนัก ทว่าปราณโอสถกลับไหลผ่านเส้นชีพจรราวกรวดทรายเย็นชืด ชีพจรช้าลงจนดับสนิทก่อนรุ่งสาง เสิ่นจิงเหอจึงบันทึกกฎ **ความดื้อยาโอสถ** ลงตำราแพทย์เป็นครั้งแรก — หนึ่งร้อย ห้าสิบ ยี่สิบห้า สิบ และศูนย์ตั้งแต่เม็ดที่ห้าเป็นต้นไป ในปีเดียวกัน ศิษย์ร่วมสำนักอีกรายผู้ถือโอสถเม็ดแรกอันบริสุทธิ์กลับไม่กลืนเอง แต่มอบให้อาจารย์อีกท่านที่ใกล้สิ้นลม เพื่อซื้อเวลายี่สิบปีให้สำนัก ขณะที่ตนเองยอมแก่ชราไปตามวัย

ในฤดูหนาวเดียวกันบนสันเขาแดนอุดร **กัวเจิ้นซาน** ผู้อาวุโสขั้นที่ ๗ แห่งสำนักหอศิลาเหนือเลือกนั่งขัดสมาธิเหนือ **ตาน้ำวิญญาณ** ใต้ศาลากลางเขา เปิดเส้นชีพจรเชื่อมเข้ากับรากปราณขุนเขาโดยตรง พิธีนั้นมอบอายุขัยเพิ่มแก่เขาห้าสิบสองปีเต็ม ทำให้ค่ายกลคุ้มครองสำนักมั่นคงครึ่งศตวรรษ ทว่าราคาปรากฏตั้งแต่วันรุ่งขึ้น พอก้าวเท้าเลยแนวหินหลักเขตหน้าประตูเขาเพียงก้าวเดียว ชีพจรในอกก็บีบรัดราวถูกเชือกเหล็กกระชากจนกระอักเลือด ตลอดห้าสิบสองปีที่เหลือ กัวเจิ้นซานไม่เคยได้เห็นแม่น้ำใหญ่หรือเมืองหลวงอีกเลย เขานั่งเฝ้าลานหินจนสิ้นลมพร้อมตาน้ำที่หม่นแสงไปเจ็ดวัน

### กรณีที่ ๒ (ยุคกลาง): คืนพันธะหมาป่าขาดสะบั้นและการตื่นกลางคันของผู้อาวุโสผนึกเวลา
* **กาลเวลา:** ยุคที่ ๖๘ ปีที่ ๗๔๐ · เดือนเก้าสารทปลาย วันที่ ๒๗ (ศ.ท. ๖๗,๗๔๐)
* **บริบท:** กลางเปลวเพลิง **สงครามราชสำนักมารจันทร์เลือด** ปะทะพันธมิตรกระบี่ ณ ช่องเขาชายแดนประจิม–อุดร

คืนลมสารทปลายคลุ้งกลิ่นสนิมเหล็ก **เผยชางเย่** นายกองสายควบคุมอสูรขั้นที่ ๖ ถูกกองซุ่มโจมตีฝ่ายมารจันทร์เลือดปิดล้อมกลางช่องเขา ข้างกายเขาคือ **ไป๋เหลียน** หมาป่าพันธะโลหิตขนสีเงินที่ผูก **พันธะแบ่งปันอายุขัยสัตว์อสูร** แน่นแฟ้น สายใยชีวิตนั้นมอบอายุขัยเพิ่มแก่เผยชางเย่สามสิบสองปี ทำให้เขาคงพละกำลังวัยฉกรรจ์แม้อายุจริงล่วงเข้าหนึ่งร้อยสี่สิบปี ทว่าเมื่อคมหอกอาบปราณมารพุ่งเข้าแผ่นหลัง ไป๋เหลียนกระโจนรับแทนจนร่างขาดครึ่ง ทันทีที่หมาป่าคู่หูสิ้นใจ พันธะชีวิตก็ขาดสะบั้น เผยชางเย่กระอักเลือดสดคำโต แรงสะท้อนฉีกพลังชีวิตหายไปกว่าหนึ่งในสามในพริบตา อายุขัยสามสิบสองปีที่ยืมมาพลันสลายหายไปพร้อมความอบอุ่นในอก ชั่วข้ามคืนนั้น ผมดำขลับของเขาเปลี่ยนเป็นสีขาวโพลนทั้งศีรษะ

ห่างออกไปสี่สิบลี้บนยอดเขาเหมันต์ ค่ายกลเตือนภัยของสำนักกระบี่หิมะขาวถูกทัพมารตีแตกในคืนเดียวกัน แรงสั่นสะเทือนปลุก **ถังซู่ชิง** ผู้อาวุโสขั้นที่ ๘ ซึ่งเข้า **จำศีลผนึกเวลา** ชะลอความชราร้อยละเก้าสิบมานานหนึ่งร้อยยี่สิบสี่ปีให้ตื่นกลางคัน กาลเวลาร้อยยี่สิบสี่ปีภายนอกทำให้ร่างกายนางแก่ลงเพียงสิบสองปีเศษ นางผลักแผ่นศิลาออกมาสังหารแม่ทัพมารสามนายจนทัพศัตรูแตกพ่ายก่อนรุ่งสาง ทว่าเมื่อควันไฟจางลง นางกวาดตามองศิษย์หลายสิบคนที่คุกเข่าคำนับโดยไม่รู้จักชื่อใครเลยแม้แต่คนเดียว เจ้าสำนักหนุ่มตรงหน้าคือเหลนของศิษย์หญิงที่นางเคยสอนจับกระบี่เมื่อศตวรรษก่อน ห้องชาเก่าถูกรื้อเป็นหออาวุธ ต้นเหมยหน้าเรือนตายไปสี่สิบปีแล้ว นางชนะศึกคืนนั้น แต่เพิ่งตระหนักว่าราคาของการจำศีลผนึกเวลา คือการตื่นมาปกป้องบ้านที่ไม่มีผู้ใดจำเสียงเรียกชื่อของตนได้อีกแล้ว

### กรณีที่ ๓ (ยุคเจ็ดยุคแห่งฎีกากระดาษ): คดีสมุดปกดำเรื่องการค้าตาน้ำและปฏิญญาห้าวิถี
* **กาลเวลา:** ยุคที่ ๙๒ ปีที่ ๕๑๔ · เดือนสิบสองเหมันต์ลึก วันที่ ๙ (ศ.ท. ๙๑,๕๑๔)
* **บริบท:** กลางยุค **เจ็ดยุคแห่งฎีกากระดาษ** (ยุคที่ ๘๙–๙๕) สองพันสองร้อยปีหลังลงนาม **กฎบัตรสหพันธ์องค์กรกลางเจ็ดหอ** (ศ.ท. ๘๙,๓๑๐)

วันที่เก้า เดือนสิบสองเหมันต์ลึก ยุคที่ ๙๒ ปีที่ ๕๑๔ **หลัวชิงเยี่ยน** ผู้ตรวจการอาวุโส **หอผนึกชาด** ร่วมกับตุลาการ **หอพิพากษากลาง** เข้าตรวจค้นสำนักเหมืองแร่รอยต่อบูรพา–ทักษิณ หลังพบว่าสำนักดังกล่าวใช้สัญญาหนี้บังคับผู้อาวุโสขั้นที่ ๖ สามรายให้ **ผูกชีพจรแกนวิญญาณสำนัก** เข้ากับตาน้ำเหมือง เพื่อตรึงไว้เฝ้าเหมืองตลอดชีวิต ซ้ำยังแอบขาย *"โอสถผลัดแก่นเม็ดที่หก"* ปลอมแก่ขุนนางชราในสามมหาจักรวรรดิโดยอ้างว่าล้างความดื้อยาได้

คณะชันสูตรพบว่าผู้อาวุโสทั้งสามมีชีพจรแตกร้าวจากการฝืนใจผูกตาน้ำ ส่วนขุนนางที่กลืนโอสถปลอมล้วนได้รับพิษโลหะหนักจนสิ้นลมก่อนกำหนด **หอพิพากษากลาง** จึงยุบสำนักนั้น ลงชื่อเจ้าสำนักในสมุดปกดำ และให้หลัวชิงเยี่ยนเรียบเรียง **ปฏิญญาห้าวิถีต่อชะตา** ประกาศทั่วเก้าแคว้นว่าทั้ง **เป่ยหมิง**, **ตงหวง**, **ซีหรง**, ห้ารัฐกันชน และสำนักทุกฝ่ายล้วนอยู่ใต้กฎชราภาพสมมาตรเดียวกัน ห้ามบังคับขืนใจผู้อาวุโสผูกตาน้ำหรือจำศีลเด็ดขาด สิบเจ็ดปีต่อมา หลัวชิงเยี่ยนในวัยหนึ่งร้อยเก้าสิบสี่ปีปฏิเสธโอสถทุกเม็ด จิบชาอุ่นจนหมดถ้วยแล้วสิ้นลมอย่างสงบ เป็นแบบอย่างของวิถีที่หกซึ่งไม่มีชื่อในตำรา — การรู้เวลาวางพู่กันลง

### กรณีที่ ๔ (ยุคที่ ๑๐๑ ปัจจุบัน): ผู้ตื่นจากยุคคงเฉิงกลางวันเปิดประตูสุสานสวนสวรรค์
* **กาลเวลา:** ยุคที่ ๑๐๑ ปีที่ ๑ · เดือนสามวสันต์ปลาย วันที่ ๑๘ (ศ.ท. ๑๐๐,๐๐๑)
* **บริบท:** สามวันหลัง **รอยแยกบรรพกาลแห่งสุสานสวนสวรรค์** เปิดออก (วันที่ ๑๕ เดือนสามวสันต์ปลาย) ท่ามกลางแรงกดดันสงครามไร้โลหิตใน **หุบเขาหยุนเหอ**

เช้าวันที่สิบแปด เดือนสามวสันต์ปลาย ยุคที่ ๑๐๑ ปีที่ ๑ กลางตลาดเช้าตีนเขาชิงซีและ **ท่าเรือหลิ่ววาน** ชายชราในอาภรณ์ผ้าป่านสีครามซีดทรงโบราณล้วง **เหรียญศิลาแปดเหลี่ยมลายหอคอย** วางบนถาดซาลาเปา แม่ค้ามองอย่างงุนงงเพราะมิใช่ศิลาวิญญาณสองเกณฑ์หรือตั๋วเงิน **หมู่ตึกวาณิชย์หลงเหมิน** ซ้ำสำเนียงที่เขาถามหา *"ถนนใหญ่สู่นครคงเฉิง"* ยังแปร่งหูราวคำร้องงิ้วโบราณ

เขาคือ **เฮ่ออวิ๋นจื่อ** — **ผู้จำศีลข้ามยุคที่ตื่นขึ้นตามธรรมชาติ** เมื่อสามวันก่อน แรงสั่นสะเทือนจากการเปิดรอยแยกสุสานสวนสวรรค์และแรงกดดันสงครามทั่วอนุทวีปทำให้ผนึกศิลาค้างชีพจรในถ้ำร้างตะวันตกแตกร้าวลง หลังหลับใหลข้ามกาลเวลากว่าหกหมื่นหกพันปีตั้งแต่ปลายยุคที่ ๓๕ ตบะขั้นที่ ๘ เดิมเสื่อมถอยเหลือขั้นที่ ๖ และชีพจรที่เหลือยืดไปได้อีกเพียงสิบเก้าปีเท่านั้น เขายืนมอง **หลักศิลาสองชื่อ** แล้วหัวเราะแผ่วเบา เพราะแม้แต่นครหอคอยคงเฉิงที่เขาตั้งใจรอเฝ้าดู บัดนี้ก็กลายเป็นเพียงประตูมิติลอยฟ้าที่เปิดทุกหนึ่งร้อยปี คืนนั้นเขาพบผู้อาวุโสสำนักเล็กในหยุนเหอที่กำลังลังเลจะเข้าจำศีลผนึกเวลา เฮ่ออวิ๋นจื่อวางเหรียญศิลาโบราณลงข้างถ้วยชาแล้วเอ่ยว่า *"หากเจ้าหลับเพื่อรอวันพรุ่งนี้ จงถามใจตนก่อนเถิดว่าวันที่ไม่มีใครรู้จักชื่อเจ้าอีกต่อไป ยังใช่พรุ่งนี้ที่เจ้าอยากตื่นมาพบหรือไม่"*

## ๓. ทำเนียบบุคคลสำคัญข้ามห้าวิถีต่อชะตา (๖ ท่าน)

### ๑. แพทย์โอสถอาวุโส เสิ่นจิงเหอ — "ผู้ชั่งน้ำหนักความดื้อยา"
* **ยุคสมัยและระดับพลัง:** ยุคที่ ๓๔–๓๕ (ศ.ท. ๓๔,๐๐๐) · ขั้นที่ ๕ • วิญญาณแรกกำเนิด (สิ้นอายุขัยวัย ๒๑๘ ปี)
* **บทบาทและวิถี (โอสถดื้อยา):** แพทย์ผู้บันทึกเส้นโค้งความดื้อยาห้าขั้น (ร้อยละหนึ่งร้อย ห้าสิบ ยี่สิบห้า สิบ และศูนย์) เป็นคนแรกหลังอาจารย์สิ้นลมทั้งที่กลืนเม็ดที่ห้า เขาวางจรรยาบรรณให้ **หุบเขาโอสถบัวหยก** และหอโอสถรุ่นหลังจดจำนวนเม็ดลงใบสั่งยาทุกครั้ง

### ๒. ผู้อาวุโสศิลารากเขา กัวเจิ้นซาน — "เสาหินมีลมหายใจแห่งหอศิลาเหนือ"
* **ยุคสมัยและระดับพลัง:** ยุคที่ ๓๔–๓๕ (ศ.ท. ๓๔,๐๐๐) · ขั้นที่ ๗ • หลอมรวมสุญญากาศ (สิ้นอายุขัยวัย ๓๔๖ ปี รวมเวลาผูกตาน้ำ ๕๒ ปี)
* **บทบาทและวิถี (ผูกชีพจรตาน้ำ):** ผู้อาวุโสผู้สละอิสรภาพตลอดห้าสิบสองปีสุดท้ายผูกชีพจรกับตาน้ำสำนัก เขาแกะสลักแผนที่แม่น้ำจากคำบอกเล่าของศิษย์และจารึกคำเตือนบนเสาประตูเขาว่า *"ตาน้ำรับได้เฉพาะชีพจรของผู้รักภูเขานี้จริง หากผูกเพราะจำยอม ภูเขาจะกลายเป็นกรงขังตั้งแต่วันแรก"*

### ๓. นายกองหมาป่าเหมันต์ เผยชางเย่ — "ผู้ผมขาวในคืนเดียว"
* **ยุคสมัยและระดับพลัง:** ยุคที่ ๖๘ (ศ.ท. ๖๗,๗๔๐) · ขั้นที่ ๖ • แปลงวิญญาณ (สิ้นอายุขัยวัย ๑๕๑ ปี รอดจากแรงสะท้อนได้อีก ๑๑ ปี)
* **บทบาทและวิถี (พันธะอสูร):** นายกองผู้ผูกพันธะชีวิตร่วมกับหมาป่าพันธะโลหิต **ไป๋เหลียน** (+๓๒ ปี) เมื่อไป๋เหลียนรับคมหอกแทนจนตาย แรงสะท้อนฉีกพลังชีวิตเขาหายไปกว่าหนึ่งในสามและผมขาวโพลนในคืนเดียว เขาจึงอุทิศช่วงท้ายสอนศิษย์ว่าพันธะอสูรคือการฝากหัวใจไว้ในอีกชีวิตหนึ่ง

### ๔. ผู้อาวุโสผนึกเหมันต์ ถังซู่ชิง — "กระบี่ที่ตื่นมาในบ้านของคนแปลกหน้า"
* **ยุคสมัยและระดับพลัง:** ยุคที่ ๖๗–๖๘ (ศ.ท. ๖๗,๗๔๐) · ขั้นที่ ๘ • มหาบรรลุ (วัยศักราช ๔๙๒ ปี / วัยชีวภาพ ๓๘๐ ปี)
* **บทบาทและวิถี (จำศีลผนึกเวลา):** ผู้อาวุโสหญิงผู้จำศีลชะลอชราร้อยละเก้าสิบนานหนึ่งร้อยยี่สิบสี่ปี ถูกปลุกกลางคันในศึกมารจันทร์เลือดจนกอบกู้สำนักได้ แต่ต้องเผชิญความอ้างว้างท่ามกลางศิษย์รุ่นเหลน บันทึกของนางก่อเกิดธรรมเนียม *"ผู้เฝ้าจดหมายเหตุคนตื่น"* ในสำนักใหญ่ทั่วหล้า

### ๕. ผู้ตรวจการหอผนึกชาด หลัวชิงเยี่ยน — "พู่กันแห่งปฏิญญาห้าวิถี"
* **ยุคสมัยและระดับพลัง:** ยุคที่ ๙๒ (ศ.ท. ๙๑,๕๑๔) · ขั้นที่ ๕ • วิญญาณแรกกำเนิด (สิ้นอายุขัยตามธรรมชาติวัย ๑๙๔ ปี)
* **บทบาทและวิถี (พยานห้าวิถีและการปลงตก):** ผู้ตรวจการ **หอผนึกชาด** ผู้คลี่คลายคดีบังคับผูกตาน้ำและออก **ปฏิญญาห้าวิถีต่อชะตา** ใต้ตรา **สหพันธ์องค์กรกลางเจ็ดหอ** พิสูจน์ด้วยวาระสุดท้ายอันสงบว่าการรู้เวลาวางมือย่อมทรงเกียรติไม่แพ้การฝืนชะตา

### ๖. ผู้ตื่นนิรนามแห่งยุคคงเฉิง เฮ่ออวิ๋นจื่อ — "แขกจากหกหมื่นปีก่อน"
* **ยุคสมัยและระดับพลัง:** ยุคที่ ๓๕ → ยุคที่ ๑๐๑ (ศ.ท. ๑๐๐,๐๐๑) · อดีตขั้นที่ ๘ ถดถอยเหลือขั้นที่ ๖ • แปลงวิญญาณ (อายุขัยเหลือราว ๑๙ ปี)
* **บทบาทและวิถี (ผู้จำศีลข้ามยุค):** อดีตผู้พิทักษ์หอคอยยุคคงเฉิงที่ตื่นขึ้นหลังรอยแยกสุสานสวนสวรรค์สั่นสะเทือน พำนักเร่ร่อนแถบ **หุบเขาหยุนเหอ** และ **ท่าเรือหลิ่ววาน** แลกน้ำชาด้วยแรงงานเพราะเหรียญศิลาโบราณสิ้นค่าไปแล้ว

## ๔. กายวิภาคและตารางเปรียบเทียบราคาของห้าวิถีต่อชะตา

| วิถีต่อชะตา | ผลลัพธ์ต่ออายุขัย | เงื่อนไขสำคัญ | ราคาที่ต้องจ่ายและจุดอ่อน | ผลกระทบต่อสำนักและจิตใจ |
| :--- | :--- | :--- | :--- | :--- |
| **๑. จำศีลผนึกเวลา** | ชะลอชราลง **ร้อยละ ๙๐** | ขั้นที่ ๕ ขึ้นไป มีห่วงค้างคา | ตัดขาดกิจการสำนักและการสำรวจ ตื่นกลางคันทันทีเมื่อสำนักวิกฤตหรือเกิดแรงกระเพื่อมวาสนา | ช่องว่างระหว่างรุ่น ตื่นมาเป็นคนแปลกหน้าในบ้านตน |
| **๒. โอสถดื้อยา** | ลดทอนตามลำดับ **๑๐๐% → ๕๐% → ๒๕% → ๑๐% → ๐%** | โอสถผลัดแก่นระดับสูงและทรัพย์สิน | ความดื้อยาสะสมถาวร เม็ดที่ห้าขึ้นไปไร้ฤทธิ์ ไม่อาจพึ่งโอสถเป็นอมตะ | ทางเลือกระหว่างกลืนเองกับสละเม็ดแรกให้อาจารย์ใกล้สิ้นลม |
| **๓. ผูกชีพจรตาน้ำ** | เพิ่มอายุขัย **๓๕ – ๖๐ ปี** | ขั้นที่ ๖ ขึ้นไป ภักดีต่อสำนักแท้จริง | **ก้าวพ้นเขตสำนักไม่ได้ตลอดชีวิต** ฝืนข้ามหลักเขตชีพจรตีกลับสาหัส | ได้ปราการเฝ้าบ้านที่มั่นคง แต่เสียกำลังสำรวจและอิสรภาพ |
| **๔. พันธะสัตว์อสูร** | เพิ่มอายุขัย **๒๐ – ๔๐ ปี** | อสูรคู่หูผูกพันลึกซึ้งหรือปลุกสายเลือด | อสูรคู่หูตาย อายุขัยส่วนเสริมขาดทันทีพร้อม **แรงสะท้อนบาดเจ็บสาหัส** | อสูรคู่หูกลายเป็นจุดตายทางยุทธวิธีและแผลใจลึกที่สุด |
| **๕. ผู้ตื่นข้ามยุค** | หลับข้ามมหายุค ตื่นพร้อมอายุขัยจำกัด **๑๕ – ๒๔ ปี** | ตื่นเฉพาะเมื่อผนึกแดนลับแตกหรือแรงกดดันสงครามโลกพุ่งสุดขีด | ตบะเสื่อมถอยและสูญเสียทุกสายสัมพันธ์ในโลกที่เปลี่ยนไปหมด | พาความรู้สาบสูญคืนแผ่นดิน แต่เปลี่ยวเหงาข้ามกาลเวลา |

กฎชราภาพใต้ฟ้าปิดสมมาตรทั่วหล้าโดยไร้ข้อยกเว้น **มหาเซียนกระบี่เทียนหยวน** แห่งยอดเขากระบี่สวรรค์เทียนเจี้ยนต้องคงชีพจรด้วยผนึกกระบี่เหมันต์ ขณะที่ **จอมมารบรรพกาลจิ่วหมิง** และ **เสวี่ยหมิง** แห่งภาคีมารกลืนสวรรค์เก้าโลหิตสลับวาระหลับในโลงหยกโลหิต ส่วนแม่ทัพและขุนนาง **เป่ยหมิง**, **ตงหวง**, และ **ซีหรง** ต่างติดกรงความดื้อยาโอสถเช่นเดียวกับสำนักเล็ก ขณะเดียวกัน ผู้อาวุโสจิตใจสงบจำนวนมากกลับเลือก **"วิถีที่หก"** — ปฏิเสธทั้งห้าวิถี ถ่ายทอดวิชา แล้วหลับตาจากไปอย่างสง่างามตามธรรมชาติ

## ๕. ปมสังเกตการณ์ยุคที่ ๑๐๑ และเหตุการณ์ผู้อาวุโสสำนัก

1. **คลื่นปลุกผู้จำศีลข้ามยุคในปีที่ ๑ และปีที่ ๔ ("ปีสามเหตุ"):** หลัง **รอยแยกบรรพกาลแห่งสุสานสวนสวรรค์** เปิดในเดือนสามวสันต์ปลาย ปีที่ ๑ **หอผนึกชาด** กังวลว่าเมื่อ **ยุคที่ ๑๐๑ ปีที่ ๔** มาถึง — ที่ **แม่น้ำหนี่สุ่ยไหลย้อน**, **เหมันต์สุริยคราสหยินลึก**, และ **คืนมหาพิธีดับสุริยคราสโลหิต** บรรจบกันในเดือนสิบสองเหมันต์ลึก — ผนึกโบราณชายแดนอาจแตกร้าวเพิ่มจนปลุกอดีตขุนพลกลียุคขึ้นกลางแผ่นดิน
2. **รอยร้าวใต้โลงหยกโลหิตและการคลายผนึกกระบี่เหมันต์:** การคลายผนึกของ **เทียนหยวน** และการขยับตัวของ **เสวี่ยหมิง** ใต้โลงหยกโลหิตสะท้อนราคาทางการเมืองของการจำศีล — ยิ่งหลับนาน รอยร้าวระหว่างผู้อาวุโสที่ตื่นขึ้นกับรุ่นศิษย์ผู้กุมอำนาจอย่าง **จิ่วหมิง** ก็ยิ่งแหลมคม
3. **ทางแยกของผู้อาวุโสสำนักในหุบเขาหยุนเหอ:** เมื่อผู้อาวุโสก้าวสู่บั้นปลายชีวิต สำนักต้องเลือกระหว่างปล่อยให้จากไปอย่างสงบ ทุ่มโอสถภายใต้เส้นโค้งดื้อยา เชิญเข้าจำศีลเป็นไพ่ตายยามถูกบุก หรือยอมให้ผูกชีพจรกับตาน้ำสำนักแลกกับการสูญเสียนักสำรวจไปตลอดกาล
4. **การลอบสังหารอสูรคู่หูและคดีโอสถปลอม:** สายลับ **นิกายพิรุณหยินเงาโลหิต** ใช้ยุทธวิธีลอบสังหารอสูรคู่หูเพื่อโค่นยอดฝีมือด้วยแรงสะท้อน ขณะที่ **หุบเขาโอสถบัวหยก** และ **สหพันธ์องค์กรกลางเจ็ดหอ** กำลังกวาดล้างขบวนการค้า *"ยาถอนความดื้อยาโอสถ"* ปลอมที่หลอกขายขุนนางชรา
5. **รอยเท้าของเฮ่ออวิ๋นจื่อกับนครเมฆาลอยคงเฉิง:** **เฮ่ออวิ๋นจื่อ** พำนักแถบเชิงเขาชิงซีและ **ท่าเรือหลิ่ววาน** ด้วยอายุขัยที่เหลือไม่ถึงยี่สิบปี สำนักที่เข้าหาด้วยความสุภาพและช่วยติดตามข่าวการเปิดประตู **นครเมฆาลอยคงเฉิง** ในยุคที่ ๑๐๑ ปีที่ ๗ อาจได้รับภูมิปัญญาค่ายกลโบราณที่สาบสูญไปหกหมื่นปี

## ๖. รายการตรวจสอบความสอดคล้องแกนหลัก

| หัวข้อตรวจสอบ | สถานะ | รายละเอียดการยืนยัน |
| :--- | :---: | :--- |
| **ปฏิทินพันปีและเดือนไทยมาตรฐาน** | ผ่าน | คำนวณศักราชตรงสูตรครบสี่ยุค (`ศ.ท. ๓๔,๐๐๐`, `๖๗,๗๔๐`, `๙๑,๕๑๔`, `๑๐๐,๐๐๑`) และใช้เฉพาะเดือนไทยมาตรฐานสิบสองเดือน |
| **ครบห้าวิถีต่อชะตาและข้อแลกเปลี่ยน** | ผ่าน | ครบจำศีลผนึกเวลา (๙๐% / ตื่นกลางคัน), โอสถดื้อยา (๑๐๐→๕๐→๒๕→๑๐→๐%), ผูกตาน้ำ (+๓๕–๖๐ ปี / ห้ามออกเขต), พันธะอสูร (+๒๐–๔๐ ปี / เจ็บสะท้อน), และผู้ตื่นข้ามยุค (๑๕–๒๔ ปี) อย่างสมมาตรทุกสำนัก |
| **เพดานโลกเบื้องล่างและสามปริศนาปลายเปิด** | ผ่าน | ยึดเพดานโลกเบื้องล่างขั้นที่ ๙ อย่างเคร่งครัด ไม่มีระดับพลังเกินเพดานโลกเบื้องล่างหรือการทะลวงฟ้าขึ้นแดนบน และคงสามปริศนาปลายเปิดไว้ตามเดิม |
| **ความบริสุทธิ์ของภาษาและกฎปลอดคำซ้ำ** | ผ่าน | ภาษาไทยวรรณศิลป์ล้วน ปราศจากรหัสโค้ดภาษาอังกฤษดิบ ปลอดพล็อตซ้ำซากต้องห้ามตามกฎแกนหลัก และไร้ชื่อซ้ำซ้อนกับคัมภีร์แม่บท |
