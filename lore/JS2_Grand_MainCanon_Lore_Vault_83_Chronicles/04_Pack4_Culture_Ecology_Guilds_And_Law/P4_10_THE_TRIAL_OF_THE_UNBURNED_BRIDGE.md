# ปูมจารีตและนิติศาสตร์ยุทธภพ: คดีสะพานไม่ยอมไหม้ — การไต่สวนครั้งประวัติศาสตร์ที่วางกฎหมายชดเชยความเสียหายจากศึกผู้บ่มเพาะ

> **เอกสารตำนานกระแสหลักประจำชุดวัฒนธรรม นิเวศ และปริศนาแห่งอนุทวีป · ฉบับสมบูรณ์ข้ามสี่ยุคสมัย**  
> **ช่วงเวลาที่ครอบคลุม:** ยุคที่ ๘๓ ปีที่ ๖๐๐ ถึง ยุคที่ ๑๐๑ ปีที่ ๑ (ศ.ท. ๘๒,๖๐๐ – ๑๐๐,๐๐๑)  
> **แกนเรื่องหลัก:** คำพิพากษาประวัติศาสตร์เมื่อคนเฝ้าสะพานสามัญชนและเสมียนน้อยแห่ง **หอจดหมายเหตุกลาง** ปฏิเสธถุงศิลาวิญญาณปิดปาก แล้วลากยอดฝีมือขั้นที่ ๘ ทั้งผู้ชนะและผู้แพ้ขึ้นบัลลังก์ชดใช้หนี้แผ่นดิน สู่การถือกำเนิดของ **กฎหมายชดเชยความเสียหายจากศึกผู้บ่มเพาะ** ที่ยังคงบังคับใช้ทั่ว **แคว้นอิสระหยุนเหอ** และ **สิบเก้าสำนักเสาหลัก** ในยุคที่ ๑๐๑

## ๑. ข้อมูลพื้นฐานและหมุดยึดจักรวาลหลัก (Metadata & Canon Anchors)

| หัวข้อข้อมูล | รายละเอียดตามคัมภีร์แม่บทแห่งอนุทวีปเทียนกู่ |
| :--- | :--- |
| **ชื่อบันทึกอย่างเป็นทางการ** | **คดีสะพานไม่ยอมไหม้ และปฐมบทกฎหมายชดเชยความเสียหายจากศึกผู้บ่มเพาะ** |
| **สถานที่เกิดเหตุปฐมบท** | **ตลาดท่าสะพานหินขาวชิงสือ** (ลำน้ำสาขาตอนกลางของ **ลุ่มน้ำหยุนเหอ** ห่างจาก **นครสองแควหยุนเหอ** ไปทางตะวันตกเฉียงเหนือราวสามสิบห้าลี้) |
| **องค์กรพิจารณาคดีหลัก** | **สหพันธ์องค์กรกลางเจ็ดหอ** (ยุคที่ ๘๓ อยู่ในรูปภาคีเจ็ดหอเดิมก่อนลงนามกฎบัตรใหญ่ ณ ศาลาศิลาเจ็ดเหลี่ยมในปี ศ.ท. ๘๙,๓๑๐) นำโดย **หอจดหมายเหตุกลาง**, **หอพิพากษากลาง**, **หอผนึกชาด** และ **ศาลล่าค่าหัว** |
| **ขอบเขตช่วงเวลา** | ยุคที่ ๘๓ (ศ.ท. ๘๒,๖๐๐) · ยุคที่ ๙๐ (ศ.ท. ๘๙,๓๑๐) · ยุคที่ ๑๐๐ (ศ.ท. ๙๙,๔๑๘) · ยุคที่ ๑๐๑ (ศ.ท. ๑๐๐,๐๐๑) |
| **ฐานอ้างอิงหลักในคลังตำนาน** | **เล่มที่ ๙๕** (*สมุดปกดำแห่งคนบาปไร้ข้อแก้ตัว และกฎบัตรสหพันธ์องค์กรกลางเจ็ดหอ*) และ **เล่มที่ ๗๐** (*ทำเนียบสนธิสัญญา บัญชีศิลาวิญญาณ กฎบัตรหอการค้า และกฎหมายยุทธภพไร้ลายลักษณ์*) เชื่อมโยงกับ **ประมวลแท่นหินชั่งโลหิต** และ **กฎน้ำบ่อไม่ยุ่งกับน้ำคลอง** |
| **คู่กรณีต้นเรื่อง** | โจทก์: **หานสือ** (คนเฝ้าสะพานสามัญชน) และ **ซูเหวินเจี้ยน** (เสมียนน้อยหอจดหมายเหตุกลาง) · จำเลยร่วม: **เจี้ยนกูเสวี่ย** (ผู้ชนะขั้นที่ ๘ สายกระบี่แดนเหนือ) และ **ฉื่อเหยียนขุย** (ผู้แพ้ขั้นที่ ๘ สายดาบอัคคีแดนประจิม) |
| **ผู้พิทักษ์กฎหมายในยุคที่ ๑๐๑** | มหาตุลาการหญิง **ซ่งเยี่ยนชิง** (ประธานเวียนสหพันธ์องค์กรกลางเจ็ดหอ) ร่วมกับ **ศาลากลางหุบเขาหยุนเหอ** และเครือข่ายบัญชีค้ำประกันของ **หมู่ตึกวาณิชย์หลงเหมิน** |

ในพงศาวดารยุทธภพตลอดแสนปี บทกวีมักขับขานถึงคมกระบี่ผ่าเมฆาและเปลวปราณขั้นที่ ๘ ที่สั่นสะเทือนขุนเขา ทว่าน้อยครั้งนักจะมีผู้หันมาถามคำถามอันเรียบง่ายและแสบสันที่สุดของสามัญชนเบื้องล่างว่า *เมื่อยอดฝีมือขั้นที่ ๘ สองคนประลองกันเพื่อรักษาหน้าตา แล้วคลื่นปราณกวาดตลาดริมน้ำกับสะพานหินของชาวบ้านพังพินาศ ใครกันเล่าที่เป็นผู้ควักเงินสร้างมันขึ้นมาใหม่*

ก่อนยุคที่ ๘๓ คำตอบของยุทธภพมีเพียงความเงียบงันกับเศษเงินทำทานที่โยนทิ้งไว้ราวเศษกระดูก ราชสำนักไม่อาจส่งทัพหลวงจับกุมยอดฝีมือข้ามแดนได้เพราะติดกรอบ **กฎน้ำบ่อไม่ยุ่งกับน้ำคลอง** ส่วนสำนักยุทธ์ต่างถือว่าชีวิตและหลังคาเรือนปุถุชนคือฝุ่นผงที่บังเอิญขวางทางวาสนา กระทั่งปี ศ.ท. ๘๒,๖๐๐ สะพานหินบะซอลต์เก่าแก่แห่งท่าตลาดชิงสือปฏิเสธที่จะพังทลายลงใต้เปลวอัคคีขั้นที่ ๘ และชายชราไร้ลมปราณหนึ่งคนกับเสมียนหมึกดำอีกหนึ่งคนปฏิเสธที่จะก้มลงเก็บถุงศิลาวิญญาณปิดปาก คดีครั้งนั้นจึงกลายเป็นตะปูเหล็กดอกแรกที่ตอกตรึงความรับผิดชอบลงบนบ่าของจอมยุทธ์ทั้งอนุทวีป

## ๒. สี่มหาเหตุการณ์ข้ามสี่ยุคสมัย (Four Multi-Era Chronological Events)

### เหตุการณ์ที่ ๑ · ยุคที่ ๘๓ (คืนประลองเหนือท่าตลาดชิงสือและการปฏิเสธถุงเงินปิดปาก)
**วันเวลา:** ยุคที่ ๘๓ ปีที่ ๖๐๐ · เดือนห้าสุริยัน วันที่ ๑๔ ถึง เดือนเจ็ดสารทแรก วันที่ ๙ (ศ.ท. ๘๒,๖๐๐)  
**สถานที่:** ตลาดท่าสะพานหินขาวชิงสือ และศาลาไต่สวนชั่วคราวแห่งภาคีเจ็ดหอริมคุ้งน้ำหยุนเหอ

บ่ายคล้อยวันที่สิบสี่ **เดือนห้าสุริยัน** ยอดฝีมือขั้นที่ ๘ สองนามผู้มีหนี้แค้นด้านศักดิ์ศรียาวนานยี่สิบปี — **เจี้ยนกูเสวี่ย** เจ้าสำนักสาขาสายกระบี่เหมันต์แดนอุดร และ **ฉื่อเหยียนขุย** ผู้อาวุโสสายดาบอัคคีแดนประจิม — เผชิญหน้ากันโดยมิได้นัดหมายกลางอากาศเหนือ **ตลาดท่าสะพานหินขาวชิงสือ** ทั้งสองถือทิฐิไม่ยอมถอยออกจากแนวลมด้วยเกรงเสียหน้าต่อศิษย์ติดตาม จึงปลดปล่อยเจตจำนงศาสตราขั้นที่ ๘ เข้าห้ำหั่นกันเหนือหลังคาตลาดสูงเพียงสามสิบจั้ง

เพียงเจ็ดกระบวนท่า คลื่นกระบี่น้ำแข็งปะทะพายุดาบเพลิงจนเกิดแรงอัดปราณระเบิดลงสู่พื้นเบื้องล่าง แผงผ้าไหม ยุ้งข้าว และโรงเตี๊ยมสองฟากฝั่งแหลกเป็นเถ้าถ่านภายในครึ่งถ้วยชา ชาวบ้านและลูกหาบเสียชีวิตสิบเก้าคน บาดเจ็บพิการสี่สิบเจ็ดคน หนึ่งในผู้ตายคือ **หานตง** บุตรชายคนเดียวของคนเฝ้าสะพานที่วิ่งย้อนไปเข็นเกวียนข้าวของหญิงชราออกจากกลางสะพาน ทว่าเมื่อควันจางลง โค้งสะพานหินบะซอลต์ผสมปูนเปลือกหอยโบราณแห่งท่าชิงสือยังคงตั้งตระหง่านไม่ยุบถล่ม เหลือเพียงผิวศิลาด้านบนที่ถูกเผาดำเกรียมเป็นร่องกระบี่และรอยดาบคู่ขนานราวตราประทับแห่งความอัปยศ

ครั้น **เจี้ยนกูเสวี่ย** ฟันทำลายเกราะปราณของ **ฉื่อเหยียนขุย** จนอีกฝ่ายกระอักโลหิตถอยร่น เขาลอยตัวลงแตะราวสะพาน โยนถุงแพรบรรจุศิลาวิญญาณระดับกลางสามสิบก้อนลงบนกองเถ้าหน้าเรือนเก็บค่าผ่านทาง แล้วเอ่ยเสียงเรียบว่า *"ถือเป็นเมตตาชดเชยแก่ผู้เคราะห์ร้ายที่ได้ยลวิถีกระบี่ขั้นแปด จงแบ่งกันซ่อมหลังคาเสีย"*

ทว่า **หานสือ** ชายชราวัยหกสิบสี่ปีผู้เฝ้าสะพานมาทั้งชีวิตกลับมิได้คุกเข่า เขาเดินกะเผลกข้ามศพบุตรชายไปหยิบถุงแพรนั้นขึ้น วางคืนลงบนแท่นหินเปื้อนเลือดตรงหน้าจอมยุทธ์ทั้งสอง พร้อมกล่าวประโยคที่จารึกไว้ในหน้าแรกของสำนวนคดีจนถึงยุคที่ ๑๐๑ ว่า *"ศิลาสามสิบก้อนซื้อหลังคาไม้ได้ แต่ซื้อสิทธิให้ท่านโยนความตายลงหัวพวกข้าแล้วเดินจากไปเยี่ยงเจ้าบุญนายคุณไม่ได้ หากท่านเรียกว่าเมตตา แปลว่าพวกข้าเป็นหนี้บุญคุณที่ท่านไม่ฆ่าให้หมดตลาดกระนั้นหรือ"*

ในยามที่เจี้ยนกูเสวี่ยจะสะบัดแขนเสื้อจากไป **ซูเหวินเจี้ยน** เสมียนหนุ่มวัยยี่สิบหกปีแห่ง **หอจดหมายเหตุกลาง** ซึ่งเดินทางมาตรวจบัญชีค่าผ่านสะพานในวันนั้นพอดี ได้ก้าวออกมายืนเคียงข้างชายชรา เขาสวมเสื้อคลุมผ้าป่านสีหม่น ถือขวดดินเผาเคลือบขี้ผึ้งสำหรับเก็บตัวอย่างเถ้าปราณและเศษคลื่นดาบ-กระบี่ที่ฝังในเนื้อหิน ก่อนประกาศปิดผนึกสะพานชิงสือเป็นพยานวัตถุ และยื่นฎีการ้องทุกข์ร่วมต่อภาคีเจ็ดหอในวันรุ่งขึ้น โดยระบุชื่อ **ทั้งผู้ชนะและผู้แพ้** เป็นจำเลยร่วม

ตลอดห้าสิบห้าวันระหว่าง **เดือนหกพิรุณร้อน** ถึง **เดือนเจ็ดสารทแรก** การไต่สวนกลางแจ้งริมตลิ่งหยุนเหอสะเทือนทุกสำนัก ฝ่ายสำนักกระบี่และสำนักดาบส่งผู้อาวุโสมาข่มขู่และเสนอเงินปิดปากเป็นห้าร้อยศิลาวิญญาณ แต่หานสือยืนกรานไม่รับเงินนอกบัลลังก์ ขณะที่ซูเหวินเจี้ยนนำผลชันสูตรปราณจาก **หอผนึกชาด** มาหักล้างข้ออ้างเรื่องอุบัติเหตุ ชี้ว่าทั้งคู่มีพื้นที่รกร้างห่างออกไปเพียงสามลี้แต่จงใจสู้เหนือตลาดเพราะไม่อยากถอยก้าวแรก วันที่เก้า **เดือนเจ็ดสารทแรก** ศาลร่วมภาคีเจ็ดหอจึงพิพากษาให้จำเลยทั้งสองร่วมรับผิดชอบค่าบูรณะตลาด สะพาน และเบี้ยเลี้ยงชีพครอบครัวผู้เสียชีวิตสิบปีเต็มในฐานะ **หนี้ตามกฎหมาย** มิใช่เงินทำทาน

### เหตุการณ์ที่ ๒ · ยุคที่ ๙๐ (การจารึกกฎหมายชดเชยลงในกฎบัตรสหพันธ์องค์กรกลางเจ็ดหอ)
**วันเวลา:** ยุคที่ ๙๐ ปีที่ ๓๑๐ · เดือนเก้าสารทปลาย วันที่ ๒๒ (ศ.ท. ๘๙,๓๑๐)  
**สถานที่:** ศาลาศิลาเจ็ดเหลี่ยม (ศูนย์ประชุมก่อตั้ง **สหพันธ์องค์กรกลางเจ็ดหอ**)

หกพันเจ็ดร้อยสิบปีหลังคำพิพากษาสะพานชิงสือ แผ่นดินเข้าสู่ **ยุคฎีกากระดาษ** ระหว่างการร่าง **กฎบัตรสหพันธ์องค์กรกลางเจ็ดหอ** ตามบันทึกใน **เล่มที่ ๙๕** ตัวแทนมหาสำนักหลายแห่งพยายามผลักดันข้อยกเว้นให้ "ความเสียหายข้างเคียงจากการประลองตามวิถีจอมยุทธ์" พ้นจากอำนาจศาลกลาง คืนก่อนลงนาม **เสิ่นกวนฉี** มหาอาลักษณ์ผู้ร่วมร่างกฎบัตรได้สั่งเข็นหีบเหล็กบรรจุสำนวนปฐมบท **คดีสะพานไม่ยอมไหม้** พร้อมแผ่นหินบะซอลต์จำลองรอยกระบี่-รอยดาบจาก **หอจดหมายเหตุกลาง** มาวางกลางศาลาศิลาเจ็ดเหลี่ยม เคียงข้างรายงานลับจากราชสำนักเป่ยหมิง ตงหวง และซีหรง ซึ่งเผยว่าเหตุจอมยุทธ์ทำลายเมืองท่าโดยไร้ผู้รับผิดชอบได้กลายเป็นข้ออ้างให้ขุนศึกโลกียะเรียกร้องยกเลิก **กฎน้ำบ่อไม่ยุ่งกับน้ำคลอง**

ความจริงอันเย็นเยียบนี้ทำให้ตัวแทนทุกฝ่ายเงียบกริบ เสิ่นกวนฉีจึงเชื่อมโยงหลักการคดีสะพานชิงสือเข้ากับ **ประมวลแท่นหินชั่งโลหิต** (ตาม **เล่มที่ ๗๐**) ก่อกำเนิดเป็น **กฎหมายชดเชยความเสียหายจากศึกผู้บ่มเพาะ** แนบท้ายกฎบัตรเจ็ดหอ โดยกำหนดเด็ดขาดว่าผู้บ่มเพาะหรือสำนักใดที่เบี้ยวหนี้ชดเชยพลเรือนเกินเก้าสิบวัน จะถูกปรับสถานะขึ้นเป็นอาชญากรใน **สมุดปกดำ** ทันที เปิดทางให้ **หอพิพากษากลาง** และ **ศาลล่าค่าหัว** ริบทรัพย์ข้ามเขตได้โดยไม่ถือว่าละเมิดอธิปไตยของสำนักหรือราชอาณาจักร

### เหตุการณ์ที่ ๓ · ยุคที่ ๑๐๐ (บททดสอบเหล็ก ณ ท่าเรือหลิ่ววานใต้สนธิสัญญาหยุนเหอ)
**วันเวลา:** ยุคที่ ๑๐๐ ปีที่ ๔๑๘ · เดือนสิบเอ็ดน้ำค้างแข็ง วันที่ ๑๗ (ศ.ท. ๙๙,๔๑๘)  
**สถานที่:** ท่าเรือหลิ่ววาน และ **ศาลากลางหุบเขาหยุนเหอ**

หลัง **สนธิสัญญาหยุนเหอ** ผู้อาวุโสขั้นที่ ๘ สองนายจากสำนักชั้นนำต่างขั้ว — สายอัคคีฝั่งประจิมและสายกระบี่ฝั่งอุดร — ปะทะกันด้วยเรื่องเรือขนส่งแร่เหล็กดาวตกใกล้ **ท่าเรือหลิ่ววาน** แรงปะทะเผายุ้งฉางสี่หลัง อู่ต่อเรือสองแห่ง และทำให้น้ำในคลองปนเปื้อนเถ้าอัคคีจนชาวประมงลงอวนไม่ได้ตลอดฤดูหนาว ทั้งสองสำนักพยายามบีบ **หอไกล่เกลี่ยกลาง** ให้ปิดคดีลับๆ ด้วยเงินเยียวยาเพียงหนึ่งในสามของมูลค่าจริง ทว่า **ซ่งเยี่ยนชิง** ตุลาการระดับกลางของ **หอพิพากษากลาง** ขัดขวางการไกล่เกลี่ยใต้โต๊ะอย่างแข็งกร้าว นางนำหน่วย **หอผนึกชาด** เก็บตัวอย่างเถ้าปราณต่อหน้าชาวเรือกลางลมหนาว **เดือนสิบเอ็ดน้ำค้างแข็ง** แล้วใช้อำนาจตามกฎหมายชดเชยอายัดบัญชีเงินฝากศิลาวิญญาณของทั้งสองสำนักที่ **หมู่ตึกวาณิชย์หลงเหมิน**

ภายในสิบห้าวัน ทั้งสองสำนักจำต้องชำระค่าเสียหายอัตราหนึ่งร้อยห้าสิบส่วนร้อย พร้อมกองทุนบำบัดลำน้ำและเบี้ยเลี้ยงชาวเรือสิบปี ซ่งเยี่ยนชิงสั่งแกะสลักคำเตือนบนเสาศิลาหน้า **ศาลากลางหุบเขาหยุนเหอ** ว่า *"ชัยชนะในยุทธภพมิใช่ใบอนุญาตเผาเรือนราษฎร"* คดีนี้เองที่ส่งให้นางก้าวสู่ตำแหน่งมหาตุลาการและประธานเวียนสหพันธ์เจ็ดหอ

### เหตุการณ์ที่ ๔ · ยุคที่ ๑๐๑ (รุ่งอรุณแสนปีและช่องโหว่สงครามตัวแทนเงา)
**วันเวลา:** ยุคที่ ๑๐๑ ปีที่ ๑ · เดือนอ้ายวสันต์ วันที่ ๑ ถึง วันที่ ๑๒ (ศ.ท. ๑๐๐,๐๐๑)  
**สถานที่:** นครสองแควหยุนเหอ ท่าเรือหลิ่ววาน และเชิงเขาชิงซี

ณ รุ่งอรุณ **ยุคที่ ๑๐๑ ปีที่ ๑ เดือนอ้ายวสันต์ วันที่ ๑** กฎหมายชดเชยเผชิญบททดสอบเจ้าเล่ห์ที่สุดในรอบหมื่นปี เครือข่ายของ **ปกดำ-๐๖ เว่ยเฉินม่อ** แห่งสมาคมมีดไร้ลายและนายทุนมืดบางกลุ่มว่าจ้างจอมยุทธ์พเนจรระดับขั้นที่ ๗–๘ ที่ไร้ทะเบียนสำนักให้แสร้งเปิดศึกยั่วยุศิษย์สำนักเล็กใน **แคว้นอิสระหยุนเหอ** ใกล้เขตตลาดและท่าเรือ เพื่อล่อให้เกิดความเสียหายพลเรือนแล้วโยนหนี้ร่วมทั้งหมดให้สำนักที่มีโฉนดที่ดินชัดเจนจนต้องยอมขายที่ดินรอบ **เชิงเขาชิงซี** ในราคาถูก **ซ่งเยี่ยนชิง** ล่วงรู้เล่ห์กลนี้จากรายงาน **หอจดหมายเหตุกลาง** แต่เกรงข่าวรั่วหากใช้เจ้าหน้าที่หอไกล่เกลี่ยกลาง นางจึงมองหาสำนักเล็กไร้พันธะรวมทั้งเพื่อนบ้านอย่าง **สำนักร้อยวิถีไผ่เขียว** และ **หุบเขาหมัดวัชระศิลาเหล็ก** ให้ช่วยเป็น *ผู้ประเมินซากปราณภาคสนาม* เพื่อเปิดโปงคดีจัดฉาก

## ๓. ทำเนียบบุคคลสำคัญข้ามยุคสมัย (Character Dossiers)

- **๑. หานสือ — เฒ่าผู้เฝ้าสะพานหินขาวชิงสือ (ยุคที่ ๘๓ · อายุ ๖๔ ปี):** สามัญชนไร้รากปราณ ช่างซ่อมตอม่อสะพานรุ่นที่สามแห่งท่าตลาดชิงสือ เขามิใช่นักบุญอุดมคติ แต่คือบิดาผู้เสียบุตรชายและช่างหินผู้หยิ่งในศักดิ์ศรี การปฏิเสธศิลาสามสิบก้อนเกิดจากสัญชาตญาณว่าหากรับเงินฐานะผู้ขอทาน วันหน้าจอมยุทธ์คนใดก็จะมาเผาตลาดอีกเมื่อไรก็ได้ บั้นปลายเขาคุมงานบูรณะสะพานจนแล้วเสร็จและสลักชื่อผู้ตายสิบเก้าคนไว้ใต้ท้องโค้งสะพานแทนชื่อผู้บริจาค
- **๒. ซูเหวินเจี้ยน — เสมียนหมึกดำแห่งหอจดหมายเหตุกลาง (ยุคที่ ๘๓ · อายุ ๒๖ ปี):** ศิษย์ปลายแถวขั้นที่ ๒ ผู้มีชีพจรตีบตันจึงผันตัวเป็นเสมียนบัญชี เขามองขาดด้วยตรรกะสถาบันว่าหากภาคีเจ็ดหอยอมให้ยอดฝีมือขั้นที่ ๘ ซื้อคำตัดสิน องค์กรกลางจะหมดความชอบธรรม หลังคดีเขาใช้เวลาสี่สิบปีเรียบเรียง *อรรถกถาหนี้ปราณและค่าสินไหม* จนเป็นตำราหลักของตุลาการรุ่นหลัง
- **๓. เจี้ยนกูเสวี่ย — จ้าวกระบี่เหมันต์ไร้รอย (ยุคที่ ๘๓ · ผู้ชนะขั้นที่ ๘ · วัย ๒๑๔ ปี):** ผู้อาวุโสสายกระบี่แดนอุดรผู้ยึดมั่นในเกียรติการประลองและมิใช่คนโหดเหี้ยม แต่เป็นตัวแทนความจองหองอันบริสุทธิ์ใจของชนชั้นผู้บ่มเพาะระดับสูง ครั้นถูกบังคับให้ยืนฟังรายชื่อผู้ตายและดูหานสือชั่งน้ำหนักความเสียหายทีละคานไม้ เขายอมวางกระบี่ชำระหนี้ครบทุกตำลึงและสั่งห้ามศิษย์ประลองใกล้ชุมชนในระยะสิบลี้ตลอดชีวิต
- **๔. ฉื่อเหยียนขุย — ดาบอัคคีเจ็ดเปลว (ยุคที่ ๘๓ · ผู้แพ้ขั้นที่ ๘ · วัย ๒๓๘ ปี):** ยอดฝีมือสายดาบอัคคีแดนประจิมผู้พ่ายแพ้และบาดเจ็บสาหัส เขาตั้งคำถามกลางศาลว่า *"ในยุทธภพ ผู้แพ้ย่อมจ่ายด้วยเลือดและศักดิ์ศรี ไฉนต้องจ่ายด้วยเงินอีกเล่า"* เมื่อหลบหนีคำพิพากษา ภาคีเจ็ดหอจึงอายัดส่วนแบ่งเหมืองแร่ของสำนักต้นสังกัดเป็นครั้งแรกในประวัติศาสตร์ จนเจ้าสำนักของเขาต้องส่งตัวกลับมาลงนามรับสภาพหนี้
- **๕. เสิ่นกวนฉี — มหาอาลักษณ์ผู้วางรากฐานหมวดชดเชย (ยุคที่ ๙๐ · วัย ๓๔๒ ปี):** นักนิติศาสตร์ชั้นครูแห่ง **หออาลักษณ์** และผู้ร่วมร่าง **กฎบัตรสหพันธ์องค์กรกลางเจ็ดหอ** ปี ศ.ท. ๘๙,๓๑๐ เป็นนักปฏิบัตินิยมเย็นชาที่แปลงอุดมการณ์ของหานสือและซูเหวินเจี้ยนให้กลายเป็นกลไกหักบัญชีอัตโนมัติและเชื่อมโยงสู่ **สมุดปกดำ**
- **๖. ซ่งเยี่ยนชิง — มหาตุลาการตาชั่งเหล็ก (ยุคที่ ๑๐๐–๑๐๑ · วัย ๓๘๙ ปีในยุคที่ ๑๐๑):** ประธานเวียน **สหพันธ์องค์กรกลางเจ็ดหอ** (ตัวละครหลักร่วมจาก **เล่มที่ ๙๕**) ผู้สร้างชื่อจากการอายัดบัญชีสองมหาสำนักในคดีท่าเรือหลิ่ววาน และกำลังปกป้องกฎหมายชดเชยจากเล่ห์กลของ **ปกดำ-๐๖ เว่ยเฉินม่อ**

## ๔. กายวิภาคกฎหมายชดเชยความเสียหายจากศึกผู้บ่มเพาะและกลไกบังคับใช้

**กฎหมายชดเชยความเสียหายจากศึกผู้บ่มเพาะ** ที่แนบท้ายกฎบัตรสหพันธ์เจ็ดหอและ **ประมวลแท่นหินชั่งโลหิต** ประกอบด้วยสี่เสาหลักที่ทำงานได้จริงภายใต้เพดานโลกเบื้องล่างและ **กฎน้ำบ่อไม่ยุ่งกับน้ำคลอง**:

1. **หลักความรับผิดร่วมโดยไม่แยกแพ้ชนะ:** หากการประลองเกิดในระยะต่ำกว่าห้าลี้จากชุมชน ตลาด ท่าเรือ หรือคันกั้นน้ำ ผู้ชนะและผู้แพ้ต้องรับผิดร่วมในสัดส่วน **ห้าสิบต่อห้าสิบ** แต่หากผลชันสูตรของ **หอผนึกชาด** พิสูจน์ได้ว่าฝ่ายหนึ่งจงใจลากสมรภูมิเข้าชุมชนหรือฝ่าฝืนธงแดงเตือนภัยของ **กองรักษาการณ์เสื้อเทาไร้ตรา** สัดส่วนจะปรับเป็น **เจ็ดสิบต่อสามสิบ** พร้อมพิจารณาความผิดอาญาเพิ่ม
2. **การชันสูตรซากปราณและการประเมินค่าสินไหมสี่หมวด:** **หอผนึกชาด** ผนึกพื้นที่ภายในสามชั่วยามเพื่อเก็บเศษปราณเทียบทะเบียนของ **หออาลักษณ์** แล้วให้ **หอจดหมายเหตุกลาง** คำนวณหนี้สี่หมวด ได้แก่ (ก) โครงสร้างพื้นฐานและสาธารณสมบัติ คิด **หนึ่งร้อยห้าสิบส่วนร้อย** ของต้นทุนสร้างใหม่, (ข) ชีวิตและทุพพลภาพของสามัญชน จ่ายเป็น **เบี้ยเลี้ยงชีพสิบปี** ในรูปแท่งเงินหลวงเทียบอัตราจาก **กฎบัตรชั่งเงินวัดปราณ** ผ่านศาลากลางหยุนเหอโดยห้ามจ่ายศิลาวิญญาณดิบแก่ชาวบ้านตรงๆ เพื่อกันการถูกปล้น, (ค) ทรัพย์สินการค้าตามบัญชีภาษีล่าสุด, และ (ง) ค่าบำบัดปราณพิษหรือเพลิงตกค้างในดินและลำน้ำ
3. **บันไดบังคับคดีสี่ขั้นข้ามสิบเก้าสำนัก:** หากไม่ชำระหนี้ภายในสามสิบวัน สหพันธ์เจ็ดหอจะเดินเครื่องตามลำดับ: **ขั้นที่หนึ่ง** อายัดวงเงินพาณิชย์ผ่าน **หมู่ตึกวาณิชย์หลงเหมิน** และ **หอไกล่เกลี่ยกลาง** → **ขั้นที่สอง** ระงับตราผ่านด่านและทะเบียนรับศิษย์โดย **หออาลักษณ์** → **ขั้นที่สาม** ยึดส่วนแบ่งสายแร่และของกลางโดย **หอผู้ถือกุญแจผนึก** → **ขั้นที่สี่** หากพ้นเก้าสิบวันหรือฆ่าปิดปากพยาน **หอพิพากษากลาง** จะจารึกชื่อลง **สมุดปกดำ** และส่งมอบหมายป้ายเหล็กดำแก่ **ศาลล่าค่าหัว** (หักค่าดูแลสิบสองส่วนร้อยและส่วนแบ่งทรัพย์ริบสามสิบส่วนร้อย)
4. **วาล์วระบายแรงดันของกฎน้ำบ่อไม่ยุ่งกับน้ำคลอง:** **สามมหาจักรวรรดิ** ยอมรับอำนาจศาลเจ็ดหอเพราะได้เงินบูรณะเมืองท่าโดยไม่ต้องเสี่ยงเปิดศึกกับสำนักยุทธ์ ส่วน **สิบเก้าสำนักเสาหลัก** ยอมชำระหนี้เพราะค่าซ่อมสะพานหนึ่งแห่งถูกกว่าการถูกทัพหลวงล้อมเขาหรือถูกตัดเส้นทางค้าขายในหยุนเหอหลายร้อยเท่า

## ๕. ตะขอจำลองโลกสังเกตการณ์และระบบชื่อเสียงสำนักยุคที่ ๑๐๑

- **เหตุการณ์ศึกพาดผ่านชุมชนและหมายเรียกชำระหนี้:** เมื่อผู้บ่มเพาะระดับขั้นที่ ๖ ถึงขั้นที่ ๘ เปิดศึกนอกลานประลองจนกระทบตลาดหรือท่าเรือ **หอผนึกชาด** จะออกรายงานชันสูตรและส่งหมายเรียกชดเชย การชำระครบตามกำหนดช่วยเพิ่มความไว้วางใจจากราษฎรและพ่อค้า ส่วนการดื้อแพ่งจะนำไปสู่การอายัดบัญชีค้าขายและเสี่ยงถูกขึ้น **สมุดปกดำ**
- **แรงเสียดทานชื่อเสียงฝ่ายธรรมะ อธรรม และสายกลาง:** สำนักฝ่ายธรรมะอย่าง **สำนักกระบี่เมฆขาว** และ **อารามพลองโพธิ์อัสนีวัชระ** ต้องแบกแรงกดดันทางศีลธรรมให้จ่ายเต็มจำนวนแม้ถูกยั่วยุ ส่วนฝ่ายอธรรมอย่าง **วังอสูรทวนโลหิตซิวหลัว** หรือ **นิกายพิรุณหยินเงาโลหิต** มักจงใจล่อศึกเข้าป่าลึกหรือใช้มือปืนไร้สังกัดเพื่อเลี่ยงลายเซ็นปราณ
- **สงครามเศรษฐกิจเงาและโอกาสของสำนักผู้เล่น:** เครือข่ายของ **ปกดำ-๐๖ เว่ยเฉินม่อ** อาจจ้างนักสู้ไร้ทะเบียนมายั่วยุศิษย์สำนักเล็กแถบ **ท่าเรือหลิ่ววาน** หรือ **เชิงเขาชิงซี** เพื่อสร้างหนี้ชดเชยบีบขายที่ดิน สำนักเล็กไร้พันธะสามารถรับตราผู้ประเมินซากปราณอิสระจาก **ซ่งเยี่ยนชิง** ร่วมกับ **สำนักร้อยวิถีไผ่เขียว** และ **หุบเขาหมัดวัชระศิลาเหล็ก** เพื่อเปิดโปงคดีจัดฉากและสะสมบารมีในหยุนเหอ
- **อนุสรณ์สะพานไม่ยอมไหม้:** ทุกวันที่เก้า **เดือนเจ็ดสารทแรก** ช่างหิน พ่อค้าเรือจ้าง และเสมียนรุ่นใหม่ของหอจดหมายเหตุกลางยังคงไปจุดธูปและวางก้อนหินแม่น้ำไว้ใต้โค้ง **สะพานหินขาวชิงสือ** เพื่อรำลึกถึงวันที่ชายชราไร้ลมปราณชนะยอดฝีมือขั้นที่ ๘ ได้ด้วยสมุดบัญชีเพียงเล่มเดียว

## ๖. บัญชีตรวจทานกฎเหล็กความถูกต้อง (Canon-Lock Checklist)

- [x] **ปฏิทินและมาตราเวลาถูกต้อง:** ยึด `๑ ยุค = ๑,๐๐๐ ปี` สอดคล้องทุกศักราช (ยุคที่ ๘๓ ปีที่ ๖๐๐ = ศ.ท. ๘๒,๖๐๐ · ยุคที่ ๙๐ ปีที่ ๓๑๐ = ศ.ท. ๘๙,๓๑๐ · ยุคที่ ๑๐๐ ปีที่ ๔๑๘ = ศ.ท. ๙๙,๔๑๘ · ยุคที่ ๑๐๑ ปีที่ ๑ = ศ.ท. ๑๐๐,๐๐๑)
- [x] **ใช้เฉพาะ ๑๒ ชื่อเดือนไทยมาตรฐาน:** ปรากฏเฉพาะ **เดือนอ้ายวสันต์**, **เดือนห้าสุริยัน**, **เดือนหกพิรุณร้อน**, **เดือนเจ็ดสารทแรก**, **เดือนเก้าสารทปลาย** และ **เดือนสิบเอ็ดน้ำค้างแข็ง** ไม่มีชื่อเดือนสากลปะปน
- [x] **เคารพเพดานพลังโลกเบื้องล่าง:** ระดับพลังสูงสุดจำกัดที่ผู้บ่มเพาะขั้นที่ ๘ ภายใต้เพดานขั้นที่ ๙ ของโลกเบื้องล่าง ไม่มีผู้บ่มเพาะเหนือเพดานดังกล่าว
- [x] **ยึดโยงคัมภีร์แม่บทและคลังตำนานหลัก:** อ้างอิงสอดคล้องกับ **เล่มที่ ๙๕**, **เล่มที่ ๗๐**, **ซ่งเยี่ยนชิง**, **ปกดำ-๐๖ เว่ยเฉินม่อ**, **ศาลากลางหุบเขาหยุนเหอ**, **หมู่ตึกวาณิชย์หลงเหมิน**, **สิบเก้าสำนักเสาหลัก** และ **กฎน้ำบ่อไม่ยุ่งกับน้ำคลอง**
- [x] **ปลอดองค์ประกอบต้องห้ามและรหัสโค้ดเกมดิบ:** ไม่มีรหัสภาษาอังกฤษของระบบเกม ไม่เฉลยสามปริศนาใหญ่ปลายเปิด และปลอดจากแม่แบบเรื่องเล่าต้องห้ามทั้งหมด
- [x] **ไม่แก้ไขไฟล์เกมใดๆ:** จัดทำเป็นเอกสารตำนานเอกเทศโดยมิได้แตะต้องหรือเปลี่ยนแปลงไฟล์เกมต้นฉบับ
