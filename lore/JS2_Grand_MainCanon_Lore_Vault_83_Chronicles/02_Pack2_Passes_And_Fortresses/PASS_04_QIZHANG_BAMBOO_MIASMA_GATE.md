# พงศาวดารแกนหลัก: ด่านค่ายไผ่หมอกเจ็ดชั้น — ปราการไผ่มีชีวิตและแนวถอนพิษแห่งบึงมรกต

## ๑. ข้อมูลกำกับพงศาวดารและหมุดหมายแผนที่จริง

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อสถานที่แกนหลัก** | **ด่านค่ายไผ่หมอกเจ็ดชั้น** |
| **สังกัดและภูมิภาค** | แคว้นกู่เจียว · เขตบึงชุ่มน้ำใต้ (แนวกันชนปากทางบกเชื่อมที่ราบสูงและป่าชุ่มน้ำลึก) |
| **ประเภทและพิกัดแผนที่จริง** | ป้อมด่านชายแดนระดับสอง · ภูมิประเทศเขตบึงชุ่มน้ำ · พิกัด `(38, 67.5)` |
| **เพื่อนบ้านใกล้ที่สุดบนแผนที่จริง** | ทิศตะวันออกเฉียงเหนือ: **หมู่บ้านไร่ชาไผ่มรกตชุ่ยจู๋** เขตหุบเขาหยุนเหอ `(44, 65.5)` · ทิศตะวันตกเฉียงเหนือ: **ป้อมด่านพายุทรายหวงซา** จักรวรรดิซีหรง `(32.5, 63)` · ทิศตะวันตกเฉียงใต้: **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** แคว้นกู่เจียว `(31, 73)` |
| **แนวเชื่อมยุทธศาสตร์** | ประตูทางบกทิศเหนือเพียงแห่งเดียวที่กั้นขวางเส้นทางจากหุบเขาหยุนเหอและขอบทะเลทรายซีหรงมิให้รุกล้ำสู่ **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** และ **นครเสาขวัญหมื่นกู่** ทางใต้ |
| **ขอบเขตช่วงเวลา** | ยุคที่ ๕๐ ปีที่ ๙๙๒ ถึง ยุคที่ ๑๐๑ ปีที่ ๑ (ศ.ท. ๔๙,๙๙๒ – ๑๐๐,๐๐๑) |
| **สถานะในจักรวาล** | พงศาวดารสถานที่แกนหลักของมหาทวีป (ไม่ใช่ภาคแยก ไม่ใช่ตำราสายบำเพ็ญเพียร และไม่ใช่พงศาวดารแม่น้ำหรือขุนเขา) |
| **กฎเหล็กประจำด่าน** | แยกขาดจากสำนักสายพิษในยุทธภพทุกแขนง ห้ามค้าพิษสงคราม และประหารลัทธิภายนอกที่ลักพาชาวเผ่าโดยไร้ข้อยกเว้น |

เหนือผืนดินดอนชื้นที่รอยต่อระหว่างเนินไร่ชาฝั่งใต้หุบเขาหยุนเหอ ขอบทะเลทรายแห้งแล้งของซีหรง และเขตบึงชุ่มน้ำใต้ของแคว้นกู่เจียว **ด่านค่ายไผ่หมอกเจ็ดชั้น** มิได้ก่อจากกำแพงศิลา หากเป็นปราการมีชีวิตที่ถักทอจากลำไผ่มรกตเจ็ดวงซ้อนกัน หล่อเลี้ยงด้วยร่องน้ำกร่อยและม่านหมอกชื้นตามแรงลมฤดูกาล ทางตะวันออกเฉียงเหนือห่างไปเพียงข้ามลำห้วยคือ **หมู่บ้านไร่ชาไผ่มรกตชุ่ยจู๋** ทางตะวันตกเฉียงเหนือคือสันทรายทอดตรงสู่ **ป้อมด่านพายุทรายหวงซา** ส่วนเบื้องหลังม่านไผ่ลงไปทางตะวันตกเฉียงใต้คือ **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** คลังยาถอนพิษสำคัญที่สุดของชาวเผ่ากู่เจียว ใครก็ตามที่หมายเดินทางบกจากแดนเหนือหรือแดนประจิมเข้าสู่บึงลึก ล้วนต้องผ่านด่านแห่งนี้ก่อนทั้งสิ้น

## ๒. สี่ห้วงกาลแห่งด่านค่ายไผ่หมอกเจ็ดชั้น

### เหตุการณ์ที่ ๑ (รอยต่อยุคที่ ๒–๓ · ยุคที่ ๕๐ ปีที่ ๙๙๒ – ยุคที่ ๕๑ ปีที่ ๔ · ศ.ท. ๔๙,๙๙๒ – ๕๐,๐๐๔)
**การปลูกค่ายไผ่มีชีวิตเจ็ดวงต้านโจรลัทธิพิษแดนเหนือ**

กว่าสามพันปีหลังสัตยาบันป้ายไม้ไผ่สีมรกตกวาดล้างลัทธิหม้อต้มกระดูกดำพ้นร่องน้ำใต้ ปลายยุคกลียุคกลับนำพาภัยคุกคามทางบกเข้ามาแทน เดือนสี่คิมหันต์แรก วันที่สิบแปด ยุคที่ ๕๐ ปีที่ ๙๙๒ (ศ.ท. ๔๙,๙๙๒) เศษเดนลัทธิพิษเถื่อนจากยุทธภพภาคเหนือรวมตัวเป็นกองโจรหน้ากากขี้เถ้า ลอบเลียบเนินใต้จากฝั่ง **หมู่บ้านไร่ชาไผ่มรกตชุ่ยจู๋** ผสานกับพรานรับจ้างขอบทรายฝั่ง **ป้อมด่านพายุทรายหวงซา** บุกจู่โจมชายขอบบึงในคืนเดือนดับเพื่อลักพาหมอยาจาก **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** รีดสูตรยาถอนพิษและขโมยหน่อว่านชุ่มน้ำ รั้วไม้แห้งและหอสังเกตการณ์ชั้นเดียวในเวลานั้นถูกคบไฟน้ำมันสนเผาวอดในชั่วยามเดียว คร่าชีวิตยามด่านสิบเก้าคนและกวาดต้อนชาวบ้านไปกว่าสามสิบชีวิต

เดือนห้าสุริยัน วันที่เก้า สภาสิบสองเผ่าเรียกประชุมด่วน **ซางเจ๋อหลิน** เฒ่าช่างปลูกไผ่แห่งเผ่าเฝ้ารากวัยหกสิบสี่ปี กับ **หลันฮุ่ยซิน** ผู้นำหน่วยลาดตระเวนบึงเสนอให้สร้างปราการมีชีวิตแทนกำแพงหินและรั้วไม้แห้ง ตั้งแต่เดือนหกพิรุณร้อน วันที่หนึ่ง ชาวเผ่าระดมขุดร่องน้ำวนเจ็ดวงซ้อนกันรอบเนินโคลน ปลูกหน่อ **ไผ่หมอกมรกต** คู่กับเถาว่านอุ้มน้ำค้างและพุ่มตะไคร่กรองหมอก ฝังกระบอกดินเผาบรรจุยางไม้กันเน่าชิงมู่เจือน้ำบึงให้รากไผ่ดูดซับจนเปลือกเหนียวทนไฟ และเจาะปล้องไผ่ตามองศาช่องลมเพื่อให้ลมเหนือและลมตะวันตกจากหวงซาพัดม่านหมอกหมุนวนเป็นวงก้นหอย

เดือนเจ็ดสารทแรก วันที่ยี่สิบสอง ปีเดียวกัน กองโจรหน้ากากขี้เถ้าย้อนมาหวังเผาค่ายซ้ำ ทว่าแนวไผ่สดอุ้มน้ำยางไม่ติดไฟ ซ้ำม่านหมอกย้อนลมและกับดักลำไผ่ดีดตัวทำให้พวกมันแตกขบวนหลงทิศ หน่วยหอกกกของหลันฮุ่ยซินจึงจับเป็นหัวหน้ากองโจรและสมุนยี่สิบสี่คนได้ทั้งหมด สภาสิบสองเผ่าสั่งประหารผู้ลักพาชาวเผ่าหน้าลานศิลาปากด่านในเช้าวันรุ่งขึ้น ก่อนปลูกวงไผ่ชั้นที่เจ็ดแล้วเสร็จสมบูรณ์ใน **เดือนอ้ายวสันต์ วันที่เก้า ยุคที่ ๕๑ ปีที่ ๔ (ศ.ท. ๕๐,๐๐๔)** กำเนิดเป็น **ด่านค่ายไผ่หมอกเจ็ดชั้น** นับแต่นั้น

### เหตุการณ์ที่ ๒ (ยุคที่ ๓ มัชฌิมกาล · ยุคที่ ๗๘ ปีที่ ๔๑๖ · ศ.ท. ๗๗,๔๑๖)
**ข้อตกลงหน้าต่างการค้าป้ายไผ่มรกตกับสมาคมพ่อค้าแดนใต้**

ล่วงสู่มัชฌิมกาล เส้นทางเกวียนใบชาจาก **หมู่บ้านไร่ชาไผ่มรกตชุ่ยจู๋** และกองคาราวานพ่อค้าสมุนไพรจากชายฝั่งแดนใต้ต่างต้องการ **ยาถอนพิษหายาก** และ **ยางไม้กันเน่า** สำหรับต่อเรือเดินสมุทร ทว่าการปิดด่านเกือบตลอดปีทำให้เกิดตลาดมืดชายป่าและเปิดช่องให้คนของสำนักสายพิษแฝงตัวเข้ามากับขบวนเถื่อน

เดือนสามวสันต์ปลาย วันที่สิบสอง ยุคที่ ๗๘ ปีที่ ๔๑๖ (ศ.ท. ๗๗,๔๑๖) **เฒ่าเหมี่ยวชิงหลิน** ผู้แทนฝ่ายโอสถแห่ง **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** จึงเปิดเจรจากับ **จ้าวสุ่ยเหอ** หัวหน้าสมาคมพ่อค้าสมุนไพรแดนใต้ใต้ซุ้มไผ่ชั้นที่สอง จนบรรลุ **ข้อตกลงหน้าต่างการค้าป้ายไผ่มรกต** ใน **เดือนห้าสุริยัน วันที่ห้า** กำหนดกติกาเหล็กสี่ประการ ได้แก่ เปิดเฉพาะวงไผ่ชั้นที่หนึ่งและสองเป็นลานแลกเปลี่ยนปีละสามวาระ (เดือนสามวสันต์ปลาย เดือนแปดใบไม้ร่วง และเดือนสิบเหมันต์แรก) ยามทิศลมเปิดหมอกชั้นนอก คาราวานทุกกองต้องปลดอาวุธหนักและรับ **ป้ายไผ่ถอนหมอก** ที่มีอายุใช้งานสามวัน อนุญาตให้แลกเปลี่ยนเฉพาะยาถอนพิษ สมุนไพรชุ่มน้ำลึก ยางไม้กันเน่า ใบชา เกลือสะอาด ผ้าทอ และเครื่องมือเหล็ก ห้ามค้าพิษสงครามหรือแมลงกู่มีชีวิตเด็ดขาด และหากคาราวานใดซุกซ่อนสาวกสำนักสายพิษหรือลอบวาดผังช่องลมจะถูกเพิกถอนสิทธิผ่านด่านถาวร

### เหตุการณ์ที่ ๓ (ยุคที่ ๔ มหาดุลยภาพหยุนเหอ · ยุคที่ ๑๐๐ ปีที่ ๔๑๒ · ศ.ท. ๙๙,๔๑๒)
**แนวกักโรคและจ่ายยาถอนพิษเจ็ดชั้นในมหาโรคระบาดไข้ชื้นข้ามทวีป**

หลังแคว้นกู่เจียวสถาปนาฐานะรัฐกันชนเต็มตัวในปลายยุคที่ ๙๖ ด่านค่ายไผ่หมอกเจ็ดชั้นต้องเผชิญบททดสอบครั้งใหญ่ใน **เดือนหกพิรุณร้อน วันที่แปด ยุคที่ ๑๐๐ ปีที่ ๔๑๒ (ศ.ท. ๙๙,๔๑๒)** เมื่อฝนร้อนตกต่อเนื่องเกือบสองเดือนก่อเกิดมหาโรคระบาด **"ไข้ไอชื้นคราม"** ลุกลามจากภาคกลางลงสู่ **หมู่บ้านไร่ชาไผ่มรกตชุ่ยจู๋** และเลียบทางเกวียนถึง **ป้อมด่านพายุทรายหวงซา** ผู้ติดเชื้อปอดอักเสบเฉียบพลันและเสียชีวิตในห้าวันหากขาดยาต้มรากบัวดำผสมยางไม้ชิงมู่ ผู้ลี้ภัยและทหารรับจ้างกว่าสี่พันคนจึงหลั่งไหลมาออกันหน้าวงไผ่ชั้นที่หนึ่ง หวังบุกชิงคลังยาที่ **หมู่บ้านหมอสมุนไพรไป๋เฉ่า**

ท่ามกลางเสียงเรียกร้องให้ปล่อยหมอกพิษปิดตายด่าน **หมอหญิงไป๋ซู่หลัน** แห่งไป๋เฉ่าเตือนว่าศพหน้าด่านจะปนเปื้อนร่องน้ำและจุดชนวนศึกเผาป่า **ฉืออวิ๋นโม่** นายด่านสายหอกกกจึงร่วมมือกับนางดัดแปลงด่านเจ็ดชั้นเป็น **แนวกักโรคและจ่ายยาถอนพิษ** ชั้นที่หนึ่งตั้งเตารมควันสมุนไพรคัดแยกผู้ป่วย ชั้นที่สองสร้างเพิงกักดูอาการเจ็ดวันแยกตามทิศลม ส่วนชั้นที่สามติดตั้ง **รางไม้ไผ่เคลือบยางกันเน่า** ยาวสิบสองจั้ง ให้หมอยาต้มยาในวงชั้นที่สี่แล้วส่งโถยาไหลลงรางแจกจ่ายโดยไม่สัมผัสตัวโดยตรง คืน **เดือนเจ็ดสารทแรก วันที่สิบหก** กองโจรรับจ้างจากฝั่งหวงซาลอบจุดไฟหวังชิงหม้อยาและลักพาไป๋ซู่หลัน แต่ฉืออวิ๋นโม่เปิดท่อหมอกกล่อมประสาทเฉพาะปีกตะวันตกสกัดไว้ได้โดยไม่กระทบผู้ป่วย แนวกักโรคยืนหยัดถึง **เดือนสิบเหมันต์แรก วันที่สิบเก้า** ช่วยชีวิตผู้คนกว่าสามพันสองร้อยรายโดยไม่มีเชื้อร้ายเล็ดลอดผ่านวงชั้นที่สี่เข้าสู่บึงลึกแม้แต่รายเดียว

### เหตุการณ์ที่ ๔ (ยุคที่ ๕ รุ่งอรุณศักราชใหม่ · ยุคที่ ๑๐๐ ปีที่ ๙๙๙ – ยุคที่ ๑๐๑ ปีที่ ๑ · ศ.ท. ๙๙,๙๙๙ – ๑๐๐,๐๐๑)
**ความตึงเครียดใต้ซุ้มไผ่ชั้นที่สาม — เหมี่ยวชิงซี กู่ซา และใบไผ่มรกตของหลันอวี้เจียว**

**ปลายเดือนสิบเอ็ดน้ำค้างแข็ง วันที่ยี่สิบเจ็ด ยุคที่ ๑๐๐ ปีที่ ๙๙๙ (ศ.ท. ๙๙,๙๙๙)** **แม่เฒ่ามรกต หลันอวี้เจียว** วัยเก้าสิบสองปี ประมุขเผ่าแมลงหยกผู้ถือป้ายไม้ไผ่สีมรกต ฝากใบไม้ไผ่สีมรกตแห้งไปกับขบวนทูตห้ารัฐกันชน ยืนยันว่าสภาสิบสองเผ่าปิดทางป่าลึก ปฏิเสธขายพิษสงครามให้จักรวรรดิซีหรง และยึด **สหพันธรัฐสุวรรณโพธิ์** เป็นหน้าต่างการค้าเพียงแห่งเดียว ทว่าภายในด่านค่ายไผ่หมอกเจ็ดชั้นกลับเกิดรอยร้าวแหลมคมเพราะหลันอวี้เจียวไร้ทายาทสายตรง

ฝ่ายหนึ่งนำโดย **เหมี่ยวชิงซี** วัยสามสิบสี่ปี ทายาทสายหมอยาผู้เสนอขยายการค้ายาถอนพิษหายากและยางไม้กันเน่าผ่านสุวรรณโพธิ์ พร้อมรักษาสายส่งใบชาและเสบียงสะอาดกับ **หมู่บ้านไร่ชาไผ่มรกตชุ่ยจู๋** เพื่อรับมือพายุสงคราม อีกฝ่ายนำโดย **กู่ซา** ขุนพลเฝ้าด่านสายเข้มงวดที่วางหลักฐานสามชิ้นกลางลานชั้นที่สาม ได้แก่ ผงพิษแมงป่องใกล้กับดักแมลงวิญญาณชายป่าของ **ภาคีพิษแมงป่องทมิฬ** แห่ง **เฒ่าพิษเฮยเซี่ย** ซึ่งถูกสภาขึ้นบัญชีล่าหัว รายงานหน่วยสอดแนมซีหรงจาก **ป้อมด่านพายุทรายหวงซา** และจดหมายสายลับตงหวงที่แฝงมากับเกวียนชาฝั่งชุ่ยจู๋ กู่ซายืนกรานปิดป่าและบังคับใช้กฎแยกขาดจากสำนักสายพิษกับโทษประหารผู้ลักพาชาวเผ่าอย่างเฉียบขาด เช้าตรู่ **วันที่หนึ่ง เดือนอ้ายวสันต์ ยุคที่ ๑๐๑ ปีที่ ๑ (ศ.ท. ๑๐๐,๐๐๑)** หลันอวี้เจียวมายืนกลางซุ้มชั้นที่สามระหว่างคนทั้งสองขณะคาราวานแรกของศักราชใหม่มาถึง นางไม่ชี้ขาดให้ฝ่ายใดชนะ หากปล่อยให้ทั้งคู่พิสูจน์ว่าใครอ่านทิศลมของยุทธภพได้แม่นยำกว่ากัน

## ๓. ทำเนียบหกบุคคลสำคัญข้ามสี่ยุค

1. **ซางเจ๋อหลิน — เฒ่าช่างปลูกไผ่ผู้วางรากค่ายเจ็ดวง (ยุคที่ ๒–๓ · ศ.ท. ๔๙,๙๒๘ – ๕๐,๐๓๒):** ผู้อาวุโสเผ่าเฝ้ารากผู้สูญเสียหลานชายในคืนกองโจรหน้ากากขี้เถ้าเผารั้วปี ๔๙,๙๙๒ เขาอุทิศสิบสองปีสุดท้ายของชีวิตวางองศาช่องลมและร่องน้ำวนทั้งเจ็ดวงจนกลายเป็นปราการมีชีวิต ก่อนสิ้นใจสั่งห้ามสลักชื่อตนบนเสาด่านเพราะเชื่อว่าผู้พิทักษ์ที่แท้จริงคือลำไผ่และผู้ดูแลมัน
2. **เหมี่ยวชิงหลิน — เฒ่าหมอยาผู้ร่างข้อตกลงหน้าต่างการค้า (ยุคที่ ๓ · ศ.ท. ๗๗,๓๕๒ – ๗๗,๔๗๘):** ผู้แทนฝ่ายโอสถแห่ง **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** ผู้ร่วมลงนามข้อตกลงปี ๗๗,๔๑๖ และประดิษฐ์ **ป้ายไผ่ถอนหมอก** อายุสามวัน เขาประคองด่านให้เปิดค้าอย่างสุจริตนานห้าสิบปีโดยไม่เคยมีสายลับสำนักพิษเล็ดลอดเข้าสู่วงชั้นใน
3. **ฉืออวิ๋นโม่ และ หมอหญิงไป๋ซู่หลัน — คู่พิทักษ์แนวกักโรคยุคที่ ๔ (ยุคที่ ๔ · ศ.ท. ๙๙,๓๖๕ – ๙๙,๔๖๐):** นายด่านสายหอกกกผู้เคร่งระเบียบกับหัวหน้าหมอยาถอนพิษแห่งไป๋เฉ่า แม้เคยขัดแย้งเรื่องงบประมาณในสภา แต่เมื่อไข้ไอชื้นครามระบาดปี ๙๙,๔๑๒ ทั้งคู่ประสานงานสร้าง **"รางยาสามชั้น"** ส่งยาข้ามรั้วและคุมแนวหมอกสกัดกองโจรหวงซา ช่วยชีวิตผู้คนกว่าสามพันสองร้อยราย
4. **แม่เฒ่ามรกต หลันอวี้เจียว — ผู้ถือป้ายไม้ไผ่สีมรกตยุคที่ ๑๐๑ (ยุคที่ ๕ · เกิด ศ.ท. ๙๙,๙๐๙ · วัย ๙๒ ปี):** ประมุขเผ่าแมลงหยกและผู้นำสภาสิบสองเผ่าแคว้นกู่เจียว นางยึดมั่นกฎแยกขาดจากสำนักสายพิษ ปฏิเสธขายพิษสงครามให้ซีหรง และส่งใบไผ่มรกตแห้งประสานห้ารัฐกันชนปลายปี ๙๙,๙๙๙ ปมหนักใจที่สุดคือการไร้ทายาทสายตรง จึงใช้ด่านค่ายไผ่หมอกเจ็ดชั้นเป็นสนามทดสอบเหมี่ยวชิงซีและกู่ซา
5. **เหมี่ยวชิงซี — ทายาทสายโอสถฝ่ายเปิดหน้าต่างการค้า (ยุคที่ ๕ · เกิด ศ.ท. ๙๙,๙๖๗ · วัย ๓๔ ปี):** ผู้นำรุ่นใหม่สายหมอยาผู้คล่องแคล่วและเชี่ยวชาญสูตรยาถอนพิษ นางเชื่อว่ากู่เจียวจะอยู่รอดได้ด้วยการทำให้โลกภายนอกต้องพึ่งพายาถอนพิษและยางไม้กันเน่า จึงผลักดันการค้าผ่าน **สหพันธรัฐสุวรรณโพธิ์** และรักษาไมตรีกับ **หมู่บ้านไร่ชาไผ่มรกตชุ่ยจู๋** ทว่าบางครั้งประเมินเล่ห์สายลับตงหวงต่ำเกินไป
6. **กู่ซา — ขุนพลเฝ้าแนวไผ่สายปิดป่าพิทักษ์จารีต (ยุคที่ ๕ · เกิด ศ.ท. ๙๙,๙๕๘ · วัย ๔๓ ปี):** ผู้บัญชาการแนวป้องกันด่านที่มีรอยแผลลูกดอกพิษจากการไล่ล่าสาวก **ภาคีพิษแมงป่องทมิฬ** เขาภักดีต่อหลันอวี้เจียวสุดหัวใจแต่ระแวงคนนอกทุกกลุ่ม ทั้งทหารซีหรงจาก **ป้อมด่านพายุทรายหวงซา** และสายข่าวตงหวง เขายืนกรานปิดป่าและประหารผู้ลักพาชาวเผ่าอย่างเฉียบขาด

## ๔. กายวิภาคด่านค่ายไผ่หมอกเจ็ดชั้นและระบบป้ายไผ่ถอนหมอก

### ๑. โครงสร้างวงไผ่มีชีวิตทั้งเจ็ดชั้น

| ชั้น | ชื่อเรียกประจำด่าน | โครงสร้างและหน้าที่ยุทธศาสตร์ | ระดับการเข้าถึง |
| :--- | :--- | :--- | :--- |
| **ชั้นที่ ๑** | **วงเสาปลดอาวุธและลานรมควัน** | ลานดินอัดหน้าแนวไผ่นอก มีเสาแขวนอาวุธหนัก บ่อล้างโคลน และเตารมควันสมุนไพรคัดกรองโรคและพิษจากฝั่งชุ่ยจู๋และหวงซา | เปิดรับคาราวานในวาระหน้าต่างการค้า |
| **ชั้นที่ ๒** | **วงลานแลกเปลี่ยนและเรือนกักโรค** | ซุ้มไม้ไผ่โปร่งลมสำหรับแลกเปลี่ยนยาถอนพิษ ยางกันเน่า ใบชา และเกลือสะอาด ยามโรคระบาดปรับเป็นเรือนกักดูอาการเจ็ดวันแยกทิศลม | เฉพาะผู้ถือ **ป้ายไผ่ถอนหมอก** ที่ยังไม่หมดอายุ |
| **ชั้นที่ ๓** | **วงซุ้มตราและรางยาส่งผ่าน** | ซุ้มไผ่โค้งฝังท่อลมหวีดเตือนภัย จุดตรวจบัญชีและที่ตั้ง **รางไม้ไผ่เคลือบยางกันเน่า** ส่งยาออกชั้นนอกโดยไม่สัมผัสตัว | จุดแบ่งอำนาจและจุดเผชิญหน้าเหมี่ยวชิงซี–กู่ซา |
| **ชั้นที่ ๔** | **วงหมอกก้นหอยและค่ายกลช่องลม** | แนวไผ่หนาสามจั้งปลูกสลับฟันปลา ปล้องไผ่เจาะรูรับลมเหนือ–ตะวันตกให้หมอกชื้นหมุนวนตัดสายตาและกลบทิศทาง | ห้ามคนนอกเข้าเด็ดขาด เว้นทูตที่สภารับรอง |
| **ชั้นที่ ๕** | **วงร่องน้ำกร่อยและกับดักรากไผ่** | คูน้ำลึกเชื่อมตาน้ำบึง ใต้น้ำขึงเถาวัลย์และท่อนซุงกันการลอบดำน้ำ พร้อมสะพานเชือกชักขึ้นลงได้ในครึ่งอึดใจ | เขตทหารและหน่วยหอกกกของกู่ซา |
| **ชั้นที่ ๖** | **วงหอต้มยาและคลังยางกันเน่า** | เรือนเสาสูงกลางดงไผ่ทึบ จุดปรุงยาถอนพิษ เก็บถังน้ำเลี้ยงยางกันเน่าบำรุงลำไผ่ และสมุดบัญชีดำลัทธิพิษเถื่อน | เขตหวงห้ามของหมอยาไป๋เฉ่าและเจ้าหน้าที่อาวุโส |
| **ชั้นที่ ๗** | **วงรากมรกตและประตูสู่นครเสาขวัญ** | วงไผ่ชั้นในสุดล้อมต้นกล้าไม้ยางกันเน่าชิงมู่สามต้น จุดชักธงสัญญาณควันเขียวแจ้งเหตุตรงถึงไป๋เฉ่าและนครเสาขวัญหมื่นกู่ | เฉพาะผู้ถือ **ป้ายไม้ไผ่สีมรกต** หรือมติสภาสิบสองเผ่า |

### ๒. กลไกป้ายไผ่ถอนหมอกและการบังคับใช้กฎเหล็ก
- **การหลอมสร้างและอายุใช้งานสามวัน:** ตัดซีกไผ่หมอกมรกตอายุห้าปีจากวงชั้นที่หก แช่น้ำต้มรากบัวดำผสมยางไม้กันเน่าสามวันแล้วประทับครั่งเขียว ไอสมุนไพรจางๆ จะสะเทินหมอกชื้นในวงชั้นที่หนึ่งถึงสาม แต่จะระเหยหมดฤทธิ์ในเจ็ดสิบสองชั่วยาม (สามวัน) เมื่อเนื้อไผ่เปลี่ยนเป็นสีเหลืองหม่น หากสายลับหลบซ่อนเกินกำหนด หมอกชื้นจะทำให้ไอและแขนขาอ่อนแรงจนถูกจับได้ทันที
- **อ่างน้ำว่านกระจกและอาญาสิทธิ์ประหาร:** ผู้เดินทางทุกคนต้องล้างมือในอ่างน้ำว่านกระจกหน้าซุ้มชั้นที่หนึ่งและสาม หากฝึกฝนพิษสายมารหรือสัมผัสผงพิษแมงป่องทมิฬ ผิวน้ำจะจับฝ้าสีม่วงคล้ำทันที นำไปสู่การไต่สวนตามกฎแยกขาดจากสำนักสายพิษ หากพบหลักฐานลักพาชาวเผ่าหรือวางกับดักแมลงวิญญาณ กู่ซามีอาญาสิทธิ์ประหารชีวิตหน้าเสาไผ่ชั้นที่หนึ่งตามคำสัตย์บรรพชนโดยไม่ต้องรอคำสั่งจากภายนอก

## ๕. ชนวนเหตุและกลไกสังเกตการณ์ยุคที่ ๑๐๑

1. **ศึกชิงทิศทางผู้สืบทอดป้ายไม้ไผ่สีมรกต:** หากคาราวานยาถอนพิษและใบชาระหว่างสุวรรณโพธิ์กับ **หมู่บ้านไร่ชาไผ่มรกตชุ่ยจู๋** ราบรื่น อิทธิพลของ **เหมี่ยวชิงซี** จะเพิ่มขึ้น ด่านจะขยายหน้าต่างการค้าและลดราคายาถอนพิษในตลาดหยุนเหอ แต่หากเกิดเหตุลอบลักพาหมอยาที่ **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** **กู่ซา** จะครองเสียงข้างมากในสภา สั่งปิดป่าและตรึงม่านหมอกจนเส้นทางบกแดนใต้ถูกตัดขาด
2. **การหยั่งเชิงจากภาคีพิษแมงป่องทมิฬและป้อมด่านพายุทรายหวงซา:** สาวกของ **เฒ่าพิษเฮยเซี่ย** อาจใช้เส้นทางขอบทรายจาก **ป้อมด่านพายุทรายหวงซา** ปลอมตัวเป็นคาราวานยาเข้ามาเจาะช่องลมชั้นที่สี่เพื่อตามหาเศษคัมภีร์ราชันหมื่นพิษกู่ ขณะเดียวกันนายทหารซีหรงที่หวงซาอาจยื่นข้อเสนอซื้อพิษสงคราม ซึ่งคำปฏิเสธของหลันอวี้เจียวอาจจุดชนวนปะทะของหน่วยลาดตระเวนชายแดน
3. **สายลับตงหวงในคราบพ่อค้าชาชุ่ยจู๋:** สายข่าวขุนนางตงหวงที่หวังตัดเสบียงยางไม้กันเน่าของเรือสุวรรณโพธิ์อาจแฝงมากับเกวียนใบชาจาก **หมู่บ้านไร่ชาไผ่มรกตชุ่ยจู๋** เพื่อลอบทำลายรากไผ่ชั้นนอก หากถูกอ่างน้ำว่านกระจกจับได้ กู่เจียวจะระงับการค้ากับฝั่งชุ่ยจู๋ชั่วคราว ส่งแรงกระเพื่อมถึงราคาชาและสมุนไพรทั่วหุบเขาหยุนเหอ
4. **การสลับโหมดแนวกักโรคและโอกาสของสำนักอิสระ:** หากเกิดคลื่นไข้ป่าเดือนหกพิรุณร้อน หรือหาก **นิกายมารกระดูกโลหิต** ของ **ประมุขชื่อกู่** ลุกล้ำเข้าใกล้ **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** ด่านจะสลับกลับสู่โหมด **รางยาส่งผ่านเจ็ดชั้น** เปิดช่องให้สำนักสายแพทย์หรือสำนักอิสระช่วยคุ้มกันเสบียงและไล่ล่าผู้ลักพาชาวเผ่า เพื่อแลกสิทธิถือ **ป้ายไผ่ถอนหมอก** ระยะยาวและความไว้วางใจจาก **แม่เฒ่ามรกต หลันอวี้เจียว**

## ๖. รายการตรวจสอบการตรึงแกนหลักจักรวาล

- [x] **ความถูกต้องของสถานที่และเพื่อนบ้านบนแผนที่จริง:** โฟกัสเฉพาะ **ด่านค่ายไผ่หมอกเจ็ดชั้น** แคว้นกู่เจียว เขตบึงชุ่มน้ำใต้ พิกัด `(38, 67.5)` เชื่อมตรงกับเพื่อนบ้านใกล้ที่สุดทั้งสามแห่ง ได้แก่ **หมู่บ้านไร่ชาไผ่มรกตชุ่ยจู๋** `(44, 65.5)`, **ป้อมด่านพายุทรายหวงซา** `(32.5, 63)` และ **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** `(31, 73)`
- [x] **ความครบถ้วนของสี่ยุคและปฏิทินมาตรฐาน:** ครอบคลุมทั้ง ๔ ห้วงกาล (รอยต่อยุคที่ ๒–๓ การปลูกค่ายไผ่มีชีวิตเจ็ดวง, ยุคที่ ๓ ข้อตกลงหน้าต่างการค้าป้ายไผ่มรกต, ยุคที่ ๔ แนวกักโรคและจ่ายยาถอนพิษเจ็ดชั้น, และยุคที่ ๕ ศักราช ๑๐๑ ความตึงเครียดระหว่าง **เหมี่ยวชิงซี** กับ **กู่ซา** ภายใต้ **แม่เฒ่ามรกต หลันอวี้เจียว**) โดยใช้เฉพาะชื่อเดือนมาตรฐานไทยทั้งสิบสองเดือน
- [x] **ความสอดคล้องกับพงศาวดารห้ารัฐกันชนยุคที่ ๑๐๑:** ตรงตามข้อมูล **แม่เฒ่ามรกต หลันอวี้เจียว** (วัย ๙๒ ปี · เผ่าแมลงหยก · ไร้ทายาทสายตรง · ส่งใบไผ่มรกตแห้งปลายเดือนสิบเอ็ดน้ำค้างแข็ง ปี ๙๙,๙๙๙), **เหมี่ยวชิงซี** (วัย ๓๔ ปี · ฝ่ายขยายการค้าผ่านสุวรรณโพธิ์), **กู่ซา** (ฝ่ายปิดป่ากันสายลับตงหวงและ **ภาคีพิษแมงป่องทมิฬ** ของ **เฒ่าพิษเฮยเซี่ย**), กฎแยกขาดจากสำนักสายพิษ และโทษประหารผู้ลักพาชาวเผ่า
- [x] **ข้อจำกัดและข้อห้ามเด็ดขาด:** เป็นพงศาวดารสถานที่แกนหลัก (ไม่ใช่ภาคแยก ไม่ใช่ตำราสายบำเพ็ญเพียร และไม่ใช่พงศาวดารแม่น้ำหรือขุนเขา) อยู่ภายใต้เพดานพลังโลกเบื้องล่าง ปลอดจากพล็อตและสัญลักษณ์ต้องห้ามทุกรายการ ไม่มีรหัสภาษาอังกฤษดิบในเนื้อหาภาษาไทย และไม่แก้ไขไฟล์เกมใดๆ
