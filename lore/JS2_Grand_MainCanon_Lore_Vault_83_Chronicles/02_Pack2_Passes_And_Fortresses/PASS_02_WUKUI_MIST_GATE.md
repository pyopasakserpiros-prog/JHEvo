# พงศาวดารด่านยุทธศาสตร์หลักอนุทวีป: ด่านหมอกเกราะดำอู๋ขุย

> **บันทึกเอกเทศแกนหลักแห่งอนุทวีป**  
> **สถานที่:** ด่านหมอกเกราะดำอู๋ขุย · แนวหุบเขาหมอกฝั่งตะวันออก อาณาจักรโยวหมิง  
> **ขอบเขตเวลา:** ยุคที่ ๕๐ ปีที่ ๑๑๘ – ยุคที่ ๑๐๑ ปีที่ ๑ (ศ.ท. ๔๙,๑๑๘ – ๑๐๐,๐๐๑)

---

## ๑. ข้อมูลกำกับเอกสารและหมุดยึดแผนที่จริง

| รายการ | รายละเอียดอ้างอิงแกนหลัก |
| :--- | :--- |
| **ชื่อสถานที่อย่างเป็นทางการ** | **ด่านหมอกเกราะดำอู๋ขุย** |
| **สังกัดภูมิรัฐศาสตร์** | อาณาจักรโยวหมิง (รัฐกันชนฝั่งตะวันตกเฉียงเหนือ ภายใต้สนธิสัญญาจุดตรวจม้าเร็วกับตระกูลเหยียน) |
| **ภูมิประเทศและระดับด่าน** | ช่องเขาหินดินดานแนวหุบเขาหมอก · ด่านปราการภูเขาระดับสอง |
| **เพื่อนบ้านใกล้ที่สุดบนแผนที่จริง** | ๑. **ด่านหยกเก่าอวี้กวาน** (หยุนเหอ · ใต้ค่อนตะวันตก)<br>๒. **ด่านประตูมังกรน้ำแข็ง** (เป่ยหมิง · ตะวันตกเฉียงเหนือ)<br>๓. **ตำบลศิลาจารึกสือเปย** (โยวหมิง · ตะวันออก) |
| **ช่วงเวลาครอบคลุม** | สี่มหายุคต่อเนื่อง — ปลายกลียุคเปลี่ยนผ่านยุคกลาง (ยุคที่ ๕๐), ยุคกลาง (ยุคที่ ๘๙), ยุคมหาดุลยภาพสามเส้า (ยุคที่ ๑๐๐), และยุคที่ ๑๐๑ ปัจจุบัน |
| **ฐานอ้างอิงแกนหลัก** | คัมภีร์แม่บทตำนานอนุทวีป และบันทึกฉากปัจจุบันยุคที่ ๑๐๑ ว่าด้วยห้ารัฐกันชน (**เหยียนม่อเหิง**, **เหยียนหว่านอิ๋ง**, **เหยียนซั่ว** และสิบเอ็ดปีสุดท้ายของคำสาป **กู่เทียนเฉิน**) |

บนผืนแผ่นดินพันลี้คูณพันลี้ หากนครโคมวิญญาณโยวหมิงเปรียบเสมือนดวงตาที่เฝ้าชั่งข่าวระหว่างเป่ยหมิงกับซีหรง **ด่านหมอกเกราะดำอู๋ขุย** ก็คือลิ้นวาล์วเหล็กกล้าที่กั้นลมหายใจฝั่งตะวันออกของหุบเขาหมอกเอาไว้ ช่องเขาหินดินดานแห่งนี้แคบเกินกว่าจะเคลื่อนทัพใหญ่ได้สะดวก แต่กลับเป็นคอขวดสายหลักที่เชื่อมถนนหินจาก **ตำบลศิลาจารึกสือเปย** เข้าสู่นครโคมวิญญาณ แยกขึ้นเหนือสู่ **ด่านประตูมังกรน้ำแข็ง** ของเป่ยหมิง และทอดลงใต้สู่ซากปราการ **ด่านหยกเก่าอวี้กวาน** แห่งหยุนเหอ ตลอดกว่าห้าหมื่นปี ด่านอู๋ขุยไม่เคยเป็นสำนักยุทธ์ หากยืนหยัดในฐานะปราการชายแดนที่ยึดถือความเงียบ วินัยเหล็ก และความเที่ยงตรงของตราประทับเหนือคมหอกคมดาบ

---

## ๒. สี่เหตุการณ์ประวัติศาสตร์ข้ามมหายุค

### เหตุการณ์ที่ ๑ (ปลายกลียุคเปลี่ยนผ่านยุคกลาง): วางศิลาเกราะดำกลางหมอกหลังสุริยคราส
* **กาลเวลา:** ยุคที่ ๕๐ ปีที่ ๑๑๘ · เดือนสิบเอ็ดน้ำค้างแข็ง วันที่ ๙ (ศ.ท. ๔๙,๑๑๘)
* **บริบท:** สามร้อยหกปีหลัง **มหาสุริยคราสเจ็ดราตรี** (ยุคที่ ๔๙ ปีที่ ๘๑๒ · ศ.ท. ๔๘,๘๑๒) ซึ่งทิ้งไอหมอกเย็นปกคลุมหุบเขาโยวหมิงถาวร

หลังฟ้ามืดเจ็ดราตรีคลี่คลาย หุบเขาฝั่งตะวันออกของสุสานหมอกโยวหมิงไม่เคยแห้งเหือดจากละอองชื้นอีกเลย ไอหมอกผสมฝุ่นแร่หินหยินกัดกร่อนเกราะเหล็กธรรมดาจนขึ้นสนิมในไม่กี่เดือน ขณะที่กองโจรแตกทัพปลายกลียุคใช้ม่านหมอกเป็นทางลัดปล้นคาราวานระหว่างแดนเหนือกับที่ราบตอนกลาง

ค่ำวันที่เก้า เดือนสิบเอ็ดน้ำค้างแข็ง ยุคที่ ๕๐ ปีที่ ๑๑๘ **อู๋ขุย** อดีตนายกองทหารราบหนักผู้ปฏิเสธการรับใช้ขุนศึกชิงบัลลังก์ นำทหารเก่าเก้าสิบหกนายและช่างตีเหล็กชายแดนสิบสี่ครอบครัวขึ้นสู่สันช่องเขาตะวันออก พวกเขาไร้ธงราชวงศ์ใด มีเพียงเกวียนบรรทุกแท่งเหล็กดำผสมผงหินหยินกับถังยางสนเคี่ยว ตลอดฤดูเหมันต์ อู๋ขุยสั่งสกัดผาหินดินดานเป็นขั้นสลับฟันปลา บีบช่องทางเดินม้าให้เหลือเพียงสองคันเกวียนสวนกัน และหลอม **เกราะแผ่นเหล็กดำเคลือบยางสนรมควัน** แจกจ่ายทุกนาย เกราะนี้ไร้เงาสะท้อนคบไฟ ทนไอกัดกร่อนของหมอกหยิน และบุข้อต่อด้วยหนังกวางชุบไขมันจนเดินยามได้แทบไร้เสียง คืนส่งท้ายปี อู๋ขุยสลักคำสัตย์สามบรรทัดเหนือซุ้มประตูชั้นในว่า *"ไม่ชักธงรุกราน ไม่เปิดช่องให้ทัพผ่านโดยไร้ตรา และไม่ยอมให้ไฟศึกเผาผู้คนเบื้องหลังม่านหมอก"* ตั้งแต่นั้น ช่องเขาแห่งนี้จึงได้นามว่า **ด่านหมอกเกราะดำอู๋ขุย**

### เหตุการณ์ที่ ๒ (ยุคกลาง): ศึกตรึงเงียบสิบเก้าทิวาต้านทัพหน้าแดนเหนือ
* **กาลเวลา:** ยุคที่ ๘๙ ปีที่ ๔๒ · เดือนสิบสองเหมันต์ลึก วันที่ ๑๘ (ศ.ท. ๘๘,๐๔๒)
* **บริบท:** ห้าสิบสี่ปีหลัง **มหาสงครามสามจักรวรรดิสิบสองปี** (ยุคที่ ๘๘ ปีที่ ๙๘๘ · ศ.ท. ๘๗,๙๘๘) ช่วงก้าวเข้าสู่เจ็ดยุคแห่งฎีกากระดาษ

แม้สงครามใหญ่จะสงบลงชั่วคราว แต่กองทัพชายแดนยังคงช่วงชิงจุดยุทธศาสตร์ล่วงหน้า เดือนสิบสองเหมันต์ลึก ยุคที่ ๘๙ ปีที่ ๔๒ **แม่ทัพเถี่ยหาน** ผู้บัญชาการกองหน้าม้าหุ้มเกราะจากแนวป้องกันเหนือ เคลื่อนกำลังสองพันสี่ร้อยนายลงใต้ผ่าน **ด่านประตูมังกรน้ำแข็ง** หมายลัดช่องเขาหมอกทางตะวันออกเพื่ออ้อมตีโอบเส้นทางเชื่อม **ด่านหยกเก่าอวี้กวาน** ภายใต้พายุหิมะ

เวลานั้น ด่านอู๋ขุยมีพลประจำการเพียงสามร้อยยี่สิบนาย ภายใต้การนำของรองแม่ทัพ **เสิ่นอวี้จาง** ผู้เชี่ยวชาญกระแสลมและเสบียง หากเปิดศึกประจัญบานย่อมถูกม้าศึกบดขยี้ในครึ่งชั่วยาม เขาจึงประกาศใช้แผน **"ตรึงเงียบสิบเก้าทิวา"** สั่งดับกระถางไฟบนเชิงเทินทุกดวง ปิดช่องโคมด้านนอก และห้ามส่งเสียงโห่ร้องโดยเด็ดขาด เมื่อทัพเถี่ยหานเข้าสู่ช่องเขาชั้นนอก กองเกราะดำเพียงปล่อยหมุดหินปิดร่องเกวียนและขึงลวดสัมฤทธิ์ดักแรงสั่นตามซอกผา ทุกครั้งที่หน่วยสอดแนมคืบคลานเข้าใกล้ พวกเขาไม่ได้ยินกลองศึก หากได้ยินเพียงเสียงเคาะแผ่นไม้แก่นเหล็กจังหวะสั้นยาวสะท้อนสลับทิศจากผาสองข้าง คู่กับลำแสงสีครามหม่นจากโคมบานเกล็ดที่วูบวาบเพียงชั่วกะพริบตาแล้วดับลง

สิบเก้าวันเต็มกลางลมเหมันต์ ทัพหน้าของเถี่ยหานไม่อาจหยั่งได้ว่าหลังม่านหมอกมีทหารสามร้อยหรือสามหมื่นนาย ม้าศึกตื่นกลัวความเงียบและเสบียงเริ่มร่อยหรอ รุ่งสางวันที่เจ็ด เดือนอ้ายวสันต์ ปีถัดมา แม่ทัพเถี่ยหานจึงสั่งถอยทัพกลับขึ้น **ด่านประตูมังกรน้ำแข็ง** โดยวางป้ายเหล็กหักครึ่งหนึ่งไว้หน้ากองหินเขตแดนเป็นสัญลักษณ์ยอมรับว่าช่องเขานี้มิอาจบุกฝ่าด้วยกำลังได้ง่าย

### เหตุการณ์ที่ ๓ (ยุคมหาดุลยภาพสามเส้า): สนธิสัญญาจุดตรวจม้าเร็วห้าหมอกกับตระกูลเหยียน
* **กาลเวลา:** ยุคที่ ๑๐๐ ปีที่ ๘๖๗ · เดือนเจ็ดสารทแรก วันที่ ๑๒ (ศ.ท. ๙๙,๘๖๗)
* **บริบท:** สองปีหลัง **ปราการด่านหยกอวี้กวานล่มสลาย** (ยุคที่ ๑๐๐ ปีที่ ๘๖๕ · ศ.ท. ๙๙,๘๖๕) จากศึกชิงเส้นทางคาราวาน

การพินาศของอวี้กวานทำให้แนวกันชนทางใต้เปิดโล่ง คาราวาน ผู้ลี้ภัย และม้าเร็วจากทุกทิศเบี่ยงเส้นทางมาแออัดที่ **ด่านหมอกเกราะดำอู๋ขุย** และ **ตำบลศิลาจารึกสือเปย** หากด่านอู๋ขุยยังปิดตัวโดดเดี่ยวย่อมขาดเสบียงและถูกสายลับแทรกซึมจนล่มตามรอยอวี้กวาน

วันที่สิบสอง เดือนเจ็ดสารทแรก ยุคที่ ๑๐๐ ปีที่ ๘๖๗ **เหยียนเจิ้นชาง** ประมุขตระกูลเหยียนรุ่นที่สิบห้าแห่งนครโคมวิญญาณ เดินทางมาเจรจาด้วยตนเองที่ลานหินกลางด่าน และเสนอ **"สนธิสัญญาจุดตรวจม้าเร็วห้าหมอก"** ซึ่งแบ่งอำนาจชัดเจนเป็นสองส่วน ประการแรก กองเกราะดำคงเอกสิทธิ์บัญชาการกำแพงและวินัยทหารสมบูรณ์ ไม่ต้องออกรบแทนราชสำนักใด และยึดกฎ **น้ำบ่อไม่ยุ่งกับน้ำคลอง** ห้ามยุทธภพใช้ด่านเป็นสมรภูมิ ประการที่สอง ด่านอู๋ขุยเปิด **หอชั่งสารสองตรา** ที่ชั้นกลางเป็นจุดคัดกรองม้าเร็วฝั่งตะวันออกของโยวหมิง โดยมีเสมียนสภาบัญชีกลางคืนและ **ตำบลศิลาจารึกสือเปย** ร่วมตรวจครั่งและชั่งน้ำหนักกระบอกสารโดยห้ามเปิดอ่านจดหมายส่วนตัว แลกกับโควตาธัญพืช น้ำมันหินหยิน และแร่เหล็กซ่อมเกราะจากคลังนครโคมวิญญาณทุกฤดูกาล

### เหตุการณ์ที่ ๔ (ยุคที่ ๑๐๑ ปัจจุบัน): คมมีดใต้เงาสิบเอ็ดปีสุดท้ายของบัลลังก์เหมันต์
* **กาลเวลา:** ยุคที่ ๑๐๑ ปีที่ ๑ · เดือนยี่บุปผา วันที่ ๖ (ศ.ท. ๑๐๐,๐๐๑)
* **บริบท:** สามสิบห้าวันหลังวันขึ้นยุคที่ ๑๐๑ ขณะคำสาปสายเลือดของจักรพรรดิ **กู่เทียนเฉิน** แห่งเป่ยหมิงเหลือเพียงสิบเอ็ดปีสุดท้าย และศึกชิงแนวทางในตระกูลเหยียนตึงเครียดขึ้น

วสันตฤดูปีแรกแห่งยุคที่ ๑๐๑ หมอกอุ่นจาก **ด่านหยกเก่าอวี้กวาน** ปะทะลมหนาวจาก **ด่านประตูมังกรน้ำแข็ง** จนช่องเขาอู๋ขุยจมในม่านขาวทึบกว่าทุกปี ภายในโยวหมิง ประมุข **เหยียนม่อเหิง** วัยเจ็ดสิบสี่ปีเริ่มให้สภาบัญชีกลางคืนของธิดาคนรอง **เหยียนหว่านอิ๋ง** วัยสามสิบเจ็ดปี คุมตาชั่งข่าวสองถาด นางสั่ง **"กักแฟ้ม"** อาการประชวรของ **กู่เทียนเฉิน** ไว้ไม่ขายให้ซีหรงเพื่อกันสงครามใหญ่ ทว่าพี่ชายของนางคือ **เหยียนซั่ว** กลับต้องการขายข่าวทัพเป่ยหมิงแลกแร่เหล็ก

คืนวันที่หก เดือนยี่บุปผา ม้าเร็วสองสายปะทะเจตนากันเงียบๆ ที่หอชั่งสารสองตรา สายแรกคือพ่อค้าสมุนไพรปลอมตัวที่ซุกกระบอกไม้ไผ่เคลือบขี้ผึ้งสองชั้นประทับตราลับสาย **เหยียนซั่ว** หมายเล็ดลอดสู่ **ตำบลศิลาจารึกสือเปย** และลงใต้ผ่าน **ด่านหยกเก่าอวี้กวาน** สายที่สองคือหน่วยลาดตระเวนเกราะน้ำแข็งจาก **ด่านประตูมังกรน้ำแข็ง** ภายใต้ระเบียบทัพของอ๋องแปด **กู่เจี้ยนหาน** ที่ประชิดหลักหินฝั่งเหนือยามดึกเพื่อหยั่งเชิงว่าด่านอู๋ขุยยังปิดทางรั่วไหลของข่าวเป่ยหมิงอยู่หรือไม่

นายกอง **หลี่โม่เฉิน** และเสมียน **ซู่เจิน** ยึดคำสั่งตราคู่ของสภาบัญชีกลางคืน สั่งกักกระบอกสารต้องสงสัยไว้ในห้องศิลาปิดผนึกอย่างเงียบเชียบโดยไม่จับกุมคนของเหยียนซั่วให้เกิดรอยร้าวในนครโคมวิญญาณ พร้อมเปิดโคมบานเกล็ดสีอำพันสามจังหวะเตือนหน่วยลาดตระเวนเป่ยหมิงให้ถอยพ้นแนวหิน ด่านอู๋ขุยจึงยืนหยัดบนเส้นด้ายแห่งยุคที่ ๑๐๑ — หากตาชั่งที่หอชั่งสารเอียงเพียงครึ่งสลึง ไฟสงครามอาจลุกลามทั่วแผ่นดินก่อนครบสิบเอ็ดปี

## ๓. ทำเนียบบุคคลสำคัญข้ามสี่ยุค

### ๑. อู๋ขุย — ปฐมนายกองเกราะดำผู้วางศิลาฐานด่าน
* **ช่วงชีวิต:** ปลายกลียุค – ต้นยุคกลาง (ยุคที่ ๔๙ – ๕๐ · ผู้ฝึกตนสายหลอมกายาขั้นสี่)
* **บุคลิกและแรงจูงใจ:** อดีตนายกองทหารราบหนักผู้มีแผลเป็นจากสะเก็ดเหล็กที่ข้อมือซ้าย พูดน้อยและไม่ศรัทธาคำสัญญาของราชสำนักใดหลังเห็นขุนศึกทิ้งหมู่บ้านชายแดนให้มอดไหม้ เขาสร้างด่านอู๋ขุยเพื่อเป็น "ธรณีประตู" ให้ผู้ลี้ภัยและคาราวานพักหายใจได้โดยไม่ต้องก้มหัวให้ขุนศึก
* **มรดก:** สูตรเกราะเหล็กดำรมควันยางสน ระเบียบเดินยามไร้เสียง และคำสัตย์สามบรรทัดบนซุ้มประตูชั้นใน

### ๒. เสิ่นอวี้จาง — รองแม่ทัพผู้บัญชาการศึกตรึงเงียบสิบเก้าทิวา
* **ช่วงชีวิต:** ยุคกลาง (ยุคที่ ๘๙ · ผู้ฝึกตนสายค่ายกลและยุทธวิธีขั้นห้า)
* **บุคลิกและแรงจูงใจ:** สุขุมละเอียดลออประดุจเสมียนคลัง เชื่อว่าชัยชนะสูงสุดของปราการชายแดนคือการทำให้ข้าศึกถอยทัพโดยพลทหารไม่ต้องหลั่งเลือด เขาใช้เวลาสิบสองปีบันทึกทิศทางลมหมอกทุกฤดูกาลจนพลิกศึกปี ๘๘,๐๔๒ ได้หมดจด
* **มรดก:** ตำรา *"แผนผังลมหมอกและจังหวะไม้เคาะ"* คู่มือประจำหอสัญญาณด่านอู๋ขุยที่สืบทอดมากว่าหมื่นปี

### ๓. แม่ทัพเถี่ยหาน — ขุนพลทัพหน้าแดนเหนือผู้ทิ้งป้ายเหล็กหัก
* **ช่วงชีวิต:** ยุคกลาง (ยุคที่ ๘๙ · ยอดฝีมือสายหอกยาวขั้นหก)
* **บุคลิกและแรงจูงใจ:** ขุนพลชายแดนเป่ยหมิงผู้หยิ่งทะนงในศักดิ์ศรีทหารแต่เปี่ยมวิจารณญาณ ไม่ยอมสละชีวิตลูกน้องสองพันสี่ร้อยนายเพื่อศักดิ์ศรีจอมปลอม การวางป้ายเหล็กหักหน้ากองหินเขตแดนก่อนถอยกลับ **ด่านประตูมังกรน้ำแข็ง** สะท้อนจรรยาบรรณนักรบที่เคารพคู่ต่อสู้ผู้มีวินัยทัดเทียมกัน
* **มรดก:** ป้ายเหล็กหักที่ฝังไว้ในผนังศิลาชั้นนอก เตือนใจทั้งสองฟากว่าช่องเขานี้ซื้อไม่ได้ด้วยความหวาดกลัว

### ๔. เหยียนเจิ้นชาง — ประมุขตระกูลเหยียนรุ่นที่สิบห้า ผู้ผูกสนธิสัญญาจุดตรวจม้าเร็ว
* **ช่วงชีวิต:** ยุคมหาดุลยภาพสามเส้า (ยุคที่ ๑๐๐ · ปู่ของเหยียนม่อเหิง · ขุนนางรัฐกันชนสายปัญญา)
* **บุคลิกและแรงจูงใจ:** นักการทูตผู้เย็นชาต่อความโลภระยะสั้น เมื่อเห็น **ด่านหยกเก่าอวี้กวาน** ล่มสลายในปี ๙๙,๘๖๕ เขาตระหนักว่าการให้เกียรติความเป็นอิสระของกองเกราะดำและแบ่งปันเสบียงจะเปลี่ยนด่านอู๋ขุยให้เป็นโล่ที่ซื่อสัตย์ที่สุดของนครโคมวิญญาณ
* **มรดก:** สนธิสัญญาจุดตรวจม้าเร็วห้าหมอก และ **หอชั่งสารสองตรา** ต้นแบบระบบคัดกรองข่าวฝั่งตะวันออก

### ๕. หลี่โม่เฉิน — นายกองเกราะดำประจำด่านอู๋ขุยคนปัจจุบัน
* **ช่วงชีวิต:** ยุคที่ ๑๐๑ ปัจจุบัน (วัย ๕๒ ปี · ผู้ฝึกตนสายหลอมกายาและดาบสั้นขั้นห้า)
* **บุคลิกและแรงจูงใจ:** อดีตศิษย์สายนอกที่วางป้ายสำนักตั้งแต่วัยยี่สิบเพื่อสวมเกราะดำตามกฎไม่ยุ่งศึกยุทธภพ รู้ดีว่าในสิบเอ็ดปีสุดท้ายของคำสาปเป่ยหมิง ชะตาของช่องเขาขึ้นอยู่กับการรักษาระยะห่างอย่างเที่ยงตรงระหว่าง **เหยียนหว่านอิ๋ง**, **เหยียนซั่ว**, และหน่วยลาดตระเวนจาก **ด่านประตูมังกรน้ำแข็ง**
* **ปมขัดแย้ง:** เคยติดหนี้บุญคุณยารักษาบาดแผลจากสายพ่อค้าของเหยียนซั่วเมื่อสิบปีก่อน ทว่าเมื่อต้องกักกระบอกสารลับ เขาเลือกยึดคำสัตย์ของอู๋ขุยเหนือบุญคุณส่วนตัว

### ๖. ซู่เจิน — เสมียนตรวจตราครั่งและผู้คุมหอสัญญาณหมอก
* **ช่วงชีวิต:** ยุคที่ ๑๐๑ ปัจจุบัน (วัย ๓๔ ปี · บัณฑิตตรวจสอบหลักฐานขั้นสาม)
* **บุคลิกและแรงจูงใจ:** หญิงสาวผู้ฝึกคัดลอกอักษรโบราณจาก **ตำบลศิลาจารึกสือเปย** ก่อนถูก **เหยียนหว่านอิ๋ง** ส่งมาประจำหอชั่งสารสองตรา นางแยกแยะครั่งปลอม รอยมีดกรีดซ้ำ และกลิ่นเหงื่อม้าที่ควบเร่งผิดปกติได้ในไม่กี่อึดใจ
* **ปมขัดแย้ง:** นางล่วงรู้ว่ามีสายลับของ **เหยียนซั่ว** แฝงตัวในหมู่ช่างลอกศิลาตำบลสือเปย จึงต้องชั่งน้ำหนักระหว่างการรายงานตรงต่อนครโคมวิญญาณกับการถ่วงเวลาให้ **เหยียนหว่านอิ๋ง** คลี่คลายเงียบๆ โดยไม่จุดชนวนศึกสายเลือด

## ๔. กายวิภาคปราการด่านเกราะดำและระบบสัญญาณหมอก

ด่านหมอกเกราะดำอู๋ขุยถูกออกแบบให้กลมกลืนกับผาหินดินดานและม่านหมอกเย็นโดยไม่พึ่งค่ายกลสิ้นเปลืองปราณระดับสูง หากอาศัยวิศวกรรมศิลา โลหะวิทยา และระเบียบข่าวกรองที่ทำงานได้แม้ยามปราณฟ้าดินแปรปรวน

### โครงสร้างปราการสามชั้น
1. **ชั้นนอก — แนวกองหินเขตแดนและร่องชะลอเกวียน:** ห่างจากประตูหลักสองร้อยก้าว แท่นศิลาสี่คู่เรียงสลับฟันปลาบังคับให้เกวียนและม้าลดความเร็วเหลือจังหวะเดินเท้า พร้อมช่องสลักหินที่ปลดหมุดถ่วงน้ำหนักปิดถนนได้ในสิบอึดใจ
2. **ชั้นกลาง — ลานพักม้าและหอชั่งสารสองตรา:** พื้นที่กึ่งเปิดตามสนธิสัญญายุคที่ ๑๐๐ มีคอกม้าเปลี่ยนผลัด โรงชาร้อน และ **หอชั่งสารสองตรา** ที่แบ่งโต๊ะตรวจเป็นสองฟาก — ฟากหนึ่งชั่งน้ำหนักและตรวจครั่งโดยเสมียนโยวหมิง อีกฟากตรวจอาวุธและป้ายผ่านทางโดยกองเกราะดำ ชาวยุทธ์ทุกสำนักต้องห่อผ้าคลุมฝักอาวุธและเก็บธงสำนักก่อนผ่านซุ้มประตูตามกฎน้ำบ่อไม่ยุ่งกับน้ำคลอง
3. **ชั้นใน — ป้อมเกราะดำและคลังศิลาใต้ผา:** ซ้อนตัวบนชะง่อนหินสูงสิบห้าจั้ง เป็นที่ตั้งโรงหลอมซ่อมเกราะ คลังธัญพืชสำรองหกเดือน และห้องศิลาผนึกครั่งสำหรับกักเก็บสารต้องสงสัยรอคำสั่งสภาบัญชีกลางคืน

### โลหะวิทยาเกราะดำและระบบสัญญาณหมอก
* **ชุดเกราะเหล็กดำอู๋ขุย:** ตีจากเหล็กหยาบผสมผงหินหยินบดละเอียดแล้วรมควันยางสนและไขมันสัตว์ ผิวเกราะสีดำด้านดูดกลืนแสงคบไฟและกันสนิมจากหมอกชื้นได้นับสิบปี ข้อต่อร้อยด้วยหนังฟอกน้ำมันให้พลทหารเดินยามเลียบเชิงเทินได้แทบไร้เสียง
* **โคมบานเกล็ดน้ำมันหินหยิน:** ใช้โคมศิลาติดบานเกล็ดไม้สลับซี่คู่แผ่นแก้วแร่สามสี — **สีอำพัน** (สถานะปกติและเตือนหน่วยลาดตระเวนให้หยุดหน้าเขตแดน), **สีครามหม่น** (พบสารต้องสงสัยหรือปิดช่องทางชั่วคราว), และ **สีชาดเข้ม** (ระดมพลเกราะดำเต็มกำลัง) ลำแสงแคบพุ่งทะลุหมอกได้ไกลกว่าคบเพลิงสามเท่า
* **ท่อลมควันยางสนและแผ่นไม้เคาะจังหวะ:** วันใดหมอกทึบจนมองไม่เห็นแสงโคม หอสัญญาณจะจุดยางสนผสมผงแร่ปล่อยควันขาวหรือเทาดำตามปล่องหินรับลมส่งข่าวไปยังแนวเฝ้าระวังใกล้ **ตำบลศิลาจารึกสือเปย** ส่วนการสื่อสารในกำแพงใช้ **แผ่นไม้แก่นเหล็กเคาะจังหวะสั้นยาว** ร่วมกับ **สายลวดสัมฤทธิ์ขึงข้ามซอกผา** โยงเข้าตุ้มหินบนหอยามเพื่อจับแรงสั่นของการลอบข้ามเขาโดยไม่ต้องใช้เสียงอึกทึก

## ๕. ปมสังเกตการณ์และแรงกระเพื่อมในยุคที่ ๑๐๑

ในโลกจำลองเชิงสังเกตการณ์ยุคที่ ๑๐๑ **ด่านหมอกเกราะดำอู๋ขุย** เป็นจุดตัดที่แรงกดดันทางการเมือง เศรษฐกิจ และยุทธภพกระเพื่อมถึงกันโดยธรรมชาติ

1. **รอยรั่วสารลับของเหยียนซั่ว:** คาราวานแผ่นลอกศิลาและสมุนไพรระหว่างนครโคมวิญญาณกับ **ตำบลศิลาจารึกสือเปย** อาจซุกซ่อนรหัสข่าวของ **เหยียนซั่ว** หากหลุดรอดการตรวจของ **ซู่เจิน** ลงใต้ผ่าน **ด่านหยกเก่าอวี้กวาน** ไปถึงสายลับซีหรง ความตึงเครียดชายแดนจะพุ่งสูงและเขย่าราคาแร่เหล็กกับค่าคุ้มกันคาราวานในหยุนเหอทันที
2. **การหยั่งเชิงจากด่านประตูมังกรน้ำแข็ง:** ตลอดสิบเอ็ดปีสุดท้ายของคำสาป **กู่เทียนเฉิน** หน่วยลาดตระเวนเป่ยหมิงสาย **กู่เจี้ยนหาน** จะเพิ่มความถี่ในการตรวจแนวผาเหนือ หาก **หลี่โม่เฉิน** ตอบโต้แรงเกินไปอาจทำให้เป่ยหมิงปิดด่านไม้สนตามที่ **เหยียนหว่านอิ๋ง** กังวล แต่หากผ่อนปรนเกินไปก็เปิดช่องให้สายลับเหนือแทรกซึม
3. **เส้นทางอพยพเงาของชาวอวี้กวานเก่า:** ลูกหลานพ่อค้าจาก **ด่านหยกเก่าอวี้กวาน** มักผ่านด่านอู๋ขุยไปเทียบทะเบียนสายตระกูลและโฉนดเก่าที่ **ตำบลศิลาจารึกสือเปย** ก่อให้เกิดข่าวลือและภารกิจคุ้มกันคาราวานเชื่อมหยุนเหอกับโยวหมิง
4. **บททดสอบกฎน้ำบ่อไม่ยุ่งกับน้ำคลอง:** จอมยุทธ์ทุกสำนักที่ผ่านช่องเขาต้องปลดธงและห่อฝักอาวุธ หากผู้ใดก่อวิวาทหรือข่มขู่เสมียนหอชั่งสาร จะถูกขึ้นบัญชีห้ามผ่านด่านและส่งชื่อเข้าสมุดสภาบัญชีกลางคืน กระทบชื่อเสียงและเส้นทางข้ามแดนระยะยาว
5. **ความผิดปกติของกระแสหมอกหยินต้นยุคที่ ๑๐๑:** ยามรุ่นเก่าบนป้อมชั้นในสังเกตว่าตั้งแต่คืนส่งท้ายยุคที่ ๑๐๐ ต่อเนื่องถึงเดือนยี่บุปผา หมอกเย็นมักลอยต่ำพร้อมกลิ่นดินชื้นผิดฤดูกาลในคืนเดือนดับ สอดคล้องกับข่าวลือแรงสั่นสะเทือนใต้พิภพทั่วอนุทวีปโดยยังไร้ผู้ล่วงรู้ต้นสายปลายเหตุ

## ๖. รายการตรวจสอบความสอดคล้องแกนหลัก

| หัวข้อตรวจสอบ | สถานะ | รายละเอียดการยืนยัน |
| :--- | :---: | :--- |
| **ขอบเขตสถานที่เฉพาะเจาะจง** | ผ่าน | มุ่งเน้นเฉพาะ **ด่านหมอกเกราะดำอู๋ขุย** บนแผนที่จริงของอาณาจักรโยวหมิง ไม่ใช่ภาคแยก วิถีบำเพ็ญ หรือตำนานภูเขาและแม่น้ำ |
| **หมุดเชื่อมเพื่อนบ้านบนแผนที่จริง** | ผ่าน | เชื่อมโยงตรงกับ **ด่านหยกเก่าอวี้กวาน** (หยุนเหอ), **ด่านประตูมังกรน้ำแข็ง** (เป่ยหมิง), และ **ตำบลศิลาจารึกสือเปย** (โยวหมิง) รวมถึงนครโคมวิญญาณ |
| **ปฏิทินพันปีและเดือนไทยมาตรฐาน** | ผ่าน | คำนวณศักราชตรงสูตรทุกยุค (`ศ.ท. ๔๙,๑๑๘`, `๘๘,๐๔๒`, `๙๙,๘๖๗`, `๑๐๐,๐๐๑`) และใช้เฉพาะชื่อเดือนไทยมาตรฐาน |
| **ความสอดคล้องตระกูลเหยียนยุคที่ ๑๐๑** | ผ่าน | ตรงกับข้อมูล **เหยียนม่อเหิง** (รุ่นที่ ๑๗ วัย ๗๔), **เหยียนหว่านอิ๋ง** (วัย ๓๗ · สภาบัญชีกลางคืน · กักแฟ้มอาการประชวร), **เหยียนซั่ว**, และสิบเอ็ดปีสุดท้ายของ **กู่เทียนเฉิน** |
| **เพดานพลังโลกเบื้องล่าง** | ผ่าน | ตัวละครทั้งหมดอยู่ในระดับสามัญชนถึงผู้ฝึกตนขั้นสาม–หก ไม่เกินเพดานตบะโลกเบื้องล่าง และเคารพกฎอายุขัยสมจริง |
| **ปลอดข้อห้ามและรหัสโค้ดดิบ** | ผ่าน | ปลอดพล็อตซ้ำซากต้องห้ามตามกฎแม่บท ไม่แตะต้องสามปริศนาปลายเปิด และปราศจากรหัสโค้ดภาษาอังกฤษดิบในเนื้อหาภาษาไทย |
| **ไม่แก้ไขไฟล์ตัวเกม** | ผ่าน | บันทึกเป็นเอกสารพงศาวดารเอกเทศในคลังตำนานด่านเท่านั้น ไม่มีการแตะต้องหรือแก้ไขไฟล์ตัวเกม |
