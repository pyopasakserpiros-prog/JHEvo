# แผ่นดินที่ยังมีชื่อคนกลับบ้าน

มหากาพย์แปดเล่มของ JianghuSect 2 ว่าด้วยวิธีที่คนธรรมดารักษาความรับผิดชอบต่อคนที่หายไป ตั้งแต่ทางขนคนหนีน้ำยุคมหาคลองถึงวันที่เมืองยุค 101 ต้องเปิดทางอีกครั้ง แต่ละเล่มเล่าเหตุและผลของคนรุ่นหนึ่งโดยมีทางเชื่อมกับประวัติศาสตร์หลักของอนุทวีป ตัวละครรุ่นหลังรับช่วงผ่านสำเนา แบบบัญชี สิ่งก่อสร้าง และธรรมเนียมที่ถูกปรับตามปัญหาของยุคตน

**สถานะ:** ร่างเนื้อเรื่องสำหรับคลังนำไปใช้ในอนาคต อ้างฐาน `main` คอมมิต `ea8097e` และตำนานศึกดาราคล้อยใน JS2 v3.17.0 ชื่อเรื่องและหมายเลขเล่มด้านล่างเป็นลำดับภายในชุด ยังไม่ใช่หมายเลขของคลังในเกม

## จุดเชื่อมและขอบเขต

- [คัมภีร์แม่บท](../../MASTER_LORE_BIBLE.md) กำหนดช่วงมหายุค ภูมิรัฐศาสตร์ สนธิสัญญาหยุนเหอ ปฏิทิน และปริศนาใหญ่ทั้งสาม เล่ม 1–7 เพิ่มประวัติศาสตร์ระดับชุมชนใต้เหตุที่กำหนดไว้ เล่ม 8 เปิดเมื่อสภาพโลกเหมาะสม
- อ่าน [ตำนานการขุดมหาคลอง](../../GAME_SOURCE/data/lore_chronicle_e4_e12_grand_canal_and_river_reshaping.js), [ทุพภิกขภัยน้ำค้างแข็ง](../../GAME_SOURCE/data/lore_chronicle_e40_e43_lantern_monks_and_frost_famine.js), [สหพันธ์คาราวานหยกทอง](../../GAME_SOURCE/data/lore_chronicle_e54_e59_merchant_caravan_hegemony_and_salt_wars.js) และ [ตำนานต้าเหริน](../../GAME_SOURCE/data/lore_chronicle_e74_e82_turning_point_death_of_republican_dream.js) เมื่อเลือกตำแหน่งย่อยหรือขยายบทตามประวัติศาสตร์
- เหตุข้ามยุคใช้การคัดลอกเอกสารและการถ่ายทอดของชุมชน เล่ม 8 อ้างอิง [ตำนานเล่ม 106](../../GAME_SOURCE/data/lore_chronicle_b106_fallen_star_pear_blossom.js) กับ [รายงานศึก](../../PATCH_REPORTS/FALLEN_STAR_CAMPAIGN_JS2_V3_17_0.md) ผลศึก การกลับมาพบกัน และทางเลือกของ NPC เปลี่ยนได้ตามโลก
- ชื่อเฉพาะที่เสนอใหม่ เช่น แคว้นด่านซู่เจี้ยนและสำนักเตาเงาสน ใช้ในขอบเขตท้องถิ่น เรื่องเน้นการเดินทาง อาหาร แรงงาน การย้ายถิ่น และสิทธิ์เข้าถึงที่พัก งานเขียนไม่ได้ออกแบบมหาวิถี สายย่อย หรือการเพิ่มตบะ

หากใช้ในอนาคต เลือกแปลงเป็นเอกสารอ่านในหอ เรื่องเล่าของคนท้องถิ่น หรือเหตุการณ์ตามสภาพโลก บางร่องรอยเป็นข้อมูลเพียงอย่างเดียว ส่วนบางร่องรอยให้คนมีเหตุผลที่จะกลับไปซ่อมทาง ช่วยเหลือเพื่อน หรือทวงถามสิทธิ์ของตน
