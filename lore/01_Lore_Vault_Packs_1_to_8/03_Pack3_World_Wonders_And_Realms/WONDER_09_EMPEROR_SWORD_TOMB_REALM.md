# ตำนานแดนลับในเกม: สุสานกระบี่จักรพรรดิบรรพกาล (เปิดครั้งแรก ศ.ท. ๔,๐๑๔ · บูรณะผนึกยุคที่ ๒๙ ศ.ท. ๒๘,๖๐๐ – ๑๐๐,๐๐๑)

> **เอกสารตำนานกระแสหลักประจำแดนลับจริงในเกม · ฉบับสมบูรณ์ข้ามสี่ยุคสมัย**  
> **ขอบเขตเนื้อหา:** ปฐมบทสัตยาบันฝังคมแห่งยุคที่ ๒๙, ด่านพิพากษาเที่ยงธรรมของหุ่นศิลาองครักษ์กระบี่หมื่นปี, คณะสำรวจตรึงผนึกสี่ฤดูของเจ็ดหอในยุคที่ ๘๑, และการแข่งขันช่วงชิงมรดกของสำนักผู้เล่นกับสิบเก้าสำนักเสาหลักในยุคที่ ๑๐๑ เฉพาะแดนลับ **สุสานกระบี่จักรพรรดิบรรพกาล**

## ๑. ข้อมูลพื้นฐานและหมุดยึดแดนลับในเกม (Metadata & In-Game Secret Realm Anchors)

| หัวข้อข้อมูล | รายละเอียดตามคัมภีร์แม่บทและโครงสร้างแดนลับจริงในเกม |
| :--- | :--- |
| **ชื่อแดนลับอย่างเป็นทางการ** | **สุสานกระบี่จักรพรรดิบรรพกาล** |
| **ภูมิภาคใหญ่ที่ตั้ง** | **แนวเทือกเขาหิมะอุดร** (สันเขาสูงเหนือแนวชายแดนมหาจักรวรรดิเป่ยหมิง ระหว่างเขตอิทธิพลของ **ยอดเขากระบี่สวรรค์เทียนเจี้ยน** กับ **สำนักกระบี่เมฆขาว** เหนือเส้นทางขึ้นจาก **ป้อมพยัคฆ์คำรามผ่าศิลา**) |
| **ลักษณะทางกายภาพ** | มหาสุสานศิลาใต้ยอดเขาหิมะนิรันดร์ ขุดเจาะลึกลงสู่สายแร่ปฐมธาตุทองคำ ประดับด้วยกระบี่หักของขุนพลทั้งฝ่ายผู้ชนะและฝ่ายผู้แพ้ ปิดปากถ้ำด้วยผนึกสี่ฤดู |
| **ระดับความอันตรายในเกม** | **ระดับ ๕** (ขั้นสูงสุดของแดนลับโบราณเปิดตามฤดูกาล) |
| **ผู้พิทักษ์ประจำแดนลับ** | **หุ่นศิลาองครักษ์กระบี่หมื่นปี** (หุ่นศิลาแกนปฐมธาตุทองคำ จารึกเจตจำนงกระบี่จากสิบสองสมรภูมิทั้งสองฝั่ง) |
| **มรดกและรางวัลหลัก** | **คัมภีร์มหาเวทกระบี่สวรรค์** และ **แก่นปฐมธาตุทองคำ** (พร้อมศิลาวิญญาณราว ๕๘๐ ก้อน และร่องรอยเคล็ดวิชาสายกระบี่-ดาบยุคโบราณ อาทิ *เพลงกระบี่เงาเกล็ดน้ำแข็งพริบตา* และ *ดาบเขี้ยววายุคลั่งตัดพายุ*) |
| **กลไกการปรากฏในโลกและกฎวัฏจักร (เล่มที่ ๔๒)** | เชื่อมประตู **ปากถ้ำศิลารับอรุณ** · **เปิดครั้งแรก:** ยุคที่ ๕ ปีที่ ๑๔ เดือนอ้ายวสันต์ วันที่ ๑๕ (`ศ.ท. ๔,๐๑๔`) · **วัฏจักร:** เปิดทุก **๑๒ ปี** นาน **๑๕ วัน** (รอบถัดไป: ยุคที่ ๑๐๑ ปีที่ ๒ เดือนยี่บุปผา วันที่ ๙) · **เพดานตบะ:** คัดกรองไม่เกิน **ขั้นที่ ๓ สร้างรากฐาน** (หรือขั้นที่ ๑ กายาเหล็กไหล) ให้ **สำนักผู้เล่น** และ **๑๙ สำนักเสาหลักภายนอก** ส่งศิษย์แข่งขันช่วงชิงมรดกอย่างเท่าเทียม |
| **ช่วงเวลาที่ครอบคลุม** | ซากมิติบรรพกาลเปิดครั้งแรก ยุคที่ ๕ ปีที่ ๑๔ (ศ.ท. ๔,๐๑๔) · บูรณะและผนึกซ้ำ ยุคที่ ๒๙ ปีที่ ๖๐๐ (ศ.ท. ๒๘,๖๐๐) · ยุคที่ ๕๒ ปีที่ ๓๑๘ (ศ.ท. ๕๑,๓๑๘) · ยุคที่ ๘๑ ปีที่ ๔๕๐ (ศ.ท. ๘๐,๔๕๐) · ยุคที่ ๑๐๑ ปีที่ ๑–๒ (ศ.ท. ๑๐๐,๐๐๑–๑๐๐,๐๐๒) |

ในคำเล่าลือของจอมยุทธ์รุ่นหลัง **สุสานกระบี่จักรพรรดิบรรพกาล** คือคลังศาสตราของราชันย์ผู้ไร้พ่ายที่พิชิตแดนเหนือด้วยคมกระบี่เดียว ทว่าความจริงใต้หิมะเจ็ดหมื่นปีกลับตรงข้ามโดยสิ้นเชิง ผู้หลับใหลในโลงหินไร้ทองคำเบื้องในคือผู้พิชิตผู้เหนื่อยล้าแห่งยุคที่ ๒๙ ที่ชนะสิบสองสมรภูมิรวดเพียงเพื่อตระหนักว่าทุกชัยชนะของตนกำลังสูบเลือดเนื้ออนุทวีปจนแห้งผาก ก่อนสิ้นลม ณ เพดานตบะขั้นที่ ๙ แห่งโลกเบื้องล่าง เขาจึงรวบรวมกระบี่หักของขุนพลทั้งฝ่ายตนและฝ่ายศัตรูมาฝังเคียงกันในสุสานแห่งนี้ เพื่อยุติเพลิงแค้นสายเลือด มิใช่เพื่อเชิดชูสงคราม

## ๒. สี่มหาเหตุการณ์ข้ามสี่ยุคสมัย (Four Multi-Era Chronological Events)

### เหตุการณ์ที่ ๑ · มหายุคที่ ๒ (กลียุคแปดก๊กและวัฏจักรหมื่นราชวงศ์)
**วันเวลา:** ยุคที่ ๒๙ ปีที่ ๖๐๐ · เดือนสิบเอ็ดน้ำค้างแข็ง วันที่ ๑๒ (ศ.ท. ๒๘,๖๐๐)  
**ชื่อเหตุการณ์:** **สัตยาบันฝังคมสิบสองทัพ — คืนจักรพรรดิกระบี่ผู้เหนื่อยล้าปลดมงกุฎลงใต้หิมะอุดร**

ปลายยุคที่ ๒๘ หลังจักรวรรดิจันทราเหมันต์ปิงเยว่ล่มสลาย แดนเหนือตกอยู่ในความระส่ำระสาย ขณะที่มหาจักรวรรดิเป่ยหมิงกำลังฟื้นตัวและร่วมวางรากฐาน **ศาลธรรมนูญสัตย์สาบาน** เจ็ดขุนศึกแดนหิมะกลับชิงอำนาจเข่นฆ่ากันไม่หยุด **เซียวเจี้ยนผิง** ยอดฝีมือกระบี่ผู้บรรลุ **เพดานตบะขั้นที่ ๙ แห่งโลกเบื้องล่าง** นำทัพพันธมิตรบ้านแตกคว้าชัยสิบสองสมรภูมิรวดจนผู้คนขนานนามว่า "จักรพรรดิกระบี่แห่งแดนเหมันต์"

ทว่าในคืนหลังชัยชนะครั้งที่สิบสอง เซียวเจี้ยนผิงกลับนั่งมองศพพลทหารวัยเยาว์ที่ตายปะปนกันจนแยกเกราะสองฝั่งไม่ออก รุ่งสางเขาเห็นหมู่บ้านเชิงเขาไร้ชายฉกรรจ์ เหลือเพียงหญิงชราหลอมผาลไถนาเป็นหัวธนู และเห็นแววตาอาฆาตของบุตรชายขุนพลทั้งสองฝ่ายที่ต่างซ่อนมีดสั้นรอวันล้างแค้น เขาจึงตระหนักว่าหากตนสวมมงกุฎตั้งราชวงศ์ ชัยชนะครั้งที่สิบสองจะเป็นเพียงเชื้อไฟของศึกครั้งที่สิบสาม

วันที่สิบสอง เดือนสิบเอ็ดน้ำค้างแข็ง ปีที่ ๖๐๐ แห่งยุคที่ ๒๙ เซียวเจี้ยนผิงซึ่งลมปราณร่วงโรยตามอายุขัยธรรมชาติและปฏิเสธการฝืนชะตาทะลวงม่านฟ้า ได้เชิญรองแม่ทัพคู่ใจ **หลี่เจิ้งชาน** กับเชลยศึก **มู่หรงฉี** บุตรชายขุนพลใหญ่ฝ่ายพ่ายแพ้ ขึ้นสู่ **ซากถ้ำสายแร่ทองคำและรอยแยกมิติปากถ้ำศิลารับอรุณ** บนยอดเขาหิมะอุดร — ซึ่งตามบันทึกเล่มที่ ๔๒ เคยเปิดออกเป็นครั้งแรกตั้งแต่ **ยุคที่ ๕ ปีที่ ๑๔ เดือนอ้ายวสันต์ วันที่ ๑๕ (ศ.ท. ๔,๐๑๔)** ในฐานะถ้ำศิลาจารึกวิถีกระบี่บรรพกาล ก่อนถูกหิมะถล่มกลบทางเข้าในยุคกลางต้น — เพื่อบูรณะ ต่อเติมค่ายกล และผนึกซ้ำเหนือฐานมิติโบราณนั้น ต่อหน้าพยานทั้งสองทัพ เขาโยนมงกุฎเหล็กดำลงเตาหลอม หักปลายกระบี่คู่กายออกครึ่งชุ่น แล้วให้ทั้งสองฝ่ายร่วมกันปักกระบี่หักของขุนพลผู้ล่วงลับจากทั้งฝ่ายชนะและฝ่ายแพ้รวมหนึ่งร้อยแปดเล่มเรียงเคียงกันลงในลานศิลาโดยห้ามสลักตราฝ่ายหรือคำว่าผู้ชนะ

คืนนั้น เซียวเจี้ยนผิงสละ **แก่นปฐมธาตุทองคำ** บูรณะและหล่อหัวใจใหม่ให้ **หุ่นศิลาองครักษ์กระบี่หมื่นปี** พร้อมจารึกอักขระคัดกรองปากถ้ำให้ยึดตามวัฏจักรเดิม (**เปิดทุก ๑๒ ปี นาน ๑๕ วัน**) และจำกัด **เพดานตบะผู้เข้าสำรวจไม่เกินขั้นที่ ๓ สร้างรากฐาน (หรือขั้นที่ ๑ กายาเหล็กไหล)** เพื่อป้องกันไม่ให้ยอดฝีมือขั้นสูงเข้ามาแย่งชิงจนเกิดสงครามซ้ำรอย แล้วซ่อน **คัมภีร์มหาเวทกระบี่สวรรค์** ซึ่งเป็นเคล็ดกระบี่หักคมและสยบจิตสังหารไว้หลังโลงศิลา ครั้นประกาศ **สัตยาบันฝังคมสิบสองทัพ** ปลดปล่อยเชลยทั้งหมดแล้ว เขาก็ปิดประตูศิลาจากด้านในและสิ้นลมอย่างสงบ ทิ้งเพียงคำจารึกว่า *"กระบี่ผู้ชนะกับกระบี่ผู้แพ้หนักเท่ากันบนตราชั่งแห่งหิมะ ผู้ใดแบกความแค้นเข้ามา จงทิ้งชีวิตไว้ใต้คมศิลา"*

### เหตุการณ์ที่ ๒ · มหายุคที่ ๓ (ยุคกลาง สิบสองอาณาจักร และยุคฎีกากระดาษ)
**วันเวลา:** ยุคที่ ๕๒ ปีที่ ๓๑๘ · เดือนสามวสันต์ปลาย วันที่ ๒๔ (ศ.ท. ๕๑,๓๑๘)  
**ชื่อเหตุการณ์:** **คืนคมกระบี่ไม่เลือกหน้า — กลุ่มนักขุดสุสานชุดแรกกับบทพิพากษาเที่ยงธรรมของหุ่นศิลา**

เวลาล่วงผ่านกว่าสองหมื่นสองพันปีสู่ต้นยุคกลางสิบสองอาณาจักร เจตนารมณ์เดิมของเซียวเจี้ยนผิงเลือนหายเหลือเพียงนิทานเล่าลือเรื่องคลังสมบัติจักรพรรดิไร้พ่าย วันที่ยี่สิบสี่ เดือนสามวสันต์ปลาย ปีที่ ๓๑๘ แห่งยุคที่ ๕๒ เมื่อหิมะละลายเผยร่องผา **กลุ่มพันธมิตรหมาป่าหิมะ** สามสิบหกคน นำโดยอดีตนายกองรับจ้าง **หานกู่เฟิง** และช่างกลปลดผนึกหญิง **เสิ่นเหลียนอิง** ลอบเจาะอุโมงค์บุกเข้าสู่สุสานได้เป็นคณะแรก

เมื่อถึง **โถงตาชั่งสองคม** หานกู่เฟิงหัวเราะเยาะป้ายศิลาที่เรียงชื่อสองฝ่ายปะปนกัน เขาเหยียบศิลาของขุนพลฝ่ายแพ้แล้วฟันโซ่ผนึกหวังคว้ากระบี่ทองเหลืองกลางแท่น ทันใดนั้นประตูศิลาปิดตายและ **หุ่นศิลาองครักษ์กระบี่หมื่นปี** สูงสามจั้งก็ลุกขึ้นจากแท่นบัลลังก์ สิ่งที่สร้างความสะพรึงมิใช่เพียงความแกร่ง หากคือความเที่ยงธรรมของค่ายกล ทุกครั้งที่ลูกสมุนปล่อยจิตสังหารหรือแทงหลังพวกพ้องเพื่อแย่งทางหนี แรงกดดันจะทวีคูณและชักนำคมกระบี่ของหุ่นศิลาเข้าปลิดชีพผู้ลงมือก่อนเสมอ เมื่อหานกู่เฟิงผลักลูกหาบขาหักไปรับคมแทนตน กระบี่ศิลากลับหักเลี้ยวข้ามร่างคนเจ็บไปสะบั้นทวนและปลิดชีพหานกู่เฟิงในกระบวนท่าเดียว

ท่ามกลางซากศพนักล่าสมบัติ **เสิ่นเหลียนอิง** ที่อ่านกลไกของโถงตาชั่งออก ตัดสินใจวางอาวุธและเครื่องมือทั้งหมดลงพื้น เดินไปประคองลูกหาบผู้บาดเจ็บสองคน แล้วปักกระบี่พกของตนลงข้างกระบี่หักโบราณโดยไม่แตะสมบัติแม้แต่ชิ้นเดียว ทันใดนั้นเสียงค่ายกลก็เงียบสงบลง หุ่นศิลาลดกระบี่ลงแนบกาย และประตูศิลาด้านข้างก็เปิดให้ผู้รอดชีวิตทั้งสามเดินออกสู่แสงตะวัน เสิ่นเหลียนอิงจึงเขียน **"บันทึกหิมะเปื้อนคม"** เผยแพร่สู่ยุทธภพว่า สุสานนี้มิได้พิพากษาตามยศศักดิ์หรือฝ่ายธรรมะ-อธรรม หากพิพากษาจิตใจของผู้ชักคม

### เหตุการณ์ที่ ๓ · มหายุคที่ ๓ (ยุคไร้เสียงและแม่น้ำเถ้า · ก่อนกฎบัตรสหพันธ์เจ็ดหอ)
**วันเวลา:** ยุคที่ ๘๑ ปีที่ ๔๕๐ · เดือนแปดใบไม้ร่วง วันที่ ๙ (ศ.ท. ๘๐,๔๕๐)  
**ชื่อเหตุการณ์:** **คณะสำรวจผนึกเจ็ดหอแห่งยุคไร้เสียง — การวางเสาตรึงผนึกสี่ฤดูและกติกาแดนลับตามวาระ**

เข้าสู่ห้วง **ยุคไร้เสียงและแม่น้ำเถ้า** ภัยแล้งยาวนานทำให้ธารน้ำแข็งบนเทือกเขาหิมะอุดรละลายถอยร่นจนปากประตูสุสานเปิดอ้าติดต่อกันสามเดือน นักดาบพเนจรและสำนักยุทธ์หลายฝ่ายแห่ขึ้นเขาฆ่าฟันกันเองจนศพทับถมและปลุกไอสังหารของหุ่นศิลาล้นออกมานอกถ้ำ ก่อนที่ราชสำนักเป่ยหมิงจะฉวยโอกาสส่งทัพหลวงเข้ายึดยอดเขาอันจะละเมิดกฎ **น้ำบ่อไม่ยุ่งกับน้ำคลอง** องค์กรกลางทั้งเจ็ดหอในยุคก่อร่าง (ก่อนการลงนามกฎบัตรสหพันธ์องค์กรกลางเจ็ดหออย่างเป็นทางการในปี ศ.ท. ๘๙,๓๑๐) จึงจัดตั้งคณะสำรวจร่วม นำโดยหัวหน้าชุดผนึกจากหอผนึกชาด **กวนชิงเหอ** คู่กับอาลักษณ์จากหอจดหมายเหตุกลาง **โจวซือหยา** และช่างกุญแจจากหอผู้ถือกุญแจผนึก

วันที่เก้า เดือนแปดใบไม้ร่วง ปีที่ ๔๕๐ แห่งยุคที่ ๘๑ คณะสำรวจสิบสองคนปลดศาสตราทั้งหมดไว้เชิงเขาแล้วเดินเข้าสู่สุสานด้วยมือเปล่า หุ่นศิลาองครักษ์เพียงยืนจ้องมองนิ่งโดยไม่ขยับ เปิดทางให้โจวซือหยาคัดลอกศิลาจารึกสัตยาบันปี ศ.ท. ๒๘,๖๐๐ ออกมาได้ครบถ้วนเป็นครั้งแรก กวนชิงเหอคัดค้านแผนระเบิดปิดถ้ำถาวรเพราะเกรงสายแร่ปฐมธาตุทองคำใต้ดินจะอัดแน่นจนระเบิดทำลายสันเขา เขาจึงติดตั้ง **"เสาตรึงผนึกสี่ฤดู"** แปดต้นรอบซุ้มประตู ให้สุสานปิดสนิทในยามปกติและคลายผนึกเฉพาะวาระกระแสปราณธาตุทองคำหนุนส่ง พร้อมวางกติการ่วมกับเป่ยหมิงและสำนักใหญ่แดนเหนือว่า ห้ามราชสำนักใดอ้างกรรมสิทธิ์เหนือสุสาน ให้เปิดเป็นแดนลับกลางเฉพาะยอดฝีมือสายสำนักยุทธ์เข้าพิสูจน์ตนตามฤดูกาลเท่านั้น

### เหตุการณ์ที่ ๔ · มหายุคที่ ๕ (รุ่งอรุณแห่งยุคที่ ๑๐๑ · วันเริ่มเกม)
**วันเวลา:** ยุคที่ ๑๐๑ ปีที่ ๑ · เดือนอ้ายวสันต์ วันที่ ๑ – เดือนสิบเหมันต์แรก (ศ.ท. ๑๐๐,๐๐๑)  
**ชื่อเหตุการณ์:** **เสียงกระบี่หักใต้หิมะอุดร — สนามแข่งขันข้ามสิบเก้าสำนักและบททดสอบของสำนักผู้เล่น**

รุ่งสางวันที่หนึ่ง เดือนอ้ายวสันต์ ปีที่ ๑ แห่งยุคที่ ๑๐๑ ท่ามกลางวิกฤตคำสาปสายเลือดเป่ยหมิงที่เหลือสิบเอ็ดปีสุดท้ายและภาวะขาดแคลนแร่เหล็กดาวตกในแดนเหนือ เสาตรึงผนึกสี่ฤดูหน้าสุสานส่งเสียงครวญก้องเป็นครั้งแรกในรอบหลายทศวรรษ ยืนยันว่าประตูแดนลับกำลังจะเปิดตามวาระฤดูกาลของปีนี้

ข่าวการตื่นตัวของสุสานดึงดูดยอดฝีมือจาก **๑๙ สำนักเสาหลัก** ขึ้นสู่ยอดเขาหิมะอุดร **สำนักกระบี่เมฆขาว** ของปรมาจารย์ไป๋หยุนส่งศิษย์เอก **ไป๋ชิงอวิ๋น** มารอเชิงเขาเพื่อหวังชิง **แก่นปฐมธาตุทองคำ** ไปพยุงคลังศาสตรา **ยอดเขากระบี่สวรรค์เทียนเจี้ยน** ส่งผู้ตรวจการชุดขาวมาเฝ้ากันไม่ให้ **คัมภีร์มหาเวทกระบี่สวรรค์** ตกสู่มือฝ่ายอธรรม ขณะที่หน่วยล่าสมบัติของ **วังอสูรทวนโลหิตซิวหลัว** กับ **ภาคีมารกลืนสวรรค์เก้าโลหิต** ลอบตัดชายแดนโยวหมิงขึ้นมาประชันหน้ากันเอง ส่วน **หมู่ตึกหมื่นวิถีรังสรรค์** ของนายท่านใหญ่ว่านเซี่ยงส่งช่างกลมาแกะรอยกลไกหุ่นศิลา และ **ป้อมพยัคฆ์คำรามผ่าศิลา** ของขุนพลเล่ยหู่ก็ส่งศิษย์ทระนงมาร่วมวัดฝีมือ

ท่ามกลางกระดานอันดุเดือด **สำนักผู้เล่น** ภายใต้เจ้าสำนักรุ่นที่ ๗ จากหุบเขาหยุนเหอมีสิทธิส่งศิษย์ขึ้นเหนือเข้าร่วมแข่งขันได้อย่างเท่าเทียมตามกติกาเจ็ดหอ และความลับที่มหาสำนักส่วนใหญ่หลงลืมยังคงทำงานอย่างเย็นเยียบ—ยิ่งคู่แข่งห้ำหั่นกันด้วยความโลภ หุ่นศิลาองครักษ์กระบี่หมื่นปียิ่งทวีความดุดัน เปิดช่องให้คณะสำรวจขนาดเล็กที่ครองสติมั่นคงคว้ามรดกตัดหน้ามหาสำนักได้จริง

## ๓. ทำเนียบบุคคลสำคัญข้ามยุคสมัย (Character Dossiers)

* **๑. เซียวเจี้ยนผิง (萧剑平) — "จักรพรรดิกระบี่บรรพกาล" ผู้ปลดมงกุฎ *(มหายุคที่ ๒ · ยุคที่ ๒๙)***  
  ยอดฝีมือกระบี่ขั้นที่ ๙ แห่งโลกเบื้องล่าง ผู้พิชิตสิบสองสมรภูมิหลังจักรวรรดิปิงเยว่ล่มสลาย แทนที่จะตั้งราชวงศ์หรือฝืนทะลวงฟ้า เขาเลือกหลอมมงกุฎและฝังกระบี่หักของขุนพลทั้งสองฝั่งร่วมกันใต้หิมะอุดร เพื่อยุติเพลิงแค้นสายเลือด
* **๒. มู่หรงฉี (慕容齐) — ทายาทขุนพลฝ่ายพ่ายแพ้ผู้ร่วมสัตยาบัน *(มหายุคที่ ๒ · ยุคที่ ๒๙)***  
  บุตรชายแม่ทัพใหญ่ฝ่ายศัตรูที่ยอมหักกระบี่บรรพบุรุษลงฝังเคียงข้างกระบี่ของเซียวเจี้ยนผิง หลังเห็นศัตรูจารึกนามบิดาตนอย่างเท่าเทียม ใช้บั้นปลายชีวิตเฝ้าดูแลศิลาจารึกนอกหุบเขาและห้ามลูกหลานทั้งสองฝั่งกลับมารบกันอีก
* **๓. หานกู่เฟิง (韩孤峰) — หัวหน้ากลุ่มหมาป่าหิมะผู้สังเวยด่านพิพากษา *(มหายุคที่ ๓ · ยุคที่ ๕๒)***  
  อดีตนายกองทหารรับจ้างผู้เชื่อมั่นในกฎผู้แข็งแกร่งกลืนกินผู้อ่อนแอ การเหยียบย่ำป้ายศิลาและทรยศลูกหาบที่บาดเจ็บทำให้เขาถูกหุ่นศิลาองครักษ์ปลิดชีพในกระบวนท่าเดียว เป็นอุทาหรณ์แรกของความเที่ยงธรรมแห่งสุสาน
* **๔. เสิ่นเหลียนอิง (沈连英) — ช่างกลผู้รอดชีวิตและผู้เขียน "บันทึกหิมะเปื้อนคม" *(มหายุคที่ ๓ · ยุคที่ ๕๒)***  
  ช่างกลปลดผนึกที่ยอมวางอาวุธลงประคองลูกหาบบาดเจ็บจนรอดชีวิตออกจากโถงตาชั่งสองคม บันทึกของเธอกลายเป็นกุญแจสำคัญที่ช่วยให้คณะสำรวจเจ็ดหอในยุคที่ ๘๑ เข้าสุสานได้โดยไม่เสียเลือดเนื้อ
* **๕. กวนชิงเหอ (关清河) — หัวหน้าคณะสำรวจผนึกเจ็ดหอ *(มหายุคที่ ๓ · ยุคที่ ๘๑)***  
  ผู้เชี่ยวชาญค่ายกลอาวุโสจากหอผนึกชาดในยุคไร้เสียง ผู้คัดค้านทั้งการระเบิดสุสานและการให้ราชสำนักเป่ยหมิงยึดครอง เป็นผู้ออกแบบ **เสาตรึงผนึกสี่ฤดู** และวางกติกาแดนลับเปิดตามวาระสืบมาถึงยุคที่ ๑๐๑
* **๖. ไป๋ชิงอวิ๋น (白清云) — ศิษย์เอกสำนักกระบี่เมฆขาว *(มหายุคที่ ๕ · ยุคที่ ๑๐๑)***  
  ยอดฝีมือสายกระบี่ผู้สุขุมรับบัญชาปรมาจารย์ไป๋หยุนนำทัพขึ้นชิงแก่นปฐมธาตุทองคำในยุคที่ ๑๐๑ เคยอ่านสำเนา *บันทึกหิมะเปื้อนคม* จึงระมัดระวังไม่ก่อศึกไร้เหตุผลในโถงตาชั่ง ทำให้เป็นคู่แข่งที่น่าเกรงขามที่สุด

## ๔. กายวิภาคห้องสุสานและสถาปัตยกรรมด่านพิพากษาเที่ยงธรรม (Tomb Chambers & Impartial-Trial Architecture Anatomy)

### โครงสร้างห้องสุสาน ๕ ชั้น
๑. **ซุ้มประตูหิมะและเสาตรึงผนึกสี่ฤดู:** ปากทางเข้าศิลาเทาล้อมด้วยเสาอักขระชาดแปดต้นที่คณะเจ็ดหอติดตั้งในปี ศ.ท. ๘๐,๔๕๐ เพื่อหน่วงกระแสปราณธาตุทองคำให้เปิดเฉพาะวาระฤดูกาล หน้าซุ้มยังมีเงาอักษรคำเตือนปี ศ.ท. ๒๘,๖๐๐  
๒. **ลานปักคมไร้ธง:** โถงวงกลมปูหินแกรนิตสีคราม ปักกระบี่หักหนึ่งร้อยแปดเล่มของขุนพลทั้งฝ่ายชนะและฝ่ายแพ้เรียงเป็นวงก้นหอย ใต้โคนสลักเพียงชื่อสกุลและวันตายโดยไร้ตราฝ่าย  
๓. **โถงตาชั่งสองคม:** ทางเดินยาวหกสิบจั้งใต้คานชั่งศิลามหึมา ค่ายกลตอบสนองต่อจิตสังหารและปราณโลหิต หากคณะสำรวจห้ำหั่นกันเอง คานชั่งจะเอียงลงและปลดปล่อยคมปราณธาตุทองคำกดทับทุกฝ่ายอย่างเท่าเทียม  
๔. **ลานศิลาองครักษ์หมื่นปี:** สนามประลองแปดเหลี่ยมใจกลางสุสาน ถิ่นพำนักของ **หุ่นศิลาองครักษ์กระบี่หมื่นปี** สูงสามจั้งที่สลับใช้เพลงกระบี่ของขุนพลทั้งสองฝั่งสิบสองสมรภูมิได้อย่างคล่องแคล่ว  
๕. **หอฝังมงกุฎและแท่นคัมภีร์หักคม:** ห้องในสุดที่ตั้งโลงหินเรียบง่ายไร้ทองคำของเซียวเจี้ยนผิงคู่เบ้าหลอมมงกุฎเหล็กดำ ด้านหลังคือแท่นสถิตของ **คัมภีร์มหาเวทกระบี่สวรรค์** และ **แก่นปฐมธาตุทองคำ**

### กฎแห่งด่านพิพากษาเที่ยงธรรมสามประการ
* **กฎแห่งความเท่าเทียมใต้หิมะ:** ค่ายกลไม่จำแนกธรรมะ อธรรม หรือฝ่ายกลาง และไม่ยำเกรงป้ายราชสำนัก ศิษย์จากสำนักเล็กในหยุนเหอกับยอดฝีมือแดนศักดิ์สิทธิ์ต้องรับเกณฑ์พิพากษาเดียวกัน
* **กฎแห่งแรงสะท้อนจิตสังหาร:** ยิ่งผู้บุกรุกลอบทำร้ายพวกพ้อง เหยียบย่ำศิลาผู้วายชนม์ หรือเปิดศึกฆ่าฟันชิงสมบัติก่อนถึงลานองครักษ์ ความดุดันของ **หุ่นศิลาองครักษ์กระบี่หมื่นปี** จะยิ่งทวีคูณ
* **กฎแห่งการวางคมเพื่อรับคม:** ผู้ที่ไม่ทำลายกระบี่หักในลานปักคมและรับมือหุ่นศิลาด้วยสติสงบ จะอ่านช่องว่างระหว่างกระบวนท่าสิบสองสมรภูมิออกและสัมผัสร่องรอยเคล็ดวิชาโบราณบนผนังศิลาได้มากที่สุด

## ๕. ตะขอแดนลับยุคที่ ๑๐๑ และการจำลองโลกสังเกตการณ์ (Epoch 101 Secret-Realm & Observer Hooks)

* **๑. การช่วงชิงระหว่างสำนักผู้เล่นกับ ๑๙ สำนักเสาหลัก:** ทุกคราวที่สุสานเปิดผนึกตามฤดูกาลในยุคที่ ๑๐๑ สำนักผู้เล่นต้องชั่งน้ำหนักการส่งศิษย์เอกขึ้นสู่แดนอันตรายระดับ ๕ เพื่อแข่งชิง **คัมภีร์มหาเวทกระบี่สวรรค์**, **แก่นปฐมธาตุทองคำ**, และศิลาวิญญาณ ๕๘๐ ก้อนตัดหน้ามหาสำนักภายนอก
* **๒. แรงกระเพื่อมต่อวิกฤตแร่เหล็กดาวตกแดนเหนือ:** หาก **สำนักกระบี่เมฆขาว** คว้าแก่นปฐมธาตุทองคำได้สำเร็จ วิกฤตศาสตราแนวหน้าฝ่ายธรรมะจะคลี่คลาย แต่หากตกสู่มือ **สำนักผู้เล่น** หรือ **หมู่ตึกหมื่นวิถีรังสรรค์** ตลาดแร่เหล็กดาวตกและสายคาราวานของ **หมู่ตึกวาณิชย์หลงเหมิน** จะตึงตัวขึ้นทันที
* **๓. รอยร้าวฝ่ายอธรรมประจิมกลางโถงตาชั่ง:** เมื่อหน่วยของ **วังอสูรทวนโลหิตซิวหลัว** และ **ภาคีมารกลืนสวรรค์เก้าโลหิต** หักหลังกันเองกลางโถงตาชั่งสองคม โทสะของหุ่นศิลาองครักษ์มักทำให้ทั้งสองฝ่ายบอบช้ำ เปิดจังหวะทองให้คณะสำรวจที่สุขุมกว่าอย่างสำนักผู้เล่นหรือ **ป้อมพยัคฆ์คำรามผ่าศิลา** ผ่านด่านตัดหน้า
* **๔. เส้นแดงกฎน้ำบ่อฯ กับราชสำนักเป่ยหมิง:** แม้วังหลวงเป่ยหมิงต้องการแก่นปฐมธาตุทองคำท่ามกลางวิกฤตคำสาปสิบเอ็ดปี แต่ด้วยข้อตกลงปี ศ.ท. ๘๐,๔๕๐ และสายตาของ **หอผนึกชาด** กับ **ยอดเขากระบี่สวรรค์เทียนเจี้ยน** ราชสำนักไม่อาจส่งทัพหลวงขึ้นเขาได้ตรง ๆ จึงต้องหันไปใช้สัมปทานว่าจ้างสำนักยุทธ์ลงแข่งแทน

## ๖. บัญชีตรวจทานกฎเหล็กความถูกต้อง (Canon-Lock Checklist)

| รายการตรวจสอบ | ผลตรวจ | รายละเอียดยืนยัน |
| :--- | :---: | :--- |
| **ปฏิทิน ๑,๐๐๐ ปีต่อยุคและสูตรปีโลก** | **ผ่าน** | ยุค ๒๙ ปี ๖๐๐ = ศ.ท. ๒๘,๖๐๐ · ยุค ๕๒ ปี ๓๑๘ = ศ.ท. ๕๑,๓๑๘ · ยุค ๘๑ ปี ๔๕๐ = ศ.ท. ๘๐,๔๕๐ · ยุค ๑๐๑ ปี ๑ = ศ.ท. ๑๐๐,๐๐๑ |
| **ใช้เฉพาะ ๑๒ ชื่อเดือนไทยมาตรฐาน** | **ผ่าน** | ใช้เฉพาะ เดือนอ้ายวสันต์, เดือนสามวสันต์ปลาย, เดือนแปดใบไม้ร่วง, เดือนสิบเหมันต์แรก, เดือนสิบเอ็ดน้ำค้างแข็ง |
| **สี่มหายุคสอดคล้องคัมภีร์แม่บท** | **ผ่าน** | เชื่อมช่วงหลังปิงเยว่และศาลสัตย์ยุค ๒๙, ต้นยุคกลางยุค ๕๒, ยุคไร้เสียงยุค ๘๑ (ก่อนกฎบัตรเจ็ดหอปี ศ.ท. ๘๙,๓๑๐), และวันเริ่มเกมยุค ๑๐๑ |
| **หมุดยึดแดนลับในเกมครบถ้วน** | **ผ่าน** | ตรงตามแดนลับจริง: **สุสานกระบี่จักรพรรดิบรรพกาล**, แนวเทือกเขาหิมะอุดร, อันตรายระดับ ๕, **หุ่นศิลาองครักษ์กระบี่หมื่นปี**, **คัมภีร์มหาเวทกระบี่สวรรค์**, **แก่นปฐมธาตุทองคำ** |
| **เพดานโลกเบื้องล่างขั้นที่ ๙** | **ผ่าน** | เซียวเจี้ยนผิงบรรลุเพียงขั้นที่ ๙ ไร้ขั้นที่สูงกว่า ไม่ทะลวงม่านกั้นภพ และไม่เฉลยสามปริศนาปลายเปิด |
| **กฎน้ำบ่อฯ และวัฏจักรสามมหาอำนาจ** | **ผ่าน** | สะท้อนเป่ยหมิงช่วงฟื้นตัวหลังปิงเยว่ และเคารพเส้นแดงไม่ส่งทัพหลวงยึดแดนลับ |
| **ปลอดพล็อตซ้ำซากต้องห้าม** | **ผ่าน** | หักมุมจักรพรรดิไร้พ่ายสู่ผู้ยุติสงคราม และปลอดองค์ประกอบต้องห้ามตามคัมภีร์แม่บททุกประการ |
| **ปลอดรหัสโค้ดเกมดิบในเนื้อหา** | **ผ่าน** | ใช้ภาษาไทยวรรณศิลป์ตลอดฉบับ ไม่มีรหัสระบบภาษาอังกฤษปะปน |
| **ไม่แก้ไขไฟล์ตัวเกม** | **ผ่าน** | บันทึกเฉพาะเอกสารตำนานแยกเดี่ยว ไม่แตะต้องไฟล์ตัวเกมหรือซอร์สโค้ดใด ๆ |
