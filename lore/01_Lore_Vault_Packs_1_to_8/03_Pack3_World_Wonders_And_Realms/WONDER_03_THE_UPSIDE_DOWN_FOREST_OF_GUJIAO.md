# พงศาวดารสิ่งมหัศจรรย์แห่งมหาทวีป: ป่าห้อยหัวแห่งรากฟ้า — เขตชีวนิเวศลับใต้หลุมยุบหินปูนกู่เจียว

## ๑. ข้อมูลกำกับพงศาวดารและเมล็ดพันธุ์แผนที่อัปเดตในอนาคต

| รายการ | รายละเอียด |
| :--- | :--- |
| **ชื่อสถานที่แกนหลัก** | **ป่าห้อยหัวแห่งรากฟ้า** (เขตชีวนิเวศลับใต้หลุมยุบหินปูนกู่เจียว) |
| **สังกัดและภูมิภาค** | แคว้นกู่เจียว · เขตบึงชุ่มน้ำใต้ลึก (ใต้ผืนพรุหินปูนระหว่างลุ่มน้ำมรกตกับแนวป่าทึบชายบึง · *หมายเหตุจำแนกตามคัมภีร์แม่บท: แห่งนี้คือระบบนิเวศชีวภาพรากพฤกษาเกาะเพดานถ้ำหินปูนตามธรรมชาติ ไร้ความวิปริตของแรงโน้มถ่วง คนละสถานที่กับ **ผนึกแดง-๐๖ ป่าไผ่กลับหัวแห่งหุบเขาฉือเยี่ยน** ในเล่มที่ 64 ซึ่งเป็นเขตแรงโน้มถ่วงสลับทิศและความทรงจำตกค้างระดับผนึกแดง*) |
| **เมล็ดพันธุ์พิกัดอัปเดตในอนาคต** | สิ่งมหัศจรรย์ทางธรรมชาติใหม่สำหรับอัปเดตแผนที่แดนใต้ · พิกัดแนะนำ `(32.4, 78.2)` · หลุมยุบหินปูนซ่อนตัวใต้บึงชุ่มน้ำ |
| **หมุดหมายเพื่อนบ้านบนแผนที่จริง** | เหนือเฉียงตะวันตก: **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** `(31, 73)` · ตะวันออกเฉียงเหนือ: **ด่านค่ายไผ่หมอกเจ็ดชั้น** `(38, 67.5)` · ใต้: **นครเสาขวัญหมื่นกู่** `(35, 89.5)` และ **หมู่บ้านพรานเขี้ยวจระเข้** `(38.5, 93.4)` · ตะวันตก: **นครผาทองสุวรรณโพธิ์** `(19.5, 78.5)` |
| **ขอบเขตช่วงเวลา** | ยุคที่ ๙ ปีที่ ๕๐๐ ถึง ยุคที่ ๑๐๑ ปีที่ ๑ (ศ.ท. ๘,๕๐๐ – ๑๐๐,๐๐๑ · ข้ามสี่ยุคสมัย) |
| **ผลผลิตยุทธศาสตร์ประจำถิ่น** | **ยางไม้กันเน่ารากฟ้า** เคลือบกระดูกงูเรือเดินสมุทร, **เห็ดเรืองแสงห้อยถ้ำ** และ **น้ำค้างแร่อุ่นใต้พิภพ** สำหรับปรุงยาถอนพิษ |
| **ผู้พิทักษ์ยุคที่ ๑๐๑** | สภาสิบสองเผ่าบึงมรกต นำโดย **แม่เฒ่ามรกต หลันอวี้เจียว** (วัย ๙๒ ปี), **เหมี่ยวชิงซี** (วัย ๓๔ ปี) และ **ชุมพรานสะพานแขวนรากฟ้า** |
| **กฎเหล็กแห่งหลุมยุบ** | ห้ามโค่นลำต้นและห้ามตัดรากแม่เด็ดขาด เก็บเฉพาะน้ำยางตามฤดูและเห็ดสุกงอม แยกขาดจากสำนักสายพิษภายนอก และห้ามพ่อค้าต่างแคว้นล่วงล้ำลงสู่ก้นหลุม |

ห่างลงไปทางใต้เฉียงตะวันออกจาก **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** ราวครึ่งวันถ่อเรือผ่านดงกกสูงท่วมหัว ผืนบึงโคลนมรกตของ **แคว้นกู่เจียว** ดูเผิน ๆ คล้ายป่าราบไร้จุดหมาย ทว่าเมื่อแหวกม่านเถาเฟิร์นเข้าสู่แอ่งหินปูนกว้างกว่าสามลี้ โลกเบื้องล่างกลับยุบตัวลงเป็นโพรงถ้ำมโหฬารลึกกว่าแปดสิบวา ราวฟ้าดินเจาะบ่อแก้วซ่อนไว้ใต้เปลือกดิน สิ่งที่ตรึงสายตาผู้พบเห็นมิใช่เพียงความลึกของเหวหิน หากคือมหาพฤกษานับร้อยต้นที่ **หยั่งรากเกาะแน่นอยู่ตามขอบปากเหวรับแสงตะวันและเพดานถ้ำหินปูน แล้วทิ้งลำต้นและเรือนยอดห้อยหัวดิ่งลงสู่เบื้องล่าง** เรือนใบสีมรกตเจือเส้นปราณเรืองแสงแผ่สยายกลางอากาศราวโคมระย้ามีชีวิต ยืดปลายยอดลงไปดูดซับไอหมอกแร่อุ่นสีฟ้าจางที่ลอยกรุ่นขึ้นมาจาก **ทะเลสาบน้ำพุร้อนใต้พิภพ** ณ ก้นหลุม ชาวเผ่ากู่เจียวขนานนามดินแดนลับนี้ว่า **ป่าห้อยหัวแห่งรากฟ้า** — อู่โอสถและยางไม้กันเน่าที่หล่อเลี้ยงบึงมรกตเงียบงันมาเกือบแสนปี

## ๒. สี่ห้วงกาลแห่งป่าห้อยหัวแห่งรากฟ้า (ศ.ท. ๘,๕๐๐ – ๑๐๐,๐๐๑)

### เหตุการณ์ที่ ๑ (ยุคที่ ๙ ปีที่ ๕๐๐ · ศ.ท. ๘,๕๐๐)
**การค้นพบหลุมยุบใต้พิภพโดยคณะหมอสมุนไพรเผ่าโบราณผู้หนีภัยแล้ง**

ปลายยุคที่เก้าแห่งศักราชเทียนกู่ ลมร้อนจากขอบทะเลทรายตะวันตกพัดข้ามแนวเขาเข้าสู่แดนใต้อย่างวิปริต ก่อเกิด **ภัยแล้งดินแตกระแหงเจ็ดฤดู** ตั้งแต่ปีที่ ๔๙๘ จนถึงปีที่ ๕๐๐ คูคลองรอบบึงชุ่มน้ำเหือดแห้งจนโคลนแตกเป็นเกล็ดปลา ว่านแก้พิษและไม้ใหญ่ชายป่าตายยืนต้นเป็นแถบ เผ่าหมอยาโบราณสายรากพฤกษาซึ่งตั้งถิ่นฐานอยู่ใกล้แหล่งน้ำดั้งเดิมก่อนการก่อร่าง **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** เผชิญภาวะอดอยากและโรคไข้ไอพิษระบาดหนัก

**เดือนห้าสุริยัน วันที่สิบสี่ ยุคที่ ๙ ปีที่ ๕๐๐ (ศ.ท. ๘,๕๐๐)** **เฒ่าฉางหลิง** หมอสมุนไพรหญิงวัยห้าสิบแปดปีแห่งเผ่าตักน้ำค้าง สังเกตเห็นฝูงนกกระจาบหางหยกและค้างคาวกินผลไม้บินหายเข้าไปใต้ซุ้มรากไทรกลางแอ่งหินปูนแห้งผาก นางจึงนำศิษย์หมอยาสิบสองคนผูกเชือกเถาวัลย์ไต่ลงตามรอยแยกหินที่ยังมีไอชื้นอุ่นพวยพุ่ง เมื่อพ้นช่องหินแคบเข้าสู่โถงถ้ำกว้าง ลมหายใจของทุกคนพลันสะดุดค้าง เบื้องบนเพดานหินปูนที่เปิดปล่องรับลำแสงอาทิตย์มีรากไม้ขนาดหลายโอบพันเกลียวแน่นกับหินพรุนราวกรงเล็บมังกร ขณะที่ลำต้นสีน้ำตาลอมหยกกลับ **ห้อยหัวดิ่งลงกลางอากาศ** กิ่งก้านแผ่สยายเรืองแสงสีเขียวอมทองอาบไอน้ำอุ่นจากทะเลสาบใต้ดินเบื้องล่าง

เฒ่าฉางหลิงลองแตะน้ำยางสีอำพันที่ซึมตามเปลือกไม้ห้อยหัวพบว่าไม่เน่าเสียแม้ตากแดดจัด และเมื่อต้มดอก **เห็ดเรืองแสงห้อยถ้ำ** ที่ขึ้นเกาะตามง่ามกิ่งกับน้ำแร่อุ่นก้นหลุม อาการไข้ไอพิษของชาวเผ่ากลับทุเลาลงภายในสามวัน **เดือนเจ็ดสารทแรก วันที่แปด** ปีเดียวกัน เผ่าหมอยาจึงตั้งหลักลับริมชะง่อนผาชั้นบนและจารึก **คำสาบานรากฟ้า** บนแผ่นหินปูนว่า *"ต้นไม้คืนชีวิตให้ผู้หลบภัย จงรับเพียงน้ำตาไม้และดอกเห็ด อย่าได้คมขวานใดแตะต้องรากแม่เป็นอันขาด"*

### เหตุการณ์ที่ ๒ (ยุคที่ ๓๖ ปีที่ ๒๑๘ · ศ.ท. ๓๕,๒๑๘)
**กำเนิดชุมพรานสะพานแขวนรากฟ้าและสัตยาบันกรีดยางสามข้อ**

ล่วงผ่านมากว่าสองหมื่นหกพันปี หลุมยุบหินปูนกลายเป็นแหล่งเสาะหา **ยางไม้กันเน่ารากฟ้า** ซึ่งชาวเผ่าพบว่าเมื่อเคี่ยวผสมเปลือกไม้ชุ่มน้ำแล้วนำไปยาแนวท้องเรือ จะทำให้เรือไม้ทนทานต่อเพรียงทะเลและน้ำเค็มได้นานกว่าเรือทั่วไปถึงสามเท่า ทว่าการโรยตัวด้วยเชือกเดี่ยวเพื่อเก็บน้ำยางจากต้นไม้ที่ห้อยหัวอยู่กลางอากาศนั้นเสี่ยงตายยิ่ง ทั้งยังมีพรานรุ่นหลังบางกลุ่มกรีดเปลือกลึกเกินไปจนลำต้นห้อยหัวสามต้นร่วงหล่นลงสู่ทะเลสาบน้ำพุร้อน

**เดือนสามวสันต์ปลาย วันที่เก้า ยุคที่ ๓๖ ปีที่ ๒๑๘ (ศ.ท. ๓๕,๒๑๘)** **ป้าเหอซิน** ช่างสานเถาวัลย์วัยสี่สิบเก้าปี กับ **อาตง** พรานปีนผาหนุ่มแห่งสายสกุลเหมี่ยว ร่วมกันคิดค้นวิธีถัก **สะพานแขวนเถาอสรพิษมีชีวิต** พาดเชื่อมระหว่างชะง่อนหินปูนรอบผนังถ้ำเข้ากับปลอกหวายหุ้มลำต้นไม้ห้อยหัวโดยไม่ตอกตะปูหรือเจาะเนื้อไม้แม้แต่รูเดียว พวกเขาก่อตั้ง **ชุมพรานสะพานแขวนรากฟ้า** เป็นหน่วยเก็บเกี่ยวประจำหลุมยุบ และประกาศ **สัตยาบันกรีดยางสามข้อ** ต่อหน้าสภาเผ่าใน **เดือนแปดใบไม้ร่วง วันที่ยี่สิบเอ็ด** ปีเดียวกัน ได้แก่ ข้อหนึ่ง ห้ามกรีดยางเกินหนึ่งฝ่ามือต่อหนึ่งลำต้นในรอบสามปี และต้องพอกแผลด้วยโคลนแร่ก้นหลุมทันที ข้อสอง เก็บเฉพาะ **เห็ดเรืองแสงห้อยถ้ำ** ที่ขอบหมวกคลี่เต็มที่แล้วเพื่อเหลือสปอร์ให้ลอยตามไอน้ำขึ้นไปเกาะกิ่งใหม่ และข้อสาม ปิดปากหลุมด้วยแนวไผ่หนามและเถาพรางตา ห้ามขุดทางเกวียนเข้าใกล้ขอบเหวในรัศมีห้าลี้ นับแต่นั้น **หมู่บ้านสะพานแขวน** ตามระเบียงหินปูนชั้นกลางจึงถือกำเนิดขึ้น หล่อเลี้ยงคลังโอสถของ **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** และอู่ต่อเรือแดนใต้ผ่านเส้นทางเรือถ่อลับอย่างยั่งยืน

### เหตุการณ์ที่ ๓ (ยุคที่ ๗๔ ปีที่ ๖๔๐ · ศ.ท. ๗๓,๖๔๐)
**ความพินาศของกองคณะตัดไม้เถื่อนและมหาภัยสะท้อนก้องแห่งถ้ำรากฟ้า**

กลางมัชฌิมกาล เมื่ออู่ต่อเรือพาณิชย์เถื่อนตามแนวเกาะชายทะเลตะวันออกขาดแคลนไม้ทนน้ำเค็ม ข่าวลือเรื่อง *"ป่าไม้ทิพย์กลับหัวใต้บึงกู่เจียวที่ทั้งต้นอิ่มด้วยยางกันเน่า"* รั่วไหลผ่านนายหน้าพ่อค้าไม้ไร้จรรยาบรรณนาม **เฉินจู๋เกอ** แทนที่จะรับซื้อยางไม้ตามโควตา เขากลับว่าจ้างทหารรับจ้างพเนจรและพรานตัดไม้เถื่อนกว่าหกสิบคน พร้อมมือมีดจากกลุ่มโจรลัทธิพิษชายขอบซึ่งรู้เส้นทางลัดเลี่ยง **ด่านค่ายไผ่หมอกเจ็ดชั้น**

**เดือนสิบเหมันต์แรก วันที่สิบเจ็ด ยุคที่ ๗๔ ปีที่ ๖๔๐ (ศ.ท. ๗๓,๖๔๐)** กองคณะตัดไม้เถื่อนลอบเข้าสู่ขอบหลุมยุบยามดึกด้วยกว้านเหล็ก โซ่ตะขอ และ **เลื่อยเพลิงเคลือบน้ำมันสน** หวังตัดรากยึดเพดานของมหาพฤกษาห้อยหัวเจ็ดต้นใหญ่ให้ร่วงลงผิวน้ำแล้วชักรอกขึ้นปากเหว เสียงเลื่อยเหล็กเสียดสีรากแม่สะท้อนก้องในโพรงหินปูนปลุก **ชุมพรานสะพานแขวน** นำโดย **หัวหน้าพราน กู่เหลียนซาน** ให้ลุกขึ้นต้านทาน ทว่าก่อนที่ฝ่ายป้องกันจะตัดเชือกกว้านได้หมด คมเลื่อยเพลิงก็ฟันเข้าสู่ท่อน้ำยางหลักของต้นรากแม่โบราณต้นหนึ่งจนขาดสะบั้น

สิ่งที่เฉินจู๋เกอไม่เคยล่วงรู้คือกลไกชีวนิเวศของป่าห้อยหัว เมื่อท่อน้ำยางแรงดันสูงฉีกขาด น้ำยางดิบเข้มข้นที่ยังมีไอระเหยติดไฟได้พุ่งสาดลงปะทะคบเพลิงกลางอากาศ ก่อลูกไฟสีเขียวมรกตวาบสว่างทั่วเพดานถ้ำ แรงกระแทกจากกิ่งยักษ์ที่ขาดร่วงลงสู่ **ทะเลสาบน้ำพุร้อนใต้พิภพ** ปลุกปล่องไอน้ำแร่ก้นบึงให้พวยพุ่งย้อนขึ้นอย่างรุนแรงราวพายุเดือด คลื่นเสียงก้องสะท้อนในถ้ำทำให้หินงอกเพดานถล่มทับกว้านเหล็กพังพินาศ กองคณะตัดไม้เถื่อนแตกกระเจิง บาดเจ็บและถูกควันยางรมจนสลบไสล ถูกนักรบเผ่ากู่เจียวจับกุมเกือบทั้งหมด **เดือนสิบเอ็ดน้ำค้างแข็ง วันที่สาม** สภาสิบสองเผ่าสั่งเนรเทศนายหน้าและประหารมือสังหารลัทธิพิษที่ลักพาพรานนำทาง ก่อนที่กู่เหลียนซานจะนำชาวบ้านปลูกหน่อรากแม่ทดแทนและวาง **ข่ายรากเตือนภัย** รอบรอยแยกหินปูนทุกช่อง

### เหตุการณ์ที่ ๔ (ยุคที่ ๑๐๐ ปีที่ ๙๙๘ – ยุคที่ ๑๐๑ ปีที่ ๑ · ศ.ท. ๙๙,๙๙๘ – ๑๐๐,๐๐๑)
**สนธิสัญญาคุ้มครองรากฟ้าภายใต้แม่เฒ่ามรกตหลันอวี้เจียวและเหมี่ยวชิงซี**

เข้าสู่ปลายยุคที่ ๑๐๐ เมื่อคลื่นปราณชีพจรมังกรเริ่มสั่นสะเทือนใต้พื้นพิภพ **ทะเลสาบน้ำพุร้อนใต้พิภพ** ในหลุมยุบกู่เจียวมีอุณหภูมิสูงขึ้นเล็กน้อย ส่งผลให้ **เห็ดเรืองแสงห้อยถ้ำ** ออกดอกสะพรั่งผิดปกติและมียางไม้กันเน่าคุณภาพสูงซึมออกมามากกว่าศตวรรษก่อน ทว่าความมั่งคั่งนี้กลับจุดชนวนความเห็นต่างในสภาสิบสองเผ่าบึงมรกตระหว่าง **เหมี่ยวชิงซี** วัยสามสิบสี่ปี ผู้เห็นควรส่งออกยางไม้และยาถอนพิษส่วนเกินอย่างโปร่งใสผ่านหน้าต่างการค้า **ท่าเรือสุวรรณโพธิ์** เพื่อสร้างพันธมิตรและรายได้เสริมปราการ กับ **กู่ซา** ผู้นำสายเข้มงวดที่ต้องการปิดตายหลุมยุบทุกเส้นทางเพื่อกันสายลับตงหวงและ **ภาคีพิษแมงป่องทมิฬ** ซึ่งเริ่มส่งคนลอบสอดแนมตามชายบึง

**เดือนสิบสองเหมันต์ลึก วันที่สิบหก ยุคที่ ๑๐๐ ปีที่ ๙๙๙ (ศ.ท. ๙๙,๙๙๙)** **แม่เฒ่ามรกต หลันอวี้เจียว** วัยเก้าสิบเอ็ดปีในขณะนั้น เสด็จลงสู่ระเบียงหินปูนชั้นกลางของป่าห้อยหัวด้วยตนเองพร้อมถือ **ป้ายไม้ไผ่สีมรกต** เพื่อไต่สวนทั้งสองฝ่ายต่อหน้า **ชุมพรานสะพานแขวนรากฟ้า** หลังพิจารณาบัญชีโควตาน้ำยางและรายงานรอยเท้าผู้บุกรุก นางจึงประกาศ **สนธิสัญญาคุ้มครองรากฟ้า** ให้มีผลบังคับใช้ตั้งแต่วันขึ้นปีใหม่ **เดือนอ้ายวสันต์ วันที่หนึ่ง ยุคที่ ๑๐๑ ปีที่ ๑ (ศ.ท. ๑๐๐,๐๐๑)** โดยมอบหมายให้ **เหมี่ยวชิงซี** กำกับ **คลังแลกเปลี่ยนน้ำยางและยาถอนพิษ** ณ **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** อนุญาตให้ส่งออกผ่าน **สุวรรณโพธิ์** ปีละสามงวดภายใต้ตราประทับไม้ไผ่มรกตโดยห้ามเปิดเผยพิกัดหลุมยุบ ขณะเดียวกันก็อนุมัติให้หน่วยของ **กู่ซา** วางค่ายกล **เถาเตือนภัยและม่านหมอกย้อนกลิ่น** รอบขอบเหว พร้อมปรับสะพานแขวนให้ถอดเก็บได้ภายในครึ่งก้านธูปหากมีผู้รุกล้ำ

## ๓. ทำเนียบหกบุคคลสำคัญข้ามสี่ยุค

### ๑. เฒ่าฉางหลิง — ผู้บุกเบิกหลุมยุบรากฟ้า (ยุคที่ ๙ · ศ.ท. ๘,๕๐๐)
* **สถานะ**: หมอสมุนไพรอาวุโสเผ่าตักน้ำค้าง (วัย ๕๘ ปีในวันค้นพบ · ผู้ฝึกตนขั้นที่ ๓ สายโอสถพฤกษา)
* **บทบาท**: สังเกตเส้นทางบินของฝูงนกกระจาบหางหยกในยามภัยแล้งเจ็ดฤดูจนค้นพบป่าห้อยหัว คิดค้นวิธีต้มดอกเห็ดเรืองแสงกับน้ำแร่ใต้พิภพแก้ไข้ไอพิษ และสลัก **คำสาบานรากฟ้า** ห้ามทำลายรากแม่ไว้บนผนังหินปูนปากถ้ำ

### ๒. ป้าเหอซิน — มารดาสะพานแขวนมีชีวิต (ยุคที่ ๓๖ · ศ.ท. ๓๕,๒๑๘)
* **สถานะ**: ช่างสานเถาวัลย์และผู้ร่วมก่อตั้งชุมพรานสะพานแขวนรากฟ้า (วัย ๔๙ ปี · ผู้ฝึกตนขั้นที่ ๔ สายช่างพฤกษา)
* **บทบาท**: สูญเสียบุตรชายจากอุบัติเหตุเชือกขาดขณะเก็บยางไม้ จึงทุ่มเทเจ็ดปีฝึกเพาะ **เถาอสรพิษมีชีวิต** ให้ถักเป็นสะพานแขวนยืดหยุ่นโดยไม่บีบรัดเปลือกไม้ และเป็นผู้ร่าง **สัตยาบันกรีดยางสามข้อ**

### ๓. กู่เหลียนซาน — ผู้พิทักษ์เพดานถ้ำในคืนเพลิงมรกต (ยุคที่ ๗๔ · ศ.ท. ๗๓,๖๔๐)
* **สถานะ**: หัวหน้าชุมพรานสะพานแขวนรากฟ้าและองครักษ์บึง (วัย ๔๒ ปี · ผู้ฝึกตนขั้นที่ ๕ สายหอกไผ่และวิชาตัวเบา)
* **บทบาท**: นำพรานสิบแปดคนต้านกองคณะตัดไม้เถื่อนท่ามกลางพายุไอน้ำแร่เดือดและเปลวเพลิงยางไม้ รักษาต้นรากแม่ที่เหลืออีกหกต้นไว้ได้ และวางระบบ **ข่ายรากเตือนภัย** รอบรอยแยกหินปูน

### ๔. เฉินจู๋เกอ — นายหน้าตัดไม้เถื่อนผู้พินาศใต้หลุมยุบ (ยุคที่ ๗๔ · ศ.ท. ๗๓,๖๔๐)
* **สถานะ**: พ่อค้าไม้เถื่อนชายฝั่งตะวันออก (วัย ๕๑ ปี · ปุถุชนผู้เชี่ยวชาญเครือข่ายอู่ต่อเรือลับ)
* **บทบาท**: ลอบนำเลื่อยเพลิงและกว้านเหล็กเข้าสู่หลุมยุบหวังโค่นไม้ทั้งต้น ความเขลาที่ไม่เข้าใจแรงดันน้ำยางและไอน้ำใต้พิภพทำให้กองคณะพินาศ ถูกสภาสิบสองเผ่าเนรเทศและขึ้นบัญชีดำชั่วลูกชั่วหลาน

### ๕. แม่เฒ่ามรกต หลันอวี้เจียว — ผู้ถือป้ายไม้ไผ่สีมรกต (ยุคที่ ๑๐๑ · ศ.ท. ๑๐๐,๐๐๑)
* **สถานะ**: ประมุขสภาสิบสองเผ่าบึงมรกตแห่งแคว้นกู่เจียว (วัย ๙๒ ปี · ยอดฝีมือขั้นที่ ๗ สายโอสถมรกตและควบคุมพฤกษา)
* **บทบาท**: ผู้นำสูงสุดผู้รักษาเอกราชของแคว้นกู่เจียว ลงนามใน **สนธิสัญญาคุ้มครองรากฟ้า** เพื่อผสานนโยบายการค้าของเหมี่ยวชิงซีเข้ากับมาตรการปิดป่าของกู่ซาโดยไม่ทำลายสมดุลหลุมยุบ

### ๖. เหมี่ยวชิงซี — ผู้ดูแลคลังโอสถรากฟ้าและทูตการค้ารุ่นใหม่ (ยุคที่ ๑๐๑ · ศ.ท. ๑๐๐,๐๐๑)
* **สถานะ**: หัวหน้าหมอยารุ่นใหม่แห่งหมู่บ้านหมอสมุนไพรไป๋เฉ่าและผู้ชิงตำแหน่งทายาทสภา (วัย ๓๔ ปี · ผู้ฝึกตนขั้นที่ ๕ สายโอสถถอนพิษ)
* **บทบาท**: ผลักดันการแปรรูป **เห็ดเรืองแสงห้อยถ้ำ** และ **ยางไม้กันเน่า** เป็นสินค้าควบคุมคุณภาพส่งออกผ่าน **ท่าเรือสุวรรณโพธิ์** เพื่อสร้างอำนาจต่อรองทางเศรษฐกิจให้กู่เจียวภายใต้กฎเหล็กไม่ตัดรากแม่

## ๔. ระบบนิเวศป่ากลับหัวและกายวิภาคหมู่บ้านสะพานแขวน

### ๑. โครงสร้างสี่ชั้นของหลุมยุบหินปูนกู่เจียว
1. **ชั้นปากเหวพรางตาและวงรากแม่รับตะวัน (ความลึก ๐ – ๑๒ วา)**: ขอบหลุมกว้างสามลี้คลุมด้วยดงกกสูงและเถาหนามธรรมชาติ ขอบหินปูนพรุนด้านในเป็นที่ยึดเกาะของ **รากแม่ต้นห้อยหัว** สีเงินแกมเขียวซึ่งรับแสงแดดและน้ำฝนจากผิวดินแล้วลำเลียงสารอาหารย้อนลงสู่ลำต้นเบื้องล่าง
2. **ชั้นเรือนยอดห้อยหัวและโถงสะพานแขวน (ความลึก ๑๒ – ๔๕ วา)**: **พฤกษารากฟ้า** นับร้อยต้นทิ้งลำต้นยาวสิบถึงยี่สิบวาดิ่งลงกลางอากาศ ใบสีมรกตมีเส้นใยเรืองแสงคอยดูดซับแสงสะท้อนและไอน้ำแร่ ตามง่ามกิ่งมี **เห็ดเรืองแสงห้อยถ้ำ** เปล่งแสงนวลยามค่ำคืนดุจท้องฟ้าจำลองใต้พิภพ
3. **ชั้นม่านหมอกแร่อุ่นและลมหมุนวน (ความลึก ๔๕ – ๖๘ วา)**: เขตรอยต่อที่ไอร้อนจากบ่อน้ำพุร้อนปะทะอากาศเย็นจากปากเหว ก่อชั้นเมฆหมอกหมุนวนพาสปอร์เห็ดลอยย้อนขึ้นไปเกาะเรือนยอด และช่วยพรางสายตาจากด้านบน
4. **ชั้นทะเลสาบน้ำพุร้อนใต้พิภพและโคลนแร่สมานแผล (ความลึก ๖๘ – ๘๐ วา)**: ผืนน้ำสีเทอร์ควอยซ์อุ่นกรุ่นจากชีพจรความร้อนใต้หินปูน ขอบตลิ่งมี **โคลนแร่สีเทาเงิน** ที่ชาวพรานใช้พอกปิดรอยกรีดเปลือกไม้ให้รากแม่สมานแผลภายในเจ็ดวัน

### ๒. กายวิภาคหมู่บ้านสะพานแขวนและวิถีเก็บเกี่ยวไร้คมขวาน
* **เรือนรังนกริมระเบียงหินปูน**: ชุมพรานราวสี่สิบครัวเรือนสร้างเรือนไม้ไผ่ขนาดกะทัดรัดเกาะตามชะง่อนผาชั้นกลางที่ความลึกยี่สิบห้าวา มุงใบจากเคลือบยางไม้กันชื้น เชื่อมต่อกันด้วย **สะพานแขวนเถาอสรพิษมีชีวิต** และรอกถ่วงถังน้ำดินเผา
* **เครื่องมือเก็บเกี่ยวตามสัตยาบัน**: พรานใช้เพียง **มีดเขาสัตว์ปลายมน** เปิดร่องเปลือกตื้นรองน้ำยางใส่กระบอกไม้ไผ่ ห้ามนำขวานเหล็กหรือคบไฟเปลือยลงสู่ชั้นเรือนยอด ยามค่ำคืนใช้เพียง **โคมเห็ดเรืองแสง** ในตะกร้าหวายโปร่งเพื่อกันประกายไฟกระทบไอน้ำยาง
* **กลไกถอดสะพานรับมือผู้บุกรุก**: สะพานแขวนหลักสี่สายจากทางลงด้านเหนือมีสลักไม้ไผ่ปลดล็อกพร้อมกัน หาก **ข่ายรากเตือนภัย** สั่นสะเทือน ชุมพรานสามารถชักเก็บสะพานเข้าชะง่อนผาได้ภายในครึ่งก้านธูป ปล่อยให้ผู้รุกล้ำเผชิญเหวลึกและม่านหมอกย้อนกลิ่น

## ๕. กลไกสังเกตการณ์ยุคที่ ๑๐๑ และชนวนเหตุสายปรุงยา–สำรวจ

1. **สมดุลโควตายางไม้กับแรงตึงเครียดในสภาสิบสองเผ่า**: ในโลกจำลองยุคที่ ๑๐๑ ผู้สังเกตการณ์สามารถเฝ้าดูผลกระทบแบบลูกโซ่ระหว่างแนวทางของ **เหมี่ยวชิงซี** กับ **กู่ซา** หากส่งออก **ยางไม้กันเน่ารากฟ้า** ผ่าน **สุวรรณโพธิ์** มากขึ้น รายได้และอิทธิพลของกู่เจียวจะสูงขึ้น แต่อัตราการแฝงตัวของสายลับตงหวงและ **ภาคีพิษแมงป่องทมิฬ** รอบชายบึงก็จะทวีความถี่ตามไปด้วย
2. **ฤดูเห็ดเรืองแสงผลิบานและภารกิจสายปรุงยา**: ทุก **เดือนเจ็ดสารทแรก** ถึง **เดือนแปดใบไม้ร่วง** เมื่อไอร้อนจากทะเลสาบพัดแรง ดอก **เห็ดเรืองแสงห้อยถ้ำ** รุ่นพิเศษจะผลิบานเต็มเรือนยอด นักบำเพ็ญเพียรสายโอสถที่ได้รับความไว้วางใจจาก **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** อาจได้รับอนุญาตให้โรยตัวลงเก็บสปอร์และน้ำค้างแร่อุ่นเพื่อปรุง **โอสถถอนพิษรากฟ้า** หรือ **ยาสมานชีพจรขั้นสูง**
3. **ชีพจรความร้อนแปรปรวนและปฏิกิริยาอสูรบึง**: เมื่อคลื่นชีพจรมังกรแดนใต้สั่นสะเทือน อุณหภูมิทะเลสาบใต้พิภพจะพุ่งสูงจนเกิดม่านหมอกหนา ก่อเหตุการณ์สุ่มทั้งการค้นพบ **ผลึกยางไม้พันปี** ก้นบึง และการที่อสูรน้ำจืดโบราณตื่นขึ้นรวมตัวรอบปากหลุม บีบให้ **ชุมพรานสะพานแขวน** ต้องประสานกำลังกับ **ด่านค่ายไผ่หมอกเจ็ดชั้น**
4. **เมล็ดพันธุ์จุดสำรวจแผนที่ในอนาคต**: พิกัด `(32.4, 78.2)` เชื่อมต่อเครือข่ายทางน้ำจาก **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** `(31, 73)` และ **นครเสาขวัญหมื่นกู่** `(35, 89.5)` เริ่มต้นในสถานะพื้นที่ลับซ่อนใต้บึง เปิดเผยได้ผ่านค่าความสัมพันธ์กับแคว้นกู่เจียว ข่าวลือโรงน้ำชา หรือเบาะแสจากบันทึกสมุนไพรสายไป๋เฉ่า

## ๖. รายการตรวจสอบการตรึงแกนหลักจักรวาล

| หัวข้อตรวจสอบ | สถานะ | รายละเอียดการสอดคล้องกับแกนหลักจักรวาล |
| :--- | :---: | :--- |
| **เพดานพลังโลกเบื้องล่าง** | ผ่าน | ตัวละครทั้งหมดอยู่ในระดับปุถุชนถึงผู้ฝึกตนขั้นที่ ๓ – ๗ (สูงสุดคือแม่เฒ่ามรกตหลันอวี้เจียว ขั้นที่ ๗) อยู่ในกรอบเพดานม่านฟ้าอย่างเคร่งครัด |
| **พิกัดและภูมิศาสตร์จริง** | ผ่าน | วางพิกัดเมล็ดพันธุ์ `(32.4, 78.2)` เชื่อมตรงกับ **หมู่บ้านหมอสมุนไพรไป๋เฉ่า** `(31, 73)`, **ด่านค่ายไผ่หมอกเจ็ดชั้น** `(38, 67.5)`, **นครเสาขวัญหมื่นกู่** `(35, 89.5)` และ **สุวรรณโพธิ์** `(19.5, 78.5)` |
| **ตัวละครยุคที่ ๑๐๑** | ผ่าน | สอดคล้องกับบันทึกห้ารัฐกันชน: **หลันอวี้เจียว** (วัย ๙๒ ปี) ถือป้ายไม้ไผ่สีมรกต, **เหมี่ยวชิงซี** (วัย ๓๔ ปี) ขยายการค้ายาถอนพิษและยางไม้กันเน่า, **กู่ซา** ป้องกันสายลับตงหวงและภาคีพิษแมงป่องทมิฬ |
| **หลักน้ำบ่อไม่ยุ่งกับน้ำคลอง** | ผ่าน | ภัยรุกรานยุคที่ ๗๔ เป็นกองคณะตัดไม้เถื่อนและโจรลัทธิพิษชายขอบ ไม่ใช่ทัพหลวงของราชสำนักเข้าตีสำนักกลาง |
| **ปฏิทินสิบสองเดือนมาตรฐาน** | ผ่าน | ใช้ชื่อเดือนไทยมาตรฐานครบถ้วน (เดือนอ้ายวสันต์, เดือนสามวสันต์ปลาย, เดือนห้าสุริยัน, เดือนเจ็ดสารทแรก, เดือนแปดใบไม้ร่วง, เดือนสิบเหมันต์แรก, เดือนสิบเอ็ดน้ำค้างแข็ง, เดือนสิบสองเหมันต์ลึก) |
| **ความบริสุทธิ์ของภาษาและแกนเรื่อง** | ผ่าน | ใช้ภาษาไทยวรรณศิลป์ล้วน ไม่มีรหัสตัวแปรภาษาอังกฤษปะปน และไม่มีองค์ประกอบต้องห้ามแทรกอยู่ในเนื้อเรื่อง |
| **ความปลอดภัยไฟล์เกม** | ผ่าน | จัดเก็บเป็นพงศาวดารอิสระในคลังตำนานสิ่งมหัศจรรย์โดยไม่แก้ไขไฟล์เกมใด ๆ |
