# บันทึกทวีปก่อนหยุนเหอ · 06 — ใบรับรองจากประภาคารที่ดับไฟ

**ยุคที่ 20 ปีที่ 267–291 · ศ.ท. 19,267–19,291** · คลังข้าวกับจุดพักเรือชั้นในทางชายฝั่ง

**ขอบเขต:** ประภาคารในเรื่องเป็นไฟนำร่องท่าชั้นใน ไม่ใช่หนึ่งในประภาคารเจ็ดยอดหรือเบาะแสต้นกำเนิดทะเลหมอก

## 1. ข้าวที่ต้องซื้อด้วยน้ำมันตะเกียง

เรือค้าสามลำรอเข้าท่าขณะที่ถังน้ำมันไฟชั้นในเหลือไม่ถึงคืน หัวหน้าท่า **เหอฮั่นซื่อ** เอาตราของกองเรือสำรวจมาขอเอาน้ำมันสำรองทั้งหมดไปคุ้มเส้นเดินเรือใหญ่ คนเฝ้าไฟ **ฉินลั่วอวี้** รู้ว่าเรือที่เร่งเข้าท่าตอนน้ำลงจะเฉียดหลักหิน เธอขอปิดช่องรับเรือใหญ่และจุดไฟแค่ฝั่งที่เรือเล็กเข้าได้ เหอยื่นใบรับต้นทุนเฝ้าไฟให้นางลงว่าไฟไม่เคยดับ หากไม่ลงชื่อท่าจะถูกตัดเงินไปซ่อมท่าอื่น

## 2. สัญญาณไฟติดครึ่งฝั่ง

ฉินใช้ข้อปฏิบัติโรงหมอเก่าที่เคยคั่นผู้เดินทางตามอันตราย ให้ปิดเฉพาะช่องน้ำที่รับไม่ไหว และกำหนดเวลาประเมินใหม่ในนิ้วมือคนเฝ้าระดับน้ำ เรือใหญ่เสียเที่ยวหนึ่งคืน ขณะที่ชาวเรือเล็กจับมือกับคลังข้าวทยอยส่งไปทีละลำ **เกาเยวี่ยเจิน** หญิงหาบข้าวขอให้เรือเล็กที่รับงานมีใบรับน้ำหนักแยกจากเรือหลวง มิฉะนั้นผู้รับประกันจะถือว่าข้าวทั้งหมดเสียหายในทะเลแล้วจ่ายเงินให้เจ้าของตราแทนผู้ขนจริง

## 3. ภัยที่เกิดจากข้ออ้างช่วยส่วนรวม

เหอบันทึกว่าได้ระดมน้ำมันเพื่อภารกิจใหญ่จริง แต่ผู้ตรวจพบว่ามีเสบียงบางส่วนถูกส่งเข้าคลังคนใกล้ตัวเพื่อเก็งกำไร ถ้าเปิดโปงทั้งหมดพร้อมกัน เสบียงกองเรือที่รับไปโดยชอบอาจถูกยึดจนไม่มีเรือไปส่งข่าวท่าอื่น ฉินออกคำให้การสองฉบับ ฉบับหนึ่งระบุยอดน้ำมันของกองเรือที่ควรรับ อีกฉบับระบุถังที่ออกวันผิดโดยให้ลูกหาบเป็นพยาน เหอไม่ยอมรับว่าตนรู้เรื่องโกง แต่จ่ายค่าซ่อมไฟตามข้อตกลงแล้วขอให้คนที่ตนส่งไปคุมถังมาอยู่ต่อหน้าผู้ตรวจ

## 4. เมื่อตลาดต้องพึ่งเรือเล็ก

ไฟนำร่องกลับมาขึ้นทั้งสองฝั่งหลังเปลี่ยนคนดูแลเงิน ท่าต้องจ่ายค่าขนให้เรือเล็กในอัตราที่สูงขึ้นเพื่อรักษาคนพายไว้ พ่อค้าบางคนต่อต้านเพราะเคยได้ประโยชน์จากเงินประกันเรือใหญ่ คนหาบข้าวเห็นช่องรับเสบียงชัดเจนครั้งแรก และมีหลักฐานให้ฟ้องเมื่อคนเก็บข้าวอ้างว่ายังมาไม่ถึง รูปแบบสำเนาใบเดินเรือกลายเป็นเครื่องมือที่คนบนฝั่งนำไปใช้กับของส่งด่าน ส่วนเหตุที่มหากองเรือยุคต่อมาถูกจำกัดการเดินทะเลยังเป็นเรื่องของประวัติศาสตร์หลัก

**ผลทางประวัติศาสตร์:** อธิบายว่าทำไมเมืองชายฝั่งพึ่งเรือเล็กและคลังคนท้องถิ่นได้หลังตลาดเรือใหญ่สะดุด โดยไม่ต้องเพิ่มการสำรวจทะเลหมอกอีกชุด
