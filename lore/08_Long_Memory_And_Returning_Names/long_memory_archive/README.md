## สายเรื่องและหลักฐานที่อยู่รอด

- **หนี้ของตรา · 01–04:** ใบรับที่คนสองฝ่ายถือถูกแปลงเป็นหลักซ่อมเครื่องและหลักแบ่งของสำรอง แสดงว่ากำลังของศูนย์กลางขึ้นกับคนที่ซ่อมและขนของในท้องถิ่นด้วย
- **อำนาจหน้าด่าน · 05–08:** ข้อปฏิบัติของหมอและชาวเรือเปลี่ยนเป็นแบบให้เสมียนแยกคำให้การ ภาระจ่าย และสิทธิ์ปิดทาง เขตอำนาจซ้อนกันได้โดยยังมีคนค้านและตรวจได้
- **คนที่ยังมีสิทธิ์พูด · 09–12:** คดีสัมปทานของเมืองที่ล่มกลายเป็นตัวอย่างให้เมืองอื่นแยกทุนซ่อมออกจากอำนาจปกครอง การอพยพทำให้ต้องคิดใหม่ว่าใครมีส่วนกำหนดค่าใช้จ่ายในถิ่นที่เพิ่งมาถึง
- **กว่าจะมีเขตกลาง · 13–16:** แผนภาษี การฝากของ และใบรับข้าวเป็นหลักฐานต่างชนิดที่ช่วยให้คนระแวงกันร่วมงานเฉพาะเรื่องได้ก่อนหยุนเหอ เรื่อง 16 จบก่อนวันลงนาม
- **สี่หน้าจากวิกฤตใหญ่ · 17–20:** เรื่องเสริมต่างยุคให้อ่านแทรกตามตาราง เรื่อง 17 เทียบได้กับการเสื่อมของเสวียนจี เรื่อง 18 กับการเก็บข่าวคนข้ามเขา เรื่อง 19 กับปัญหาเขตทางน้ำ และเรื่อง 20 ทิ้งสำเนาเรื่องพักทางที่คนจัดเรือนในเรื่อง 16 อ่านในเวลาต่อมา

คนรุ่นหลังใช้สำเนา ตำราแบบงาน และข้อพิพาทที่ถูกอ้างซ้ำ เอกสารบางอย่างถูกคัดผิดชื่อหรือเหลือเพียงส่วนที่ยังมีคนใช้ ไม่สมมติว่ากระดาษต้นฉบับ สถาบันเดิม หรือตัวละครคนเดิมอยู่ครบข้ามยุค
