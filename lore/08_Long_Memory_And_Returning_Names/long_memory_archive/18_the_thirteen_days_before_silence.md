# บันทึกทวีปก่อนหยุนเหอ · 18 — สิบสามวันก่อนเมืองเลิกตีระฆัง

**ยุคที่ 49 ปีที่ 332–352 · ศ.ท. 48,332–48,352** · นครเล็กในแนวลำน้ำตอนเหนือ

**บริบท:** อยู่หลังความผิดปกติช่วงต้นภาคสุริยคราส และก่อนมหาสุริยคราสเจ็ดราตรีกับศึกดาราคล้อยหลายศตวรรษ

## 1. ความเงียบที่ผู้ครองนครเข้าใจว่าเชื่อฟัง

นครชิวตงส่งเวรยามด้วยเสียงระฆังจากประตูสี่ด้าน เมื่อทางเหนือเริ่มมีคืนผิดฤดู หญิงตั้งหอนาฬิกาน้ำ **ถานชิวเซี่ย** พบว่าคนขึ้นไปเปลี่ยนเวรต้องค้างอยู่บนหอจนหลับเพราะเสียงไม่ดังออกมาถึงตลาด เจ้าหอ **โจวหย่วนต้า** สั่งเพิ่มยอดผู้ลงเวรโดยไม่ยอมเปลี่ยนวิธีบอกเวลา เพราะคนที่อยู่ไกลเริ่มถามว่าด่านยังอยู่ใต้เมืองจริงหรือไม่ เขารู้ว่าถ้าคนเชื่อว่าเมืองแจ้งภัยไม่ได้ ร้านเสบียงจะขนของออกเองก่อนนายเมืองขอซื้อ

## 2. วันที่ความกลัววิ่งเร็วกว่าคนส่งข่าว

ข่าวว่าตลาดล่างปิดทำให้คนเฝ้าทางเหนือทิ้งเวรไปดูครอบครัว ไม่มีคำสั่งยืนยันว่าทางล่างปลอดภัย ถานจึงส่งคนไปตามเรือนที่รู้ว่าติดอยู่ก่อน ทางเหนือเหลือผู้เฝ้าไม่พอและผู้คุมภายนอกเข้ามายึดคลังฟืน **ลั่วไห่เฉิง** อดีตคนตีระฆังเสนอตั้งคนติดต่อประจำเรือนตามจุดพัก แบ่งว่าวันนี้ใครรู้ข่าวจากที่ใด ไม่จดว่าคนไปตามข่าวเป็นผู้ทิ้งตำแหน่งทันที โจวปฏิเสธในตอนแรกเพราะผู้คุมคลังอยากให้ลงโทษคนที่กลับมาเพื่อรักษาวินัย

## 3. วันปิดประตูเหนือ

สิบสามวันหลังเสียงหอแรกขาด นายเมืองต้องเลือกระหว่างนำกองกลับไปยึดคลังฟืนกับคุมทางเล็กที่ยังขนอาหารให้เรือนรอบตลาด โจวเลือกทางเล็กและออกหนังสือว่าประตูเหนือถูกปิดไปโดยยอมให้คนหนีออกมาได้ตามลำดับ ผู้รักษาคลังฟืนที่ยึดไว้ไม่ได้รับรองจากคนในตลาดตามที่หวัง จึงยอมเปิดขนของแลกค่าจ้างตามจริงหลังอาหารของคนเฝ้าหมด ถานนำคนกลับไปเก็บลูกตุ้มจากหอนาฬิกาน้ำและพบแผ่นเวรซึ่งยังมีชื่อโจวลงดูแลคืนที่ไม่มีใครมาแทนเขา

## 4. สัญญาณที่มาถึงเป็นคน

นครเลิกใช้ระฆังเป็นเงื่อนไขเดียวสำหรับเปิดประตู ผู้ดูแลตลาดหาคนพักตามเส้นแยกเพื่อส่งข่าวยืนยันสองทอด ความเสียหายของชิวตงยังอยู่ในสมุดเสบียงและมีคนโต้แย้งว่าหากตีคลังคืนก่อน เมืองอาจต่อรองได้มากกว่านี้ จนเมื่อมีคนกลับมาคัดหนังสือช่วงปี 352 พวกเขาเก็บทั้งสองความเห็นไว้ เรื่องคืนผิดฤดูถูกเล่าตามหลักฐานของคนเฝ้าทางโดยไม่มีใครอ้างว่ารู้สาเหตุของปรากฏการณ์ทั่วทวีป

**ผลทางประวัติศาสตร์:** อธิบายการกระจายช่องส่งข่าวเมืองตอนเหนือก่อนวิกฤตยุค 49 ครั้งสำคัญ จึงสามารถหยิบเป็นที่มาของความต่างระหว่างเมืองที่พึ่งศาลากลางแห่งเดียวกับเมืองที่ตั้งขบวนจากครัวเรือนของตน
