# บันทึกทวีปก่อนหยุนเหอ · 04 — คอกที่ห้าของชายแดนหวงเย่

**ยุคที่ 10 ปีที่ 416–438 · ศ.ท. 9,416–9,438** · เมืองหน้าทุ่งทางตะวันตก

## 1. คนเลี้ยงกับคนทวงของ

กองเก็บส่วยหวงเย่มาถึงพร้อมใบเรียกอาหารสัตว์เพื่อส่งขึ้นเหนือ เมืองหน้าทุ่งมีคอกสี่คอก ส่วนคอกหลังสุดถูกคนเลี้ยงใช้พักสัตว์ที่ไม่ยอมให้ตีตรากองทัพ **หวงเสวียหนิง** ผู้ตรวจเสบียงต้องส่งยอดตามใบสั่ง แต่ **อวี๋เมิ่งชาง** คนตัดหญ้าพาไปดูว่าคอกที่ห้ามแตะมีทั้งสัตว์งานและลูกเพิ่งหย่านม หากพรากไป เมืองจะไม่มีแรงลากเมล็ดถึงนาช่วงวสันต์ เขาเสนอให้แยกคอกที่ห้าเป็นส่วนสำรองสำหรับการเพาะปลูก แล้วชดอาหารกองทัพด้วยค่าขนจากทางค้าจริง

## 2. ความอดอยากที่รับตราไม่ได้

หวงเสนอให้ทำตามเมื่อมีเงินถึงมือ แต่กองเกวียนซีหรงเลื่อนเที่ยวเพราะการถอยทัพและขยายความระวังตามแนวชายแดน เลี้ยงคอกที่ห้าไว้กลายเป็นค่าข้าวที่เมืองแบก **หลัวตงซง** ผู้ดูแลลานเกลือเสนอซื้ออาหารส่วนเกิน แลกให้เขามีสิทธิ์ไถ่สัตว์ที่ถูกเบิกก่อนเวลา คนเลี้ยงกลัวว่าจะตั้งคอกใหม่ด้วยชื่อผู้ช่วยแล้วถูกยึดแบบเดิม หวงใช้วิธีขีดชิ้นซ่อมจากเว่ยหลูแยกยอดจริงและสิทธิ์ขายออกจากกัน ชื่อคนที่มีส่วนยืมอาหารปรากฏในบัญชีแต่ผู้ให้กู้ไม่มีสิทธิ์ถือประตูคอก

## 3. การตัดสินผิดที่มีคนจ่ายแทน

ปี 420 ฝนช้า หวงคิดว่าคอกที่ห้าพอแบ่งไปอีกหนึ่งคันโดยไม่เสียฤดูหว่าน ผู้เฝ้าคอกยอมเพราะนางเคยรักษาสัญญา แต่สัตว์อ่อนแรงและลากกลับไม่ไหว คนทำนาชั้นล่างต้องใช้แรงคนแทนและหว่านไม่ทันเกือบหนึ่งแถบ หวงลงชื่อชดค่าจ้างโดยใช้เงินตำแหน่งของตน ลูกชายอวี๋เป็นผู้ให้การทั้งที่ญาติบางคนอยากเอาเรื่องไปใช้เรียกความผิดชอบชายแดนทั้งหมด ข้อพิพาทจำกัดอยู่ที่การเบิกครั้งนั้น ผู้ดูแลที่ตัดสินผิดยังมีหน้าที่ทำงานต่อจนใช้หนี้ครบ

## 4. สองคอกหลังเปลี่ยนธง

เมื่ออำนาจหวงเย่เสื่อม เมืองถูกเรียกส่วยจากผู้ถือธงใหม่ คนเลี้ยงเหลือคอกใช้ได้สองแห่ง พวกเขาให้กองเกวียนต่างฝ่ายซื้อแรงลากในลานเดียวกัน แต่กันสัตว์งานไว้ตามฤดูจริง ครอบครัวหวงบางบ้านลงหลักปักฐานที่เมืองใหม่ บางบ้านเปลี่ยนงานไปเฝ้าทางบก เมืองเสียฐานส่งทัพไป แต่มีคนที่ยังทำไร่อยู่มากพอรักษาตลาด

**ผลทางประวัติศาสตร์:** ช่วยให้เห็นว่าทำไมบางเมืองอยู่ต่อได้หลังจักรวรรดิสัตว์อสูรเสื่อม และการถอนกำลังของขั้วใหญ่มีต้นทุนกับคนที่ไม่ได้ถือธงใดเลย
