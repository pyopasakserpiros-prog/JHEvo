# บันทึกทวีปก่อนหยุนเหอ · 07 — สองตราใต้ชายคาเดียว

**ยุคที่ 23 ปีที่ 184–209 · ศ.ท. 22,184–22,209** · ศาลาจ่ายค่าจ้างชานเมืองในตงหวง

**จุดเชื่อม:** กรณีท้องถิ่นหลังการผลัดอำนาจตงหวงและระบบคู่ตราในประวัติศาสตร์หลัก

## 1. หลักฐานที่เจ้าของตราทั้งคู่ไม่อยากอ่าน

คนขนศิลาไปทำกำแพงเมืองได้รับค่าจ้างไม่ครบ เอกสารหัวกระดาษมีตราเก่าซึ่งอีกหน่วยไม่รับ แต่มีตราใหม่รับรองการเบิกเสบียงของโครงการเดียวกัน **ถังกวงเซี่ย** เจ้าของใบส่งของลงมาขอเงินคืนให้ลูกจ้าง ส่วนเสมียนราชวงศ์ **ลู่ผิงฉี** รู้ว่าถ้าออกเงินทั้งหมดวันนี้ คลังจะไม่มีข้าวซื้อสำหรับช่างที่ยังขุดคู เขาพยายามให้พ่อค้าต้องยื่นคำขอใหม่ทีละรายเพื่อซื้อเวลา ถังพาคนขนศิลามานั่งนับวันทำงานต่อหน้าศาลาและประชาชนเริ่มมองเห็นว่าสองตราเคยร่วมมือเมื่อได้ประโยชน์

## 2. วิธีต่อสู้ด้วยยอดที่เห็นตรงกันก่อน

ลู่ขอยืมมาตราบันทึกของท่าชั้นใน ทวนว่าจ่ายข้าวไปถึงคนกี่คนแล้ว และแยกคนที่ยังขนของต่อออกจากครัวเรือนผู้เสียชีวิต **เติ้งชิวหรง** ลูกสาวผู้ดูแลที่เก็บแผ่นศิลาใช้เศษกระดานขีดวันฝนปิดลานเทียบกับใบงาน เธอพบว่าพ่อเคยช่วยผู้รับเหมาขีดวันทำงานเกินจริงสองวัน แต่ยังมีแรงงานที่ขาดค่าแรงอีกเจ็ดวัน ถังยอมคืนส่วนเกินของตัวเองแล้วใช้ใบรับจริงไปฟ้องส่วนที่เหลือ ซึ่งทำให้คนในสังกัดบางคนเปลี่ยนไปอยู่กับผู้รับเหมาคู่แข่ง

## 3. สัญญาจ่ายสองทาง

ส่วนเบิกรายจ่ายที่ทั้งสองหน่วยรับรองถูกจ่ายให้คนงานโดยตรง ที่โต้แย้งกันต้องแขวนไว้ในศาลาให้คนที่เกี่ยวข้องแสดงยอดเอง ลู่เสนอขายศิลาที่วางทิ้งจากโครงการมาจ่ายส่วนแรก คลังไม่ต้องเอาข้าวฤดูหน้าออกทั้งหมด พ่อของเติ้งถูกถอดออกจากงานนับของ แต่ได้จ่ายชดเชยผ่านงานดูแลเครื่องชั่ง เติ้งต้องกลับไปนอนบ้านเดิมและฟังเขาโกรธอยู่หลายเดือนก่อนจะได้ยินว่าเขามาขอให้ช่วยอ่านสัญญางานใหม่

## 4. สิทธิ์ที่มีจริงในบางเมือง

ศาลาจ่ายค่าจ้างทำแบบสองตราต่ออีกสองทศวรรษ เมืองข้าง ๆ ใช้เพียงกับงานขนของที่ทั้งสองหน่วยเคยลงชื่อพร้อมกัน ไม่มีคำสั่งว่าราษฎรทั่วไปจะถือสิทธิ์เท่าขุนนาง ผู้ที่อยู่ใต้เจ้าของตราฝ่ายเดียวจึงยังร้องทุกข์ลำบาก แต่เมื่อเกิดงานร่วมกัน เจ้าหน้าที่รุ่นถัดไปเริ่มเผื่อเงินค่าจ้างไว้ในส่วนที่ไม่มีฝ่ายใดถอนฝ่ายเดียว

**ผลทางประวัติศาสตร์:** ให้รายละเอียดว่าระบบคู่ตราทำให้เกิดทั้งความรับผิดร่วมและช่องชิ่งหนี้ ส่วนราชวงศ์และเหตุผลัดบัลลังก์ตามคัมภีร์แม่บทคงเดิม
