# บันทึกทวีปก่อนหยุนเหอ · 15 — ข้าวจากด่านที่ท้องฟ้ากดต่ำ

**ยุคที่ 98 ปีที่ 820–821 · ศ.ท. 97,820–97,821** · เส้นทางเกวียนสายรองในช่วงสี่สิบวันแห่งฟ้าต่ำ

## 1. เมื่อของที่เคยไปถึงในวันเดียวเริ่มขาด

ขบวนคนรับจ้างขนข้าวเข้าด่านเขายอมเดินทางบกหลังช่องขนส่งเร็วหยุดใช้งาน **ถงอี๋ชิว** ผู้นำทางเจอรถเสียสองคันขวางช่องล่าง **เจียงเว่ยอัน** นายกองเฝ้าฝั่งนอกอยากปิดทางทั้งวันเพื่อกันคนจากอีกฝ่ายเอาความโกลาหลมาลอบเข้าด่าน แต่ถ้าปิดครัวเรือนปลายเขาจะยังไม่ได้ข้าวเป็นคืนที่สาม หญิงขายฟืนวางตะกร้าไว้หน้าประตูและขอให้เจ้าหน้าที่นับคนที่ต้องเดินกลับไปหาลูก ไม่ใช่เพียงนับยอดขบวนที่มีตราหลวง

## 2. การยอมให้คนที่กลัวกันตรวจรถคันเดียวกัน

เจียงนำแบบฝากของสามฝ่ายจากศาลาทางผ่านมาใช้ให้ผู้คุมด่านอีกข้างร่วมเปิดเกวียนทีละคัน โดยแต่ละฝ่ายบันทึกจำนวนของและชื่อคนเดินทางของตัวเอง ถงชี้ทางรองที่ไม่ให้รถหนักผ่าน ให้คนต้องการไปถึงก่อนเลือกเดิน มือทหารกับมือคนแบกข้าวต้องช่วยกันยกรถเสียขึ้นจึงจะเปิดช่องกลางได้ ผู้ตรวจสองฝ่ายยังคงจับคนที่ถือใบผ่านปลอมไว้คนละฝั่ง ไม่มีคำสั่งให้ปล่อยตามกันไปทั้งหมด

## 3. ของที่มาถึงช้าจนเป็นต้นทุนของอีกบ้าน

คืนที่ล้อเกวียนผ่านได้ ข้าวครึ่งหนึ่งไปถึงตลาดเมืองก่อนที่น้ำในหม้อของโรงพักจะหมด คนที่อยู่ท้ายหุบได้รับช้ากว่าอีกสองวัน **ลิ่วหานจือ** ผู้เก็บยอดส่งของตามไปพบเรือนที่ต้องขายสัตว์งานซื้ออาหารก่อนรถถึง เขาเขียนจำนวนวันที่ช้าไว้ข้างใบรับว่าส่งครบ เพื่อให้ผู้จัดขบวนรุ่นหลังไม่ใช้รายงานส่งครบเป็นหลักฐานว่าทุกบ้านรอดโดยไม่เสียอะไร เจียงยอมให้จดข้อความนี้ในสำเนาด่านแม้จะทำให้ผู้บังคับบัญชาของตนเห็นว่าการรักษาทางมีช่องโหว่

## 4. เมื่ออากาศกลับมาเหมือนเดิม

ปี 821 ฝ่ายที่เคยร่วมทางเริ่มเรียกค่าผ่านแยกกันอีก คนสองฝั่งยังส่งสำเนายอดเรือนขาดไว้ดูเองเพื่อเตรียมข้าวล่วงหน้าคนละส่วน ช่องส่งข่าวฉุกเฉินอยู่ต่อโดยอาศัยญาติร้านเกวียนของถง เชื้อสายผู้นำสองฝ่ายถูกจารึกว่าเคยพักรบชั่วคราวเพื่อเปิดทาง ไม่ได้หมายความว่าข้อพิพาทชายแดนจบแล้วหรือว่าสองฝ่ายค้นพบต้นเหตุฟ้าต่ำ

**ผลทางประวัติศาสตร์:** เพิ่มหลักฐานของคนปลายทางในช่วงภัยทวีป และแสดงว่าเหตุร่วมกันสร้างกติกาพักข้อพิพาทเฉพาะงานได้โดยที่ความระแวงเดิมยังอยู่
