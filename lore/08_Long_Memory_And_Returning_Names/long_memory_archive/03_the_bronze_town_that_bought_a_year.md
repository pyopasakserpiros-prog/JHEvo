# บันทึกทวีปก่อนหยุนเหอ · 03 — นครสำริดที่ซื้อเวลาได้หนึ่งปี

**ยุคที่ 8 ปีที่ 232–262 · ศ.ท. 7,232–7,262** · ช่วงปลายอำนาจจักรวรรดิกลไก

**นครสมมติ:** เว่ยหลู เป็นเมืองอู่ซ่อมฝั่งบูรพา ชื่อกับอาณาเขตอยู่ระดับท้องถิ่น

## 1. การซื้ออิสรภาพด้วยเสียงระฆัง

พอเสวียนจีเริ่มขาดทองแดง เจ้าห้องเก็บแร่ **ติงเยวี่ยหลาน** ถูกสั่งส่งอะไหล่กองทัพทั้งที่เมืองเว่ยหลูต้องใช้ชิ้นส่วนแบบเดียวกันกับประตูน้ำ ช่างยกของ **เซิ่นเป้าฉวน** ขอผ่อนส่งหนึ่งปี แลกกับให้เมืองเปิดอู่ซ่อมแก่ขบวนหลวงทุกรอบโดยคิดค่าของตามจริง ฝ่ายคลังยอมเพราะเคยเสียขบวนหนักไปที่สะพานซึ่งเมืองนี้ต้องดูแล ในพิธีทำสัญญา ติงให้ตีระฆังเพียงครั้งเดียว เพื่อสื่อว่ามีเวลาหนึ่งปีเท่านั้น ธรรมเนียมนี้ภายหลังถูกเล่าผิดว่าเมืองได้อิสรภาพถาวรในวันนั้น

## 2. มือที่กำลังถอดเครื่องของตนเอง

ขุนนางจากเมืองอื่นเห็นข้อยกเว้นแล้วเลื่อนส่งของตาม เมืองหลวงจึงส่งผู้ตรวจมาตีราคาเครื่องสูบน้ำเป็นทรัพย์ที่จะยึด ติงพาเขาลงไปดูใต้เรือนช่างว่าเฟืองที่รับน้ำหนักถูกซ่อมด้วยทองแดงที่ชาวบ้านซื้อเอง รอยชื่อด้านในยังอยู่ ผู้ตรวจยอมกันชิ้นซ่อมที่มีหลักฐานออก แต่เรียกชดส่วนที่เหลือจากสัญญาเดิม เซิ่นเสนอขายเครื่องยกเรือหน้าท่าแทนประตูน้ำ ท่าเรือเสียเรือใหญ่ไปครึ่งหนึ่งและร้านข้าวริมน้ำเริ่มปิด ทว่าพื้นที่ด้านในยังไม่ถูกน้ำท่วม

## 3. คนงานปฏิเสธความมั่นคงที่เสนอให้

เป่ยหมิงกับตงหวงต่างส่งนายหน้ามาเสนอหลักประกันเสบียงแลกสิทธิ์รับคนงานไปเข้าประจำโรงช่างของตน นายหน้าคนหนึ่งยอมรับช่างทั้งครัวเรือน ส่วนอีกฝ่ายเสนอเงินแรกเข้าสูงกว่าแต่รับเฉพาะคนเดินทางได้ ติงเปิดให้คนเลือกไปตามบ้านที่ต้องเลี้ยง ไม่สามารถกันไม่ให้ครึ่งหนึ่งจากไปได้ เซิ่นอยู่รักษาประตูเดิมและต้องจ้างคนที่ไม่เคยเรียนแบบซ่อมมาทำงาน หลังช่างรุ่นก่อนออกไป ชุดลิฟต์หนักของเมืองไม่มีใครเปิดใช้อีกโดยปลอดภัย

## 4. เมืองที่ยังใช้ชื่อเดิม

ปี 262 เว่ยหลูกลายเป็นเมืองช่างขนาดเล็กในเครือข่ายพ่อค้าแห่งใหม่ ตระกูลติงยังเก็บกุญแจอู่แต่ไม่มีสิทธิ์สั่งปิดทางของผู้ที่ไม่ได้อยู่ในสังกัด เมื่อเอกสารเกี่ยวกับเครื่องในคลังหาไม่ครบ คนท้องถิ่นนำสัญญาหนึ่งปีขึ้นแสดงเพื่อยืนยันว่าพวกเขาเคยจ่ายซ่อมเอง ลูกหลานของผู้ที่อพยพไปสองจักรวรรดิลงชื่อเป็นพยาน แม้บางคนไม่ยอมกลับมารับงานที่เมืองเก่า

**ผลทางประวัติศาสตร์:** นครอู่ช่างเป็นตัวอย่างของการเสื่อมจากการเสียคนและเครื่องมือทีละอย่าง ผู้คนกับความรู้กระจายไปหลายขั้วโดยไม่ผูกขาดการรับมรดกจากเสวียนจีในเรื่องใหญ่
