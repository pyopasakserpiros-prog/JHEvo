# บันทึกทวีปก่อนหยุนเหอ · 08 — คำสัตย์บนสะพานที่ปิดอยู่

**ยุคที่ 33 ปีที่ 209–232 · ศ.ท. 32,209–32,232** · ด่านข้ามแม่น้ำระหว่างสองเขตอำนาจ

## 1. สองฝ่ายอ้างหน้าที่คนละอย่าง

คนของสำนัก **ม่านกก** ดึงโซ่ปิดสะพานหลังมีคนขนของลอบพาศิษย์หนีออกไป ราชสำนักท้องถิ่นสั่งเปิดเพราะครัวเรือนฝั่งนอกกำแพงส่งข้าวเข้าตลาดไม่ได้ **เมิ่งลั่วเชียน** หัวหน้าศิษย์เฝ้าทางกลัวว่าหากยอมใครก็จะอ้างว่าเป็นพ่อค้าได้ ส่วนขุนนาง **หลัวจี้อัน** ไม่ต้องการขึ้นไปบุกสำนักเพราะอีกฝ่ายยอมให้เข้าค้นตลาดโดยไม่ขัดขวาง จึงกลายเป็นข้อพิพาทแบบที่คำสัตย์ระหว่างฝ่ายต้องแยกธุระของคนเดินทางออกจากเรื่องของพวกตน

## 2. คนที่มาซื้อผ้าเป็นพยานไม่ได้ทุกเรื่อง

หญิงเรือชื่อ **หูซิ่วถง** เห็นศิษย์คนนั้นขึ้นเรือแต่ไม่เห็นการพาหนีตั้งแต่ต้น ศาลาท้องถิ่นซึ่งรับแบบหนังสือสัตย์จากศาลธรรมนูญให้แยกคำที่นางเห็นเองกับคำบอกต่อ คดีที่คิดว่าเป็นการลักพาตัวเปลี่ยนเมื่อพบศิษย์อาสาไปส่งข่าวแม่ที่ป่วย ขณะเดียวกันมีคนอีกสองคนถูกขนข้ามโดยไม่ยินยอมและไม่มีชื่อในทะเบียนของสำนัก การเปิดสะพานวันนี้จึงไม่ได้แก้คดีทั้งหมด

## 3. ข้อแลกเปลี่ยนที่ทั้งสองฝ่ายเห็นว่าตนเสียเปรียบ

เมิ่งยอมส่งสมุดคนผ่านของสำนักให้ตรวจเฉพาะคืนเกิดเหตุ แลกกับให้หลัวชดข้าวที่ถูกหน่วยเก็บภาษียึดไปโดยไม่มีใบรับ ชาวเรือเสนอเปิดทางข้ามเฉพาะช่วงกลางวันจนรู้ว่าคนสองคนถูกพาไปไหน ผู้รับประกันทางสองฝ่ายต้องจดวันที่จะกลับมาทบทวนและค่าชดใช้หากไม่ได้เปิดตามสัญญา ราชสำนักคุมภาษีที่ด่านได้ต่อ ส่วนการสืบเรื่องศิษย์ยังให้สำนักรับผิด ตำหนักอื่นที่อยู่ห่างไม่ถูกลากเข้ารับคำสัตย์นี้โดยอัตโนมัติ

## 4. ใครยังติดอยู่ฝั่งโน้น

ปี 232 สะพานเก่าถูกเปลี่ยนเสาและเขียนกติกาใหม่ คนทำทางยังเว้นบรรทัดบนป้ายให้ระบุชื่อผู้ที่อยู่ฝั่งที่ปิดและเหตุจำเป็นต้องข้าม ชื่อที่ถูกเว้นไม่ใช่รายชื่อผู้มีอภิสิทธิ์ หากเสมียนลงให้คนในสกุลตนทุกเที่ยว ป้ายที่เขียนชื่อต่อหน้าคนในตลาดกลายเป็นหลักฐานให้คนอื่นทักท้วงได้ หูซิ่วถงไม่ยอมรับตำแหน่งเฝ้าป้าย เธอพายเรือต่อจนมือข้างหนึ่งยกพายไม่ไหว

**ผลทางประวัติศาสตร์:** แสดงการใช้งานกฎน้ำบ่อฯ ระยะที่ศาลสัตย์มีบทบาท ผ่านคดีระดับด่านที่เกือบกลายเป็นเหตุให้ราชสำนักกับสำนักข้ามเขตกัน
