# บันทึกทวีปก่อนหยุนเหอ · 09 — เมืองหลวงที่ต้องเช่าถนนของตน

**ยุคที่ 38 ปีที่ 217–265 · ศ.ท. 37,217–37,265** · แคว้นชางไถ สมาพันธ์ป้อมขนาดเล็กภายในทวีป

## 1. ข้อเสนอที่ช่วยให้แม่ทัพรอดได้หนึ่งฤดู

ขณะที่มหาอำนาจกำลังสร้างปราการ แคว้นชางไถบริหารทางข้ามภูเขาสามช่องจากเมืองหลวงเล็ก ๆ เจ้าคลัง **เว่ยฉางอี๋** ให้กองพ่อค้าจ่ายเงินล่วงหน้าแลกสิทธิ์เก็บค่าผ่านทั้งสามทางสิบปี เงินนั้นช่วยให้แม่ทัพ **ฟ่านฮุยเฉิง** ซื้อฟืนและรักษาคนเฝ้าป้อมได้โดยไม่เกณฑ์เด็กเพิ่ม ผู้แทนร้านค้า **เกิ่งซื่อเฟิน** เตือนว่าหากเปิดสัญญาไม่ครบ คนที่รับสิทธิ์ช่องหนึ่งจะคิดค่าผ่านซ้ำกับอีกช่อง เว่ยเลือกลงนามโดยหวังว่าชัยชนะฤดูหน้าจะทำให้คลังได้ทางเลือกเพิ่ม

## 2. วันที่กองรักษาเมืองต้องรออนุญาต

ห้าปีต่อมา หินถล่มปิดทางหลัก นายเก็บเงินปฏิเสธให้ขบวนข้าวผ่านช่องที่สองในราคาเดิม แม้ฟ่านยกตราเมืองหลวงมาด้วยก็ถูกขอดูยอดค้างเลี้ยงทหารของตน คนลากเชือกยกหินไม่ยอมกลับไปทำงานเพราะเงินจากกองพ่อค้ายังไม่ถึงมือ เกิ่งนำสำเนาคดีสะพานปิดของสำนักม่านกกมาชี้ว่าใครต้องรับผิดเปิดทาง แล้วพบว่าสัญญาชางไถไม่ได้ระบุหน้าที่นั้น มีแต่สิทธิ์เก็บเงินตรงปลายทางทั้งหมด

## 3. เมื่อการฉีกสัญญาทำให้คนของตัวเองเสียเงิน

ฟ่านเสนอขับนายเก็บเงินออกจากทั้งสามช่อง เว่ยพาเขาไปคุยกับคนขายฟืนที่เก็บเงินทั้งชีวิตแล้วเอาไปลงกับกองพ่อค้า หากยกเลิกทันที คนกลุ่มนั้นจะสูญเงินทั้งหมด เกิ่งเสนอให้ช่องที่สองเปิดผ่านได้โดยเก็บค่าดูแลจริง และให้หนี้ทุนที่ยังไม่คืนค่อยจ่ายจากช่องที่ซ่อมเสร็จ นายทุนใหญ่ถอนผู้คุมออก ขณะที่ผู้ลงทุนรายย่อยยอมเปลี่ยนเป็นเงินคืนผ่อนหลายปี ฟ่านต้องยุบป้อมปลายทางเพราะไม่มีเงินสำรองจ่ายเวรอีก

## 4. การสิ้นสุดที่ไม่มีพิธีล้มราชวงศ์

ปี 265 ชางไถเหลือทางให้ดูแลเพียงสองช่อง และไม่มีป้อมพอเก็บเงินจากตลาดด้านนอก สภาช่างกับสมาคมคนลากเกวียนรับดูแลทางร่วมกัน เจ้าคลังคนต่อมาส่งตราเมืองหลวงคืนตระกูลเดิม แต่เกิ่งให้คงใบรับค่าแรงเก่าที่รัฐบาลค้างจ่ายไว้เพื่อให้ลูกหลานมาขอพิสูจน์หนี้ได้ตามเงื่อนไข สงครามระหว่างมหาอำนาจดำเนินต่อไปทั้งที่ชื่อของแคว้นหายจากแผนที่สัญญา

**ผลทางประวัติศาสตร์:** แคว้นเล็กไปไม่รอดเพราะขายอำนาจดูแลเส้นทางเพื่อหาเงินรับวิกฤต มีสำเนาคดีชางไถอยู่ในมือช่างและเจ้าหนี้ จึงไม่มีฝ่ายเดียวได้เป็นผู้เล่าว่าเมืองล่มเพราะอะไร
