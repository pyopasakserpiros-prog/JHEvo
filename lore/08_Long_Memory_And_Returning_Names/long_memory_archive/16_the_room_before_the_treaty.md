# บันทึกทวีปก่อนหยุนเหอ · 16 — ห้องรอที่ไม่มีที่นั่งประธาน

**ยุคที่ 100 ปีที่ 180 ถึงต้นปีที่ 181 · ศ.ท. 99,180–99,181** · จุดพักคนส่งเอกสารนอกหุบเขาหยุนเหอ

**จุดตัด:** สนธิสัญญาจริงลงนามปีที่ 181 เดือนสี่คิมหันต์แรก วันที่ 10 ตามคัมภีร์แม่บท ซูฉินและฝ่ายเดิมยังเป็นผู้รับบททางประวัติศาสตร์ เรื่องนี้จบก่อนวันลงนาม

## 1. สิ่งที่คำสั่งหยุดทัพยังตอบไม่ได้

ด่านรองในแนวสองแควต้องเตรียมเรือนพักและทางส่งหนังสือให้ผู้แทนหลายฝ่าย ผู้รับเหมาหลักเรียกให้ตั้งธงฝ่ายที่จ่ายค่าเสาเป็นเจ้าของเรือน **จูซวงเม่ย** ผู้จัดงานคนท้องถิ่นขอให้เอาธงออกเพราะคนส่งหนังสือจากอีกฝ่ายจะไม่กล้าเข้าพัก **ต่งเหวินคุน** คนดูแลม้าค้านว่าหากเรือนเสียหายแล้วไม่มีคนถือธง ก็ไม่รู้จะเอาค่าซ่อมจากใคร ทั้งคู่จึงต้องทดสอบว่าจะให้ผู้แทนพักร่วมเส้นทางได้อย่างไรโดยที่คนในท้องถิ่นยังได้รับค่าแรง

## 2. หลักฐานที่ไม่มีความน่าเกรงขาม

จูนับฟืน หมอน และเวลาที่คนส่งข่าวแต่ละชุดต้องใช้ต่อเที่ยว ระบบที่ใช้ในห้องพักนำรูปแบบต่างยุคมารวมกัน มีบันทึกวันส่งแรง แยกเงินซ่อมออกจากสิทธิ์บริหารทาง และให้คนในพื้นที่ตรวจยอดเสบียง ต่งนำใบของเรือนปลายด่านฟ้าต่ำซึ่งจดยอดส่งครบกับวันที่ไปถึงไม่ตรงกันมาให้ดู เขาให้คนถือหนังสือเขียนเวลาถึงเองอีกข้างหนึ่ง เพื่อให้ผู้มีตำแหน่งไม่สั่งรวมยอดเวลารอออกไปจากบัญชี

## 3. การปฏิเสธที่ทำให้เอาเรือนมาใช้ได้จริง

เจ้าหน้าที่ของฝ่ายหนึ่งยื่นคนคุมประตูประจำให้โดยขอชื่อคนมาพักทุกคืน จูเสนอให้รับเพียงคนส่งฟืนที่เบิกเป็นรายเที่ยว แต่ให้คนดูแลประตูเป็นคนรับจ้างจากด่าน ผู้เสนอถอนเงินก้อนแรกจนคนงานต้องซ่อมหลังคาเพียงครึ่งหนึ่ง ต่งแบ่งคอกเดิมมาใช้รับม้าฝน และรับความรับผิดคืนเงินหากม้าเจ็บระหว่างอยู่กับตน คนงานที่เห็นว่างานนี้ทำให้เสียรายได้ทยอยออกไป บางคนกลับมาเมื่อได้เห็นยอดงานที่ต้องจ่ายจริงก่อนลงแรง

## 4. ก่อนวันที่พงศาวดารจะเริ่มนับ

ต้นปี 181 ชาวเมืองเห็นขบวนเอกสารเดินสวนกันโดยไม่มีใครต้องขออนุญาตใช้ตราอีกฝ่ายที่เรือนรอ ประโยชน์ของเรือนเล็กมีเพียงทำให้คนส่งสารพักและเดินทางต่อได้ก่อนผู้แทนถึงหุบเขา พอส่งงานเสร็จ จูกับต่งคืนเงินค้างให้ช่างทีละคน และเก็บสมุดบัญชีไว้ให้คนเปิดดูได้ คนในเรือนไม่ได้รู้ว่าผู้แทนจะตกลงกันทุกข้อหรือว่าการเจรจาจะล้มเหลว พวกเขานั่งฟังเสียงฝนหยดใส่ถังใบเดิมที่ยังไม่ได้ซ่อมหลังคาให้ครบ

**ผลทางประวัติศาสตร์:** เป็นทางเข้าจากเรื่องของคนท้องถิ่นไปถึงเหตุการณ์หลัก สัญญาพักเรือนและการขนส่งเป็นตัวอย่างเล็กว่าคำว่าเขตกลางต้องมีคนจัดการและรับต้นทุนจึงใช้ได้ ตัวบท ผู้เจรจา วันลงนาม และผลการตั้งหยุนเหอตามคัมภีร์หลักอยู่ในบันทึกเดิม
