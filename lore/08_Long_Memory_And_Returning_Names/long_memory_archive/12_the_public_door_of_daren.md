# บันทึกทวีปก่อนหยุนเหอ · 12 — ประตูประชุมที่ไม่มีเจ้าของคนเดียว

**ยุคที่ 79 ปีที่ 612–637 · ศ.ท. 78,612–78,637** · ด่านโรงเกวียนในวงอิทธิพลสาธารณรัฐต้าเหริน

## 1. ใครต้องมีที่นั่งสำหรับออกเสียง

ศาลาเลือกคนดูแลค่าเสบียงโดยให้ผู้มีบ้านจ่ายภาษีลงชื่อได้ คนงานยกของที่พักในลานไม่ถือว่ามีบ้าน แม้ต้องเสียเงินค่ายามและอยู่เฝ้าประตูตลาดทุกคืน **อิ่นเหมยชิว** ผู้ดูแลศาลาเสนอให้คนกลุ่มนี้เข้าพูดได้ก่อนนับเสียง **เกาเหวินจู** ผู้ค้าไม้ค้านว่าหากคนเข้ามาเพียงฤดูเดียวเลือกวิธีใช้เงินสะสมเมืองได้ คนที่อยู่หลังพวกเขาก็ต้องจ่ายต่อ ผลประชุมครั้งแรกจบลงโดยยังไม่อนุมัติไม้ซ่อมหลังคาในช่วงฝน

## 2. เงินที่ดูเหมือนมาจากผู้หวังดี

ผู้แทนขั้วนอกเสนอจ่ายค่าซ่อมทั้งหมดแลกให้ผู้เฝ้าประตูเข้าเวรเป็นคนของตน ศาลาตรวจพบว่าคู่สัญญาเดิมของผู้แทนคนนั้นเคยระงับค่าจ้างของคนที่ลาออกกลางฤดู อิ่นพาคนเฝ้าเอกสารจากโรงโม่มาเปิดวิธีให้คนมีที่พักโดยไม่ต้องยอมย้ายสังกัด เกาเอาเงินที่กันไว้ให้ลูกชายซื้อเรือมาช่วยจ่ายค่าวัสดุรอบแรกโดยขอให้ระบุว่าเป็นเงินกู้ ไม่ใช่สิทธิ์ออกเสียงเพิ่ม คนทำงานยอมให้หักรายได้จากเวรใหม่บางส่วนคืนเขาเพราะยอดเงินเปิดให้ตรวจได้

## 3. กฎที่เริ่มใช้กับคนที่อยู่จริง

ชุมชนตกลงให้คนที่รับเวรและอยู่พ้นฤดูฝนมีส่วนออกเสียงเรื่องค่าใช้ประจำฤดู ส่วนสิทธิ์ขายที่ดินและเงินสะสมเมืองต้องเรียกคนอยู่ระยะยาวมาหารือเพิ่ม ผู้คัดค้านนำกลุ่มลูกจ้างไปเฝ้าประตูอีกแห่งและเก็บค่าผ่านเอง อิ่นจึงต้องหาคนทดแทนจากตลาดที่ไม่เคยมีใครสนใจ สิทธิ์ที่เพิ่มขึ้นแลกกับลานกลางที่เล็กลงและรายได้จากคนเดินผ่านลดลงจริง

## 4. หลังแผ่นกฎบัตรหลุดจากผนัง

เมื่อความขัดแย้งใหญ่ค่อย ๆ ทำให้ต้าเหรินถอยจากพื้นที่ในเวลาต่อมา คนเฝ้าลานเลิกแขวนคำสาบานของสาธารณรัฐเพื่อให้ตลาดยังเปิดได้ ทั้งฝ่ายเกาและอิ่นตกลงให้ใช้ช่องเวลาเวรและบัญชีจ่ายค่ายามเดิมต่อ ชาวบ้านรุ่นต่อมาหลายคนรู้เพียงว่าผู้เฝ้าประตูมีสิทธิ์เรียกประชุมเรื่องค่าเวร โดยไม่รู้ว่าครั้งหนึ่งเรื่องนี้เคยถูกถกในนามสิทธิ์พลเมือง สำเนาที่ส่งไปเก็บต่างเมืองยังมีทั้งความเห็นคัดค้านและเหตุผลของผู้ชนะ

**ผลทางประวัติศาสตร์:** ทำให้เห็นว่ากฎบัตรทิ้งวัฒนธรรมการพูดและการบัญชีไว้ได้ แม้รัฐใหญ่ไม่รอด เรื่องไม่ย้ายวันล่มสลาย ไม่เปลี่ยนตัวผู้ก่อตั้ง และไม่อ้างว่าลานนี้กำหนดกฎหมายของสาธารณรัฐทั้งประเทศ
