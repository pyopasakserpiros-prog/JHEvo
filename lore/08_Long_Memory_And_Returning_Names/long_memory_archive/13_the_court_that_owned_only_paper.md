# บันทึกทวีปก่อนหยุนเหอ · 13 — ราชสำนักที่มีเพียงเส้นบนกระดาษ

**ยุคที่ 93 ปีที่ 506–531 · ศ.ท. 92,506–92,531** · หุบค้าเหยาฉือในสมัยราชโองการกระดาษ

## 1. อำนาจสามชั้นบนตลาดเดียว

**เฮ่อเสวียอี๋** ผู้ทำแผนภาษีได้รับคำสั่งวาดเขตที่ราชสำนักท้องถิ่นอ้างว่าเป็นของตน เมื่อไปถึงตลาด พบว่าเขตบนกระดาษกินถึงทางน้ำที่อีกสำนักเป็นเจ้าของแพ และชายป่าที่บ้านคนออกซ่อมทางให้ทุกฤดู หากวาดตามคำสั่งครบจะได้ค่าจ้างและช่วยให้หัวหน้าคลังมีตัวเลขยืนขอกู้เงิน แต่จะเอาไปเก็บภาษีจากคนที่การปกครองไม่เคยไปถึง **ลู่เจาหยง** ผู้เก็บเงินลาดตระเวนอยากให้เส้นอยู่กว้าง เพราะต้องเลี้ยงทหารยามที่รักษาถนนจริง

## 2. แผนที่สามฉบับ

เฮ่อทำแผนที่สามแผ่น แผ่นแรกบอกผู้ที่อ้างสิทธิ์ แผ่นที่สองบอกผู้ที่ดูแลถนนและทางน้ำ ส่วนแผ่นที่สามลงชื่อผู้ที่จ่ายเงินจริงตามใบรับ เธอใช้ธรรมเนียมเปิดยอดของลานต้าเหรินเพื่อให้คนเสียเงินได้แก้แผ่นสุดท้าย คนขายปลาคืนเงินส่วนที่เกินให้ผู้คุมแพโดยยังปฏิเสธภาษีทหารที่ไม่ได้คุ้มทางน้ำ ลู่พบว่าคนที่เขาเชื่อว่าไม่จ่ายอะไรเลยออกข้าวเลี้ยงยามผลัดดึกมานานโดยไม่มีตรารับ

## 3. เส้นชัยที่ไม่มีใครมีหมึกวาดได้ตามใจ

ราชสำนักสั่งห้ามใช้แผ่นที่สองและสามในห้องไต่สวน พ่อค้าในหุบจึงเตรียมเอาทุนไปเปิดตลาดข้างนอก ลู่เข้าเป็นพยานว่ากำลังทหารของตนไปคุ้มได้แค่ช่วงหินชัน ยอมลดเขตเก็บเป็นรายช่วงที่ส่งคนได้จริง โดยขอเงินจากผู้ใช้ทางในวันไหนก็ได้แทนสิทธิ์ผูกกับชื่อบ้าน ขุนนางขายสิทธิ์เก็บอ้างอิงแผนที่หลวงได้ต่ออีกระยะ แต่ไม่มีใครยอมซื้อราคาเดิมถ้าสัญญาไม่แนบยอดดูแลถนน ราชสำนักจึงต้องถอนคนออกจากทางชันบางช่วงเพื่อรักษาผู้คุมด่านหลักไว้ให้ได้

## 4. ชื่อคนทำแผนถูกขูด แต่เส้นยังเหลือ

ชื่อเฮ่อหายจากฉบับราชการในปี 531 เพราะผู้ว่าจ้างคนใหม่ไม่อยากรับว่าการตรวจเดิมทำถูก ในสมุดของพ่อค้า แผ่นที่สามถูกคัดต่อและมีวงจุดทางที่ทหารลู่เคยช่วยคุ้มจริง ลู่เสียตำแหน่งเมื่อยามถูกลด เขากลับไปรับจ้างพาคนเดินป่าข้ามทางชันเดิมและออกใบรับเองทุกครั้ง

**ผลทางประวัติศาสตร์:** แสดงว่าชื่อเจ้าแคว้น สิทธิ์ตามเอกสาร และอำนาจดูแลพื้นที่ห่างกันได้อย่างไรในยุคฎีกากระดาษ แบบสามแผ่นกลายเป็นหลักอ้างอิงในการตรวจข้อพิพาททางผ่านของยุคถัดมา
