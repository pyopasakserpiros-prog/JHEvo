# บันทึกทวีปก่อนหยุนเหอ · 01 — มงกุฎที่ส่งข้าวไม่ถึง

**ยุคที่ 1 ปีที่ 67–83 · ศ.ท. 67–83** · แอ่งนาเจ็ดคันหลังเทียนกู่แตก

## 1. ผู้แทนที่เอาตราหลวงเก่ามาแทนข้าว

นายจ่ายเสบียง **อิ่นกว่างจวิน** มาถึงแอ่งนาเจ็ดคันพร้อมตราแห่งกรมคลังเก่า เขามีคำสั่งให้เปิดยุ้งและมีทหารขาดค่าจ้างสิบสองคน แต่ยุ้งว่างมาแล้วสองปี หลังประตูฟ้าแตกครัวเรือนฝากเมล็ดพันธุ์ที่รอดไว้กับโรงสี แม่หม้ายเจ้าของโรงสี **หลวนเจียอิง** รู้ว่าเปิดห้องเก็บเมล็ดแล้วขบวนของเขาจะมีข้าวเพียงพอกินถึงต้นฤดูฝน นาที่นี่กลับไม่มีอะไรหว่าน เธอให้เขาเปิดยุ้งหลวงต่อหน้าคนทั้งตำบล แล้วถามว่าจะเอาอะไรจ่ายคืนให้พวกเขาเมื่อถึงฤดูปลูก

## 2. ไม้ขีดที่อยู่คนละมือ

อิ่นยอมให้หลวนถือไม้ขีดครึ่งซีกสำหรับยอดที่จ่ายข้าว และให้ทหารเฝ้าครึ่งที่มีวันส่งแรงงานคืน ข้อตกลงกินเวลาเพียงฤดูเดียว ทหารลงไปช่วยซ่อมล้อสีข้าวและคุมทางเกวียนบางคืนโดยยังเก็บสิทธิ์ถอนตัวหากมีเหตุที่บ้าน ครัวเรือนยอมเอาข้าวปรุงสุกไปให้แต่เก็บเมล็ดพันธุ์ต่างหาก เมื่อมีคนกระซิบว่าทหารคุมทางจะยึดโรงสี อิ่นเสนอให้พวกเขารับค่าจ้างเป็นข้าวตามงานเสร็จ ไม่ถือกุญแจตลอดเวลา ทหารสองนายไปเข้ากับผู้คุมท่าอีกแห่งเพราะต้องหาเงินเดือนเดียวกันให้ครอบครัว

## 3. หลักฐานของผู้ที่กำลังเสียอำนาจ

ปี 71 ผู้ครองเมืองชั่วคราวเรียกเก็บข้าวอ้างว่าเป็นหนี้ยุคเทียนกู่ เขานำทหารอิ่นที่เคยออกไปกลับมาด้วยในฐานะคนของตัวเอง หลวนไม่สามารถต้านกำลังได้ แต่ซีกไม้ที่คนงานถืออยู่แสดงว่าผู้ครองเมืองเคยรับแรงซ่อมทางโดยจ่ายต่ำกว่ายอด เมื่อชาวนาหยุดขนข้าวและกองเกวียนเปลี่ยนเส้นทาง เขายอมคืนทหารไปทำงานที่ค้างและรับเงินเพียงค่าคุ้มภัยที่ทำไปแล้ว อิ่นต้องเสียตำแหน่งนายจ่ายเสบียงเพราะยืนยันยอดดังกล่าว เขาจึงหันไปรับจ้างตรวจไม้ขีดให้ตลาดเล็ก ๆ และไม่เคยได้ตราหลวงคืน

## 4. มงกุฎในตะกร้าเครื่องชั่ง

หลังหลวนเสียชีวิตในปี 83 ลูกสาวเธอพบตราที่อิ่นเคยเอามาแสดงนอนอยู่ในตะกร้าเศษโลหะโรงสี คนงานใช้ถ่วงตาชั่งเมื่อขนฟาง คำขวัญในใบสั่งงานรุ่นใหม่ยังเรียกงานนั้นว่า “เสบียงช่วยพระนคร” แต่รายการที่คนในตลาดยอมรับคือวันส่งแรง ค่าข้าว และชื่อคนที่เคยไปซ่อมทาง เมื่อมีใครจดผิด สำเนาจากอีกฝั่งเอามาเทียบได้

**ผลทางประวัติศาสตร์:** ตัวอย่างขนาดเล็กว่าด่านกับชุมชนเลิกถือว่าตราเดิมเพียงอย่างเดียวพอเบิกทรัพย์ แบบไม้ขีดสองฝ่ายมีผู้สืบต่อหลายสกุลโดยไม่ต้องถือว่าแอ่งนาเป็นต้นกำเนิดระบบบัญชีของทั้งทวีป
