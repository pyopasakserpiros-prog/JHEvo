# บันทึกทวีปก่อนหยุนเหอ · 02 — เฟืองที่หมู่บ้านจ่ายเอง

**ยุคที่ 5 ปีที่ 332–361 · ศ.ท. 4,332–4,361** · ชายขอบเครือข่ายโรงช่างจักรวรรดิเสวียนจี

## 1. เครื่องยกข้าวที่มาถึงก่อนคำสั่ง

โรงช่างเสวียนจีส่งเครื่องยกกระสอบให้ท่าเกวียนในเชิงเขา เครื่องทำงานได้ด้วยน้ำหนักสลับกัน เด็กไม่ต้องลงไปแบกข้าวจากลานต่ำในฤดูฝน ช่างตรวจ **เฉิงลั่วฉิน** ยืนยันให้คลังส่วนกลางถือแบบเฟืองไว้เพื่อป้องกันการเอาไปหลอมเป็นอาวุธ คนทำโรงสี **ไป๋เว่ยถง** ขอสิทธิ์ซ่อมชิ้นที่สึกด้วยงบของหมู่บ้าน เฉิงยอมให้เปลี่ยนได้แต่ไม้รองเครื่อง เพราะไม่อยากให้ชิ้นส่วนจากต่างโรงทำอันตรายคนงาน แล้วฝากลูกศิษย์ไว้สอนวิธีหยุดเครื่องก่อนซ่อม

## 2. วันที่คลังมองไม่เห็นท่าน้ำ

สามฤดูต่อมาเฟืองชุดหลักบิ่น ทางหลวงให้ความสำคัญกับโรงซ่อมทหารที่อยู่เหนือกว่า ใบเบิกเปลี่ยนเฟืองรอข้ามฤดูจนข้าวชื้นและกองเกวียนยกเลิกสัญญา ไป๋ตีไม้ขีดราคาและวันส่งตามแบบที่บ้านโรงสีเก่าเคยใช้ ให้คนส่งข้าวกับช่างลงคนละครึ่ง เขาเสนอให้ลอกเฉพาะเฟืองที่เสียจากชิ้นตัวอย่าง ไม่จับส่วนที่ใช้กับกองทัพ ลูกศิษย์ยอมรับงานโดยให้ทุกคนถอยเมื่อทดลองรอบแรก เฟืองแตกต่อหน้าชาวบ้าน ไม่มีใครบาดเจ็บ แต่ต้นทุนทองแดงที่ยืมมาหมดไปครึ่งหนึ่ง

## 3. ช่างสองฝ่ายบนตั่งเดียวกัน

เฉิงกลับมาพร้อมหมายยึดเครื่อง เธอเห็นชิ้นที่แตกและรู้ว่าหากขนเครื่องทั้งตัวออกเรือข้าวจะเลิกเข้า เธอเปิดแบบของโรงหลวงเฉพาะส่วนรับน้ำหนัก ให้ช่างท้องถิ่นเปิดรายการโลหะที่ใช้จริง คนของจักรวรรดิยังมีสิทธิ์มาตรวจ แต่หมู่บ้านได้ถือแบบซ่อมและสัญญาว่าต้องหักบันทึกต้นทุนให้คนจ่ายดู ช่างใหม่ตีเฟืองได้สำเร็จในเดือนถัดมา ส่วนเฉิงถูกลดเงินรางวัลเพราะส่งสำเนาแบบนอกเครือข่ายที่ได้รับอนุญาต โรงช่างหลักภายหลังขอใช้บันทึกเฟืองบิ่นของเธอเพื่อแก้ข้อเสียแบบเดิม

## 4. เครื่องหมายที่อยู่ด้านใน

เมื่อไป๋แก่ลง เขาสอนลูกศิษย์สลักชื่อหมู่บ้านไว้ด้านในเฟือง คนใช้เครื่องมองไม่เห็นเว้นแต่หยุดมาถอดล้าง เป็นวิธีบอกว่าชิ้นนี้คนที่นี่ซ่อมได้จริง ต่อมาโรงงานหลายแห่งสลักตราเดียวกันเพื่ออวดทั้งที่ไม่มีช่างฝีมือ เครือข่ายช่างจึงให้เครดิตตามสิ่งที่ถอดตรวจได้กับการซ่อมที่เคยทำต่อหน้าคนใช้

**ผลทางประวัติศาสตร์:** ความชำนาญท้องถิ่นเกิดจากความล่าช้าของอำนาจส่วนกลาง การถือแบบซ่อมช่วยเปิดพื้นที่ให้คนลุกขึ้นรับผิดชอบ ขณะที่ข้อจำกัดบางส่วนของเสวียนจียังสมเหตุผลกับความปลอดภัย
