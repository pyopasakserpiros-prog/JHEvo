# แผ่นดินที่ยังมีชื่อคนกลับบ้าน · เล่ม 5 — ภูเขาที่นับเฉพาะคนเป็น

**ยุคที่ 86 ปีที่ 639–653 (ศ.ท. 85,639–85,653)** · ทางพักเกวียนทางตะวันตกเฉียงเหนือ

**จุดเชื่อม:** ภัยแล้งยุค 86 ปี 640 และการโยกย้ายที่ส่งผลต่อรัฐกันชน เสนอให้เกิดกับหน่วยปกครองท้องถิ่นแนวชายขอบเท่านั้น

## 1. หมู่บ้านที่จำเป็นต้องมีคนครบ

แคว้นเล็ก **ซู่เจี้ยน** อยู่ได้เพราะคนงานเฝ้าบ่อและสัตว์ลากเกวียนตามทางพักสามแห่ง เมื่อบ่อชั้นบนเริ่มแห้ง คนจำนวนหนึ่งไปอยู่กับญาติตามเมืองอื่น แต่ผู้ดูแลต้องจ่ายด่านคุ้มกันตามจำนวนคนที่ขึ้นทะเบียน เขาจึงขอให้ **ซือชงอี้** คนตรวจบ่อ จดชื่อคนที่จากไปว่าอยู่ครบ และปันน้ำในนามของคนเหล่านั้นมาเติมบ่อเก็บกลาง ซือยอมในตอนแรก เขาคิดว่ารักษาข้อตกลงกับด่านไว้จะช่วยคนที่ยังอยู่ให้อยู่ต่อได้ **เจี่ยซวงอี๋** เจ้าของกองล่อรู้เรื่องเมื่อมารับน้ำแล้วต้องจ่ายค่าใช้บ่อให้คนที่ไม่เคยเห็นหน้า

## 2. วันที่บ่อของเมืองว่าง แต่บัญชียังเต็ม

ต้นฤดูฝนปี 640 หญิงเฝ้าบ่อเอาด้ายผูกถังใบสุดท้ายเพื่อให้ตนจำได้ว่าใช้รอกไปลึกเท่าใด เธอดึงขึ้นมาได้แต่โคลน ขณะที่คณะตรวจจากนอกแคว้นกำลังมาดูยอดน้ำ ซือพาไปดูบ่อว่างก่อนเปิดสมุดให้ตรวจ เขายอมรับว่าตนเป็นคนจดชื่อเท็จและแสดงรายชื่อจริงว่าครัวเรือนไหนไปพักที่ใด เจี่ยใช้แผ่นตรวจล้อของลู่รุ่นก่อนที่คนขนของยังคัดลอกเป็นแบบมาเขียนยอดคนจริง เธอยอมลดจำนวนล่อที่รับจ้างให้มีที่นั่งบนเกวียน แต่ขอให้มีสัญญาชำระค่าฟางที่ต้องซื้อเพิ่มเมื่อไปถึงเมืองปลายทาง

## 3. บ้านที่ชั่งน้ำหนักได้

วังแคว้นสั่งให้ขนป้ายบรรพชนและหีบเงินขึ้นเกวียนก่อน ด้วยหวังว่าจะตั้งเมืองขึ้นใหม่ที่อื่น หมอประจำคณะ **อู๋ซิ่วจาง** นำเด็กไข้สูงไปนั่งบนที่ของตนแล้วเดินแทน ซือได้โควตาเกวียนหนึ่งคัน เขาไม่ได้ขอให้คนทิ้งป้ายบรรพชน แต่ให้แยกชิ้นที่ถือไปกับตัวได้จากหีบขนาดใหญ่ เจี่ยไปถึงเมืองที่รับขบวนช้ากว่าหอเกวียนคู่แข่งสามวัน จึงเสียสัมปทานขนเสบียงในปีถัดมา เธอยอมล้มร้านของตัวเองครึ่งหนึ่งเพื่อจ่ายค่าฟางตามที่รับปากกับคนป้อนสัตว์

## 4. สิ่งที่เมืองใหม่ไม่ย้อนให้

ปี 653 มีน้ำกลับมาที่บ่อชั้นล่าง ลูกหลานบางบ้านขอกลับไปเปิดด่าน แต่พบว่าถนนเก่าพังเกินซ่อมและทางค้าหลักย้ายออกไปแล้ว ซู่เจี้ยนไม่ได้กลับมาเป็นแคว้น ลูกชายผู้ดูแลวังเพิ่งทราบว่าพ่อเคยโอนบ่อกลางให้ครัวเรือนที่ยอมอยู่ล้างบ่อแทนที่จะยกให้ทายาท เขาพยายามฟ้องคืนและแพ้โดยมีคนเฝ้าบ่อเก่ามาให้การ จากนั้นเขาเลือกเช่าเรือนช่างใกล้เมืองใหม่และเปิดอู่ซ่อมรอกเล็ก ๆ ญาติบางคนยังเห็นว่าเขายอมแพ้ง่ายเกินไป

**ผลที่ส่งต่อ:** คนเฝ้าบ่อรุ่นหลังคัดสำเนาผังให้เห็นทั้งระดับน้ำที่ตักได้และระดับที่คนต้องเริ่มย้ายออก ตามแบบเสาคู่ที่พบในเอกสารผู้พลัดถิ่นของต้าเหริน รายชื่อผู้กลับแยก “จะกลับบ้านเมื่อบ่อใช้ได้” ออกจาก “ต้องได้รับสิทธิ์อาศัยตอนนี้” ผังบ่อและทะเบียนคนช่วยอธิบายว่าเหตุใดชุมชนบางแห่งรักษาชื่อเดิมแม้เสียเมือง ส่วนบางแห่งต้องเริ่มต้นด้วยชื่อใหม่
