# แผ่นดินที่ยังมีชื่อคนกลับบ้าน · เล่ม 7 — ประตูที่บ้านไม่มีเลข

**ยุคที่ 100 ปีที่ 940–948 (ศ.ท. 99,940–99,948)** · ย่านล่างของหลิ่ววาน

**จุดเชื่อม:** วิกฤตศิลาสองเสียงและสถานภาพผู้พลัดถิ่นหลังหกแคว้นล่ม เหตุหลักอยู่ที่สัญญาเช่าและค่าจ้าง

## 1. คืนที่ค่าแรงซื้อข้าวไม่ได้

ในเดือนเจ็ดสารทแรก ปี 940 คนพายเรือในย่านล่างได้รับศิลาตามจำนวนเดิม แต่แม่ค้าข้าวตรวจแล้วรับเพียงครึ่งมูลค่า **ผังเซิ่งซิน** ผู้ให้เช่าห้องเร่งเก็บเงินค้าง เพราะหอการค้าที่ให้เขากู้ขอหลักประกันเพิ่ม ครอบครัวที่ไม่มีเลขบ้านถูกเสนอให้ย้ายไปอยู่โรงเก็บผ้าหากฝากบุตรเป็นแรงงานตามสัญญา หญิงชื่อ **เซี่ยหย่งหมิ่น** เจ้าหน้าที่วัดพื้นที่ ผู้เคยเช่าห้องจากลูกของสุ่ยเหมยอันและเห็นร้านซักผ้าใช้ตะขอพักเสื้อให้คนที่ยังหาเจ้าของไม่ได้ ปฏิเสธลงนามรับรองห้องว่าง เพราะมีมุ้งห้าหลังแขวนอยู่ด้านใน แม้ทางบัญชีเจ้าของซื้อพื้นที่มาแบบไม่มีผู้อาศัยแล้วก็ตาม

## 2. คนที่เลือกช่วยโดยยังเก็บค่าเช่า

ผังพยายามหาเงินจากห้องว่างเพิ่มแทนบีบคนเก่า เขายื่นราคาค้างและดอกเบี้ยจริงให้ชุมชนดู ขอให้มีตัวแทนตรวจยอดก่อนรับความช่วยเหลือจากหอการค้า **เจิ้งไห่เจิน** หมอประจำท่าออกค่ามุ้งเพิ่มให้หนึ่งครอบครัวโดยลงชื่อกำกับว่าเป็นของยืม ไม่เอาหนี้มาหักค่าแรง ผู้เช่าที่เกลียดผังเพราะเคยถูกริบผ้าห่มยังไม่ยอมให้เขาเป็นคนบันทึกยอด เซี่ยจึงยอมเสียรายได้จากการวัดที่ครึ่งเดือนเพื่อช่วยตรวจบัญชี พร้อมเปิดให้คนที่สงสัยจ้างผู้ตรวจอีกคนมาดูได้ด้วย

## 3. ห้องที่มีประตูจริง

ปี 941 กลุ่มนายทุนเสนอซื้อโรงเก็บผ้าเพื่อปรับเป็นห้องพักให้แรงงานและชดใช้หนี้ผัง แลกสิทธิ์คุมค่าแรงกับการเข้าออก คนพายเรือบางคนรับข้อเสนอเพราะต้องการงานทันที เซี่ยใช้บันทึกผังพื้นกับรายการผู้เช่าจริงยืนยันว่าหลังแบ่งห้องยังต้องมีประตูออกเป็นของตัวเอง และให้คนที่ไม่ได้เป็นลูกจ้างใช้ทางเดินร่วมต่อไป หอการค้ายอมรับเงื่อนไขเพราะถ้าไม่มีคนชำนาญน้ำ เรือฤดูฝนจะเข้าเทียบท่าไม่ได้ตามกำหนด เงินช่วยบางส่วนไปลงที่ค่าซ่อมพื้น และส่วนที่เหลือชำระหนี้เท่าที่มีคนยอมรับ ไม่ได้ล้างหนี้ของผังทั้งหมด

## 4. เตียงว่างที่ทิ้งไว้

ปี 948 ผู้เช่าบางคนซื้อห้องได้เอง ขณะที่หลายคนยังเป็นคนงานรับจ้างต่อวัน หมอเจิ้งเสียชีวิตด้วยโรคตามวัยในเรือนเช่าของตน คนในย่านตกลงให้เตียงหนึ่งว่างเสมอสำหรับผู้มาถึงโดยไม่มีคนรับรอง แต่เมื่อมีคนมาครั้งละหลายครอบครัว พวกเขาต้องผลัดกันจ่ายค่าฟืนและยอมให้ผู้อยู่อาศัยอธิบายว่าตนมีภาระอะไรอยู่ ข้อปฏิบัติเปลี่ยนไปตามปีและจำนวนคนที่มาถึง รอยเดิมที่อยู่ตลอดคือประตูออกได้จากด้านใน และที่หัวเตียงมีช่องให้ผู้เข้าพักลงชื่อเองเมื่อพร้อม

**ผลที่ส่งต่อ:** เรือนพักมีต้นทุนและคนรับผิดชอบจริง กลุ่มที่ทำให้ย่านอยู่ได้มีทั้งผู้เช่าที่ร่วมกันตรวจบัญชี เจ้าหนี้ที่ยอมแก้สัญญา คนซ่อมประตู และหมอ ชื่อถนนในยุค 101 อาจจำคนใดคนหนึ่งผิด ๆ ว่าเป็นผู้ก่อตั้งทุกอย่าง
