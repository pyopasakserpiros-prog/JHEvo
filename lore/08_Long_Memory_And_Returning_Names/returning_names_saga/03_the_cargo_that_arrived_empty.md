# แผ่นดินที่ยังมีชื่อคนกลับบ้าน · เล่ม 3 — คาราวานที่มาถึงมือเปล่า

**ยุคที่ 56 ปีที่ 103–125 (ศ.ท. 55,103–55,125)** · เส้นทางคาราวานสายรองด้านตะวันตก

**จุดเชื่อม:** ช่วงสหพันธ์คาราวานหยกทองมีอำนาจ และผลของอัตราค่าขนที่บีบทางเล็ก

## 1. ล้อที่เสียก่อนถึงด่าน

ระหว่างที่ค่าผ่านทางเกลือบนเส้นหลักขึ้นราคา **ลู่อู๋เหยา** รับจ้างนำขบวนของร้านเล็กผ่านเส้นหินด้านตะวันตก เขารับสัญญาชดใช้สินค้าเต็มราคาแลกค่าตอบแทนที่พอจ้างช่างซ่อมทาง วันกลางฝน ล้อเกวียนคันข้าวบิดตรงลานพักจนขวางทางคนจากหมู่บ้านที่ลาดเขาพัง คนบาดเจ็บนั่งอยู่ได้แต่เดินลงไม่ได้ ก่อนออกเดินทาง ลู่เคยเห็นโรงต้มข้าวที่จดจำนวนชามแยกจากชื่อผู้ที่ยังไม่ได้กิน คนเฝ้าเตาบอกว่าจดแบบนี้จะรู้ได้ว่าควรเผื่อข้าวให้ใคร ลู่นึกถึงป้ายไม้ใบนั้นตอนปลดเกลือกับผ้าเนื้อดีลงจากเกวียนให้พวกเขาขึ้น แล้วฝากผู้คุมกองเขียนชื่อผู้รับในใบส่งของแทนลังสินค้า คนส่งสารถือใบไปถึงด่านก่อนขบวน ด่านตอบว่าเที่ยวกลับจะต้องเสียค่าขน “คนไม่มีสังกัด” อีกอัตราหนึ่ง

## 2. ผู้รับของที่ไม่มีหน้าในบัญชี

**จ้าวเหวินซู** เจ้าของร้านผ้าปฏิเสธชดใช้ในตอนแรก เพราะผ้าผูกอยู่กับเงินมัดจำงานแต่งของลูกสาว ขณะที่หัวหน้าด่าน **หลินเจิ้งซา** รู้ว่าถ้าเปิดทางให้ขบวนนี้ เขาอาจต้องรับผิดต่อเจ้าสัมปทานที่เก็บเงินล่วงหน้าไปแล้ว จ้าวขอดูเกวียนที่ขนคนมาถึงและพบช่างย้อมเก่าของร้านอยู่ในนั้น เขายอมปล่อยให้ใช้คอกม้าของร้านพักชั่วคราว แต่ยังเรียกค่าผ้าคืนตามสัญญา ลู่ยังต้องหาทางปิดบัญชี เจ้าของร้านคนอื่นกลัวว่าถ้าปล่อยหนี้โดยไม่มีข้อตกลง คาราวานอาจอ้างเหตุช่วยคนทุกครั้งที่ของหาย

## 3. การไต่สวนบนเกวียน

หลินให้พ่อค้า คนงาน หมอ และชาวบ้านดูรอยล้อกับพื้นที่ที่พังด้วยกัน พบว่าขบวนเก็บของได้อีกครั้งถ้าเปิดทางเล็ก แต่ไม่มีใครยอมเสี่ยงเดินกลับก่อนฝนหยุด จ้าวยอมสละมูลค่าผ้าบางส่วนหากชุมชนช่วยซ่อมทางและตั้งหีบเงินชดเชยจากค่าผ่านรอบหน้า ลู่ยอมถูกพักใบอนุญาตหนึ่งเดือนเพราะเลือกเส้นทางผิดเอง กลุ่มคนที่เขาช่วยไม่ต้องเซ็นรับภาระค่าผ้า หัวหน้าด่านรับคำด่าทั้งสองฝั่งและยอมเปิดทางคนโดยคิดเงินเฉพาะเที่ยวที่จะกลับไปขนสินค้าจริง

## 4. เมื่อหีบชดเชยถูกออกแบบใหม่

ปี 125 ร้านใหญ่ซื้อสิทธิ์ทางย่อยและพยายามเปลี่ยนเงินชดเชยให้เป็นค่าทางลัดแลกสิทธิ์กันขบวนคนเจ็บลงเขา ลูกจ้างของจ้าวเป็นคนเปิดสำเนาสัญญา โดยวงคำว่า “ค่าเดินทางขนคนต้องผ่านได้แม้หีบว่าง” ไว้ ผู้จ้างบังคับให้เขาออกจากร้าน เขาเปิดเพิงรับซ่อมล้อริมทางโดยได้เงินทุนจากชาวบ้านเพียงพอซื้อเครื่องมือสองชิ้น หีบจริงถูกยึดไป แต่ทางยังมีคนช่วยดูและเก็บค่าใช้จ่ายแบบเปิดเผยต่างหาก เรื่องนี้ถูกจดในสมุดของช่างซ่อมมากกว่าในพงศาวดารพ่อค้า

**ผลที่ส่งต่อ:** สัญญาตัวอย่างจากเส้นทางเล็กถูกคัดแยกจากข้อพิพาทใหญ่ เป็นบรรพแบบหนึ่งของทางผ่านฉุกเฉินในภายหลัง สหพันธ์ยังมีเส้นทางหลักและกำลังผูกขาดตามเรื่องเดิม
