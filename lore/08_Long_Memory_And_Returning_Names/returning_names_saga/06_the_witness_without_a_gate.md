# แผ่นดินที่ยังมีชื่อคนกลับบ้าน · เล่ม 6 — พยานผู้ไม่มีประตูให้กลับ

**ยุคที่ 100 ปีที่ 864–875 (ศ.ท. 99,864–99,875)** · ด่านเก่าอวี้กวานและทางไปหลิ่ววาน

**จุดเชื่อม:** อวี้กวานล่มในปี 865 สนธิสัญญาหยุนเหอมีผลอยู่แล้ว เรื่องนี้ติดตามหนึ่งขบวนและข้อพิพาทที่ตามมา

## 1. วันซักผ้าก่อนปิดด่าน

**สุ่ยเหมยอัน** เจ้าของร้านซักผ้าเล็กหน้าด่าน ได้ยินข่าวว่าจะปิดทางเลียบเขาในรุ่งเช้า เธอเก็บเสื้อที่ลูกค้ายังไม่มารับแยกตามรอยเย็บ แล้วเอากระดาษเขียนชื่อไปฝากคนเฝ้าทาง เธอกังวลว่าเจ้าของเสื้อจะมาถึงทางเดิมโดยไม่รู้ว่าคนในตลาดย้ายแล้ว **ต้วนจื่อหยู** ผู้รักษาตราด่านเห็นว่าคำเตือนเปิดเผยการถอนกำลัง จึงยึดกระดาษไว้ เมื่อด่านล่ม เขาเอากระดาษนั้นคืนให้เธอและบอกว่ามีเวลาพาคนออกตามทางหาบหินก่อนที่เส้นทางจะควบคุมไม่ได้ เขายังเก็บตราไว้ด้วยความหวังว่าจะกลับมาเข้าประจำการได้อีก

## 2. ชายที่เอาตรามาขออาหาร

เมื่อถึงพักแรมก่อนหลิ่ววาน ต้วนใช้ตราเบิกข้าวให้คนในขบวน พ่อครัวปฏิเสธเพราะเพิ่งได้ข่าวว่าด่านแตกและตราอาจถูกขโมย เขายอมจ่ายข้าวหลังสุ่ยเอาถุงเงินค่าซักผ้าของตนออกค้ำ ขบวนจึงถึงท่าน้ำพร้อมกัน แต่พ่อค้าคนหนึ่งอ้างว่าตนจ่ายเงินให้ต้วนสองครั้งเพื่อผ่านด่าน หัวหน้าท่าจึงกันไม่ให้เขาออกเรือจนกว่าคำกล่าวหาจะได้รับการตรวจ ต้วนอยากใช้ตรายืนยันว่าตนยังเป็นเจ้าหน้าที่ สุ่ยกลับยืนยันให้สอบเรื่องเงินแยกจากเรื่องว่าคนในขบวนสมควรได้ข้าวหรือไม่ และกลายเป็นคนแรกที่จะมีผลเสียหากคำให้การของตนผิด

## 3. ตราที่ทำให้ความผิดถูกนับสองครั้ง

**จางไป๋หลาน** เสมียนผู้ตรวจใช้ข้อปฏิบัติของคนเฝ้าบ่อซู่เจี้ยนที่สอนให้แยกสิทธิ์พักระหว่างทางออกจากสิทธิ์กลับถิ่น แล้วจึงตรวจเรื่องเงิน เธอพบใบรับเงินจริงอยู่สองใบ ใบหนึ่งเป็นค่าผ่าน ส่วนอีกใบเป็นค่าขนคนเจ็บที่ต้วนตั้งเองตอนรถค้าง ไม่มีใครอ้างได้ว่าเขามีสิทธิ์เก็บเงินอย่างหลัง แต่พ่อค้าได้รับความเสียหายจริงและเขาก็ช่วยคนเจ็บจริง ศาลไกล่เกลี่ยสั่งให้คืนเงินก้อนหลังผ่านงานพายเรือชดใช้ ส่วนตราเก็บเข้าคลังหลักฐาน สุ่ยได้รับเงินที่วางค้ำคืนเพียงบางส่วน เพราะข้าวที่เธอจ่ายไปส่วนหนึ่งไม่มีใครมารับผิดชอบ เธอเปิดร้านซักผ้าใหม่ในเรือนเช่าที่เล็กกว่าเดิมและตกลงรับผ้าเด็กกำพร้าจากท่าเดือนละสองครั้ง

## 4. ทางเลือกของคนที่ได้สิทธิ์อยู่

ปี 875 ทางกลับด่านเก่าปลอดภัยขึ้น มีคนชวนสุ่ยกลับไปตั้งร้านตรงจุดเก่า เธอบอกว่าเธอคิดถึงบ้าน แต่ลูกของเธออยู่หลิ่ววานและเรียนพายเรือที่นั่นแล้ว ต้วนไปกับคณะสำรวจทางเก่าเพื่อหาหมุดที่เคยใช้ตัดยอดเสบียง เขากลับมาพร้อมตะขอแขวนเสื้อซี่หนึ่ง ส่งให้สุ่ยโดยไม่ได้ขอให้เก็บไว้แทนความทรงจำเดิม คนรุ่นหลังในร้านแขวนตะขอนั้นไว้เพื่อพักผ้าของลูกค้าที่หาเจ้าของไม่พบ

**ผลที่ส่งต่อ:** พยานคนหนึ่งให้ข้อมูลที่เป็นคุณแก่ผู้ถูกกล่าวหาได้ขณะยืนยันว่าเขาเคยทำผิด คดีให้ตัวอย่างว่าทะเบียนพลัดถิ่น อำนาจของด่านเดิม และข้อพิพาทการค้าต้องใช้หลักฐานคนละชุด
