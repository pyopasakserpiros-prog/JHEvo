# แผ่นดินที่ยังมีชื่อคนกลับบ้าน · เล่ม 2 — ฤดูหนาวที่ไม่ถามแซ่

**ยุคที่ 42 ปีที่ 327–346 (ศ.ท. 41,327–41,346)** · เชิงเขาหนาวฝั่งตะวันออก

**จุดเชื่อม:** ภัยหนาวและทุพภิกขภัยยุค 40–44 รวมถึงการเปลี่ยนแปลงของงานหลอมและงานโอสถ

## 1. เบี้ยก้อนสุดท้ายของเรือนช่าง

เมืองหน้าด่านจ่ายข้าวปันส่วนตามจำนวนคนที่มีทะเบียนบ้าน คลื่นคนหิวจากหุบด้านบนเข้ามาพร้อมฤดูหนาวเร็ว คนลาดตระเวนเก็บไม้เตาไปเผาให้โรงต้มข้าวหลวงก่อน เกวียนของ **กัวซือเหม่ย** ช่างซ่อมกระทะของสำนักเตาเงาสนมาถึงทันเห็นเด็กคนหนึ่งเอาตราสกุลของคนตายมาขอข้าว ตัวอักษรด้านหลังถูกขูดจนกลายเป็นแผ่นไม้บาง พนักงานคลัง **เผยอี้เจา** จับเด็กได้แต่ยังยื่นข้าวของตัวเองให้ เขาไม่มีอำนาจให้คลังเปิดอีกครั้งเมื่อครบโควตา

## 2. โรงต้มที่รับชามแทนตรา

กัวใช้เงินค่าซ่อมเหล็กซื้อข้าวปลายคลัง แล้วจุดเตาในโรงหล่อที่งานหยุดเพราะไม่พอถ่าน เธอรับชาม บันทึกจำนวนคนตามชามที่ใช้จริง และเก็บช่องไว้สำหรับคนที่ยังต้องตักเผื่อ ลูกศิษย์ **มู่หรงชิวเติง** เสนอให้ปล่อยคนไร้ชื่อกินก่อน ผู้จ่ายทุนในเมืองค้านเพราะคนท้องที่อาจเสียสิทธิ์ เผยเลยส่งบัญชียอดหลังต้มหักยอดที่ไปถึงปากคนข้ามเขาให้ทั้งสองฝ่ายดู เขาลงชื่อกำกับถุงที่ค้างส่ง การทำเช่นนี้เปิดเผยว่าญาติของเขาค้างส่งข้าวอยู่สองขบวน เขาถูกพ้นงานคลังและกลับมาเป็นคนกวนหม้อให้กัว

## 3. การซื้อเวลาของเมือง

หลังเดือนสิบเอ็ดน้ำค้างแข็ง เมืองเสนอซื้อสิทธิ์ใช้โรงต้ม หากผู้รับข้าวยอมเกณฑ์แรงงานหนึ่งฤดู กัวตกลงเฉพาะสัญญากับคนสมัครใจ และให้ลูกศิษย์อ่านสัญญาต่อหน้าครอบครัวคนที่อ่านไม่ออก หญิงม่ายคนหนึ่งปฏิเสธเพราะการกลับไปปลูกข้าวสำคัญกว่า เผยพานางออกจากเมืองและไม่ได้กลับมาถึงก่อนหิมะรอบสอง เมื่อขบวนของเขากลับมาในวสันต์ ผู้คนเห็นว่าเขาเสียสามนิ้วไป แต่พาคนงานจากหมู่บ้านที่เมืองเคยถือว่าอพยพหมดแล้วกลับมาด้วย คนที่เลือกทำสัญญาอยู่ในเมืองได้ค่าจ้างและค่าชามตามที่ตกลงกัน ผู้ที่ไม่ลงนามยังได้รับข้าวข้ามฤดู

## 4. เตาที่เจ้าสำนักยอมเสีย

ปี 346 สำนักเตาเงาสนแตกกันเรื่องต้องปิดโรงต้มเพื่อฟื้นกำไรหรือไม่ กัวต้องคืนสัญญาขนเหล็กให้อีกสำนักและขายห้องหลอมชั้นบนเพื่อรักษาอาคารข้างล่าง ศิษย์ฝีมือดีบางคนจึงย้ายออก โรงต้มอยู่ต่อได้ในฐานะของเมือง ส่วนสำนักค่อย ๆ หายจากทำเนียบ ช่างที่จากไปหลายคนตั้งประเพณีเลี้ยงข้าวหลังฤดูหนาวโดยไม่ยกชื่อกัวขึ้นรับความดี กัวเองไม่ได้ออกไปตามให้ใครจดชื่อกลับมา เธอฝากเผยทำเครื่องหมายไว้ที่ก้นชามว่าใช้งานได้เจ็ดสิบครั้งก่อนต้องเปลี่ยน

**ผลที่ส่งต่อ:** การปันอาหารโดยให้คนมีตัวตนก่อนสอบทะเบียนมีทั้งฝ่ายสนับสนุนและฝ่ายเสียดายแรงงานและข้าว ช่องชื่อผู้กลับกลายเป็นช่อง “คนที่ยังรอส่วนแบ่ง” ในธรรมเนียมโรงต้ม หม้อ หมายเลขชาม และยอดถ่านอาจบอกความจริงได้มากกว่าเรื่องเล่าเชิดชูคนใจบุญ
