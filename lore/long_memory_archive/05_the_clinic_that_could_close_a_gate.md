# บันทึกทวีปก่อนหยุนเหอ · 05 — โรงหมอที่สั่งปิดด่านได้

**ยุคที่ 14 ปีที่ 118–133 · ศ.ท. 13,118–13,133** · แอ่งทางค้าด้านใต้ในช่วงวิกฤตหมอกพิษมรกต

## 1. เด็กบนหม้อเกลือ

วันที่เที่ยวเกลือขาด ทหารด่านพบเด็กนั่งสั่นอยู่ในเกวียนเสบียง โรงหมอเล็กของ **จีหลันซวี่** ขอหยุดขบวนเพื่อตรวจคนทั้งหมด นายด่าน **ฟางเผยจง** สั่งให้อยู่ห่างถังน้ำหลัก แต่ไม่อยากปิดทางเพราะอีกสองชุมชนรอข้าว รถที่จอดบังสะพานดึงดูดคนขายยาราคาแพงและเจ้าหนี้ที่มารอเอาของ ผู้รับสัมปทานเสนอรับตัวเด็กไปไว้สำนักของตนแลกใบยืนยันว่าขบวนปลอดภัย จีไม่รู้ว่าต้นเหตุอาการคืออะไรและปฏิเสธลงชื่อ

## 2. ค่ารักษาของคนที่เดินทางผ่านไม่ได้

ฟางยอมปิดด่านสามวัน โดยให้โรงหมอตัดสินตามอาการที่เห็น กลุ่มผู้ดูแลคอกม้าพบว่าข้าวของด่านเองกำลังหมด จีขอดูบัญชีสำรองตามฤดูกาลที่เมืองหน้าทุ่งเคยกันไว้เลี้ยงสัตว์งาน แล้วให้คนกลางกับคนในหมู่บ้านกำกับยอดที่เปิดใช้จริง เจ้าหนี้ยอมเลื่อนชำระเฉพาะขบวนที่ถูกสั่งหยุด หากใครประกาศปิดทางเองจะเบิกไม่ได้ หมอจึงต้องลงชื่อว่าขอดูอาการของใครและนัดทบทวนเมื่อไร ผู้ที่ไม่ถูกตรวจยังมีสิทธิ์ยื่นขอให้หมออีกคนมาดู

## 3. คนที่ไม่ยอมเดินทางต่อ

เมื่อครบสามวัน เด็กดีขึ้นและขบวนที่ไม่มีอาการเตรียมออกเดินทาง แต่คนงาน **หยางสี่เฉียน** ขออยู่เฝ้าคนพี่ซึ่งยังไข้ เขาถูกขู่ว่าจะไม่ได้รับค่าจ้างเที่ยวใดเลย ฟางให้คนอื่นรับงานขนเกลือต่อและจ่ายหยางเฉพาะส่วนที่ทำถึงด่าน เจ้าของขบวนยื่นเรื่องร้องเรียน จีให้คนเดินทางต่อโดยรับข้อมูลจากคนที่ยอมเปิดเผยอาการ การเปิดทางไม่ต้องรอให้ทุกคนหายดีพร้อมกัน อีกสามสัปดาห์หยางค่อยกลับถึงเมืองพร้อมพี่ชาย แล้วไปทำงานให้ขบวนที่กล้าจ้างเขาทั้งที่เสียฤดูขนของไปแล้ว

## 4. ทางที่เปิดได้อีกครั้ง

หลังวิกฤตใหญ่คลายลง โรงหมอถูกขอให้ใช้สิทธิ์เดิมปิดทางเมื่อพ่อค้าไม่ยอมจ่ายค่าชั่ง จีปฏิเสธและยอมเสียเงินอุดหนุนจากด่าน แต่ให้ฝากสำเนาใบปิดทางทุกฉบับไว้ที่โรงพักเกวียน คนรุ่นหลังจำสิทธิ์โรงหมอคู่กับวันหมดอายุและเสียงค้านจากคนที่ต้องเสียเที่ยวเดินทาง ข้อพิพาทระหว่างหน่วยตรวจโรค ด่าน และพ่อค้ายังไม่ยุติในสมัยนั้น

**ผลทางประวัติศาสตร์:** ข้อตกลงเล็กนี้ทำให้การจำกัดทางด้วยเหตุรักษาคนต้องมีผู้ลงชื่อ ทบทวนได้ และมีการแบ่งต้นทุน ต่อมาแบบเอกสารถูกทดลองใช้ในเมืองอื่นในช่วงที่กติกาน้ำบ่อกับน้ำคลองยังอยู่ระหว่างก่อตัว
