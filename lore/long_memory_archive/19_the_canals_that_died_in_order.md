# บันทึกทวีปก่อนหยุนเหอ · 19 — เมืองที่ยอมปล่อยคลองสองสายให้ตาย

**ยุคที่ 83 ปีที่ 390–417 · ศ.ท. 82,390–82,417** · ปลายน้ำสาขาในวิกฤตแม่น้ำเถ้า

## 1. แผนที่ที่เต็มไปด้วยสีของคนอื่น

น้ำในคลองทั้งสามลดลงจนไม่พอเลี้ยงนา ท่าเรือ กับโรงล้างแร่พร้อมกันได้ **เสวียเหม่ยชิง** หัวหน้าคนดูฝายนำยอดน้ำที่ขีดจากริมประตูไปเสนอว่าต้องปิดสองแขนง ผู้ครองเมือง **กงฉือเทียน** เห็นว่าโรงล้างแร่เก็บภาษีได้มากที่สุดจึงอยากเปิดแขนงนั้นไว้ นายหน้าข้าวเคยสัญญาจะส่งสำรองให้เมืองหากไม่มีเรือเข้า เงื่อนไขที่ไม่มีใครอ่านให้คนขายปลาฟังคือข้าวจะมาถึงเฉพาะเมื่อถนนอีกเมืองไม่ปิดทางเกวียน

## 2. คนที่ยอมเสียไร่แต่ไม่ยอมเสียลูกจ้าง

ชาวนาจากแขนงกลาง **เวินผิงลู่** เสนอให้เผื่อแอ่งดื่มกินและทางเข้าตลาดก่อนปล่อยน้ำให้โรงงาน เขายอมสละไร่ที่สูงสุดหากคนเช่าของตนได้รับสิทธิ์ทำงานซ่อมฝาย เงินที่จะจ่ายต้องมาจากการเลิกจ้างคนเวรกลางคืนในโรงแร่ ผู้คุมงานโต้กลับว่าคนของตนก็มีบ้านและปากท้อง เสวียเลยให้คนเรือพาทั้งสองฝ่ายไปดูจุดต่ำสุดก่อนลงชื่อรับรองว่าจะเหลือน้ำเท่าใด เมื่อเห็นว่าคนในฝั่งอื่นเผาครัวแล้วทยอยไป พวกเขายอมเลิกพูดว่าการเปิดสายของตนจะทำให้ทุกเมืองรอดไปพร้อมกัน

## 3. การชนะเลือกได้เพียงคลองที่อยู่

เปิดทางน้ำเลี้ยงชุมชนล่างกับท่าเล็กเพียงสายเดียว โรงล้างแร่หยุดและคนงานจำนวนมากขายสิทธิ์พักไปอยู่เมืองอื่น เมืองส่วนกลางยังเก็บภาษีจากท่าได้แต่ต้องใช้เงินซื้ออาหารให้แรงงานที่ตกงาน คนที่ถือสัญญารับข้าวยอมจ่ายชดเมื่อเส้นทางเกวียนใช้ไม่ได้เพราะให้วงเล็บเงื่อนไขตัดสิทธิ์ออกต่อหน้าคนดูฝาย เรื่องที่พังลงคือความหวังว่าจะรักษาทั้งเมืองแบบเดิมไว้ได้อีก กงอยู่ต่อจนปิดบัญชีแล้วคืนที่ดินโรงแร่ที่ไม่ได้ใช้ให้สองหมู่บ้านเช่ารวมกัน

## 4. เมื่อน้ำไหลกลับทางเดิมไม่ได้

ปี 417 น้ำกลับมาสูงขึ้นช่วงหนึ่ง ไม่พอให้ใช้น้ำเท่าเดิม และคลองร้างมีหมู่บ้านใหม่ตั้งบนขอบตื้น คนรุ่นลูกเลือกค้ำทางน้ำที่ใช้จริงก่อนโดยเปิดให้คณะถนนกับคณะฝายตรวจงบคนละชุด เมืองที่เสียคนงานไปชวนช่างเดิมกลับมาแต่ต้องเจอเงื่อนไขนายจ้างใหม่ พวกเขาจึงจ้างเป็นฤดูและยอมให้กลับบ้านชั่วคราวได้ ข้าวและแร่ยังกลับมาขายที่ตลาดเดียวกัน แต่ปริมาณและอำนาจต่อรองต่างจากก่อนแล้งมาก

**ผลทางประวัติศาสตร์:** ทำให้แผนที่หลังวิกฤตมีเหตุว่าทำไมท่าหนึ่งเติบโตแล้วอีกท่าหายไป เป็นเรื่องของแขนงย่อยและความเสียหายสะสม ไม่ใช่เหตุเฉลยตำนานนครถานเถ้า
