# บันทึกทวีปก่อนหยุนเหอ · 11 — ใบผ่านทางใต้หินโม่

**ยุคที่ 67 ปีที่ 510–533 · ศ.ท. 66,510–66,533** · ทางอพยพก่อนรัฐกันชนลงหลักปักฐาน

## 1. หน่วยที่นับเฉพาะคนเดินเอง

กองเกวียนจากหลายบ้านมาถึงแนวเขาที่มีพ่อค้าจ่ายค่าคุ้มกันไว้แล้ว กองคุ้มภัยนับยอดเฉพาะผู้เดินเองได้ ขณะที่เด็ก คนแก่ และผู้แบกคนเจ็บจะเสียค่าพักเพิ่ม **จินซิ่วเซียน** ผู้ดูแลโรงโม่เสนอเปิดเรือนพักหลังสีข้าวโดยให้ครัวเรือนลงยอดอาหารที่ต้องใช้วันต่อวัน คณะผู้ถือใบผ่านทางกลัวว่าคนที่เข้ามาพักจะค้างจนแย่งงาน ทางคุ้มภัยจึงขอให้จินรับรองว่าจะรู้ชื่อปลายทางของทุกคน

## 2. ครอบครัวที่อยากไปคนละที่

ครอบครัวของ **ฮวาเจียชุน** จำทางที่จะไปอาศัยกับญาติได้สามเส้น แต่สมาชิกไม่เห็นตรงกันว่าจะตามคนงานเหมืองไปหรือรอข่าวลูกชายจากเมืองเก่า จินยืมแบบรับรองร่องน้ำของชุ่ยเหยามาแยกสิทธิ์พักชั่วคราวออกจากถิ่นปลายทาง เจ้าหน้าที่ใบผ่านทางยอมให้ขึ้นทะเบียนไม่ครบข้อมูลตามเดิมแลกกับการนับยอดคนจริงอีกรอบก่อนส่งข้าม ทางคุ้มภัยเริ่มรู้ว่าจะต้องเตรียมเกวียนเท่าไร ครอบครัวบางส่วนจึงตัดสินใจแยกกันไปโดยนัดพบใหม่ที่โรงโม่ในหนึ่งปี

## 3. ตราที่ซ่อนเพื่อกันการเกณฑ์คนกลับ

นายหน้าจากเขตเก่าส่งคนมาขอรายชื่อชายที่หนีภาระค้าง โดยถือหนี้ครัวเรือนทั้งบ้านเป็นหลักฐาน จินให้ดูยอดอาหารและใบรับค่ายาม แต่เก็บใบที่ระบุปลายทางกับชื่อเด็กไว้ใต้แผ่นหินโม่ **เฝิงหลัวอี้** หัวหน้ากองคุ้มภัยไม่ยอมเป็นผู้ร่วมซ่อน เขายื่นเอกสารเฉพาะของคนที่รับรองด้วยตนและปล่อยจินรับผิดส่วนที่เธอกันไว้ ทั้งคู่ไม่พูดกันหนึ่งฤดู แต่คนของเฝิงยังกลับมาซ่อมทางก่อนหิมะเพื่อไม่ให้คนที่เหลือติดเขา

## 4. โรงโม่ที่กลายเป็นที่ติดต่อ

หลังคนละกลุ่มเข้าถึงถิ่นใหม่ โรงโม่ไม่โตเป็นเมืองใหญ่และไม่มีคนสืบตำแหน่งจินอย่างเป็นทางการ มีคนเฝ้าเอกสารผลัดกันมาวันตลาดและเปิดใบให้เจ้าตัวหรือผู้ที่รับมอบสิทธิ์ดู ฮวาพบลูกชายหลังผ่านไปสิบเอ็ดปีโดยอาศัยคนพากระสอบแป้งไปจำคำลงชื่อเก่าได้ แต่ลูกสาวยังอยู่กับเรือนช่างที่ย้ายไปอีกเมืองและไม่อยากกลับ บัญชีสายตั้งถิ่นบางฉบับจึงมีหลายชื่ออ้างถิ่นออกเดินทางเดียวกันโดยไม่ถือว่าทุกชื่อเป็นญาติกัน

**ผลทางประวัติศาสตร์:** แยกการอพยพของครัวเรือนออกจากเรื่องเล่าเส้นเดียวของขั้วการเมือง ช่วยให้เข้าใจการเกิดเครือญาติข้ามรัฐโดยไม่ต้องเพิ่มหรือย้ายรัฐกันชนใด
