## High priority: missing regression suite

`GAME_SOURCE/test/run_all.js` registers `diplomacy_sanctum_ancestral_suite`, and the package's START_HERE and report instruct readers to run it, but `test/diplomacy_sanctum_ancestral_suite.js` is absent from the ZIP. The regression runner fails with `Cannot find module`. The report's claim of 79/79 passing suites cannot be verified from this deliverable. Recover the actual test and rerun it; do not delete the registration or replace it with a placeholder.

## High priority: report and implementation discrepancies

The report names `CONTENT.negotiateTreaty`, `CONTENT.dispatchDiplomaticCaravan`, `CULT.checkTechniqueCompatibility`, and `CULT.equivalentTier`, but definitions of these exact names were not found in the included JavaScript. `js/sect.js` checks for the two CONTENT functions before invoking them, so those guarded autonomous diplomacy paths do not execute when the functions are absent. Investigate whether the implementation is missing, named differently, or the report is inaccurate; repair the actual integration and provide end-to-end tests. The ZIP does contain sanctum code (`EX.SANCTUMS`) and bottleneck code (`CULT.inspectProgressionBottleneck`), so absence of the reported names alone does not prove those entire systems are absent.

## Verification performed

The standalone build regenerated byte-identically to the ZIP's bundled HTML. The included parallel runner reported 71/79 groups passed, 8 failed, no timeouts. One failure is the missing suite above; seven browser groups failed to launch because the environment's installed Playwright lacks its expected Chromium binary. These seven results are environment blockers, not proof of game defects or passes. Browser behavior and performance were not validated in this run. Results generated under /tmp are not part of the repository. No application fixes were applied: the missing tests cannot safely be reconstructed or treated as passing from the report alone.
