  2. ในระบบ Edit Hub / Action ถ่ายทอดวิชา (`EDITOR.directCatalogAction`): เมื่อสั่งถ่ายทอดวิชา ระบบตรวจสอบเพียง `!t.innateOnly` และ `!n.cult` แต่ไม่ได้ตรวจสอบว่าตัวละครนั้นมีวิถีหรือสายย่อยตรงตามเงื่อนไขของวิชาหรือไม่

- **แนวทางแก้ไข:** 
  - ใน `MENTORSHIP.transmitQi` ให้เพิ่มเงื่อนไขตรวจสอบว่าวิชานั้นเข้ากันได้กับสายของศิษย์: `CULT.isSubCompatible(tObj, disciple.cult.sub) && (tObj.path === 'ANY' || tObj.path === disciple.cult.path)`

### 2. [B-02] ระบบ Save/Load ไม่ตรวจสอบ Schema Version (`SIM.deserialize`)
- **ตำแหน่งไฟล์:** `GAME_SOURCE/js/sim.js` บรรทัด 797–842 (`SIM.deserialize`)
- **สาเหตุ & อาการ:** ใน `SIM.deserialize` มีการตรวจสอบเฉพาะ `s.hc !== HC.FINGERPRINT` แต่ตัวแปร `s.schemaVersion` และ `s.v` ถูกใส่ไว้เพียงใน `knownKeys` โดยไม่มีการตรวจเช็คเปรียบเทียบว่าเวอร์ชันของไฟล์เซฟเข้ากันได้กับเกมเวอร์ชันปัจจุบันหรือไม่ (`s.schemaVersion > SIM.SAVE_SCHEMA_VERSION` หรือ `s.v > SIM.VERSION`)
- **ผลทดสอบจริง:** เมื่อทดลองปลอมแปลงไฟล์ Save ให้มีเวอร์ชัน `9999.0.0` ตัวเกมยอมโหลดไฟล์เซฟขึ้นมาทำงานโดยไม่มีการแจ้งเตือนหรือปฏิเสธใดๆ และเมื่อระบบ Autosave ทำงาน เซฟใหม่จะเขียนทับ Marker กลับเป็น `2.0.0` ทันที เสี่ยงอย่างยิ่งต่อการเปิดเซฟจากเกมในอนาคตที่โครงสร้างข้อมูลเปลี่ยนไปแล้วทำให้ State พังอย่างเงียบๆ
- **แนวทางแก้ไข:** เพิ่มการตรวจเช็คเวอร์ชันใน `SIM.deserialize`:
  ```javascript
  if (s.schemaVersion && s.schemaVersion > SIM.SAVE_SCHEMA_VERSION) {
    throw new Error('ไฟล์เซฟมาจากเวอร์ชันที่ใหม่กว่า (Schema ' + s.schemaVersion + ' > ' + SIM.SAVE_SCHEMA_VERSION + ') ไม่สามารถโหลดได้');
  }
  ```

### 3. [B-03] อัตราเปิดตันเถียนของคนธรรมดาเร็วเกินจริง 6 เท่า (`clamp` ชั่วโมงขั้นต่ำ 0.1)
- **ตำแหน่งไฟล์:** `GAME_SOURCE/js/cultivation.js` บรรทัด 8265 (`computeStudyGain`) และ 8277 (`computeQiGatherGain`)
- **โค้ดที่เป็นปัญหา:**
  ```javascript
  const hrs = Math.max(0.1, Number(dtHours) || 1);
  ```
- **สาเหตุ & อาการ:** กิจกรรม `study_dao` และ `gather_qi` ใน `ai.js` (บรรทัด 499, 540) ทำงานแบบเรียลไทม์ทุก tick ละ 1 นาทีเกม (`dtHours = 1/60 = 0.0167`) แต่ถูกคำสั่ง `Math.max(0.1, ...)` บังคับปัดเศษขึ้นเป็น `0.1` ทุกนาที! ส่งผลให้อัตราการได้ความรู้และปราณสูงกว่าความเป็นจริงถึง **6.0 เท่า**!
- **ผลกระทบ:** คนธรรมดาเข้าสำนักเพียง 1.2 – 2.6 วันเกม (29–62 ชั่วโมง) ก็เปิดตันเถียนทะลวงเป็นเซียนได้ทันที ทำให้ประชากรเซียนล้นสำนักอย่างรวดเร็ว (ซิมูเลชัน 120 วันมีผู้บ่มเพาะใหม่ทะลักถึง 44 คน) ขัดกับปรัชญา Pillar 1 ที่ต้องการให้การบำเพ็ญมีความสมจริง
- **แนวทางแก้ไข:** เปลี่ยน `Math.max(0.1, ...)` เป็น `Math.max(1e-4, ...)` หรือตัด clamp ออก และปรับเกณฑ์ตัวคูณรายชั่วโมงให้ใช้เวลาเรียนรู้และรวบรวมปราณอย่างสมเหตุสมผล (เช่น 2–6 เดือนเกม ตามระดับรากวิญญาณ)

### 4. [B-04] คัมภีร์มหาวิถี (`MANUAL_PATH_*`) กดใช้แล้วปลดล็อกวิถี "XIAN" เสมอ!
- **ตำแหน่งไฟล์:** `GAME_SOURCE/js/economy.js` บรรทัด 2218–2227 + `GAME_SOURCE/data/data_items.js`
- **โค้ดที่เป็นปัญหา:**

  case 'EFX_UNLOCK_SECT_PATH_MANUAL': {
    const tPath = (params && params.targetPath) || 'XIAN';

- **สาเหตุ & อาการ:** ใน `data_items.js` คัมภีร์ทั้ง 27 เล่มระบุ `params: { pathIndex: ..., comprehensionBonus: 25 }` โดย **ไม่มีตัวแปร `params.targetPath`** (แต่ไปใส่ `targetPath` ไว้นอก params บนตัวไอเทม `item.targetPath`) เมื่อเรียกใช้ไอเทมผ่าน `executeItemEffectById` ตัวแปร `params.targetPath` จึงเป็น `undefined` และตกไปที่ fallback `|| 'XIAN'` เสมอ!

- **แนวทางแก้ไข:** ใน `economy.js` ให้ดึงจาก `(params && params.targetPath) || (item && (item.targetPath || item.path)) || (item && item.id && item.id.replace(/^MANUAL_PATH_/, '')) || 'XIAN'` และเติม `targetPath` ลงใน `params` ของไอเทมทั้ง 27 รายการให้ครบถ้วน

### 5. [B-05] ผลึกมรดกวิถี (`CRYSTAL_PATH_*`) เกิดอาการ "กินของเปล่า" ไม่ทำงาน
- **ตำแหน่งไฟล์:** `GAME_SOURCE/js/economy.js` บรรทัด 2228–2234 และ `GAME_SOURCE/js/cultivation.js` บรรทัด 8434–8457 (`bestowPathCrystal`)
- **สาเหตุ & อาการ:** มีข้อผิดพลาด 2 ชั้น:
  1. ตัวแปร `targetPath` ว่างเช่นเดียวกับข้อ 4 ตกเป็น `'XIAN'`
  2. เมื่อกดใช้ไอเทม ฟังก์ชัน `useConsumableItem` (economy.js:2559) ได้ทำการหักผลึกออกจากคลัง (`ECO.take`) **ก่อน** ที่จะส่งต่อไปยัง `bestowPathCrystal` แต่ฟังก์ชัน `bestowPathCrystal` ดันเขียนเช็คซ้ำว่ายังมีผลึกอยู่ในคลังหรือไม่ (`ECO.count(...) > 0`) เมื่อไม่พบเพราะเพิ่งถูกหักไป จึงคืนค่า `{ ok: false, reason: "missing-crystal" }`
- **ผลกระทบ:** ผลึกวิถีหายไปจากคลัง แต่ศิษย์ไม่ได้รับการตื่นรู้วิถีใดๆ เลย (เสียของฟรี)

### 6. [B-06] ข้อมูลผู้ฝึกตนของผู้ลี้ภัย/ศิษย์แปรพักตร์ต่างสำนักพัง (`prog = null`, `sub = "NONE"`)
- **ตำแหน่งไฟล์:** `GAME_SOURCE/js/expedition.js` บรรทัด 5822–5826
- **โค้ดที่เป็นปัญหา:**
  ```javascript
  fullNpc.cult = { 
    path: pPath, 
    sub: fig.cult.sub || 'NONE', 
    stage: pStage,
    prog: Math.round(CULT.threshold(fullNpc) * 0.45), ...
  ```
- **สาเหตุ & อาการ:** ฟังก์ชัน `CULT.threshold(fullNpc)` ถูกเรียกขณะที่ object `fullNpc.cult` ยังสร้างไม่เสร็จสมบูรณ์ ทำให้คำนวณได้ค่า `NaN` ซึ่งเมื่อแปลงเป็น JSON จะกลายเป็น `null` นอกจากนี้ค่าสายย่อย fallback ถูกใส่เป็น `'NONE'` ซึ่งไม่มีจริงในระบบ
- **ผลกระทบ:** ศิษย์ที่รับเข้ามาใหม่จะติดหล่ม `prog: null`, ไม่สามารถทะลวงด่านได้, สกิลประจำสายย่อยไม่ทำงาน, และระบบ Track ไม่รองรับ
- **แนวทางแก้ไข:** สร้าง object `fullNpc.cult` ขั้นต้นให้เรียบร้อยก่อนเรียกคำนวณ `CULT.threshold` และหาก `fig.cult.sub` ว่าง ให้สุ่มเลือกสายย่อยที่มีอยู่จริงของ `pPath` แทน `'NONE'`
