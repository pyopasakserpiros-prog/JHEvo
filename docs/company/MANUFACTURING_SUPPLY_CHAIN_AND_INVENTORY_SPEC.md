## 2. โครงสร้างคลังสินค้า 3 ระดับ (Three-Tier Warehouse System)

เพื่อให้การจัดการสต็อกมีความสมจริง ระบบจำลองต้องแบ่งการจัดเก็บสินค้าออกเป็น 3 โซนที่ชัดเจน:

```
[รถบรรทุกส่งชิ้นส่วน]
         │
         ▼
┌──────────────────────────────────────────────┐
│ 1. คลังวัตถุดิบ (Raw Materials Warehouse)     │
│    • ชั้นวางชิปและวงจรอิเล็กทรอนิกส์ (IC Rack)  │ <--- บันทึกใน w.inventory.rawMaterials
│    • ชั้นวางโครงสร้างโลหะและพลาสติก (Mech Rack) │ <--- ฝ่ายจัดซื้อสั่งเข้ามาเติม
│    • แร็ควางลังบรรจุภัณฑ์และโฟม (Box Pallets)  │
└──────────────────────┬───────────────────────┘
                       │ ช่างเดินมาเบิกวัตถุดิบ (Material Kitting)
                       ▼
┌──────────────────────────────────────────────┐
│ 2. พื้นที่ระหว่างการผลิต (WIP — Work In Process)│
│    • แท่นบัดกรีแผงวงจร (PCBA Soldering)      │ <--- บันทึกใน w.production.wipUnits
│    • แท่นขันน็อตและประกอบตัวเครื่อง (Main Assembly)│ <--- กำลังประกอบ ยังส่งมอบไม่ได้
│    • แท่นทดสอบเบิร์นอินและตรวจ QC (QA Test Bench) │ <--- มีของรอซ่อม (Rework Pool)
└──────────────────────┬───────────────────────┘
                       │ ชิ้นงานผ่าน QC 100% + แพ็กลงกล่อง
                       ▼
┌──────────────────────────────────────────────┐
│ 3. คลังสินค้าสำเร็จรูป (Finished Goods Warehouse)│
│    • สินค้าแพ็กกล่องพร้อมส่ง (Ready to Ship)   │ <--- บันทึกใน w.inventory.finishedGoods
│    • ล็อตสินค้าที่จองแล้วตามสัญญา (Allocated)  │ <--- รอรถบรรทุกลูกค้ามารับของ
│    • ประตูแท่นเทียบรถส่งสินค้า (Loading Dock)  │
└──────────────────────────────────────────────┘
```

## 3. ระบบการจัดซื้อวัตถุดิบ (Procurement & Supplier Selection)

ฝ่ายจัดซื้อ (Logistics / Admin) ต้องมีบทบาทในการเลือกสั่งซื้อวัตถุดิบตามสถานการณ์จริง:

### 3.1 ทางเลือกซัพพลายเออร์ 3 ช่องทาง (3 Sourcing Channels)
1. **ซัพพลายเออร์โรงงานต่างประเทศ (Overseas Direct Factory):**
   * **ข้อดี:** ราคาถูกที่สุด (ส่วนลด 25–30%)
   * **ข้อจำกัด:** มีจำนวนสั่งซื้อขั้นต่ำ (MOQ เช่น ขั้นต่ำ 50–100 ชิ้น) และใช้เวลาส่งนาน (Lead Time 7–10 วัน)
   * **การตัดสินใจ:** ฝ่ายจัดซื้อจะเลือกสั่งทางนี้เมื่องานยังมีเวลาเหลือเฟือและต้องการประหยัดต้นทุน
2. **ตัวแทนจำหน่ายในประเทศ (Local Authorized Distributor):**
   * **ข้อดี:** สั่งได้ไม่มีขั้นต่ำ ส่งของไว (Lead Time 1–2 วัน)
   * **ข้อจำกัด:** ราคากลางมาตรฐาน
   * **การตัดสินใจ:** ใช้สำหรับการสั่งซื้อประจำสัปดาห์ทั่วไป
3. **ตลาดด่วนกรณีวิกฤต (Emergency Spot Market — บ้านหม้อ/คลองถมด่วน):**
   * **ข้อดี:** สินค้าส่งด่วนมาถึงโรงงานภายใน 4 ชั่วโมง
   * **ข้อจำกัด:** ราคาบวกเพิ่ม 50%
   * **การตัดสินใจ:** ฝ่ายจัดซื้อจะสั่งช่องทางนี้ต่อเมื่อ "วัตถุดิบหมดกะทันหัน แต่ออเดอร์ใกล้ถึงเดดไลน์ใน 24 ชั่วโมง"

### 3.2 ขั้นตอนการทำงานของระบบจัดซื้ออัตโนมัติ (Autonomous PO Cycle)
1. **ตรวจเช็กจุดสั่งซื้อซ้ำ (Reorder Point Calculation):**
   $$\text{Reorder Point} = (\text{อัตราการใช้งานต่อวัน} \times \text{Lead Time วัน}) + \text{Safety Stock}$$
2. **การเปิดใบสั่งซื้อ (Issue Purchase Order):**
   * พนักงานจัดซื้อเดินไปที่โต๊ะ Admin ทำเอกสาร PO
   * ตัดเงินสดจ่ายค่าของ (ลงบัญชีคู่ตัดเงินสด `cash` เข้าบัญชีซื้อวัตถุดิบ `materials`)
3. **การเดินทางของวัตถุดิบ (In-Transit):**
   * มีสถานะรถขนส่งที่กำลังเดินทางมาถึง
4. **การตรวจรับและเข้าคลัง (Receiving & Inspection):**
   * รถขนส่งมาจอดที่ Loading Dock
   * พนักงานคลังสินค้าเดินไปตรวจสอบกล่อง นับจำนวน
   * มีโอกาส 1–2% ที่จะพบชิ้นส่วนชำรุดจากการขนส่ง (Defective Inbound) ต้องทำเรื่องเคลม
   * ชิ้นส่วนที่สมบูรณ์จะถูกย้ายขึ้นชั้นวางในคลังวัตถุดิบทันที

## 5. ผลกระทบต่อระบบจำลอง (Simulation & Balance Impacts)

เมื่อนำระบบนี้มาใช้งาน จะทำให้เกมมีมิติความลึกที่สมจริงอย่างมาก:
1. **วิกฤตของขาดสายผลิต (Component Shortage Bottleneck):**  
   หากขาดน็อตเพียงตัวเดียว หรือลืมสั่งสายชาร์จ Type-C สินค้าชิ้นนั้นจะไม่สามารถส่งมอบได้ ช่างต้องหยุดรอ หรือต้องวิ่งไปซื้อของแพงฉุกเฉิน
2. **การบริหารพื้นที่คลังสินค้า (Warehouse Capacity Management):**  
   คลังวัตถุดิบมีพื้นที่จำกัด ไม่สามารถสั่งของมากองท่วมโรงงานได้ ต้องบริหาร Just-in-Time (JIT)
3. **ความเสี่ยงเงินจมในสต็อก (Dead Stock & Working Capital):**  
   ถ้าสั่งซื้อชิ้นส่วนมาดองไว้มากเกินไป เงินสดจะหมดและไม่มีเงินจ่ายค่าจ้างสิ้นเดือน เกิดวิกฤตสภาพคล่องทันที
