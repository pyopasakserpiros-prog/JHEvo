# รายงานกู้ซอร์สและพัฒนา Company Campus

## ฐานที่ใช้

กู้ source HTML, CSS และ 9 โมดูล JavaScript จากไฟล์ standalone ที่ผู้ใช้ส่ง จากนั้นเปรียบเทียบกับ ZIP ที่พบภายหลัง: JavaScript ทั้ง 9 ไฟล์ตรงกันทุกไบต์ก่อนแก้. ไม่คัดลอก JS2 หรือ asset จาก ZIP มายังสาขา company. Human core 1.0.0 และ CORE_LOCK ไม่เปลี่ยน

## สิ่งที่ทำ

- เพิ่มปุ่มปิดแถบตัวละคร ปรับแถบมือถือ และไม่เปิดคนแรกทับแผนที่โดยอัตโนมัติ
- รองรับซูมด้วยปุ่ม/ล้อเมาส์/บีบนิ้ว โดยยึดจุดกึ่งกลางนิ้ว; เดินตาม path สูงสุด 4 ช่องต่อ 5 นาทีเกม แทนการข้าม 24 ช่อง และวาดการเคลื่อนที่ต่อเนื่อง
- ขยายแผนที่ 40×25 ย้ายสถานี/อาคารให้ห่างขึ้น เพิ่มศูนย์ฝึกที่พนักงานไปเรียนจริง; อาคาร 7 ประเภทมีระดับ 1–3, ภาพตามระดับ/ประเภท และผลต่อการผลิต การพัก หรือการฝึก
- CEO บทบาท coordinator ประเมินลงทุนตามความต้องการ นิสัย ทักษะ และเงินสำรอง หักค่าอัปเกรดในบัญชีและแสดงเหตุผล; ชำระหนี้จากส่วนเกินอย่างมีเงินสำรอง
- ฝ่ายขาย/CEO ประเมินดีลที่มีกำไรขั้นต้นจากวัตถุดิบก่อนรับ; จัดซื้อต้องมีผู้รับผิดชอบอยู่ทำงาน; CEO ประเมินผู้สมัครเมื่อขาดคนและบันทึกเหตุผล
- เปลี่ยนหน้าบริหารเป็นอ่านอย่างเดียว; Edit Hub ให้เลือกวัตถุดิบ/จำนวน และตัวละครสำหรับแก้ชื่อ บุคลิก ค่านิยม ฟื้นฟูและฝึกทักษะ; ตรวจข้อมูลผิดก่อนเปลี่ยนสถานะ
- เพิ่มเครื่องมือ unit/integration และ Playwright browser ตรวจมือถือ เดสก์ท็อป ซูม แถบปิด Edit Hub การลงทุน ผลภาพ และการเดินเกมเอง

## ผลตรวจ

- npm test: 102 tests ผ่านทั้งหมดในรอบตรวจหลังพัฒนาซอร์ส
- npm run check: ผ่าน syntax, schema และ SHA-256 แกนมนุษย์
- npm run test:browser: 6 กรณีผ่านทั้งหมด; ใช้ Chromium จำลอง viewport
- Node benchmark: 8 คนเฉลี่ยประมาณ 0.27 ms/tick, p95 ประมาณ 0.98 ms; 30 คนเฉลี่ยประมาณ 1.77 ms/tick, p95 ประมาณ 6.96 ms. วัดเฉพาะ simulation ไม่ใช่ FPS หรือผลบน Android จริง

## ข้อจำกัด

ประเมินดีลจากต้นทุนวัตถุดิบ ยังไม่รวมต้นทุนทั้งหมด, ยังไม่มีการกู้ฉุกเฉินอัตโนมัติหรือระบบสัมภาษณ์เต็มรูปแบบ, เส้นทางเป็นกริดสถานีและภาพอาคารยังไม่มี collision ภายในอย่างละเอียด, ยังไม่ทดสอบด้วยมือถือ Android จริง. สิทธิ์เสกไอเทมรอบนี้ครอบคลุมวัตถุดิบใน catalog

## จัดสาขา

ลบสกิล 13 ชุดที่อ้างอิง JS2 โดยเฉพาะและสคริปต์ auto-push ที่ชี้ main; ย้ายพิมพ์เขียว/รายงานเก่าไป docs/company/history พร้อมคำเตือนว่าเป็นประวัติ. ไอเดียบริษัทและหลักฐานแกนยังเก็บไว้. ไม่เปลี่ยน branch main.
