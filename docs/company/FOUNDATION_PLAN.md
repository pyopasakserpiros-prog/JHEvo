# โครงระบบบริษัท v0.1.0 — แผนลงมือ

ผู้ใช้ให้ Codex สร้างระบบก่อน และส่ง Claude ทำกราฟิก ตัวละคร พื้นที่/UI ทีหลัง ไม่รออนุมัติแบบภาพหรือใช้โควต้ากับเกม JS2

- แกนมนุษย์แยกไฟล์และล็อก hash หลังตรวจ: มิติบุคลิก/ค่านิยม/ความถนัด/ศักยภาพ สูตรความสามารถ การเรียนรู้ สภาพชีวิต และการตอบรับคำขอ อาชีพ/ทักษะเพิ่มภายนอกแกน
- ระบบบริษัทเป็นข้อมูล JSON ที่ทำซ้ำจาก seed ได้: โซน/สถานี/ทางเดิน พนักงานและความสัมพันธ์ งาน/สัญญา ซื้อ/จองวัตถุดิบ ประกอบ/ตรวจ/ซ่อม/แพ็ก/ส่ง รับเงิน ค่าแรง/หนี้ R&D และความอยู่รอด
- public commands ตรวจข้อมูลก่อนเปลี่ยน; view model แยกจาก state; renderer ไม่ใช้ RNG เกม; schema ตรวจตอน save/load
- ใช้ JavaScript ที่รันได้ทั้ง Node และเบราว์เซอร์ ไม่ต้องใช้บริการภายนอก หน้า debug ใช้ DOM ทดสอบคำสั่งและสถานะ เป็นเพียงเครื่องมือของแพตช์ระบบ ไม่ใช่งานกราฟิกแทน Claude
- ทดสอบจากสัญญาการใช้งานก่อนลงโค้ด: core determinism/bounds/extension/agency, หน้างานสองโซน/เส้นทาง, conservation/transactions, autonomy/stress/learning, scenario/long run, malformed save และ continuation, bridge purity/commands, browser debug/build/offline
- ส่งมอบ Claude: facade ที่ใช้ได้จริง field/หน่วย/เวลา/กิจกรรม snapshots จุดต่อ visual descriptors ตัวอย่าง consumer และ prompt ขอบเขตกราฟิกที่อนุญาตให้สร้างสรรค์โดยไม่แก้กฎเกม/แกนที่ล็อก
