## 3. ระบบโลจิสติกส์และซัพพลายเชนครบวงจร (`w.logistics` & B2B Negotiation)

1. **การเจรจาดีลธุรกิจ B2B โดยฝ่ายขาย (`evaluateSalesNegotiation`)**:
   - พนักงานฝ่ายขายใช้ทักษะ `sales` ร่วมกับความถนัด `communication`, `emotionalInsight`, `verbal` และนิสัย `assertiveness`, `ambition` ในการเจรจากับ **บริษัทคู่ค้า B2B ทั้ง 6 แห่ง**
   - บันทึกคะแนนการเจรจา (`pitchScore`), สไตล์การปิดดีล (`Aggressive B2B Pitch`, `Consultative Trust`, `Balanced Commercial`) และสร้างความเชื่อมั่นสะสมกับบริษัทลูกค้า (`client.trustScore`)
2. **โลจิสติกส์ขาเข้า (Inbound Procurement Shipments)**:
   - ฝ่ายจัดซื้อสั่งวัตถุดิบ 14 ชนิดจาก **บริษัทซัพพลายเออร์ต้นน้ำ 4 แห่ง** ออกใบสั่งซื้อ (PO) และติดตามสถานะรถบรรทุกขนส่งขาเข้าพร้อมหมายเลขทะเบียนรถ (`70-xxxx ชลบุรี`), ต้นทางนิคม/ท่าเรือ และสถานะ `paperwork` -> `transit` -> `received`
3. **สายการผลิตหลายสาย (Multi-Line Production Routing — Line A / Line B / Line C)**:
   - กระจายงานประกอบและตรวจสอบคุณภาพข้ามสายการผลิตที่เปิดใช้งาน พร้อมเก็บสถิติจำนวนชิ้นงานที่ผลิตสำเร็จแยกตามสายการผลิต
4. **โลจิสติกส์ขาออกและการส่งออก (Outbound Fleet Dispatch)**:
   - ฝ่ายคลังและโลจิสติกส์แพ็กสินค้าสำเร็จรูปลงกล่องและปล่อยรถบรรทุกส่งออก (`71-xxxx กทม.`) ไปยังบริษัทคู่ค้า B2B บันทึกชื่อผู้ปล่อยรถ ความตรงต่อเวลา และการวางบิลเก็บเงิน (`invoicing` -> `paid`)

- **บริษัทคู่แข่งในตลาด 5 แห่ง (`competitors`)**: *บมจ. ไททัน อิเล็กทรอนิกส์*, *บจก. อีสเทิร์น ออโต้เทค*, *บมจ. สยามเนเชอรัล ฟู้ดส์*, *บจก. โซลาร์เทค เอเชีย*, *บมจ. เอเพ็กซ์ อินดัสเตรียล กรุ๊ป* พร้อมคำนวณส่วนแบ่งตลาดของบริษัทเรา (`ourMarketSharePct`) เทียบกับคู่แข่ง
