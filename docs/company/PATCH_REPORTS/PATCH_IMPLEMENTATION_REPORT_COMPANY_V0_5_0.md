# รายงานผลการพัฒนาแพตช์ Siam Enterprise / Company Simulation — รุ่น v0.5.0

## 1. สรุปภาพรวมการอัปเกรดในรุ่น v0.5.0 (Executive Summary)
แพตช์ **v0.5.0** ยกระดับโครงสร้างองค์กร สายการบังคับบัญชา การขยายพื้นที่ที่ดินนิคมอุตสาหกรรม (Greenfield Campus Progression) และระบบสายการผลิตให้มีความลึกและสมจริงตามมาตรฐานโรงงานอุตสาหกรรมและบริษัทมหาชนครบวงจร:

1. **พีระมิดตำแหน่งและสายอาชีพ 10 ระดับ (`Lv.1` ถึง `Lv.10` / Job Grades `G1`–`G10`)**:
   - ขยายลำดับขั้นตำแหน่งจากเดิม 4 ระดับเป็น **10 ระดับเต็มรูปแบบ** ครอบคลุมทั้ง 7 สายวิชาชีพ (`sales`, `admin`, `engineer`, `assembler`, `inspector`, `logistics`, `coordinator`) โดยอ้างอิงโครงสร้างองค์กรอุตสาหกรรมการผลิตจริง ([Organimi Manufacturing Structure](https://www.organimi.com/manufacturing-organizational-structure/), [ZeniaHR Manufacturing Org Structure](https://www.zeniahr.com/hrms/org-structure/manufacturing-company-org-structure/), [PointFactors Company Position Hierarchy](https://pointfactors.com/posts/company-position-hierarchy), [FirstHR Company Hierarchy](https://firsthr.app/blog/core-hr/company-hierarchy), [Talentive Manufacturing Hierarchy](https://talentive.com/en/employers/manufacturing-hierarchy/))
   - ตั้งแต่น้องใหม่หน้าไลน์ (`Lv.1`) -> ช่าง/เจ้าหน้าที่ชำนาญการ (`Lv.2`) -> หัวหน้ากลุ่มในไลน์ผลิต/กลุ่มงาน (`Lv.3`) -> หัวหน้าหมวด/หัวหน้ากะ (`Lv.4`) -> รองหัวหน้าแผนก (`Lv.5`) -> หัวหน้าแผนก/ผู้จัดการแผนก (`Lv.6`) -> รองหัวหน้าฝ่าย/รองผู้จัดการโรงงาน (`Lv.7`) -> หัวหน้าฝ่าย/ผู้อำนวยการฝ่าย/ผู้จัดการโรงงาน (`Lv.8`) -> รองกรรมการผู้จัดการใหญ่ C-Suite (`Lv.9`) -> ประธานเจ้าหน้าที่บริหารสูงสุด (`Lv.10` CEO)
2. **ผังองค์กรหลายระดับ 4 ชั้น (`ORG_TREE`: สายงาน -> ฝ่าย -> แผนก -> กลุ่มงาน/ไลน์ผลิต)**:
   - พนักงานทุกคนมีสังกัดชัดเจนครบ 4 ชั้น: **สายงาน (`Division`) › ฝ่าย (`Department`) › แผนก (`Section`) › กลุ่มงานย่อย/ไลน์ผลิต (`Group / Line`)**
   - รองรับการแตกไลน์ผลิต (`การแตกไลน์ผลิต`) เมื่อบริษัทก่อสร้างอาคารสายการผลิตใหม่ (`Line B`, `Line C`, `Line D`) พนักงานฝ่ายผลิตจะกระจายตัวเข้าสู่แผนกและกลุ่มงานประจำไลน์ผลิตใหม่โดยอัตโนมัติ
3. **การขยายพื้นที่ที่ดินนิคมสีเขียว (`56×34` ช่อง) และอาคารก่อสร้างเพิ่มรวม 12 แห่ง**:
   - ขยายผังนิคมอุตสาหกรรมจาก `40×25` เป็น **`56×34` ช่อง** พร้อมที่ดินสีเขียวว่างเปล่า (Greenfield Reserve) รอการพัฒนา
   - เพิ่มแปลงก่อสร้างอาคารใหม่บนที่ดินส่วนขยายเป็น **12 แห่ง** (เพิ่ม **อาคารสายการผลิตที่ 4 Cleanroom & HV Line D**, **ศูนย์ปฏิบัติการแล็บทดสอบมาตรฐาน ISO/IEC QA Lab**, **โรงบำบัดน้ำเสียและสาธารณูปโภคหมุนเวียน Eco Utility Plant**, และ **ศูนย์แสดงสินค้าอุตสาหกรรมและสถาบันฝึกอบรม Corporate Expo & Academy**)
4. **รูปแบบการผลิตเฉพาะทาง 5 ระบบ (`PRODUCTION_MODES`), โหมดควบคุมจังหวะโรงงาน 3 โหมด (`PRODUCTION_REGIMES`), วัตถุดิบ 20 ชนิด และสินค้า 16 ชนิด**:
   - เพิ่มรูปแบบเทคโนโลยีการผลิต 5 ระบบ (`smt_precision`, `cnc_mechanical`, `cleanroom_batch`, `high_voltage_cell`, `automated_modular`) และโหมดควบคุมจังหวะสายพาน 3 โหมด (`craft_precision`, `lean_balanced`, `mass_throughput`)
   - ขยายวัตถุดิบจาก 14 เป็น **20 ชนิด** และสินค้าจาก 12 เป็น **16 ชนิด** ครอบคลุม 4 อุตสาหกรรมหลัก

| ระดับ (Grade) | ชื่อระดับชั้นมาตรฐาน | บทบาทในโรงงาน (Factory Operations) | บทบาทในออฟฟิศและบริหาร (Office & Executive) | โควตา Span of Control & ผู้ประเมินสายตรง |
| :--- | :--- | :--- | :--- | :--- |
| **Lv.1 (`G1`)** | พนักงานปฏิบัติการระดับต้น | พนักงานฝ่ายผลิตหน้าไลน์ / QC หน้าไลน์ / คลังแพ็กกิ้ง | เจ้าหน้าที่ขาย B2B / จัดซื้อ-บัญชี / วิศวกรระดับต้น | ไม่จำกัด (ระดับเริ่มต้น) |
| **Lv.2 (`G2`)** | พนักงานชำนาญการ / อาวุโส | ช่างเทคนิคสายการผลิตชำนาญการ / ผู้ตรวจ QA อาวุโส | เจ้าหน้าที่บริหารลูกค้าอาวุโส / วิศวกรอาวุโส | สูงสุด 45% ของแผนก (ประเมินโดย `Lv.3+`) |
| **Lv.3 (`G3`)** | หัวหน้ากลุ่มงาน / หัวหน้าชุดในไลน์ | หัวหน้ากลุ่มในไลน์ผลิต (Line Group Leader) / หน.กลุ่ม QC | หัวหน้ากลุ่มงานขาย / หน.กลุ่มจัดซื้อ / หน.กลุ่มวิศวกรรม | 1 อัตราต่อ 5 คนในแผนก (ประเมินโดย `Lv.4+`) |
| **Lv.4 (`G4`)** | หัวหน้าหมวด / หัวหน้ากะ | หัวหน้ากะสายการผลิต (Shift Foreman / Section Supervisor) | หัวหน้าหมวดการค้า / หน.หมวดซัพพลายเชน / หน.หมวดวิศวกรรม | 1 อัตราต่อ 7–8 คนเมื่อบริษัทขยายตัว (ประเมินโดย `Lv.5+`) |
| **Lv.5 (`G5`)** | รองหัวหน้าแผนก / ผู้ช่วย ผจก.แผนก | รองหัวหน้าแผนกสายการผลิต / รอง หน.แผนก QC / คลัง | รองหัวหน้าแผนกขาย / รอง หน.แผนกจัดซื้อ-การเงิน / R&D | 1 อัตราต่อ 10 คนในแผนก (ประเมินโดย `Lv.6+`) |
| **Lv.6 (`G6`)** | หัวหน้าแผนก / ผู้จัดการแผนก | หัวหน้าแผนกการผลิตประจำไลน์ / ผจก.แผนก QC / คลัง | หัวหน้าแผนกขายพาณิชย์ / ผจก.แผนกจัดซื้อและบัญชี / R&D | 1 อัตราต่อ 14 คนในแผนก (ประเมินโดย `Lv.7+`) |
| **Lv.7 (`G7`)** | รองหัวหน้าฝ่าย / รอง ผอ.ฝ่าย | รองผู้จัดการโรงงาน / รองผู้อำนวยการฝ่ายผลิต-คุณภาพ | รองผู้อำนวยการฝ่ายพาณิชย์ / การเงิน / วิศวกรรม | 1 อัตราต่อ 20 คน เมื่อพนักงานรวม ≥ 14 คน (ประเมินโดย `Lv.8+`) |

## 3. ตารางรูปแบบการผลิต 5 ระบบ (`PRODUCTION_MODES`) และสินค้าทั้ง 16 ชนิด

| รหัสรูปแบบการผลิต | ชื่อระบบสายการผลิต | จุดเด่นเชิงวิศวกรรม | สินค้าในระบบ (รวม 16 ชนิด) |
| :--- | :--- | :--- | :--- |
| **`smt_precision`** | สายประกอบไมโครอิเล็กทรอนิกส์ความแม่นยำสูง (SMT) | โบนัสคุณภาพ QC +3%, ลดการสึกหรอเครื่องจักร 10% | ลำโพงบลูทูธ (`speaker`), กล่องควบคุม IoT (`iotController`), กล้อง AI ตรวจสอบคุณภาพ (`visionCamera`) |
| **`cnc_mechanical`** | สายขึ้นรูปโลหะและประกอบกลไกหนัก (CNC & Mechatronics) | เร่งความเร็วประกอบ +4%, โบนัส QC +1% | โมดูลเซนเซอร์ยานยนต์ (`autoSensor`), ชุดควบคุมมอเตอร์ EV (`evController`), แขนกลเซอร์โวมอเตอร์ (`servoActuator`) |
| **`cleanroom_batch`** | สายสกัดและบรรจุปลอดเชื้อแบบล็อต (Cleanroom Sterile Batch) | เร่งความเร็วผลิตล็อตใหญ่ +12%, โบนัส QC +4% | เครื่องดื่มสมุนไพร (`herbalDrink`), โปรตีนอัดแท่ง (`energyProtein`), เครื่องดื่มบูสต์ภูมิคุ้มกัน (`functionalShot`), ซองเจลโพรไบโอติกส์ (`probioticElixir`) |
| **`high_voltage_cell`** | สายประกอบเซลล์พลังงานและทดสอบแรงดันสูง (High-Voltage) | โบนัสคุณภาพและความปลอดภัย QC +5% | แพ็กแบตเตอรี่ EV (`batteryPack`), อินเวอร์เตอร์โซลาร์ (`homeInverter`), ตู้ชาร์จรถยนต์ไฟฟ้าความเร็วสูง (`evFastCharger`) |
| **`automated_modular`** | สายประกอบโมดูลอัตโนมัติความเร็วสูง (Automated Modular) | เร่งความเร็วสายพานอัตโนมัติ +15%, โบนัส QC +2% | โคมไฟปรับแสง (`lamp`), มิเตอร์ไฟฟ้า Smart Grid (`smartMeter`), เครื่องชาร์จโซลาร์พกพา (`solarCharger`) |
