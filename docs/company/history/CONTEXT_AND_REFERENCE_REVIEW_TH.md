# บริบทปัจจุบันและข้อมูลอ้างอิง

ผู้ใช้ต้องการเกมจำลองคนและบริหารบริษัทที่มีทั้งออฟฟิศ/โรงงานที่ขยายต่อได้ ให้ความสำคัญกับแกนมนุษย์ที่ต้องตรวจรอบคอบก่อนล็อกถาวร

หลังOpusหมดโควต้าระหว่างคิดและการลองส่งClaudeฟรีทำทั้งเกมไม่สำเร็จ ผู้ใช้ให้Codexพัฒนาโครงระบบก่อน ปัจจุบันมีระบบจริงใน COMPANY_SOURCE แล้ว ขั้นถัดไปคือ Gemini Argon4 ตรวจ/พัฒนาแกนและโครงสร้าง → Codexตรวจรับ → Claudeทำกราฟิก

เริ่ม START_HERE_FOR_AI และ project_status_and_ai_onboarding ดู HUMAN_CORE_MODEL/PRESENTATION_API/FOUNDATION_REPORT สำหรับสิ่งที่มีจริง พิมพ์เขียวOpusเป็นไอเดียเก่า ตัวเลข/รายละเอียดในนั้นไม่ได้บังคับใช้ และไม่มีต้นฉบับความคิดให้ผู้ตรวจเทียบว่าครบทุกส่วน

ข้อมูลJS2เดิมถูกนำออกตามคำขอผู้ใช้ ไม่ต้องดึงกลับมา เกมบริษัทเป็นโครงการแยก ดำเนินงานใน COMPANY_SOURCE สาขาcompany รักษางานผู้อื่นและรายงานข้อจำกัดตามจริง
