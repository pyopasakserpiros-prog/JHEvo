## 1. วิสัยทัศน์และข้อกำหนดหลัก (The Core Vision)

เกมนี้คือ **เกมจำลองชีวิตพนักงานและวิกฤตบริษัทอิเล็กทรอนิกส์ขนาดเล็ก (SME)** ที่กำลังจะล้มละลาย (Runway 90 วัน)  
หัวใจสำคัญของเกมคือ **"ผู้เล่นเป็นผู้สังเกตการณ์ (God View / Observer) เหมือน JianghuSect 2 (JS2)"**
1. **NPC บริหารและทำงานเอง 100% (Zero-Player Micromanagement):** ผู้เล่นไม่ต้องกดรับออเดอร์ ไม่ต้องกดซื้อวัตถุดิบ ไม่ต้องกดรับคนเอง พนักงานในบริษัทแต่ละตำแหน่งจะตัดสินใจและขับเคลื่อนบริษัทเอง
2. **ผังพื้นที่แบบนิคมบริษัทภายนอก (Campus Grounds):** แสดงเป็นผืนแผ่นดินมุมมอง Bird's-eye 2D Canvas มีอาคารสำนักงาน โรงงาน โรงอาหาร คลังสินค้า และประตูรั้วใหญ่ พนักงานเดินสัญจรกลางแจ้งบนทางเท้า เมื่อเข้าอาคารไปทำงาน **เราไม่แสดงเฟอร์นิเจอร์ภายในอาคาร** (ผู้เล่นคลิกดูข้อมูลข้างในผ่านหน้าต่าง Building Drawer เหมือนใน JS2)

## 3. งานที่ต้องลงมือทำในแพตช์ v0.1.0 (Detailed Implementation Steps)

### ขั้นตอนที่ 1: ปรับ Simulation Loop ให้เป็น Autonomous 100% (`js/sim.js`)
* **ตัดการพึ่งพาคำสั่งคลิกจากผู้เล่นออกทั้งหมด:**
  * ลบคำสั่งที่รอผู้เล่นกด เช่น `case "acceptOffer"`, `case "buyMaterials"`, `case "hire"` ออกจาก public dispatch ที่ผู้เล่นต้องกดประจำวัน
* **ให้ NPC ตัดสินใจตามบทบาทหน้าที่ (Role-Based Autonomy):**
  1. **ฝ่ายขาย (Sales Role):**
     * เมื่อมีข้อเสนอ (Offers) เข้ามาในตลาด NPC ฝ่ายขายจะคำนวณกำไร, ระยะเวลาส่งมอบ, และความพร้อมของโรงงาน
     * ตัดสินใจเซ็นรับออเดอร์ (`acceptOffer`) อัตโนมัติ โดยคิดจากทักษะ Sales และค่านิยม `income` / `achievement`
  2. **ฝ่ายคลังและจัดซื้อ (Logistics / Admin Role):**
     * หมั่นตรวจเช็กสต็อกวัตถุดิบ (PCB, ตัวถัง, ดอกลำโพง, LED, เซ็นเซอร์)
     * หากวัตถุดิบชิ้นใดต่ำกว่าเกณฑ์ความปลอดภัย (Reorder Point เช่น เหลือ < 10 ชิ้น) และบริษัทมีเงินสดพอ ให้เปิดคำสั่งซื้อ (`buyMaterials`) โดยคำนวณ Lead Time ส่งของตามจริง
  3. **ฝ่ายผลิตและช่าง (Assembler / Inspector / Packing):**
     * เมื่อมีออเดอร์ที่รับมา ช่างประกอบจะเดินไปหยิบของจากคลังมาประกอบที่โรงงาน
     * ชิ้นงานที่ประกอบเสร็จส่งต่อให้ฝ่ายตรวจคุณภาพ (QC) ตรวจสอบความถูกต้องตามสูตร Yerkes-Dodson Stress Curve ใน `human-core.js`
     * ถ้าผ่าน QC ส่งไปแพ็กลงกล่องเตรียมส่งมอบ ถ้าไม่ผ่าน QC ส่งซ่อม (Rework)
  4. **ฝ่ายบุคคลและผู้บริหาร (Coordinator / HR / CEO):**
     * ประเมินอัตราส่วนงานค้างต่อจำนวนพนักงาน หากงานล้นต่อเนื่องเกิน 3 วัน และกระแสเงินสดมี Runway > 30 วัน ให้ทำการเปิดรับสมัครและจ้างพนักงานใหม่เข้ามาเสริมทีม
  5. **วงจรชีวิตประจำวัน (Daily Life Routine):**
     * **08:30 น.:** พนักงานเดินผ่านประตูใหญ่ (Main Gate) เข้ามาในบริษัท แยกย้ายเข้าอาคารสำนักงานและโรงงาน
     * **12:00 – 13:00 น.:** พนักงานทุกคนหยุดงาน เดินออกจากอาคารข้ามลานกลางแจ้งมารับประทานอาหารที่ **โรงอาหารพนักงาน (Canteen)** เพื่อฟื้นฟู Hunger และ Energy
     * **17:00 น.:** หมดเวลาทำงานปกติ พนักงานที่ไม่มีงานด่วนจะเดินออกจากอาคาร มุ่งหน้าออกประตูใหญ่กลับบ้าน
     * **17:00 – 20:00 น. (OT):** พนักงานที่มีงานค้างหรือมีคำขอ OT จะประเมินผ่าน `H.respondToRequest()` ถ้าตกลงจะอยู่ทำงานล่วงเวลาต่อในอาคาร
     * **พักผ่อนระหว่างวัน:** พนักงานที่เครียดจัดจะเดินออกมาสูดอากาศหรือสูบบุหรี่ที่สวนหย่อมกลางแจ้ง

### ขั้นตอนที่ 2: สร้างระบบแสดงผล 2D Canvas แดนบริษัท (Campus Renderer — `js/campus-render.js`)
* **สร้าง Canvas 2D แสดงภาพมุมมอง Bird's-eye (คล้ายแผนที่สำนักของ JS2):**
  * **ขนาดแผนที่:** กว้าง x ยาว พอดีจอ (รองรับ Responsive ทั้ง Mobile และ Desktop)
  * **ผืนแผ่นดิน (Grounds):** พื้นหญ้า/ลานคอนกรีต มีรั้วล้อมรอบ มีถนนและทางเดินเท้าเชื่อมต่อระหว่างอาคาร
  * **อาคารภายนอก (Exterior Buildings):**
    1. **อาคารสำนักงานใหญ่ (Office HQ):** ตึกกระจกโมเดิร์น ฝ่ายบริหาร, ฝ่ายขาย, บัญชี
    2. **อาคารโรงงานผลิต (Factory Plant):** อาคารโรงงานทรงจั่ว มีปล่องควันและสัญลักษณ์สายฟ้า
    3. **โรงอาหารพนักงาน (Staff Canteen):** อาคารโรงอาหารพร้อมสัญลักษณ์ช้อนส้อม
    4. **คลังสินค้าและจุดขนส่ง (Warehouse & Loading Dock):** โกดังเก็บของ มีประตูม้วนและแท่นจอดรถบรรทุก
    5. **อาคารวิจัยและนวัตกรรม (R&D Lab):** ห้องแล็บเทคโนโลยี
    6. **สวนหย่อม / จุดพักผ่อน (Courtyard / Smoking Area):** มีต้นไม้ ม้านั่ง และจุดพักผ่อน
    7. **ประตูใหญ่ / ป้อมยาม (Main Gate):** ทางเข้า-ออกหลักของนิคมบริษัท
* **การเคลื่อนที่ของตัวละคร (Chibi Sprite Animation):**
  * พนักงานแสดงผลเป็น Sprite Chibi น่ารัก เดินตามทางเท้าภายนอก
  * เมื่อพนักงานเดินถึงประตูอาคาร ให้ตัวละคร "เดินมุดเข้าอาคาร" (Fade out หรือซ่อนตัวละครไว้ข้างในอาคาร)
  * ไม่วาดโต๊ะหรือเฟอร์นิเจอร์ภายในอาคารให้รกสายตา
  * มีบอลลูนข้อความ/ไอคอนลอยบนหัวเมื่อมีเหตุการณ์ (เช่น ไอคอนกาแฟ ☕, ข้าว 🍚, เครียด 💢, เงิน 💰, เม้าท์มอย 💬)
* **บรรยากาศกลางวัน-กลางคืน (Day/Night Lighting):**
  * แสงแดดสดใสช่วงกลางวัน (08:30 – 16:30 น.)
  * แสงสีส้มอบอุ่นยามพลบค่ำ (16:30 – 18:00 น.)
  * แสงสีน้ำเงินครามยามค่ำคืน (18:00 – 06:00 น.) โดยหน้าต่างของอาคารที่มีคนทำ OT และไฟเสาทางเดินจะเปิดสว่าง (Warm Light) เหมือนระบบ Night Lighting ของ JS2

### ขั้นตอนที่ 3: ระบบปฏิสัมพันธ์และ UI หน้าต่างข้อมูล (Inspect Drawers & HUD)
* **แถบข้อมูลหลักด้านบน (Top Status HUD):**
  * ชื่อบริษัท, วันที่ และเวลาจำลอง (เช่น วันที่ 5 | 11:45 น.)
  * ปุ่มควบคุมความเร็วเวลา: หยุด (Pause), 1×, 2×, 5×
  * ยอดเงินสดคงเหลือ (Cash), หนี้สิน (Debt), ค่าใช้จ่ายต่อวัน (Burn Rate), และ Runway คงเหลือ (วัน)
* **หน้าต่างตรวจสอบอาคาร (Building Inspect Drawer):**
  * เมื่อผู้เล่นคลิกที่อาคารใด ๆ บนแผนที่ ให้เปิดหน้าต่าง Drawer จากด้านข้าง (เหมือนคลิกอาคารใน JS2):
    * **คลิกที่ Office HQ:** แสดงรายชื่อผู้บริหาร/ฝ่ายขาย, สัญญาออเดอร์ที่กำลังเจรจา, รายรับรอเก็บ
    * **คลิกที่ Factory:** แสดงรายชื่อช่างที่กำลังประกอบงาน, งานที่กำลังทำ, สถิติ QC Pass/Reject
    * **คลิกที่ Warehouse:** แสดงสต็อกวัตถุดิบและสินค้าสำเร็จรูป, สถานะรถขนส่งที่กำลังเดินทางมา
    * **คลิกที่ Canteen:** แสดงรายชื่อพนักงานที่กำลังนั่งกินข้าว, บรรยากาศการสนทนา
* **หน้าต่างตรวจสอบพนักงาน (Character Sheet Drawer):**
  * เมื่อคลิกที่ตัวละครพนักงานที่กำลังเดินอยู่ข้างนอก หรือคลิกชื่อพนักงานจากใน Building Drawer:
    * แสดงภาพพอร์ตเทรต, ชื่อ, ตำแหน่ง, เงินเดือน
    * แถบสถานะชีพ: Energy, Focus, Hunger, Stress, Morale
    * มิตินิสัยและค่านิยมหลักจาก `human-core.js`
    * บันทึกความคิดล่าสุด (Recent Thoughts / Logs)
* **แถบนโยบายประธานบริษัท (CEO Policies):**
  * ผู้เล่นสามารถปรับนโยบายระดับสูงได้:
    * นโยบาย OT: อัตราเงินพิเศษ 1.5× หรือ 2.0×
    * นโยบายสวัสดิการอาหารกลางวัน: ค่าข้าวฟรีวันละ ฿0 – ฿100 ต่อหัว
    * การกู้เงินฉุกเฉิน / ชำระหนี้คืนธนาคาร
* **แถบแจ้งเตือนเหตุการณ์ (Event Feed):**
  * แสดงข้อความภาษาไทยด้านล่างหรือด้านข้าง: เช่น *"ฝ่ายขายปิดดีลออเดอร์ลำโพงบลูทูธ 15 ตัว สำเร็จ!", "วัตถุดิบแผงวงจร 30 ชิ้น มาส่งถึงคลังแล้ว", "ชิ้นงานไม่ผ่าน QC ส่งช่างต้นซ่อมแซม"*

## 4. ผลลัพธ์ที่คาดหวังเมื่อส่งมอบ (Deliverables)
1. หน้าจอเกมที่เปิดขึ้นมาแล้วเห็น **นิคมบริษัท (Campus)** สวยงามทันที
2. พนักงานเดินเข้า-ออกอาคาร กินข้าว ทำงาน ทำ OT เองอย่างมีชีวิตชีวา โดยผู้เล่นไม่ต้องคอยคลิกสั่งงาน
3. คลิกดูข้อมูลอาคารและข้อมูลพนักงานได้อย่างลื่นไหล
4. โค้ดมีโครงสร้างสะอาด แยกหน้าที่ชัดเจน และผ่านชุดทดสอบ 100%
