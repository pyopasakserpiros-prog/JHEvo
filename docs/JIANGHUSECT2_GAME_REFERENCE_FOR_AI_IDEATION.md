# JianghuSect 2 — เอกสารอ้างอิงโลกและระบบเกม

เอกสารนี้รวบรวมภาพรวมเกม ระบบในซอร์ส และทะเบียนวิถี/สายย่อย เพื่อให้โมเดล AI ภายนอกที่ยังไม่เห็น repository เข้าใจบริบท เนื้อหาเป็นข้อมูลอธิบายเกม ไม่ใช่ชุดคำถามหรือคำสั่งให้สร้างฟีเจอร์

**ภาพซอร์สที่ใช้อ้างอิง:** 8 พฤศจิกายน 2026  
**runtime:** JianghuSect 2, patch 2.3.0, SIM 1.10.11, save schema 2.3.0-grand-dao-deep-parity-release  
**commit ที่อ่าน:** 4ec1c07f65f0d692d6406328d8aeefd3ff65e338

## วิธีอ่านและขอบเขตความน่าเชื่อถือ

ซอร์สที่โหลดผ่าน <code>GAME_SOURCE/test/load.js</code> และทะเบียนใน <code>GAME_SOURCE/data/</code> เป็นหลักฐานหลักสำหรับชื่อและจำนวนที่ตรวจนับจาก runtime ได้ เอกสารพัฒนาช่วยอธิบายเจตนาการออกแบบ แต่บางข้อความมาจาก snapshot คนละรุ่น

คำว่า “มีในทะเบียน” หมายถึงมีข้อมูลหรือ API ในซอร์ส ไม่ได้รับรองว่าผู้เล่นเข้าถึงทุกชิ้นได้ครบ หรือว่าความสมดุลและการเชื่อมต่อสมบูรณ์แล้ว รายงานบัคฉบับรวมเก็บผลตรวจจากหลาย snapshot และผู้ตรวจ จึงเป็นหลักฐานให้ตรวจต่อ ไม่ใช่คำยืนยันว่าบัคทุกข้อยังเกิดใน checkout นี้

ไฟล์ <code>project_status_and_ai_onboarding.md</code> มีข้อมูลหลายช่วงพัฒนาปะปนกัน ส่วนต้นระบุฐาน <code>JS2-v2.3.0</code> และ 43 วิถี/286 สายย่อย แต่ตารางและ roadmap บางส่วนยังใช้ตัวเลขเก่า เช่น 12 วิถี/132 สายย่อย และเวอร์ชัน v3.x/v4.x เอกสารนี้จึงใช้ runtime ปัจจุบันเป็นหลัก ไฟล์ active patch v2.4.0 เป็นข้อกำหนดงานถัดไป ไม่ใช่รายการความสามารถที่ทำเสร็จแล้ว

## ภาพรวมเกม

JianghuSect 2 หรือ “The Grand Dao Epoch” เป็นเกมจำลองบริหารสำนักในยุทธภพและโลกบำเพ็ญเพียรแบบ Wuxia/Xianxia ผสมการจำลองชีวิต NPC แบบเดินหน้าเอง ผู้เล่นกำหนดทิศทางสำนัก จัดคนและตำแหน่ง จัดสรรทรัพยากร วางแผนการฝึกและขยายสำนัก แล้วติดตามผลจาก NPC เหตุการณ์โลก และความขัดแย้งระหว่างสำนัก

เกมไม่ได้มีเพียงการต่อสู้หรือสะสมระดับพลัง วงจรหลักเชื่อมการเติบโตของคนเข้ากับการบริหาร เศรษฐกิจ การสร้างสิ่งของ สัตว์วิญญาณ การสำรวจ การทูต สงคราม ความสัมพันธ์ และพงศาวดาร ตัวละครมีอายุ ความต้องการ ความทะเยอทะยาน ความสัมพันธ์ ความทรงจำ และประวัติการกระทำ โลกเปลี่ยนไปตามเวลาแม้ไม่ได้สั่งควบคุมตัวละครทุกคนโดยตรง

วงจรการเล่นโดยรวมคือ รับหรือค้นพบสมาชิก ช่วยให้คนธรรมดาเริ่มบำเพ็ญเพียร พัฒนาวิถีและวิชา จัดสรรบุคลากรและทรัพยากร ขยายสำนัก ส่งคณะออกสำรวจ/ทำภารกิจ/เจรจา/ล่าอสูร แล้วติดตามผลที่ย้อนกลับมากระทบเศรษฐกิจ การเมือง ชีวิต NPC และพงศาวดาร

## รูปแบบโปรแกรมและเวอร์ชัน

โปรเจกต์ใช้ JavaScript แบบ vanilla/IIFE, HTML5 Canvas 2D และ CSS มีซอร์สแยกโมดูลกับไฟล์ HTML เดี่ยวสำหรับเล่นแบบออฟไลน์ เนื้อหาที่ผู้เล่นเห็นยึดภาษาไทยเป็นหลัก Runtime ระบุ SIM 1.10.11, patch 2.3.0 และ save schema 2.3.0-grand-dao-deep-parity-release ส่วน <code>GAME_SOURCE/README.md</code> ยังแสดง 3.1.1 จากเอกสารรุ่นก่อน จึงไม่ควรใช้ไฟล์นั้นตัดสินเวอร์ชันปัจจุบัน

## ระบบบำเพ็ญเพียรและความก้าวหน้า

ตัวละครเลือกได้จาก 43 มหาวิถีซึ่งมีเพดานขั้นไม่เท่ากัน แต่ละวิถีมีธีม กลไกหลัก ทรัพยากร เกจเฉพาะ ความเสี่ยง และสายย่อย วิถีหนึ่งอาจเน้นปราณและการทะลวงขั้น อีกวิถีใช้ศรัทธา การหลอมกาย การควบคุมวิญญาณ กลไก/หุ่นเชิด สัตว์วิญญาณ การสร้างวัตถุ การปกครอง หรือกฎเฉพาะทาง ระดับขั้นในทะเบียนปัจจุบันมีตั้งแต่ 4 ถึง 9 ขั้น

เอกสารสถานะอธิบายวงจรคนธรรมดาสู่ผู้บำเพ็ญเพียรว่า ผู้เริ่มต้นศึกษาแนวทาง สะสมความเข้าใจเต๋า ฝึกปราณและเปิดตันเถียนก่อนเข้าสู่วิถี เนื้อหายังกล่าวถึงหอคัมภีร์ คู่มือวิถี ผลึกมรดก การสอนโดยอาจารย์ และกิจกรรมอภิปราย/บททดสอบของแต่ละวิถี รายละเอียดเหล่านี้มีบันทึกในเอกสารคนละช่วง จึงควรตรวจทางเข้าถึงใน build ที่เล่นก่อนถือว่าทุกขั้นตอนปรากฏครบใน UI

ทะเบียนทักษะแยกวิชา/เทคนิคและมนตรา มีระดับและข้อกำหนดการเรียน วิถี/สายย่อยที่รองรับ ธาตุ บทบาทในศึก อาวุธที่เข้ากัน และชุดท่าต่อสู้ ข้อมูลบางชนิดเป็นโปรไฟล์ที่นำไปประกอบกันได้ ไม่ใช่ปุ่มทักษะหนึ่งต่อหนึ่ง

## ทะเบียนวิถีและสายย่อยฉบับเต็ม

รายการต่อไปนี้ดึงจาก <code>CULT.PATHS</code> โดยตรง คำอธิบายกลไก ทรัพยากร เกจ และจุดเด่น/ข้อจำกัดของสายย่อยเป็นข้อมูลในทะเบียน ไม่ใช่ผลตรวจสมดุล

### 1. XIAN — วิถีเซียน (บ่มเพาะปราณฟ้าดิน)
- ขั้นสูงสุด: 9 ขั้น
- ทรัพยากร/เงื่อนไขหลัก: ศิลาปราณและโอสถทะลวงขั้น
- เกจประจำวิถี: เจตจำนงกระบี่ (Sword Intent)
- กลไกแกนกลาง: ดูดซับปราณฟ้าดินเข้าสู่ตันเถียน มีขั้นย่อยละเอียดที่สุด (9 ขั้น) ทะลวงขั้นแรกง่ายแต่ขั้นสูงต้องเข้าใจกฎเต๋าและผ่านฟ้าทัณฑ์
- ความเสี่ยงสูงสุดที่ระบุ: เซียนเสียจิต / จิตมารกลืนวิญญาณ (ธาตุไฟเข้าแทรกจนคลุ้มคลั่งหรือสูญเสียตบะ)
- สายย่อย (16):
  - <code>SWORD_IMMORTAL</code> — สายกระบี่สวรรค์ — ทรัพยากร แร่เหล็กไหลดาราและเจตจำนงกระบี่；จุดเด่น พลังโจมตีทะลวงเกราะสูงสุด สังหารศัตรูข้ามขั้นได้；ข้อจำกัด เปลืองปราณมหาศาลและเปราะบางต่อค่ายกลลวงจิต
  - <code>FIVE_ELEMENTS</code> — สายเบญจธาตุสมดุล — ทรัพยากร ผลึกเบญจธาตุและสมุนไพรห้าสี；จุดเด่น ปรับตัวได้ทุกภูมิประเทศ ฟื้นฟูปราณเร็วและเสถียร；ข้อจำกัด ไร้ท่าไม้ตายสังหารฉับพลัน
  - <code>ELIXIR_DAO</code> — สายโอสถอมฤตและพิษ — ทรัพยากร สมุนไพรวิญญาณพันปีและราชากู่พิษ；จุดเด่น หลอมโอสถทะลวงขั้นเองได้ อายุขัยยืนยาวและใช้พิษสลายปราณ；ข้อจำกัด การปะทะซึ่งหน้าด้อยกว่าสายยุทธ์
  - <code>ASTRAL_ARRAY</code> — สายค่ายกลดาราและยันต์ — ทรัพยากร จานค่ายกลหยกและพู่กันชาดวิญญาณ；จุดเด่น คุมสมรภูมิหมู่และป้องกันสำนักได้แกร่งที่สุด；ข้อจำกัด ต้องใช้เวลาวางค่ายกล แพ้ทางผู้ฝึกกายาที่พุ่งประชิดตัวเร็ว
  - <code>BLOOD_DEMON</code> — สายมารกลืนโลหิต — ทรัพยากร ผลึกโลหิตสดและวิญญาณผู้ฝึกตน；จุดเด่น ทะลวงขั้นไวในศึกสงคราม ดูดกลืนปราณศัตรูมาฟื้นฟูตน；ข้อจำกัด เสี่ยงเกิดจิตมารสูงที่สุดและแพ้ทางสายฟ้าทัณฑ์สวรรค์
  - <code>PHANTOM_SOUL</code> — สายวิญญาณเร้นลับและมายา — ทรัพยากร มุกจันทราวิญญาณและธูปหลอนจิต；จุดเด่น โจมตีจิตวิญญาณโดยตรง ลอบสังหารและพรางกายไร้ร่องรอย；ข้อจำกัด ร่างกายเปราะบาง แพ้ทางปราณหยางบริสุทธิ์
  - <code>TIME_VOID</code> — สายมิติว่างเปล่าและกาลเวลา — ทรัพยากร ผลึกมิติว่างเปล่าและทรายกาลเวลาโบราณ；จุดเด่น บิดเบือนห้วงมิติเพื่อหลบหลีกการโจมตีถึงตายและชะลอจังหวะกระบวนท่าศัตรู；ข้อจำกัด ใช้ปราณจิตวิญญาณสูงมาก หากสมาธิสั่นคลอนจะถูกแรงสะท้อนของมิติบาดเจ็บเอง
  - <code>SOUND_ZITHER</code> — สายคลื่นเสียงพิณสวรรค์สะกดวิญญาณ — ทรัพยากร ไม้บรรพกาลทำพิณและเส้นไหมวิญญาณเจ็ดเสียง；จุดเด่น ส่งคลื่นเสียงปราณโจมตีทะลุเกราะภายนอกและชำระล้างใจมารให้สหายร่วมรบ；ข้อจำกัด แพ้ทางสมรภูมิที่มีเสียงอึกทึกกึกก้องหรือศัตรูที่ปิดกั้นโสตประสาทสมบูรณ์
  - <code>YIN_YANG_HARMONY</code> — สายหยินหยางหมุนเวียนไร้ลักษณ์ — ทรัพยากร หยกคู่หยินหยางและน้ำค้างสุริยันจันทรา；จุดเด่น เปลี่ยนแรงโจมตีของศัตรูให้ย้อนกลับและฟื้นฟูสมดุลปราณกลางศึกได้ต่อเนื่อง；ข้อจำกัด ต้องรักษาสมดุลหยินหยางอย่างเคร่งครัด หากเอียงข้างใดข้างหนึ่งปราณจะแปรปรวน
  - <code>FROST_MOON_IMMORTAL</code> — สายเซียนจันทราเหมันต์ — ทรัพยากร ผลจันทราเหมันต์และไอเย็นแสงจันทร์；จุดเด่น ตั้งรับและสวนกลับด้วยไอเย็น ป้องกันวิชาเพิ่ม 10% ความเร็วร่ายเพิ่ม 6；ข้อจำกัด พลังโจมตีกายภาพลด 4% ต้องค้นพบและเรียนคัมภีร์สวนกลับก่อนใช้ท่าเฉพาะ

### 2. BODY — วิถีกายา (หลอมกายาเหล็กไหลสู่เซียน)
- ขั้นสูงสุด: 5 ขั้น
- ทรัพยากร/เงื่อนไขหลัก: โลหิตอสูรบรรพกาลและแร่เหล็กไหล
- เกจประจำวิถี: เตาหลอมโลหิตปราณ (Blood Furnace)
- กลไกแกนกลาง: ไม่ดูดซับปราณฟ้าดิน แต่ใช้ไฟพิภพ โลหิตอสูร และแรงกดดันหลอมกระดูกและเนื้อหนังเพียง 5 ขั้นใหญ่ ทะลวงยากกว่าเซียนปราณมากแต่ไร้เทียมทานในศึกประชิด
- ความเสี่ยงสูงสุดที่ระบุ: กายาร่างพัง / เส้นโลหิตบรรพกาลระเบิด (เนื้อหนังรับพลังงานไม่ไหวจนร่างแหลกสลาย)
- สายย่อย (16):
  - <code>TIGER_SOVEREIGN</code> — สายพยัคฆ์ราชันย์คลั่ง — ทรัพยากร กระดูกพยัคฆ์ขาวและสุราโลหิตอสูร；จุดเด่น ความเร็วและพลังหมัดทะลวงค่ายกลรุนแรงดั่งพยัคฆ์ขย้ำ；ข้อจำกัด ต้องเผาผลาญพลังชีวิตเมื่อสู้ยืดเยื้อ
  - <code>BLOOD_DRAGON</code> — สายมังกรโลหิตบรรพกาล — ทรัพยากร เกล็ดมังกรและโลหิตอสูรระดับสูง；จุดเด่น ฟื้นฟูบาดแผลกลางศึกได้เองและมีแรงกดดันสายเลือดมังกร；ข้อจำกัด ต้องการทรัพยากรโลหิตอสูรมหาศาลในการทะลวงขั้น
  - <code>VAJRA_BODHI</code> — สายวัชระโพธิสัตว์ไม่บุบสลาย — ทรัพยากร ทองคำศักดิ์สิทธิ์และศิลาวัชระ；จุดเด่น ป้องกันอาวุธวิเศษและต้านทานฟ้าทัณฑ์ได้สูงสุด；ข้อจำกัด เคลื่อนที่ช้าและขาดความพลิกแพลง
  - <code>DEVOURING_FIEND</code> — สายอสูรกลืนกินสรรพสิ่ง — ทรัพยากร แก่นอสูรทุกชนิดและแร่พิษ；จุดเด่น กลืนกินเนื้ออสูรและอาวุธศัตรูเพื่อเพิ่มความแข็งแกร่งทันที；ข้อจำกัด รูปลักษณ์กลายพันธุ์และเสี่ยงคลุ้มคลั่ง
  - <code>SOLAR_FORGE</code> — สายเพลิงสุริยันหลอมกาย — ทรัพยากร เพลิงแก่นพิภพและเหล็กไหลอุกกาบาต；จุดเด่น กายาแผ่เพลิงสุริยันเผาผลาญศัตรูและหลอมศาสตราด้วยมือเปล่า；ข้อจำกัด แพ้ทางดินแดนน้ำแข็งขั้วโลกอย่างรุนแรง
  - <code>THUNDER_BODY</code> — สายกายาอสนีบาตทลายสวรรค์ — ทรัพยากร แก่นสายฟ้าสวรรค์และแร่เหล็กไหลอสนีบาต；จุดเด่น ชักนำสายฟ้าทัณฑ์มาหลอมกระดูก ความเร็วพุ่งประชิดดั่งสายฟ้าฟาดและต้านทัณฑ์ฟ้าสูง；ข้อจำกัด ชีพจรรับภาระหนักจากการเก็บประจุสายฟ้า เสี่ยงเกิดอาการชาและบาดเจ็บภายใน
  - <code>JADE_IMMORTAL_BODY</code> — สายกายาหยกพิสุทธิ์หมื่นพิษไม่กล้ำกราย — ทรัพยากร แก่นหยกขาวหมื่นปีและบัวหิมะชำระไขกระดูก；จุดเด่น เนื้อหนังและกระดูกใสบริสุทธิ์ดั่งหยกเซียน ต้านทานพิษร้ายและคำสาปโลหิตทุกชนิด；ข้อจำกัด พลังทำลายล้างดิบด้อยกว่าสายพยัคฆ์คลั่งและสายมังกรโลหิต
  - <code>TITAN_MOUNTAIN_BODY</code> — สายกายายักษ์บรรพกาลแบกขุนเขา — ทรัพยากร ศิลาแก่นปฐพีและหัวใจอสูรยักษ์ภูผา；จุดเด่น ขยายร่างปราณยักษ์บรรพกาล รับศึกหน้าด่านแทนศิษย์ทั้งสำนักและทลายกำแพงเมืองด้วยหมัดเดียว；ข้อจำกัด เป็นเป้าโจมตีขนาดใหญ่และเคลื่อนไหวเชื่องช้ากว่าสายวิชาตัวเบา
  - <code>WOOD_SPRING_BODY</code> — สายกายาพฤกษาอมตะ — ทรัพยากร บัวหยกเขียวร้อยปีและน้ำพุวิญญาณ；จุดเด่น พลังชีวิตเพิ่ม 12% ป้องกันกายภาพเพิ่ม 10% ใช้วิชาเปลือกพฤกษาสร้างโล่；ข้อจำกัด โจมตีกายภาพลด 6% ความเร็วเคลื่อนที่ลด 4 เหมาะกับการยืนรับศึก
  - <code>STAFF_GUARD</code> — องครักษ์พลองเหล็ก
  - <code>WAR_SPEAR_SOVEREIGN</code> — ราชันย์ทวนศึกทลายทัพ
  - <code>IRON_BOW_SENTINEL</code> — พยัคฆ์เกาทัณฑ์ศิลาเหล็ก
  - <code>OVERLORD_HEAVY_BLADE</code> — จอมดาบผ่าขุนเขา
  - <code>METEOR_IRON_FIST</code> — กายาหมัดอุกกาบาตเหล็กไหล — ทรัพยากร ผลึกปราณธาตุ EARTH_METAL และคัมภีร์สายย่อย；จุดเด่น หลอมหมัดด้วยแร่อุกกาบาตหนักดั่งขุนเขา ทุบทำลายเกราะและจุดระเบิดศิลาเหมันต์แตกสลาย (โดดเด่นพลังโจมตีกายภาพและเจาะเกราะ แลกกับความคล่องตัวต่ำ)；ข้อจำกัด ต้องอาศัยการวางจังหวะท่วงท่าและตราประทับให้สอดคล้องกับศาสตราประจำสาย
  - <code>NINE_SUNS_FURNACE_BODY</code> — กายาเตาหลอมเก้าสุริยัน — ทรัพยากร ผลึกปราณธาตุ FIRE และคัมภีร์สายย่อย；จุดเด่น เปลี่ยนร่างกายเป็นเตาหลอมเก้าสุริยัน เผาผลาญเลือดส่วนหนึ่งเพื่อเร่งปราณและแผ่คลื่นความร้อนเผาศัตรูรอบข้าง (โดดเด่นเลือดสูงและระเบิดพลังโอเวอร์ไดรฟ์)；ข้อจำกัด ต้องอาศัยการวางจังหวะท่วงท่าและตราประทับให้สอดคล้องกับศาสตราประจำสาย
  - <code>ABYSSAL_LEVIATHAN_BONE</code> — กายากระดูกมังกรสมุทรบาดาล — ทรัพยากร ผลึกปราณธาตุ WATER_ICE และคัมภีร์สายย่อย；จุดเด่น เคี่ยวกรำโครงกระดูกด้วยแรงดันก้นสมุทรน้ำแข็ง ดูดซับพิษและเลือดไหลมาสร้างเกราะน้ำแข็งคุ้มกาย (โดดเด่นความถึกและการตั้งรับแนวหน้า)；ข้อจำกัด ต้องอาศัยการวางจังหวะท่วงท่าและตราประทับให้สอดคล้องกับศาสตราประจำสาย

### 3. GOD — วิถีเทพ (หลอมรวมศรัทธาปวงชนสู่เทวะ)
- ขั้นสูงสุด: 4 ขั้น
- ทรัพยากร/เงื่อนไขหลัก: พลังศรัทธาจากผู้คน ศาลเทพ และสาวก
- เกจประจำวิถี: ศรัทธาเทวะศักดิ์สิทธิ์ (Divine Faith)
- กลไกแกนกลาง: ไม่ดูดปราณ ไม่ฝึกกายเป็นหลัก แต่รวบรวมศรัทธาจากผู้คนและศาลเทพเพียง 4 ขั้นใหญ่ ทะลวงยากที่สุดและหากเมืองในปกครองล่มสลายหรือผู้คนหมดศรัทธาจะตกขั้นทันที!
- ความเสี่ยงสูงสุดที่ระบุ: เทพล่มสลาย / ศรัทธาสูญสิ้นตกขั้น (เทวรูปแตกร้าว อาณาจักรเทพพังทลายและตบะลดฮวบ)
- สายย่อย (13):
  - <code>WAR_DEITY</code> — สายเทพสงครามพิทักษ์แดน — ทรัพยากร ศรัทธาจากชัยชนะในสมรภูมิและโลหิตศัตรู；จุดเด่น ยิ่งออกรบชนะศรัทธายิ่งพุ่ง มอบบัฟขวัญกำลังใจให้กองทัพทั้งสมรภูมิ；ข้อจำกัด หากพ่ายแพ้ศึกใหญ่ศรัทธาจะดิ่งเหวทันที
  - <code>MERCY_DEITY</code> — สายเทพเมตตาคุ้มครองชน — ทรัพยากร ศรัทธาจากการช่วยเหลือผู้ประสบภัยและโรงทาน；จุดเด่น ศรัทธามั่นคงที่สุด ฟื้นฟูบ้านเมืองและขจัดโรคพิษได้รวดเร็ว；ข้อจำกัด ไม่ถนัดการบุกสังหารล้างเผ่าพันธุ์
  - <code>FATE_ORACLE</code> — สายเทพชะตาพยากรณ์ — ทรัพยากร ศรัทธาจากคำพยากรณ์แม่นยำและพิธีบูชาดวงดาว；จุดเด่น หยั่งรู้แผนลอบสังหารล่วงหน้าและบิดเบือนโชคชะตาในการประลอง；ข้อจำกัด เมื่อฝืนชะตาสวรรค์มากเกินไปจะถูกสะท้อนกลับ
  - <code>TOTEM_BEAST_GOD</code> — สายเทพอสูรบรรพกาล — ทรัพยากร ศรัทธาจากชนเผ่าและการสังเวยอสูรยักษ์；จุดเด่น อัญเชิญร่างอวตารเทพอสูรลงมาถล่มค่ายกลศัตรู；ข้อจำกัด ถูกสำนักฝ่ายธรรมะมองว่าเป็นลัทธินอกรีต
  - <code>UNDERWORLD_JUDGE</code> — สายเทพยมโลกพิพากษากรรม — ทรัพยากร ศรัทธาต่อกฎแห่งกรรมและป้ายวิญญาณบรรพชน；จุดเด่น ใช้เพลิงกรรมพิพากษาศัตรู ยิ่งศัตรูมีค่าบาปและหนี้เลือดสูง พลังโจมตียิ่งทวีคูณ；ข้อจำกัด แสดงอานุภาพได้ลดลงเมื่อต่อสู้กับผู้ทรงคุณธรรมที่ไร้บาปติดตัว

  - <code>HARVEST_EARTH_GOD</code> — สายเทพบิดรผืนแผ่นดินและพืชพรรณ — ทรัพยากร ศรัทธาจากปวงชนชาวนาและชีพจรผืนปฐพี；จุดเด่น ฟื้นฟูสวนสมุนไพรวิญญาณและเมืองที่เสียหายจากสงครามได้เร็วที่สุด ศรัทธาไม่เสื่อมคลายง่าย；ข้อจำกัด เน้นการตั้งรับและฟื้นฟู ไม่โดดเด่นด้านการไล่สังหารศัตรูที่หลบหนี
  - <code>MEDICINE_BODHI_GOD</code> — สายเทพโอสถโพธิญาณ — ทรัพยากร สมุนไพรทิพย์ โอสถรักษา และแรงศรัทธาชาวบ้าน；จุดเด่น พลังชีวิตเพิ่ม 8% ป้องกันวิชาเพิ่ม 14% ใช้ฉัตรบัวทองสร้างโล่คุ้มตน；ข้อจำกัด โจมตีวิชาลด 6% ความเร็วร่ายลด 4 เน้นการคุ้มครอง
  - <code>SUN_BOW_DEITY</code> — เทพศรสุริยันพิฆาตมาร

### 7. KARMA_SAMSARA — วิถีกรรมวัฏและสังสารวัฏ
- ขั้นสูงสุด: 8 ขั้น
- ทรัพยากร/เงื่อนไขหลัก: ลูกประคำชะตากรรมและน้ำค้างสังสารวัฏเก้าภพ
- เกจประจำวิถี: กงล้อวัฏสงสาร (Karmic Wheel)
- กลไกแกนกลาง: ตาชั่งเวรกรรมและวิบากสะท้อน (Karmic Ledger & Six-Realm Wheel): บันทึกเหตุแห่งความเสียหายจริงในศึก เพื่อเลือกตอบสนองระหว่างการสะท้อนวิบากกรรม การตัดวาสนา หรือการสละหนี้กรรมเยียวยาพวกพ้อง
- ความเสี่ยงสูงสุดที่ระบุ: วิบากกรรมรุมล้อม / ติดในภพชาติมายา (Karmic Tribulation — แรงอาฆาตย้อนรอยและจิตสับสนในสังสารวัฏ)
- สายย่อย (10):

  - <code>SIX_PATHS_WHEEL</code> — สายสังสารหกภพภูมิ — ทรัพยากร ศิลาจารึกภวจักรและน้ำค้างหกภพ；จุดเด่น หมุนกงล้อเลือกตั้งมั่นใน 1 ภพภูมิ (เทวา อสูร มนุษย์ เดรัจฉาน เปรต นรก) ปรับสมดุลรุก-รับตามสถานการณ์；ข้อจำกัด แต่ละภพภูมิมีข้อแลกเปลี่ยนชัดเจนและมีระยะเวลาตั้งมั่นก่อนเปลี่ยนภพถัดไป

  - <code>BODHI_VOW_GUARDIAN</code> — สายมหาปณิธานโพธิสัตว์คุ้มภพ — ทรัพยากร ศิลาคำสัตย์โพธิญาณและระฆังทองคำอธิษฐาน (สร้างสรรค์พิเศษ v2.0.8)；จุดเด่น ตั้งคำสัตย์คุ้มครองสหายร่วมรบ แบ่งเบาความเสียหายและเปลี่ยนความเสียสละเป็นปราณหยางคุ้มกันทั้งหมู่คณะ；ข้อจำกัด ต้องรักษากำลังใจและวินัยให้มั่นคง ห้ามทอดทิ้งพวกพ้องกลางศึก

  - <code>NETHER_RIVER_REAPER</code> — ยมทูตเคียวโซ่แม่น้ำลืมเลือน — ทรัพยากร ผลึกปราณธาตุ YIN_SHADOW และคัมภีร์สายย่อย；จุดเด่น เหวี่ยงโซ่ยมโลกผูกมัดศัตรูสองรายให้รับความเสียหายร่วมกัน พร้อมปลิดชีพเป้าหมายที่บาดเจ็บหนัก (โดดเด่นการผูกโซ่สะท้อนดาเมจและท่าสังหาร)；ข้อจำกัด ต้องอาศัยการวางจังหวะท่วงท่าและตราประทับให้สอดคล้องกับศาสตราประจำสาย

  - <code>MYRIAD_BEAST_PACK</code> — สายจ้าวฝูงหมื่นอสูรรุมสังหาร — ทรัพยากร เขาสัญญาณจ่าฝูงและตราบัญชาหมื่นอสูร；จุดเด่น ขยายขีดจำกัดอสูรคู่สัญญาออกรบสูงสุด 4 ตน จัดสรรงบบัญชาการรุมขย้ำและโอบล้อมศัตรู；ข้อจำกัด ต้องดูแลเสบียงและความเหนื่อยล้าของฝูงอสูรหลายตน

  - <code>RUNE_ARRAY_ENGRAVER</code> — สายจ้าวอักขระยันต์และค่ายกลศาสตรา — ทรัพยากร สิ่วหยกสลักอักขระดาราและหมึกวิญญาณชาด；จุดเด่น สลักอักขระยันต์และค่ายกลลงบนศาสตราและชุดเกราะ ยิงคลื่นอักขระสะกดศัตรูและกางม่านคุ้มกันปราการฉีเหมิน；ข้อจำกัด ต้องใช้ปราณจิตในการคุมอักขระหลายชั้นพร้อมกัน
  - <code>DIVINE_FLAME_SMELTER</code> — สายจ้าวอัคคีหลอมฟ้ากลืนแร่ — ทรัพยากร แก่นเพลิงสุริยันและแร่เหล็กดาวตก；จุดเด่น ผสานไฟเตาโอสถและไฟโรงหลอมเป็นหนึ่งเดียว ระเบิดปราณเพลิงสุริยันเผาผลาญเป็นวงกว้าง บำเพ็ญได้รวดเร็วทั้งยามปรุงยาและตีเหล็ก；ข้อจำกัด ใช้พลังงานและปราณต่อกระบวนท่าสูง
  - <code>SPIRIT_FEAST_HEALER</code> — สายครัวทิพย์ฟื้นชีวา — ทรัพยากร ไฟเตาหลอมโอสถ ทั่งสวรรค์ร้อยหลอม แร่ปราณ และสมุนไพรวิญญาณ；จุดเด่น ปรุงอาหารสมานกายและฟื้นกำลัง พร้อมพยุงชีวิตยามศึก；ข้อจำกัด ไม่เร่งการบ่มเพาะเท่าสายสำรับเต๋า และโจมตีตรงต่ำ
  - <code>JADE_MEAL_PREPARER</code> — สายสำรับหยกเตรียมบำเพ็ญ — ทรัพยากร ไฟเตาหลอมโอสถ ทั่งสวรรค์ร้อยหลอม แร่ปราณ และสมุนไพรวิญญาณ；จุดเด่น ปรับสมดุลวัตถุดิบเป็นอาหารเตรียมสมาธิและการทะลวงขั้น；ข้อจำกัด ฟื้นกายฉุกเฉินได้น้อยกว่าครัวฟื้นชีวาและป้องกันกายบาง
  - <code>CELESTIAL_ARMOR_ARTISAN</code> — สายช่างเกราะไหมเหล็กสวรรค์ — ทรัพยากร ไฟเตาหลอมโอสถ ทั่งสวรรค์ร้อยหลอม แร่ปราณ และสมุนไพรวิญญาณ；จุดเด่น ตีเกราะและชุบแผ่นคุ้มกาย เพิ่มการป้องกันและความทนทานของชุดเกราะ；ข้อจำกัด ถ่วงการเคลื่อนไหวและให้พลังโจมตีน้อยกว่าช่างอาวุธ
  - <code>STAR_METEOR_WEAPONSMITH</code> — ปรมาจารย์ตีศาสตราเหล็กอุกกาบาต — ทรัพยากร ผลึกปราณธาตุ EARTH_METAL และคัมภีร์สายย่อย；จุดเด่น ตีหลอมศาสตราเหล็กอุกกาบาต เสริมพลังมอดิฟายเออร์ของอาวุธที่สวมใส่และทุบทำลายเกราะศัตรูอย่างแม่นยำ (โดดเด่นการหลอมอาวุธและรีดประสิทธิภาพอุปกรณ์สูงสุด)；ข้อจำกัด ต้องอาศัยการวางจังหวะท่วงท่าและตราประทับให้สอดคล้องกับศาสตราประจำสาย
  - <code>NINE_REVOLUTIONS_ALCHEMIST</code> — ปรมาจารย์โอสถเก้าวัฏจักรกลั่นฟ้า — ทรัพยากร ผลึกปราณธาตุ FIRE และคัมภีร์สายย่อย；จุดเด่น ควบคุมไฟโอสถเก้าวัฏจักร ยกระดับผลโอสถทุกชนิดและจุดระเบิดปฏิกิริยาไฟ-พฤกษาเผาผลาญศัตรู (โดดเด่นการปรุงโอสถขั้นสูงและปฏิกิริยาเพลิงโอสถ)；ข้อจำกัด ต้องอาศัยการวางจังหวะท่วงท่าและตราประทับให้สอดคล้องกับศาสตราประจำสาย
  - <code>PUPPET_RELIC_ARTIFICER</code> — ปรมาจารย์หลอมศาสตราอาคมและหุ่นทิพย์ — ทรัพยากร ผลึกปราณธาตุ LIGHTNING และคัมภีร์สายย่อย；จุดเด่น สร้างสิ่งประดิษฐ์อาคมและชาร์จพลังยันต์ซ้ำได้ในสมรภูมิ พร้อมปลดปล่อยวิชาที่ติดมากับศาสตราด้วยอานุภาพสูงขึ้น (โดดเด่นการใช้ไอเทมชาร์จและวิชาประจำศาสตรา)；ข้อจำกัด ต้องอาศัยการวางจังหวะท่วงท่าและตราประทับให้สอดคล้องกับศาสตราประจำสาย

### 11. ARRAY_TALISMAN — วิถีค่ายกลและอักขระยันต์
- ขั้นสูงสุด: 8 ขั้น
- ทรัพยากร/เงื่อนไขหลัก: หมึกชาด หยกค่ายกล และสมาธิในการเชื่อมจุดปราณ
- เกจประจำวิถี: ยันต์แปดทิศสะสม (Eight-Trigram Sigils)
- กลไกแกนกลาง: บ่มเพาะจากการวางค่ายกลและเขียนยันต์ ใช้ผนึกควบคุมศัตรูและม่านคุ้มกัน ประสิทธิภาพแปรตามทักษะที่ฝึกจริง
- ความเสี่ยงสูงสุดที่ระบุ: อักขระขาดตอนทำให้ปราณสะท้อน ต้องพักสมาธิก่อนตั้งค่ายใหม่
- สายย่อย (7):
  - <code>EARTH_VEIN_WARDEN</code> — สายผู้พิทักษ์ค่ายกลชีพจรดิน — ทรัพยากร หมึกชาด หยกค่ายกล และสมาธิในการเชื่อมจุดปราณ；จุดเด่น ยึดจุดค่ายกลเป็นแนวคุ้มกัน สร้างโล่และทนแรงปะทะ；ข้อจำกัด เคลื่อนที่และร่ายช้าเมื่อเทียบกับผู้เขียนยันต์จู่โจม
  - <code>SEAL_SCRIPT_EXORCIST</code> — สายยันต์ผนึกชำระมาร — ทรัพยากร หมึกชาด หยกค่ายกล และสมาธิในการเชื่อมจุดปราณ；จุดเด่น อ่านรอยปราณแล้วปิดช่องร่ายศัตรู มีสมาธิคุ้มกันวิชาจิต；ข้อจำกัด รับศาสตราประชิดไม่เก่งและขาดพลังระเบิด
  - <code>THUNDER_TALISMAN_ADEPT</code> — สายยันต์อัสนีทะลวงทัพ — ทรัพยากร หมึกชาด หยกค่ายกล และสมาธิในการเชื่อมจุดปราณ；จุดเด่น ร่ายยันต์สายฟ้าเจาะแนวและขัดจังหวะด้วยอัสนี；ข้อจำกัด ปราณป้องกันบางและกระบวนท่าระดับสูงใช้ปราณมาก
  - <code>MIRAGE_ARRAY_WEAVER</code> — สายค่ายกลมายาพรางเงา — ทรัพยากร หมึกชาด หยกค่ายกล และสมาธิในการเชื่อมจุดปราณ；จุดเด่น บิดทิศทางและบังสายตา เปิดช่องถอนตัวจากวงล้อม；ข้อจำกัด พลังทำลายตรงต่ำและรับการโจมตีที่หลบไม่พ้นได้ไม่ดี
  - <code>ASTRAL_STARFALL_ARRAY</code> — ปรมาจารย์ค่ายกลดาราตกสะกดภพ — ทรัพยากร ผลึกปราณธาตุ ASTRAL และคัมภีร์สายย่อย；จุดเด่น กางค่ายกลดาราตกครอบคลุมสนามรบ โจมตีศัตรูทุกตัวที่ติดตราดาราพร้อมกันและทลายเกราะเวท (โดดเด่นการทำลายล้างหมู่ตามตราดารา)；ข้อจำกัด ต้องอาศัยการวางจังหวะท่วงท่าและตราประทับให้สอดคล้องกับศาสตราประจำสาย
  - <code>VERMILION_SEAL_TALISMAN</code> — ปรมาจารย์ยันต์ชาดเพลิงสุริยันปราบมาร — ทรัพยากร ผลึกปราณธาตุ FIRE และคัมภีร์สายย่อย；จุดเด่น ซัดยันต์ชาดเพลิงสุริยันต่อเนื่องดั่งห่าฝน จุดระเบิดพายุเพลิงคลั่งและชำระล้างปราณมาร (โดดเด่นความเร็วในการร่ายยันต์และดาเมจระเบิดธาตุไฟ-หยาง)；ข้อจำกัด ต้องอาศัยการวางจังหวะท่วงท่าและตราประทับให้สอดคล้องกับศาสตราประจำสาย
  - <code>LABYRINTH_MIST_FORMATION</code> — ปรมาจารย์ค่ายกลหมอกเขาวงกตเร้นลับ — ทรัพยากร ผลึกปราณธาตุ WATER_ICE และคัมภีร์สายย่อย；จุดเด่น เนรมิตค่ายกลหมอกเขาวงกตอำพรางพรรคพวก เพิ่มอัตราหลบหลีกและแช่แข็งตรึงขาศัตรูที่หลงเข้ามา (โดดเด่นการพรางตัวทีมและควบคุมพื้นที่)；ข้อจำกัด ต้องอาศัยการวางจังหวะท่วงท่าและตราประทับให้สอดคล้องกับศาสตราประจำสาย

### 12. STRATEGY_GOVERNANCE — วิถีพิชัยยุทธ์และอภิบาลสรรพชน
- ขั้นสูงสุด: 8 ขั้น
- ทรัพยากร/เงื่อนไขหลัก: ตำราพิชัย บัญชีเสบียง และประสบการณ์ดูแลผู้คน
- เกจประจำวิถี: ตราอาญาสิทธิ์จอมทัพ (Command Authority)
- กลไกแกนกลาง: ฝึกตนผ่านการวางแผน การจัดการ การค้า และการเจรจา เสริมการประสานหมู่และการส่งกำลังมากกว่าพลังโจมตีเดี่ยว
- ความเสี่ยงสูงสุดที่ระบุ: คำสั่งซับซ้อนเกินกำลังทำให้เสียจังหวะและปราณสมาธิ
- สายย่อย (8):
  - <code>BATTLEFIELD_STRATEGIST</code> — สายกุนซือธงศึก — ทรัพยากร ตำราพิชัย บัญชีเสบียง และประสบการณ์ดูแลผู้คน；จุดเด่น อ่านแนวรบ ชี้จุดอ่อนและเร่งขวัญกำลังใจยามเปิดศึก；ข้อจำกัด ความแข็งแรงประชิดต่ำ ต้องอาศัยจังหวะบัญชา
  - <code>SECT_STEWARD</code> — สายผู้ดูแลรากฐานสำนัก — ทรัพยากร ตำราพิชัย บัญชีเสบียง และประสบการณ์ดูแลผู้คน；จุดเด่น วางระเบียบคลังและแนวคุ้มกัน ให้สำนักตั้งรับได้ต่อเนื่อง；ข้อจำกัด โจมตีต่ำและเคลื่อนย้ายกำลังได้ช้า
  - <code>DIPLOMATIC_ENVOY</code> — สายทูตประสานพันธมิตร — ทรัพยากร ตำราพิชัย บัญชีเสบียง และประสบการณ์ดูแลผู้คน；จุดเด่น อ่านผู้คน เจรจาและรักษาความสงบ พร้อมสะกดแรงปะทะชั่วคราว；ข้อจำกัด ขาดพลังโจมตีและเกราะกายยามถูกบีบเข้าประชิด
  - <code>CARAVAN_QUARTERMASTER</code> — สายผู้จัดเสบียงคาราวาน — ทรัพยากร ตำราพิชัย บัญชีเสบียง และประสบการณ์ดูแลผู้คน；จุดเด่น เตรียมเสบียงและเส้นทางล่าถอย รักษาปราณสำหรับเดินทางไกล；ข้อจำกัด พลังระเบิดและการยืนปะทะกับศัตรูหนักต่ำ
  - <code>CIVIL_TEACHING_MENTOR</code> — สายอาจารย์อภิบาลศิษย์ — ทรัพยากร ตำราพิชัย บัญชีเสบียง และประสบการณ์ดูแลผู้คน；จุดเด่น ถ่ายทอดตำราและประคองขวัญศิษย์ ให้ฝึกตนอย่างมีสมาธิและฟื้นตัวจากความกดดัน；ข้อจำกัด โจมตีและเจาะเกราะต่ำ ต้องใช้เวลาประสานใจผู้ร่วมทาง

### 16. SONIC_HARMONY — วิถีเสียงประสานและพิณยุทธ

  - <code>WAR_DRUM_TEMPEST_HERALD</code> — สายกลองศึกปลุกขวัญสะท้านภพ — ทรัพยากร สายพิณไหมสวรรค์ ขลุ่ยหยก และคลื่นปราณสั่นพ้องในอากาศ；จุดเด่น รัวกลองศึกอสนีบาตกระตุ้นเลือดนักสู้ของพรรคพวกทั้งกองทัพ เพิ่มพลังโจมตีและเขย่าขวัญศัตรู；ข้อจำกัด ต้องควบคุมเกจประจำวิถี (คอร์ดสัจธรรม (Harmonic Chord)) และอาวุธประจำสายให้สอดคล้องกัน
  - <code>RESONANT_BELL_EXORCIST</code> — สายกระดิ่งกังวานสลายมาร — ทรัพยากร สายพิณไหมสวรรค์ ขลุ่ยหยก และคลื่นปราณสั่นพ้องในอากาศ；จุดเด่น สั่นกระดิ่งวิญญาณและลูกประคำขับไล่ภาพมายา สลายค่ายกลและล้างคำสาปให้ทั้งทีม；ข้อจำกัด ต้องควบคุมเกจประจำวิถี (คอร์ดสัจธรรม (Harmonic Chord)) และอาวุธประจำสายให้สอดคล้องกัน

### 17. VENOM_GU — วิถีพิษและหนอนกู่โบราณ

- ทรัพยากร/เงื่อนไขหลัก: สมุนไพรพิษเบญจพิษ โถเพาะหนอนกู่ และเข็มปราณสกัดพิษ

  - <code>BLOOD_PARASITE_HEXER</code> — สายปรสิตโลหิตสูบชีพจร — ทรัพยากร สมุนไพรพิษเบญจพิษ โถเพาะหนอนกู่ และเข็มปราณสกัดพิษ；จุดเด่น ฝังหนอนกู่โลหิตเข้าสู่บาดแผลศัตรู ดูดเลือดและปราณกลับมาเสริมความคลั่งของตนเอง；ข้อจำกัด ต้องควบคุมเกจประจำวิถี (หนอนกู่ร่วมชีพ (Symbiotic Gu)) และอาวุธประจำสายให้สอดคล้องกัน
  - <code>CORROSIVE_MIASMA_WEAVER</code> — สายทอหมอกพิษกัดกร่อนเกราะ — ทรัพยากร สมุนไพรพิษเบญจพิษ โถเพาะหนอนกู่ และเข็มปราณสกัดพิษ；จุดเด่น โบกพัดพ่นหมอกพิษโบราณปกคลุมสนามรบ กัดกร่อนเกราะและโล่ปราณของศัตรูทุกรอบ；ข้อจำกัด ต้องควบคุมเกจประจำวิถี (หนอนกู่ร่วมชีพ (Symbiotic Gu)) และอาวุธประจำสายให้สอดคล้องกัน

### 18. PRIMORDIAL_SHIFTER — วิถีแปรรูปบรรพกาลและแปลงกาย

  - <code>VERMILION_PHOENIX_WING_ASCENDANT</code> — สายปีกหงส์เพลิงอมตะคืนชีพ — ทรัพยากร โลหิตอสูรบรรพกาล แก่นกระดูกสัตว์เทวะ และการปลุกสัญชาตญาณดิบ；จุดเด่น งอกปีกหงส์เพลิงสุริยันเหินเวหา สะบัดขนอัคคีเผาผลาญศัตรูและฟื้นคืนชีพจากเถ้าถ่าน；ข้อจำกัด ต้องควบคุมเกจประจำวิถี (สายเลือดบรรพกาล (Bloodline Atavism)) และอาวุธประจำสายให้สอดคล้องกัน

### 21. MERCANTILE_DAO — วิถีพาณิชย์มหามรรคาและพันธสัญญา

- ความเสี่ยงสูงสุดที่ระบุ: หากฝ่ายตนผิดสัญญาหรือบัญชีขาดดุล ความน่าเชื่อถือและเกราะพันธสัญญาจะพังทลายทันที

  - <code>BLOOD_CONTRACT_NOTARY</code> — สายผู้พิทักษ์พันธสัญญาประกาศิต — ทรัพยากร ลูกคิดทองคำ พู่กันร่างสัญญา และกระแสการหมุนเวียนทรัพยากรที่สมดุล (ห้ามเสกทรัพยากรฟรี)；จุดเด่น จารึกสัญญาโลหิตผูกมัดศัตรู หากเป้าหมายลงมือโจมตีจะถูกลงทัณฑ์ด้วยโซ่พันธสัญญาทองคำ；ข้อจำกัด ต้องควบคุมเกจประจำวิถี (บัญชีพันธสัญญา (Contract Ledger)) และอาวุธประจำสายให้สอดคล้องกัน

  - <code>CROWD_ROAR_BRAWLER</code> — สายหมัดสังเวียนสะท้านเสียงเชียร์ — ทรัพยากร เสียงโห่ร้องแห่งลานประลอง การท้าดวลตัวต่อตัว และเพลิงขวัญกำลังใจ；จุดเด่น ยิ่งการต่อสู้ยืดเยื้อและดุเดือด หมัดยิ่งหนักหน่วงและสะเทือนขวัญศัตรูทั้งสนาม；ข้อจำกัด ต้องควบคุมเกจประจำวิถี (เพลิงเกียรติยศลานประลอง (Renown Flame)) และอาวุธประจำสายให้สอดคล้องกัน
  - <code>BANNER_GLORY_MARSHAL</code> — สายธงชัยเกียรติยศปลุกขวัญทัพ — ทรัพยากร เสียงโห่ร้องแห่งลานประลอง การท้าดวลตัวต่อตัว และเพลิงขวัญกำลังใจ；จุดเด่น ชูธงเกียรติยศแห่งสำนักกลางสนามรบ เพิ่มพลังรบและป้องกันความตื่นตระหนกให้ทั้งทีม；ข้อจำกัด ต้องควบคุมเกจประจำวิถี (เพลิงเกียรติยศลานประลอง (Renown Flame)) และอาวุธประจำสายให้สอดคล้องกัน

## การต่อสู้และการสร้าง build

การต่อสู้เป็นระบบคอมโพสิตที่ผสมผู้ต่อสู้ วิชา ท่วงท่า อาวุธ ธาตุ สถานะ ระยะ ตำแหน่ง และบริบทสนาม ไม่ได้พิจารณาค่าพลังโจมตีดิบอย่างเดียว ระบบที่พบใน runtime ได้แก่

- การวางตำแหน่งและระยะ 5 แถบ ตั้งแต่ประชิดมากถึงยิงไกล พร้อมระยะขั้นต่ำตามลักษณะวิชา/อาวุธ
- การตรวจแนวสายตา คาดตำแหน่งปลอดภัย คุ้มกันแนวหลัง สกัดกั้น และเขตควบคุมพื้นที่
- โปรไฟล์ยุทธวิธีตามตระกูลอาวุธ บทบาทการต่อสู้ และบุคลิก AI ในสนาม
- เงื่อนไขกลาง ทริกเกอร์ ท่วงท่า แอ็กชันคอมโพสิต โดเมนสนามรบ และ effect ID สำหรับไอเทม
- การชาร์จวิชา การร่ายที่ถูกขัดจังหวะ การประสานวิชา การทำงานร่วมกันข้ามวิถี และการวิเคราะห์ชิ้นส่วนเป้าหมายบางชนิด
- สถานะเผาไหม้ เลือดออก พิษ สโลว์ สตัน ใบ้ อ่อนแอ ตาบอด ลดเกราะ และสถานะเฉพาะกลไก
- ปฏิกิริยาธาตุ 34 แบบ ระบบ gauge และเอฟเฟกต์สร้างความเสียหาย/ควบคุม/สนับสนุน
- การสรุปผลยุทธวิธีและส่งผลสำคัญเข้าสู่พงศาวดาร
- traits/ความชำนาญถาวรจากพฤติกรรมในสนามรบ โดยมีระบบบันทึกการกระทำและตรวจการปลดล็อก

ตระกูลอาวุธมี 16 ชนิด: หอก, กระบอง/ไม้พลอง, ธนู, โฟกัส/เครื่องราง, ดาบใหญ่, หมัด, กระบี่, พิณ, พู่กัน, แส้, ประคำ, กรงเล็บ, เข็ม, พัด, แอสโทรแล็บ/เครื่องดูดาว และลูกคิด แต่ละตระกูลเกี่ยวข้องกับระยะ โปรไฟล์ยุทธวิธี วิชา ความชำนาญ อุปกรณ์ และตำรับผลิตที่ต่างกัน

ตัวละครประกอบ build ได้จากวิถี สายย่อย เกจเฉพาะ วิชา/มนตรา ธาตุ อาวุธ/อุปกรณ์ และบทบาททีม การมีรายการครบในทะเบียนไม่ได้ยืนยันว่าการกระจายวิชาและอาวุธสมดุล รายงานตรวจสอบพบว่าบางตระกูลมีวิชาหรือเงื่อนไขใช้อาวุธน้อยกว่ากลุ่มอื่น

## สัตว์อสูร สัตว์วิญญาณ และนิเวศ

ทะเบียนสัตว์แยกชนิด สายตระกูล ทักษะธรรมชาติ ระดับ/ความแข็งแกร่ง และของที่ได้จากการล่า runtime มีวงจรสัตว์ป่า การต่อสู้ การจับหรือเลี้ยงสัตว์ บทบาทสัตว์ร่วมทาง ขีดจำกัดจำนวนสัตว์ประจำตัว/สำรอง สายเลือด traits และค่าสถานะจากความผูกพัน

วัสดุดรอปมีตั้งแต่เขี้ยว หนัง ขน แก่นสัตว์ พิษ เกล็ด หัวใจ ขนนก และเนื้ออสูร วัสดุอยู่ร่วมกับเศรษฐกิจ ตำรับ งานหลอม/ปรุงยา และการจัดการทรัพยากร แต่รายงานตรวจเกมมีประเด็นวัสดุที่ไม่มีผู้ใช้ ตำรับที่ไม่เชื่อมกับระบบผลิต และสายโซ่ประโยชน์ที่ไม่ครบ จึงไม่ควรเหมารวมว่าของดรอปทุกชิ้นมีผู้ใช้แล้ว

ทะเบียนหลัก <code>JD.BEASTS.species</code> มี 128 รายการ แต่ API วิถีสัตว์คืน 134 ID ไม่ซ้ำ และมีราชันสัตว์อสูร 6 รายการ ตัวเลข 128/134 เป็นความต่างของขอบเขตทะเบียนจนกว่าจะตรวจว่ารวมชนิดเสริมใดบ้าง

## สำนัก การปกครอง และชีวิตประจำวัน

สำนักเป็นฐานการเล่นและเครือข่ายทรัพยากร ประกอบด้วยสมาชิก ตำแหน่ง อาคาร สิ่งอำนวยความสะดวก ยอดเขา นโยบาย การฝึก การผลิต คลัง และความสัมพันธ์ภายนอก ระบบบริหารมี 6 ทำเนียบ 25 ตำแหน่ง และเอกสารสถานะระบุ 8 ยอดเขาเฉพาะทาง

ตำแหน่งบริหารมีการแต่งตั้ง เลือกผู้สืบทอด จัดอันดับ จ่ายเงินเดือน/เบี้ยหวัด งานประจำวัน การตัดสินใจของเจ้าหน้าที่ นโยบายสำนัก และการกระจายคลังตามความต้องการหน่วยงาน เอกสารสถานะยังอธิบายธรรมนูญสำนัก สภายุทธศาสตร์ ค่ายพักแนวหน้า ขนส่งเสบียง และคุก/เชลยศึก

NPC ดำเนินชีวิตตามเวลา มีความหิว การพักผ่อน ความเครียด สุขภาพจิต ความสัมพันธ์และความทะเยอทะยาน แกน Human Core ที่เอกสารสถานะอ้างถึงมีบุคลิกภาพ 14 ด้าน คุณค่า 8 ด้าน ความถนัด 6 ด้าน และปณิธาน 9 สาย ระบบ cognition/AI เกี่ยวกับความทรงจำ เป้าหมาย ความสัมพันธ์ การยื่นคำร้อง ความขัดแย้งในลำดับชั้น การเลื่อนตำแหน่ง เกษียณ เสียชีวิต และประวัติบุคคล

## เศรษฐกิจ การผลิต และอุปกรณ์

เศรษฐกิจเชื่อมอาหาร วัตถุดิบ งานช่าง การปรุงยา การเก็บเกี่ยว การทำเหมือง การประมง ตลาด และคลังสำนัก ตำรับระบุวัตถุดิบและผลผลิต มีการตรวจต้นทุน/เวลาผลิต สำรองวัตถุดิบ และบันทึกธุรกรรม งานช่างเกี่ยวข้องกับคุณภาพ การสึกหรอ ซ่อม ปรับธาตุ หลอมด้วย catalyst และอุปกรณ์แบบสุ่ม

- วัสดุ สมุนไพร แร่ วัตถุดิบอสูร อาหาร โอสถ และสินค้าคราฟต์
- ช่องสวมใส่อาวุธ เกราะ และเครื่องประดับ
- ตำรับผลิตและเงื่อนไขความพร้อมของวัสดุ
- การปรับคุณภาพ ซ่อม สึกหรอ หลอม และปรับธาตุ
- อุปกรณ์หายาก/อาวุธตำนาน การสั่นพ้องระหว่างชิ้นหรือเงื่อนไขผูกจิต
- ตลาดภายนอก คาราวาน สต็อกและการกระจายของในสำนัก

จำนวนสูงไม่ได้รับรองว่าทุกประเภทหลากหลายเท่ากัน รายงาน audit วิเคราะห์ความหนาแน่นของวิชา/อาวุธ และบันทึกปัญหาบางอย่างในวงจรหลอม รูน คุณภาพและการปลุกอาวุธ

## แผนที่โลก การสำรวจ และความขัดแย้ง

แผนที่โลกแบ่งเป็น 5 ภูมิภาคและ 45 โหนด มี 19 สำนัก canonical เส้นทางเดินทาง โหนดทรัพยากร จุดผิดปกติ แดนลับ และตำแหน่งเหตุการณ์ เอกสารสถานะระบุสำนักคู่แข่งหลัก active 6 แห่ง

คณะเดินทางมีเวลาเดินทาง ความจุขนของ การค้า เจรจา รับสมัคร การโจมตีระหว่างทาง และการส่งของกลับสำนัก การสำรวจเชื่อมกับจุดสนใจเฉพาะ แดนลับ การชิงสมบัติ เหตุการณ์ฟ้าดิน ภัยพิบัติ และวาสนาของคณะ

ความสัมพันธ์สำนักครอบคลุมการทูต พันธมิตร สภาพันธมิตร บรรณาการจากสำนักบริวาร กบฏ การอ้างสิทธิ์ทรัพยากร การปะทะ การยกทัพตีสำนัก และการประลองยุทธภพ ผลการรบเชื่อมกับบทสรุปยุทธวิธีและพงศาวดาร

แผนที่สำนักมี 8 ยอดเขาในทะเบียนสถานะ พร้อม sanctuary สิ่งปลูกสร้างและจุดให้บริการ ผังเชื่อมกับสถาปัตยกรรม เส้นทางภายใน หมอก เงาและเอฟเฟกต์อาคารตามรายงาน implementation

## พงศาวดาร สายสัมพันธ์ และความต่อเนื่องของโลก

เหตุการณ์จากการต่อสู้ การสำรวจ การเมือง และชีวิตบุคคลส่งเข้าพงศาวดารได้ รายงานสถานะระบุรูปแบบรายงาน 11 แบบและสายโซ่เหตุ–ผลหลายมิติ ประวัติศิษย์และบุคคลสำคัญเก็บเป็น historical people รวมถึงผู้เสียชีวิตหรือพ้นจากบทบาท

โลกยังมีผู้มาเยือน บุคคลเร่ร่อน ตำนานที่กลับมาปรากฏ เหตุการณ์รับศิษย์ การสืบทอดตำแหน่ง และสายตระกูล เหตุการณ์จึงสะสมเป็นประวัติของสำนักและยุทธภพ ไม่ใช่เพียงผลชนะ/แพ้ของภารกิจเดียว

## แผนที่ความเชื่อมโยงระหว่างระบบ

- **วิถีบำเพ็ญเพียร** → สายย่อย → เกจ/ขั้น/ทรัพยากร → วิชา/มนตรา → อาวุธ/ธาตุ → บทบาทและผลการต่อสู้
- **สัตว์อสูร** → ถิ่นอาศัย/การสำรวจ → ต่อสู้/จับเลี้ยง → วัสดุดรอป → ตำรับ/การผลิต/เศรษฐกิจ หากมี consumer เชื่อมครบ
- **NPC** → บุคลิก/ความถนัด/ความต้องการ → งานและตำแหน่ง → ความสัมพันธ์/ความขัดแย้ง → การกระทำโลก → พงศาวดาร/ประวัติบุคคล
- **สำนัก** → การปกครอง/ทำเนียบ/ยอดเขา → ผลิตและกระจายทรัพยากร → ฝึกศิษย์ → การทูต/สงคราม
- **โลกและภารกิจ** → โหนด/ภูมิภาค/เหตุการณ์ → คณะเดินทางและการต่อสู้ → ทรัพยากร/ผู้คน/ผลการเมือง → การเปลี่ยนแปลงสำนักและพงศาวดาร
- **อุปกรณ์** → แหล่งที่มา/คราฟต์/ดรอป → ข้อกำหนดผู้ใช้และวิถี → โบนัส/กลไกต่อสู้ → สึกหรอ/ซ่อม/หลอม/ตลาด

อาวุธใหม่อาจเชื่อมกับวิชา ความชำนาญ แหล่งหา ตำรับและอุปกรณ์ในตระกูลเดียวกัน สัตว์ใหม่อาจเชื่อมกับภูมิภาค พฤติกรรมต่อสู้ การจับเลี้ยง วัสดุดรอป และผู้ใช้วัสดุ รายงานตรวจสอบหลายฉบับกำลังติดตามสายโซ่เหล่านี้

## แยกของปัจจุบัน ข้อเสนอ และบัค

- **runtime/data:** ชื่อวิถี สายย่อย วิชา/มนตรา วัสดุ สัตว์ ไอเทม ตำรับ อาวุธ และ API ที่ loader โหลดได้
- **patch/implementation report:** เจตนาการทำงานและขอบเขตฟีเจอร์ของแพตช์นั้น ใช้ประกอบความเข้าใจ แต่เทียบกับ runtime เมื่อจำนวนหรือสถานะขัดกัน
- **active patch prompt v2.4.0:** งานเป้าหมายรุ่นถัดไป ยังไม่นับเป็นความสามารถที่ทำเสร็จ
