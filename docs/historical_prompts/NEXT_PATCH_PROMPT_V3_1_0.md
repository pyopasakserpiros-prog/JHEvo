  - **AI & Narrative Designers:** พฤติกรรม อุปนิสัย แรงจูงใจ ความขัดแย้ง และการตัดสินใจของ NPC รายบุคคลและกลุ่ม

- ต้องป้องกันไม่ให้เกิดช่องโหว่ทรัพยากรฟรี (Infinite Resource Loop) หรือการตัดสินใจที่ขัดแย้งกันเอง

- ให้ปลดล็อกตำแหน่งเหล่านี้อย่างสมบูรณ์ และประสานเข้ากับระบบรันไทม์จริง (`envoy`, `spymaster`, `beastmaster`, `arraymaster`)
- ขยายโครงสร้างตำแหน่งบริหารให้ครอบคลุมงานบริหารสำนักทั้ง **6 ทำเนียบฝ่ายหลัก (24 ตำแหน่งบริหาร หรือตามที่คุณออกแบบเพิ่มเติมอย่างเหมาะสม)**
- **ทุกตำแหน่งต้องมีรายละเอียดครบองค์ประกอบจริงในโครงสร้างข้อมูล:**
  1. `id`: รหัสอ้างอิงตำแหน่ง (เช่น `commander`, `envoy`, `spymaster`, `beastmaster`, `arraymaster`, `treasury`, `warden` ฯลฯ)
  2. `nameTh`: ชื่อตำแหน่งภาษาไทยที่สง่างามตามสำนวนยุทธภพ
  3. `hall`: อาคาร/แท่นงานประจำสำหรับไปปฏิบัติหน้าที่จริง (เช่น `training_ground`, `gate`, `main_hall`, `mission_hall`, `treasury`, `forge`, `alchemy`, `infirmary`, `discipline`, `dungeon`)
  4. `minRank`: ระดับขั้นต่ำของศิษย์ที่แต่งตั้งได้ (เช่น `2: ศิษย์ใน`, `3: ศิษย์แกนกลาง`, `4: ผู้อาวุโส`)
  5. `stipendBonus`: เบี้ยหวัดศิลาวิญญาณเสริมรายเดือนที่ได้รับจริงจากการดำรงตำแหน่ง (ส่งผลต่อความมั่งคั่งส่วนตัวของ NPC และการซื้อโอสถ/อุปกรณ์)
  6. `authority`: ค่าบารมีและอำนาจยำเกรง (เช่น 50–90 แต้ม) ส่งผลต่อน้ำหนักเสียงโหวตในสภาผู้อาวุโส (`SECT.ELDER_COUNCIL_EDICTS`) และความเคารพจากศิษย์ผู้น้อย
  7. `suitability`: ฟังก์ชันประเมินความเหมาะสมในการแต่งตั้ง (คำนวณจากทักษะ, พรสวรรค์, บุคลิกภาพ, และขั้นพลังตบะ)
  8. `descTh`: คำอธิบายขอบเขตอำนาจหน้าที่

### 2.2 สิทธิตัดสินใจและบทบาทหน้าที่จริง (Real Autonomous Jurisdictions)
ตำแหน่งต้องไม่ใช่แค่ป้ายชื่อ แต่ต้องมีกลไกที่ทำงานจริงในวงจรชีวิตของเกม (`SECT.runOfficerJurisdictionSingle` และ `COG.officeDecision`):
- **ราชทูตยุทธภพ (`envoy` / `diplomacy`):** ตรวจสอบท่าทีของ 19 สำนักคู่แข่ง, ส่งเครื่องบรรณาการหรือเจรจาขอความช่วยเหลือจากพันธมิตร, ป้องกันการแข็งข้อของสำนักบริวาร, เพิ่มผลลัพธ์การเจรจาใน `EXPED.diplomacyResult`
- **เจ้าหอข่าวกรองและเงา (`spymaster` / `intelligence`):** ตรวจจับข่าวลือโรงเตี๊ยมและเบาะแสศาสตราวุธ, ลดคลื่นใต้น้ำทางการเมือง (`undercurrent`), สกัดกั้นการวินาศกรรม, ส่งสัญญาณเตือนเมื่อมีสำนักอริเตรียมบุก
- **เจ้าอุทยานสัตว์วิญญาณ (`beastmaster` / `beastcare`):** ตรวจสอบความหิวและความเหนื่อยล้าของสัตว์วิญญาณสำนัก, ป้อนอาหารปราณ, ดูแลการเพาะพันธุ์ (`breedBeasts`), จัดทัพสัตว์อสูรเฝ้าประตูสำนัก (`WAR_BEAST`)
- **ปรมาจารย์ค่ายกลและปราการ (`arraymaster` / `formation`):** ฟื้นฟูความสมบูรณ์ของม่านพลังสำนัก (`W.sect.arrayIntegrity`), ปรับจูนเส้นชีพจรฮวงจุ้ยอาคาร (`SECT.FENG_SHUI`), เปิดเดินมหาค่ายกลพิทักษ์สำนัก
- **ผู้คุมทัณฑ์และเชลยศึก (`warden`):** ควบคุมคุกใต้ดิน (`W.sect.dungeon`), ดำเนินการเค้นคัมภีร์ยุทธ์จากเชลย, ดำเนินการเรียกค่าไถ่ศิลาวิญญาณ, เกลี้ยกล่อมเชลยฝีมือดีให้แปรพักตร์เข้าสำนัก
- **ผู้อาวุโสหอคลัง / เสบียง / ตลาด:** จัดสรรงบประมาณโอสถสวัสดิการ, ตรวจสอบข้าวสารสำรอง, คุมกองคาราวานสินค้า
- **แม่ทัพสำนัก / กองหน้าพิทักษ์ด่าน:** จัดกำลังพลลาดตระเวน, นำทัพสกัดกั้นศัตรูที่ประตูสำนัก, วางตำแหน่งยุทธวิธีแนวหน้า (Tank/ZoC)

### 3.1 การจัดโครงสร้างเมนูที่ใช้งานง่ายบนมือถือ (Mobile-Friendly Clean UX)

- **แถบเลือกยอดเขาแถวเดียว (Single-Row Horizontal Scrollable Selector):**

  `[ 🗺️ ภาพรวมทุกยอดเขา | ⚔️ ยอดเขากระบี่ | 🗡️ ยอดเขาดาบ | 🌿 ยอดเขาโอสถ | 🔨 ยอดเขาโรงหลอม | 📚 ยอดเขาคัมภีร์ | 🐾 ยอดเขาอสูร | 🛡️ ยอดเขาปราการ | ☯️ ยอดเขาค่ายกล | 🏆 ศึกประลองยอดเขา ]`
- **ไม่ซ้อนเมนู 3 ชั้น:** ผู้เล่นสามารถแตะสลับดูแต่ละยอดเขาได้ทันทีในหน้าจอเดียว

### 3.2 รายละเอียดที่ต้องมีในหน้าระบบยอดเขา (`SECT.PEAKS`)
1. **หน้า "🗺️ ภาพรวมทุกยอดเขา":**
   - แผนผังเปรียบเทียบทั้ง 8 ยอดเขา: ตราสัญลักษณ์, ผู้นำยอดเขาปัจจุบัน, จำนวนศิษย์ในสังกัด, ระดับความรุ่งเรือง, และสายสัมพันธ์ระหว่างยอดเขา (ยอดเขาพันธมิตร vs ยอดเขาคู่ปรับ)
   - รายชื่อ **ศิษย์อิสระไร้สังกัดยอดเขา** พร้อมปุ่มให้ผู้เล่นหรือเจ้าสำนักเลือกส่งศิษย์เข้าสังกัดยอดเขาที่เหมาะสม
2. **หน้ารายละเอียดยอดเขาเฉพาะ (เช่น "⚔️ ยอดเขากระบี่"):**
   - **ทำเนียบผู้นำยอดเขา:** แสดง **ประธานยอดเขา (Peak Master)** (ศักดิ์เทียบเท่ารองเจ้าสำนัก) และ **รองประธานยอดเขา (Deputy)** พร้อมปุ่มแต่งตั้ง/ถอดถอน
   - **ทำเนียบศิษย์ประจำยอดเขา:** รายชื่อศิษย์ทุกคนที่สังกัดยอดเขานี้ พร้อมปุ่มกดโยกย้ายสังกัด
   - **นโยบายการจัดสรรทรัพยากรประจำยอดเขา (`policy.allocationRuleTh`):** เลือกว่ายอดเขานี้เน้นแจกโอสถตามผลงาน, ตามขั้นพลัง, หรือแบ่งเท่าเทียม
   - **ค่ายกลปราณยอดเขา:** แสดงโบนัสบัฟตบะประจำยอดเขา (+14% อัตราฝึกปราณตามวิถีเฉพาะ)
3. **หน้า "🏆 ศึกประลองยอดเขา" (Peak Tournaments):**
   - ปุ่มจัดงานประลองยุทธ์เชื่อมสัมพันธ์ระหว่างยอดเขา
   - ตารางสถิติผู้ชนะเลิศประจำฤดูกาล และการชิงแต้มเกียรติยศยอดเขา

## 6. กฎเหล็กด้านความสมบูรณ์ของแพ็กเกจ ZIP และการตรวจสอบก่อนส่งมอบ (Strict Delivery Gate)

> [!CAUTION]
> **บทเรียนและปัญหาที่เคยเกิดขึ้นในอดีต (ห้ามเกิดซ้ำเด็ดขาด):**

> 2. โฟลเดอร์ใน ZIP ไม่มีสิทธิ์ Unix Mode (`0755`) ทำให้ระบบ Linux ตีความเป็น `d---------` (`0000`) จนเปิดเข้าไปตรวจไม่ได้
> 3. รายงานระบุว่าผ่านหมด แต่ไม่ได้ทดลองรันจากไฟล์ที่แตกออกมาจริง

### เช็กลิสต์ 5 ข้อที่ต้องตรวจให้ครบก่อนกดส่งมอบ:
1. **บรรจุโครงสร้างโปรเจกต์ฉบับเต็ม (`JHEvo-main/`):**
   - รวมไฟล์เกมออฟไลน์เดี่ยว `JianghuSect_single.html` ที่บิลด์ใหม่ล่าสุด
   - ซอร์สโค้ดทั้งหมดใน `GAME_SOURCE/` (`js/`, `data/`, `css/`, `assets/`, `index.html`)
   - ชุดทดสอบครบ 116 ชุดใน `GAME_SOURCE/test/` (รวม `_harness.js`, `v300_tactical_combat_and_living_chronicle_suite.js`, และชุดทดสอบใหม่ที่เขียนเพิ่ม)
   - เครื่องมือทั้งหมดใน `GAME_SOURCE/tools/`
   - โฟลเดอร์สกิล `.agents/skills/` ครบทุกสกิล
   - เอกสารรายงานผลการพัฒนา `PATCH_REPORTS/PATCH_IMPLEMENTATION_REPORT_V3_1_0.md`
2. **กำหนดสิทธิ์ Directory Entries และ Files ให้ถูกต้องเสมอ:**
   - ใช้สคริปต์ Python แม่แบบด้านล่างนี้ในการสร้าง ZIP เพื่อรับประกันว่าโฟลเดอร์ทุกชั้นได้สิทธิ์ `0755` (`drwxr-xr-x`) และไฟล์ได้ `0644`:
   ```python
   import os, zipfile, stat

   src_root = "/path/to/project_root"
   zip_path = "JHEvo-v3.1.0-checkpoint.zip"
   prefix = "JHEvo-main"
   exclude_top = {".git", ".agent_cmd", ".agent_out", ".agent_status", "agent_runner.sh", zip_path, ".checkpoint_temp", ".par_test.log"}

   with zipfile.ZipFile(zip_path, "w", zipfile.ZIP_DEFLATED) as zf:
       root_info = zipfile.ZipInfo(prefix + "/")
       root_info.create_system = 3
       root_info.external_attr = (stat.S_IFDIR | 0o755) << 16 | 0x10
       zf.writestr(root_info, b"")

       for dirpath, dirnames, filenames in os.walk(src_root):
           rel_dir = os.path.relpath(dirpath, src_root)
           if rel_dir == ".":
               dirnames[:] = [d for d in sorted(dirnames) if d not in exclude_top]
               filenames = [f for f in sorted(filenames) if f not in exclude_top]
           else:
               dirnames.sort()
               filenames.sort()
               arc_dir = f"{prefix}/{rel_dir}/"
               d_info = zipfile.ZipInfo(arc_dir)
               d_info.create_system = 3
               d_info.external_attr = (stat.S_IFDIR | 0o755) << 16 | 0x10
               zf.writestr(d_info, b"")

           for fname in filenames:
               full_path = os.path.join(dirpath, fname)
               rel_path = os.path.relpath(full_path, src_root)
               arc_name = f"{prefix}/{rel_path}"
               st = os.stat(full_path)
               zinfo = zipfile.ZipInfo.from_file(full_path, arc_name)
               zinfo.create_system = 3
               mode = 0o755 if (st.st_mode & 0o111) else 0o644
               zinfo.external_attr = (stat.S_IFREG | mode) << 16
               zinfo.compress_type = zipfile.ZIP_DEFLATED
               with open(full_path, "rb") as f:
                   zf.writestr(zinfo, f.read())
   ```
3. **ขั้นตอนการตรวจรับรองตนเองก่อนส่งมอบ (Mandatory Self-Verification Unpack):**
   - หลังสร้างไฟล์ ZIP เสร็จสมบูรณ์ ให้ทำการ **ทดลองแตกไฟล์ ZIP ลงในโฟลเดอร์ชั่วคราวใหม่จริง ๆ**
   - ตรวจว่าเปิดเข้าไปในโฟลเดอร์ได้โดยไม่มีข้อผิดพลาด Permission Denied
   - ทดสอบรันคำสั่งตรวจสอบความสมบูรณ์จากโฟลเดอร์ที่แตกออกมา:
     ```bash
     cd <unpacked_dir>/JHEvo-main/GAME_SOURCE
     node tools/build_single.js
     node tools/validate_data_schema.js
     node test/core_lock.js
     node test/v300_tactical_combat_and_living_chronicle_suite.js
     ```
   - ยืนยันว่า Node.js suites ผ่านครบ 100% จึงส่งมอบ ZIP ให้ผู้ใช้
4. **ความสมบูรณ์ของแกนมนุษย์และลำดับสคริปต์:**
   - ตรวจ `git diff GAME_SOURCE/js/human_core.js` ว่าว่างเปล่า (byte-identical 100% ล็อกลายนิ้วมือ `155:2f9c9dd7`)
   - ลำดับ `<script>` ใน `index.html` และ `test/load.js` ตรงกันครบถ้วน
