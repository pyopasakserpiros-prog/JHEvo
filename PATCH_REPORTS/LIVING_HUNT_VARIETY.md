# Living Hunt — ความหลากหลายและข้อมูลอสูรบนแผนที่

ฐาน `main-debug` commit `5be07c3`; ผู้ใช้อนุมัติขยาย pool และให้ตัวที่สุ่มเกิดใช้ข้อมูลต้นแบบครบ พร้อมคงอิทธิพลพื้นที่และดรอปที่ลดลง

## ผลลัพธ์และการตัดสินใจ

- จาก pool เดิม113ชนิด เป็น125ชนิด: ครบทุกอสูรบกที่มีข้อมูลใช้งานได้ใน catalog140รายการ อีก15รายการเป็นสัตว์น้ำและยังอยู่ในแหล่งน้ำ/ระบบสำรวจเดิม ไม่สุ่มขึ้นบก
- 241รายการอ้างอิงใน pool ตามถิ่นอาศัยและระดับ ช่องตะวันตกและตะวันออกรองรับอสูรระดับต้นเพิ่มด้วย รักษา ID pool เดิม เพิ่มกลุ่ม catalog ตามชนิดพื้นที่และระดับ และรักษา pool ตำนานแยกจากการเติมธรรมดา
- ลดน้ำหนักการสุ่ม pool/ชนิดที่มีอยู่ซ้ำบนแผนที่ เพื่อให้ประชากรหลากหลาย โดยยังสุ่มด้วย W.rng ตามน้ำหนักและกติกาถิ่นอาศัย ไม่รับประกันว่าจะพบทุกชนิดในเซฟเดียว
- เป้าหมาย48/เพดาน60 และเพดานตำนาน1 เหมือนแพตช์ก่อน การขยาย pool ไม่เพิ่มการสุ่มตำนานต่อชั่วโมง

## ข้อมูลตัวจริง

`WILD.speciesDefinition(id)` รวมข้อมูลราชันกับชนิดฐานที่อ้างถึง และสร้าง elementProfile จากธาตุเดิมเฉพาะเมื่อข้อมูลไม่ได้ระบุไว้ ไม่สุ่มธาตุใหม่
เมื่อเกิดจริงจะสำเนาข้อมูล JSON จากต้นแบบครบทุกฟิลด์ แล้วเพิ่ม/แทนที่สถานะเฉพาะตัว เช่น instance ID, ตำแหน่ง, HP และ combat runtime; ไม่มีการแก้ catalog กลาง ธาตุ/โปรไฟล์ธาตุ รูปร่าง สี ขนาด anatomyProfile รายการวัตถุดิบ สถานที่พบ บทบาท tameable/captureRule และ specialAbility ยังคงอยู่ในตัวจริงและเซฟ

อิทธิพลพื้นที่ใช้เฉพาะตัว `wild && landInfluence`: HP4เท่า ความเสียหายที่ปล่อยในศึกwildเหลือ60% ตามระบบก่อนหน้านี้ เพิ่ม `kind:'beast'` เพื่อให้ใช้ฐานค่าสถานะชนิดอสูรถูกต้อง จึงอาจต่างจากฐานศัตรูทั่วไปเล็กน้อย แม้ cpต้นแบบเท่าเดิม

## ทักษะและการต่อสู้

ก่อนหน้านี้ skl ว่างตอนเกิด แต่ COMBAT.ensureFighter จะเติมท่าทั่วไปให้เมื่อเข้าศึกอยู่แล้ว แพตช์นี้ไม่ได้ถือว่าก่อนหน้าไม่มีท่าเลย
ตอนนี้สร้างชุดท่าตั้งแต่เกิด โดย `SK.beastFamily` และ `SK.foeSkills`: รวม38รูปแบบตามตระกูลและระดับ เช่น หมาป่ากระหน่ำ/พุ่ง หมีและเต่าตั้งรับ วิหคซัดไกล อสรพิษ/แมลงใช้พิษ พฤกษาตรึงด้วยราก รวมถึงท่าธาตุและท่าระดับสูง

ความสามารถมีชื่อจากข้อมูลเดิมเชื่อมเข้าการใช้ท่าจริง:

| Ability | กลไก |
|---|---|
| ABIL_IRON_MARROW_GUARD | ตั้งสวนกลับและสร้างโล่ |
| ABIL_THUNDER_TUSK_STAMPEDE | พุ่งทะลวงพร้อมลดเกราะ |
| ABIL_SOLAR_STAR_AEGIS | สร้างโล่ พร้อม keyword ดูดซับ/เกราะปรับตัวของต้นแบบ |
| ABIL_MIST_QILIN_BLESSING | บำบัดเป็นบริเวณและแปลงส่วนรักษาเกินเป็นโล่แบบมีเพดาน |
| ABIL_BODHI_THORN_SANCTUARY | ฟื้นฟู/โล่ในบริเวณ ผูกความเสียหายศัตรูเมื่อมีมากกว่าหนึ่ง และสะท้อนแบบรวมศูนย์ |
| ABIL_FROST_PEARL_MAELSTROM | มีตัวแปลงท่าควบคุม แต่ต้นแบบเป็นสัตว์น้ำ จึงไม่อยู่ใน pool บก |

การ์ดชื่อ/ธาตุของท่าใช้ข้อมูลต้นแบบ เอฟเฟกต์และผลการรบใช้ช่องทาง COMBAT เดิม ไม่เพิ่มชุด VFX ใหม่ รูปอสูรใช้ visual/archetype ของตัวจริง รวมราชันที่สืบทอดจากชนิดฐาน

## จับเลี้ยงและรางวัล

กฎ tameable=false ถูกปฏิเสธ กฎลดHPหรือ BEAST_TAMING ตรวจค่าจริง กฎบูชาสมุนไพรใช้สมุนไพรในกระเป๋าส่วนตัวและหักของเมื่อพยายามจับ หากทักษะถึงทางเลือกที่ระบุไม่ต้องเสียสมุนไพร
กฎชื่อ SPIRIT_PACT/ANCESTRAL_PACT ยังไม่มีพิธีใหม่ในแพตช์นี้ จึงเข้าถึงได้ผ่านทางเลือก BEAST_TAMING75/85 ที่ระบุในข้อมูล ไม่ให้ผ่านเพราะมีข้อความกฎอย่างเดียว

ดรอปวัสดุธรรมดา18%/ตำนาน65% และโอกาสชำแหละชั้นแรก12%/50%เหมือนก่อน ยังคงเลือกจาก drops ของชนิดจริง ไม่เพิ่มรางวัลจากการเพิ่ม pool การรับปราณมีงบต่อศึกและยังต้องมีผลงานจริง ไม่เพิ่มปราณสำหรับการจับแทนฆ่า

## ประสิทธิภาพ

เลือกโอกาสล่าที่ใกล้และเหมาะระดับก่อน แล้วตรวจคะแนน/เส้นทางจริงครั้งละ8เป้าหมาย หากไปไม่ได้ทั้งชุดจึงดูชุดถัดไป แทนการคำนวณคะแนนซ้ำหลายครั้งใน comparator ของ sort
ไม่มีการเพิ่มลูปสแกน catalog140ชนิดทุกtick: ขยาย pool ครั้งแรกและเมื่อจำนวนชนิดเปลี่ยน
