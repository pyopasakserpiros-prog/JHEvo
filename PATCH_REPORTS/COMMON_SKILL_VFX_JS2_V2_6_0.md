# JS2-v2.6.0 refinement — Common skill effects

Base `915c9ac`. Adds 30 restrained common Canvas forms for 66 existing T1/T2 active techniques, 12 active-passive routes and 22 live status routes. Existing 45 Signature forms / 256 Signature mappings and Legendary identities are preserved. Runtime version / save schema unchanged.

The user requested visible effects for accessible early-game skills rather than additional rare Legendary art. Ordinary path starters, weapon drills, poison/control, healing, ally support and passive stances are covered. The basic healer's two moves have separate healing and qi-support imagery. Status visuals follow real affected owners and disappear at expiry; passive visuals require actual active loadout/compatibility/conditions. Persistent glyphs also reach foes and wild beasts. No combat damage, targeting, status duration, acquisition odds, economy, RNG, save fields or data catalogs were changed.

Rendering uses a separate common catalog and explicit technique routes; tier is capped at T2. Explicit rare artwork retains precedence. Selected basic moves with the old automatic `burst` heuristic now receive the compact common presentation at rendering time, rather than an oversized generic Signature fallback. Casts last 540 ms with 11–15 px forms, versus the larger 920 ms Signature and 1,500 ms Legendary presentations. At most one positive and one harmful status symbol plus one eligible passive mark can draw per actor. Existing generic aura fallback remains for unmapped buffs. Reduced Motion freezes decorative animation; no new save metadata is introduced.

The [complete registry](../docs/audits/COMMON_SKILL_VFX_REGISTRY.md) contains every ID, Thai name, tier/grade, common form and availability caveat, plus the passive/status routes. [Form gallery](../docs/visuals/common-skill-vfx/common-skill-forms.png) / [status gallery](../docs/visuals/common-skill-vfx/common-status-auras.png). This is a refinement of main JS2-v2.6.0, not a parallel game version.
