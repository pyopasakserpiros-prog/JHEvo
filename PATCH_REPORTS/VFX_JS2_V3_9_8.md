# JS2 v3.9.8 — ภาพสัตว์อสูรและไอคอนเหนือตำนาน

พัฒนาจาก `main` คอมมิต `8974465` โดยใช้ [แพ็กภาพสัตว์ v3 และ v4 Sovereign](https://github.com/pyopasakserpiros-prog/JHEvo/tree/91103556a850c6e313830a5d731cdb21315f0057/ideas/model_vfx) และ [เอกสารออกแบบภาพใน ideas](https://github.com/pyopasakserpiros-prog/JHEvo/tree/91103556a850c6e313830a5d731cdb21315f0057/ideas/from%20carbon)

- สัตว์เทพสี่ทิศใช้ตราประจำตัวเมื่อเติบโตสูงขึ้น ทั้งในฉากและหน้าคู่หู มังกรใช้สายฟ้า พยัคฆ์ใช้คมแสง หงส์ใช้เปลวขนนก และเต่าใช้ตราหกเหลี่ยม ขณะเป็นพาหนะมีรอยแสงต่ำกว่าแนวผู้ขี่
- คู่หูคุนเผิง จิ้งจอกเก้าหาง กิเลน และไป๋เจ๋อ ระดับตำนานและเหนือตำนานมีตราของแต่ละสาย รวม 8 แบบตามสายและระดับที่มีอยู่
- อสูร 5 ตัวตามแพ็ก v3 มีชุดสีและลายแสงเฉพาะตัว ได้แก่ มังกรสมุทรเก้าเศียร เทพอสูรพิทักษ์ชีพจร เทาเที่ย พยัคฆ์ราชันย์โลหิต และพญาครุฑสายฟ้าม่วง
- วัสดุหลอมและปรุงยาเหนือตำนาน 20 รายการมีไอคอนแยกรูปทรง ปรับพื้นหลังไอคอนวิชา กรอบสมบัติ ป้ายวาสนาบนแผนที่ และแสงไอคอนโอสถด้วย CSS
- ตัววาด Cache รูปทรงแยกจากสถานะเกมและลดชั้นแสงเมื่อซูมออกหรือใช้คุณภาพต่ำ แพตช์ใช้เส้นทางภาพที่เกมมีอยู่ เลข 3.9.8 แสดงในชื่อหน้า ส่วนตัวอ่านเซฟยังใช้คีย์รุ่นเดิม

ผ่าน `validate_data_schema.js` (0 ข้อผิดพลาดและ 0 คำเตือน), `carbon_compendia_master_suite.js` และ `wildlife_variety_browser.js` บน Chromium สร้าง `GAME_SOURCE/JianghuSect_single.html` ใหม่แล้ว และเปิดดูภาพสัตว์สี่ทิศ สัตว์อสูรอ้างอิงทั้ง 5 และไอคอนวัสดุหลอม 10 รูปจากไฟล์เกมเดี่ยว
