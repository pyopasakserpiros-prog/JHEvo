# v2.0.28 — บรรพชนรายบุคคล

ต่อยอดหอบรรพชนเดิมให้กดป้ายเพื่อดูรายละเอียดรายคน ได้แก่ วิชาเอก พร สาเหตุและวันจารึก อาจารย์ ศิษย์ ผลงาน เหตุการณ์ และสายสืบทอดตามข้อมูลที่มีจริง เมื่อจารึกป้ายใหม่ ระบบเก็บภาพข้อมูลและเหตุการณ์ที่เกี่ยวข้องสูงสุด 12 รายการไว้กับป้าย เพื่อให้อ่านได้หลังบุคคลไม่อยู่ในสำนัก

ป้ายเก่าที่ไม่มีภาพข้อมูลแสดงเฉพาะข้อมูลที่มีและแจ้งเมื่อไม่มีประวัติ ไม่สร้างเรื่องย้อนหลัง ระบบพรและเงื่อนไขจารึกเดิมยังทำงานตามเดิม ข้อมูลสายสืบทอดแสดงตามประวัติที่ระบบเก็บไว้

ตรวจ `ancestor_profile` ทั้งการจารึก เหตุการณ์เสียชีวิตและถ่ายทอด ข้อมูลเก่าและบันทึก/โหลด; ตรวจหน้าจอมือถือผ่าน Chromium; ชุดสายสืบทอด เซฟ core lock standalone และ schema validator ผ่าน ดูสรุปการทดสอบรวมด้านล่าง

ชุดตรวจรวม 98/108 กลุ่มผ่าน: 7 กลุ่มเป็นไฟล์ทดสอบที่ขาดในแพ็กเกจฐาน และ 3 กลุ่ม (`craft_transactions`, `organs_experiments_politics`, `world_rank`) มีผลล้มเหลวเหมือนฐานเดิมที่ตรวจไว้ในรายงาน v2.0.26
