# v2.0.26 — สายสืบทอดและพงศาวดาร

บันทึกเหตุการณ์ฝากตัวอาจารย์–ศิษย์และพิธีถ่ายทอดปราณที่เกิดจริงลง `W.sect.mentorship.history` พร้อมชื่อ รหัส วันที่ ผลการถ่ายทอด และวิชาที่สืบทอดถ้ามี บันทึกสูงสุด 200 รายการและแสดง 30 รายการล่าสุดในหน้าบันทึก หน้าภาพรวมตัวละคร และหอบรรพชน ชื่อที่บันทึกไว้ยังแสดงได้หลังบุคคลเสียชีวิตหรือไม่อยู่ในสำนัก ไม่มีการสร้างเหตุการณ์ย้อนหลังจากข้อมูลที่ไม่เคยบันทึก

แก้การเปลี่ยนอาจารย์ให้ลบความสัมพันธ์ที่ใช้งานของอาจารย์เดิม ป้องกันสายสืบทอดวนซ้ำ และทำให้การฝากตัวคู่เดิมไม่เพิ่มเหตุการณ์ซ้ำ แก้ข้อความแจ้งผลการฝากตัว ชี้แนะ และถ่ายทอดให้ใช้ผลจริงจากระบบ และปุ่มถ่ายทอดให้ใช้ขั้นเทียบเคียงและตรวจการถ่ายทอดที่เคยทำแล้ว

ส่วนขยายนี้ยังไม่ได้สร้างผังตระกูลหลายรุ่นแบบกราฟ หรือพงศาวดารครบทุกเหตุการณ์ของสำนัก ประวัติการชี้แนะแต่ละครั้งไม่ได้ถูกเก็บเพิ่มในประวัติใหม่ การบันทึกมีขีดจำกัด 200 รายการ

ตรวจ `test/lineage_history.js`, `test/core_lock.js`, `test/save_integrity.js`, `test/ui_content.js`, `test/npc_cognition.js`, `test/standalone.js`, schema validator และการเปิดประวัติตัวละคร/บันทึกบน Chromium 390×844 ผ่าน ชุดตรวจรวม 94/104 กลุ่มผ่าน โดย 7 กลุ่มไม่มีไฟล์ทดสอบในแพ็กเกจเดิม และ 3 กลุ่ม (`craft_transactions`, `organs_experiments_politics`, `world_rank`) ล้มเหลวเช่นเดียวกันเมื่อรันเทียบกับแพ็กเกจ 2.0.25 ก่อนแก้ไข
